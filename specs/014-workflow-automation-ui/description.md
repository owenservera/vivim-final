Build a visual workflow automation editor so users can create scheduled tasks without writing code. The backend AutomationScheduler already supports cron-based schedules with capability execution and webhook triggers. Build a frontend workflow editor with: (1) A visual timeline/canvas showing all active automations with their schedule (cron expression displayed in human-readable form — "Every day at 9 AM"). (2) A "New Automation" form with fields: name, description, schedule (with a natural language input like "every weekday at 8am" that converts to cron), trigger event (cron schedule OR webhook with generated URL OR capability event like "provider:health_changed"), and action (pick from the capability catalog — e.g., "send daily digest", "run health report", "reindex memory"). (3) A run history log showing when each automation last ran, its status (success/failure), and one-click "Run Now" to test. (4) Enable/disable toggle for each automation. (5) Pre-built workflow templates: Daily Digest (summarizes yesterday's conversations), Health Report (checks all providers and sends status), Memory Reindex (rebuilds semantic search index), Cleanup Inactive (archives conversations older than 30 days). The backend scheduler, capability runner, and workflow engine all exist — this spec builds the frontend editor and wires it to the existing automation infrastructure.
