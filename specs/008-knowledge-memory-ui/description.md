Surface the existing knowledge and memory engines in the chat UI as interactive side panels. Create three collapsible panels in the chat interface: (1) Memory Context — shows relevant facts, recent episodes, and procedural rules fetched from the MemoryEngine via the memory:query capability. Updates as the conversation progresses. (2) Semantic Search — a search bar with two tabs: "Text Match" (FTS5 search via POST /api/conversations/search) and "Semantic" (embedding-based search via the SemanticSearchEngine). Search results show conversation snippets with timestamps and click-to-navigate. (3) Knowledge Synthesis — a "Synthesize" button that calls the CrossConversationSynthesizer to extract themes, entities, and decision patterns across all conversations. Display results as a timeline of decisions and a tag cloud of recurring topics. All three backend engines already exist and are wired — this spec builds their frontend UI panels and connects them to the existing capability execution pipeline.
