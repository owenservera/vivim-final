Implement one-click data portability for vivim users. The ExportEngine already exists and can export conversations, messages, memory records, and canvas definitions. Build a unified "Export All My Data" button in workspace settings that: (1) Shows what will be exported (conversations count, message count, memory entries, canvas definitions). (2) Lets the user choose format (JSON or Markdown — JSON for machine portability, Markdown for human readability). (3) Generates the export, shows a progress bar, and triggers a browser download of a .zip file containing the export. Also implement the reverse: an "Import Data" flow that reads a previously exported .zip, validates its structure, and ingests conversations/knowledge/memory/canvas definitions through the existing KnowledgeIngestionEngine. Show an import preview with conflict resolution (skip duplicates, overwrite, keep both). Add a confirmation dialog before import to prevent accidental data loss. Both engines already exist backed — this spec builds the frontend export/import UX with progress tracking.
