Build a guided first-run onboarding flow for vivim. When a user opens the app for the first time (no providers configured), show a step-by-step wizard that walks them through adding their first AI provider account. The wizard detects available Chrome profiles, launches a visible Chrome window to the provider's login page, waits for the user to complete login, verifies the session, and saves the account. Show progress indicators at each step (launching Chrome, waiting for login, verifying, saving). After the first provider is added, show a quick tour of key features: the infinite canvas, the chat surface, and the provider health dashboard. If the user already has providers, skip the wizard entirely and go straight to the canvas. The Existing ChromeSetupWizard engine handles the backend — this spec is about the frontend onboarding UI and first-run detection logic.
