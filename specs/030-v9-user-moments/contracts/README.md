# API Contracts: Wire 10 Critical User Moments in v9 Canvas

This directory documents the interface contracts the v9 canvas frontend binds to.
All endpoints are existing backend routers (no new backend code per SC-010).

## Files
- `rest.md` — REST endpoint contracts (moments 1–5, 7–10)
- `websocket.md` — WebSocket protocol contract (moment 6)
- `capability.md` — UnifiedCapability execution contract (moments 2, 4, 5)
