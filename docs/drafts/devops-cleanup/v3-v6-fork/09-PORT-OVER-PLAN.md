### Unit Overlap

- **v3 and v4:** NO overlap. Different architectures.
- **v3 and v5:** Kernel units overlap (v3 absorbed 19 kernel units, v5 has 20 kernel units). But the fork IDs are different.
- **v4 and v5:** v4 is a strict subset of v5 (71 of 91 units). v5 = v4 + kernel + oracle + surfaces.

### Which Fork to Implement?

- **v3-fork-canon:** If building a capability-driven system (provider → capability → session)
- **v4-fork-canon:** If building a CDP-only system (Chrome browser control, no self-healing)
- **v5-fork-canon:** If building a CDP system WITH kernel self-healing (recommended for production)
