# Unit 1.8 — Validation (typecheck + offline tests)

**Source:** PRD R8; all scenarios
**Depends on:** 1.1–1.7
**Produces:** Evidence that the v17 toolkit is bounded, structured-JSON, and does not hang.

---

## Context

Each new command must be proven agent-safe: bounded, structured-JSON, non-hanging. Validation is
run offline (no servers, no DB) wherever possible so it cannot itself block.

## Procedure (run from repo root)
```
bun run typecheck                                              # clean on all new files
bun run devops runtime-test catalog-gen                       # ok, writes .runtime/capability-catalog.json
bun run devops runtime-test discover --offline                 # ok, caps WITHOUT a server
bun run devops runtime-test build backend --cap=demo_thing    # ok, writes skeleton (then delete)
bun run devops runtime-test ensure-browser                    # {ok:false, source:'none'}
bun run devops runtime-test loop --goal="vague"               # {needsClarification:true} (no spin)
bun run devops runtime-test stop                              # idempotent ok
```

## Acceptance
- `typecheck` clean for `devops/runtime-test/*` and `devops/index.ts`.
- `discover --offline` succeeds with the server stopped.
- `loop --goal=<vague>` returns `needsClarification` and exits within seconds (no 120s spin).
- No orphan processes remain after `stop`.
