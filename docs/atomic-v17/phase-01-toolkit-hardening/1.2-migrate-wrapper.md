# Unit 1.2 — Non-interactive migrate wrapper

**Source:** PRD R3, R8; Scenario C
**Depends on:** none
**Produces:** `devops runtime-test migrate --name=<x>` — a Prisma migration that cannot block on stdin.

---

## Context

`bunx prisma migrate dev` (no `--name`) prompts for a migration name on stdin and **hangs
indefinitely** when run non-interactively by an autonomous agent. This was the #1 identified
lockup. The fix is to always pass `--name` (non-interactive) and wrap the spawn in a hard timeout
so even a stuck child is killed.

## Interface

### New file: `devops/runtime-test/migrate.ts`
- `runMigrate(name: string, timeoutMs = 120_000): Promise<MigrateResult>` — spawns
  `bunx prisma migrate dev --name <name>`, captures stdout/stderr, kills the child on timeout.

### New CLI subcommand
- `bun run devops runtime-test migrate --name=<x> [--timeout=ms]` → `{ok, output, error?, timedOut?}`

## Steps
1. Implement `migrate.ts` (spawn + timeout + kill).
2. Wire `migrate` case in `devops/index.ts`.
3. Document in SKILL.md.

## Acceptance
- `migrate --name=x` runs without any stdin prompt.
- A contrived blocked child is killed at the timeout and returns `timedOut:true`.
- `typecheck` clean.
