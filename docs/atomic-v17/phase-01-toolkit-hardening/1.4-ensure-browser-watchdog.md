# Unit 1.4 — ensure-browser precheck + agent-death watchdog

**Source:** PRD R4, R7, R8; Scenario B, D
**Depends on:** none
**Produces:** `ensure-browser` precheck (deterministic source) + `watchdog` background reaper +
in-process `process-guard` (the "hook that intercepts context just in case").

---

## Context

`engage` needs a live Chrome debug port. When none exists it returned "No session/governor" and
the agent either looped `debug` forever or falsely declared success. Separately, the supervisor
spawns `serve` **detached** — if the *agent* process dies, the server + spawned Chrome survive as
orphans. Two fixes: (1) a deterministic `ensure-browser` precheck the agent branches on; (2) a
watchdog that reaps on agent death, plus an in-process guard that reaps on any interrupt/exception.

## Interface

### New file: `devops/runtime-test/ensure-browser.ts`
- `ensureBrowser(): Promise<BrowserStatus>` — checks `VIVIM_ADOPT_PORT`, else scans 9222–9332 for a
  Chrome DevTools `/json/version`; returns `{ok, source:'adopted'|'spawned'|'none', port?}`.

### New file: `devops/runtime-test/watchdog.ts`
- `startWatchdog(parentPid, intervalMs=5000)` — polls parent pid via `process.kill(pid,0)`; on
  death runs `stopServices()` then exits. `unref()`'d so it doesn't block its own lifetime.

### New file: `devops/runtime-test/process-guard.ts`
- `installProcessGuard()` — registers SIGINT/SIGTERM/uncaughtException/unhandledRejection →
  `stopServices()` then exit. Installed at the top of every `runtime-test` command in `devops/index.ts`.

### New CLI subcommands
- `bun run devops runtime-test ensure-browser` → `{ok, source}`
- `bun run devops runtime-test watchdog --pid=<n>` → monitors (kept alive as a detached bg script)

## Steps
1. Implement `ensure-browser.ts`, `watchdog.ts`, `process-guard.ts`.
2. Wire subcommands + install `installProcessGuard()` in the `runtime-test` switch.
3. Add `finally { await stopServices() }` around the loop's `runOrchestrationCycle`.
4. Document in SKILL.md.

## Acceptance
- `ensure-browser` returns `source:'none'` (deterministic) when no Chrome is up.
- `process-guard` ensures a Ctrl+C during a `loop` triggers `stop` (no orphan).
- `typecheck` clean.
