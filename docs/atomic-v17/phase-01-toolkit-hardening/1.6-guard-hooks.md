# Unit 1.6 — Devops guard hooks (lefthook)

**Source:** PRD R6, R8; Scenario C, E
**Depends on:** 1.2 (migrate status check)
**Produces:** lefthook guards that block a commit while servers run or a migration is pending, and
block a push on P0/P1 source findings.

---

## Context

The only git hooks were `lefthook.yml` pre-commit (lint/format/typecheck/invariants-B) and
pre-push (`bun test`). Nothing prevented committing while `.runtime/*.pid` servers were alive
(orphan risk) or with a pending Prisma migration (half-migrated schema). The fix adds a `guard`
pre-commit command (TS, testable, cross-platform) and an `audit-code standard` pre-push command.

## Interface

### New file: `devops/runtime-test/guard.ts`
- `runGuard(): GuardResult` — checks for any `.runtime/*.pid` (servers running) and runs
  `bunx prisma migrate status` (timeout 30s); returns `{ok, violations[]}`.

### Modified: `lefthook.yml`
- pre-commit adds `guard: run: bun run devops runtime-test guard`.
- pre-push adds `audit: run: bun run devops audit-code standard`.

## Steps
1. Implement `guard.ts` + export from barrel.
2. Add `guard` CLI subcommand in `devops/index.ts`.
3. Edit `lefthook.yml`.
4. Document in SKILL.md.

## Acceptance
- `devops runtime-test guard` returns `ok:false` with a violation when a `.pid` exists.
- `git commit` while servers run is blocked by lefthook (after `lefthook install`).
- `typecheck` clean.
