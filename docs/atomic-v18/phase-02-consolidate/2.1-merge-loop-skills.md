# Unit 2.1 — Consolidate devops + vivim-runtime skill docs

**Source:** PRD R4; skills upgrade design P2.1
**Depends on:** 1.1, 1.2, 1.3 (typecheck must pass first)
**Produces:** One unified `devops` skill with tracker-mode and goal-mode

---

## Context

Both `devops` and `vivim-runtime` describe the autonomous loop. They share the same
infrastructure (`devops/runtime-test/`) but have different entry points:
- `devops`: tracker-driven (`bun run devops run`) — drives atomic units from the tracker
- `vivim-runtime`: goal-driven (`bun run devops runtime-test loop --goal="..."`) — drives from a user goal

This overlap causes confusion. The agent doesn't know which skill to load.

## Interface

### Merged skill: `.opencode/skill/devops/SKILL.md`
The unified skill should document:

1. **Overview** — Agent-driven autonomous dev loop for vivim-final
2. **Two modes:**
   - **Tracker mode** (default): `bun run devops run` — picks next unit from tracker, implements, gates, commits
   - **Goal mode**: `bun run devops runtime-test loop --goal="..."` — interprets goal, builds full stack, verifies
3. **Commands reference** — all CLI commands in one place
4. **Build strategies** — backend, frontend, database, automation (from vivim-build)
5. **Invariants** — Governor Canon, Store Contracts, One Entry Point
6. **Integration** — how devops connects to other skills

### Remove: `.opencode/skill/vivim-runtime/SKILL.md`
- Move unique content (goal-mode specifics, build strategies) into `devops`
- Delete the file or mark as deprecated with a redirect to `devops`

## Steps
1. Read both skill docs — identify unique content in each
2. Write merged `devops/SKILL.md` with both modes documented
3. Delete or deprecate `vivim-runtime/SKILL.md`
4. Update any cross-references in other skills
5. Verify the agent can load the merged skill
6. Commit

## Acceptance
- `.opencode/skill/devops/SKILL.md` documents both tracker-mode and goal-mode
- `.opencode/skill/vivim-runtime/SKILL.md` is removed or deprecated
- No broken cross-references in other skills
- Agent loads `devops` skill and understands both modes
