# Unit 2.4 — Update stale skill references

**Source:** PRD R8, R9, R10; skills upgrade design P3
**Depends on:** 2.1 (merged doc is source of truth)
**Produces:** All skill docs reference existing files/commands

---

## Context

4 of 9 skills reference files, commands, or paths that don't exist:
1. `devops-generators`: references `bun run taxonomy-gen` CLI (not wired in `devops/index.ts`)
2. `devops-roadmap`: references `bun run devops truth full` and `research` subcommands
3. `vivim-runtime`: references `src/engines/harness/`, `src/canvas/`, `src/engines/cdp-capability-registrar.ts`
4. `devops`: references `docs/atomic-v3-fork-canon/01-tracker.md` (may be wrong path)

## Interface

### For each stale reference, choose one:
1. **Fix the reference** — update the path/command to the correct one
2. **Create the missing file** — if the reference is to something that should exist
3. **Mark as optional** — if the feature is deprioritized, note it as optional/future
4. **Remove the reference** — if the feature is abandoned

### Specific fixes:
- `devops-generators`: Either wire `taxonomy-gen` CLI or mark taxonomy generation as optional
- `devops-roadmap`: Verify truth subcommands work; update paths if needed
- `vivim-runtime`: Remove references to non-existent modules (harness, canvas, cdp-registrar)
- `devops`: Verify tracker path; update if needed

## Steps
1. For each stale skill: read the doc, identify stale references
2. For each stale reference: decide fix/create/mark-optional/remove
3. Apply fixes
4. Verify no broken references remain
5. Commit

## Acceptance
- All 9 skill docs reference existing files/commands
- No "file not found" when following a skill's instructions
- `bun run devops` commands referenced in skills actually work
