## Context

`vivim-build` is a clean engine implementation template (137 lines). It describes:
- Engine file structure
- Implementation template (Store Contract → Config → Interface → Implementation)
- Testing pattern (mock store contract)

This is a sub-workflow of the devops loop, not a standalone skill. It should live inside
the `devops` skill's "Build Strategies" section.

## Interface

### Move content
- Copy `vivim-build/SKILL.md` content into `devops/SKILL.md` under `## Build Strategies > Engine Implementation`
- Ensure the template is referenced, not duplicated (link to `src/engines/` for examples)

### Remove: `.opencode/skill/vivim-build/SKILL.md`
- Delete the file or mark as deprecated with redirect to `devops`

## Steps
1. Read `vivim-build/SKILL.md` — extract unique content (template, testing pattern)
2. Add to `devops/SKILL.md` under Build Strategies
3. Delete or deprecate `vivim-build/SKILL.md`
4. Commit

## Acceptance
- `devops/SKILL.md` contains engine implementation template
- `vivim-build/SKILL.md` is removed or deprecated
- Agent loads `devops` and can implement engines using the template
