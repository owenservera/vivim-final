# Unit 22.2 — Program store (contract + impl, Store Contracts invariant)

**Design Doc:** `docs/atomic-v14/SYNTHESIS.md` §1 (invariant 2)
**Depends on:** 22.1
**Produces:** `capability-program-store.ts` **contract** + `capability-program-store-impl.ts`
**impl** — the DI seam for program persistence. Engines depend on the contract only.

---

## Context

cap-store reads programs via `db.getProgram(best_program_id)`. To honor the vivim-final
**Store Contracts** invariant (engines depend on `contracts/*.ts`, never `impl`), this
unit splits program access into a contract and an impl, mirroring the existing
`capability-store.ts` / `capability-store-impl.ts` pair.

## Existing Baseline

- `src/storage/contracts/capability-store.ts` + `src/storage/capability-store-impl.ts`.
- 22.1 extended `CapabilityProgramRow`.

## Interface

### `src/storage/contracts/capability-program-store.ts`

```typescript
import type { CapabilityProgramRow } from './capability-store.js'

export interface ProgramInput {
  id: string
  bindingId: string
  version: number
  status: string
  programKind: 'recipe' | 'selector'
  configJson: string
}

export interface CapabilityProgramStore {
  getProgram(id: string): Promise<CapabilityProgramRow | null>
  getProgramsByBinding(bindingId: string): Promise<CapabilityProgramRow[]>
  getBestProgram(bindingId: string): Promise<CapabilityProgramRow | null>
  upsertProgram(input: ProgramInput): Promise<CapabilityProgramRow>
  setBest(bindingId: string, programId: string): Promise<void>
}
```

### `src/storage/capability-program-store-impl.ts`

Implements against Prisma, delegating validation to `validateProgramConfig` (22.1).
`getBestProgram` returns the row flagged best for the binding (wires cap-store
`best_program_id`).

## Acceptance Criteria

1. Contract file exports `CapabilityProgramStore` with the 5 methods; no Prisma import.
2. Impl file imports Prisma + contract; implements all methods.
3. `getBestProgram` reflects the cap-store `best_program_id` semantic.
4. `typecheck` + lint pass; existing capability-store tests unaffected.

## Tests
