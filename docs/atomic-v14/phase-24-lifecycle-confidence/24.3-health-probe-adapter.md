# Unit 24.3 — Health probe adapter (cap-store `health-probe` → governor slave health)

**Design Doc:** `docs/atomic-v14/SYNTHESIS.md` §2.5
**Depends on:** 24.1, 23.4
**Produces:** `src/engines/harness/health-probe.ts` — ports cap-store `health-probe.ts`
to read vivim-final's governor slave health (`lastHealthCheck`, `consecutiveFailures`,
`circuitState`) and feed the ladder (24.1), so a dead slave flips a binding toward
`broken` without waiting for an execution attempt.

---

## Context

cap-store probes a slave's health between executions to demote broken bindings early.
vivim-final's `ChromeGovernor` already tracks `lastHealthCheck` / `consecutiveFailures`.
This adapter turns that into ladder inputs (24.1) — no new probing loop, just a mapping
over existing governor state.

## Existing Baseline

- `src/engines/chrome-governor.ts` — `ChromeSlave.lastHealthCheck`,
  `consecutiveFailures`, `circuitState`.
- 24.1 `autoStatus`, `BindingStatus`.
- cap-store `src/executor/health-probe.ts` (reference).

## Interface

### `src/engines/harness/health-probe.ts`

```typescript
import type { ChromeGovernor } from '../chrome-governor.js'
import { deriveSlaveId } from '../ids.js'
import type { BindingStatus } from './binding-ladder.js'

export interface SlaveHealth { alive: boolean; consecutiveFailures: number; circuitOpen: boolean }

export function probeSlave(governor: ChromeGovernor, providerId: string, accountId: string): SlaveHealth {
  const slave = governor.getSlave(deriveSlaveId(providerId, accountId))
  if (!slave) return { alive: false, consecutiveFailures: 1, circuitOpen: false }
  return {
    alive: slave.status !== 'error',
    consecutiveFailures: slave.consecutiveFailures,
    circuitOpen: slave.circuitState === 'open',
  }
}

/** Map probe → next binding status. */
export function statusFromProbe(current: BindingStatus, h: SlaveHealth): BindingStatus {
  if (!h.alive || h.circuitOpen) return 'broken'
  if (h.consecutiveFailures > 0) return current === 'stable' ? 'flaky' : current
  return current
}
```

## Acceptance Criteria

1. `probeSlave` reads governor slave state (no new probe loop).
2. `statusFromProbe` demotes to `broken`/`flaky` on dead/flaky slave.
3. `typecheck` passes.
