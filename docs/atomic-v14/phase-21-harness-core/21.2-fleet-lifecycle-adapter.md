# Unit 21.2 — Fleet lifecycle adapter (cap-store `fleet.ensure` → vivim `FleetSupervisor`)

**Design Doc:** `docs/atomic-v14/SYNTHESIS.md` §2.1, §2.5
**Depends on:** 21.1
**Produces:** `HarnessFleet` adapter over vivim-final's existing `FleetSupervisor` —
the cap-store `fleet.ensure(providerId)` primitive, governor-gated and circuit-aware.

---

## Context

cap-store's `executeBinding` calls `fleet.ensure(providerId)` to guarantee a hidden
Chrome slave is running before connecting CDP. vivim-final **already has**
`FleetSupervisor` (`src/executor/fleet-supervisor.ts`) behind `ChromeGovernor`. This
unit wraps it as a `HarnessFleet` contract so the harness executor (23.1) can ensure a
slave without touching CDP directly.

## Existing Baseline

- `src/engines/chrome-governor.ts` — `ChromeGovernor` holds a `FleetSupervisor`.
- `src/storage/contracts/fleet-supervisor.ts` — `FleetSupervisor` contract
  (`ensure`, `health`, `CircuitState`).
- cap-store `src/executor/fleet-supervisor.ts` — proven `ensure`/`CircuitOpenError`
  semantics (reference, not copied).

## Interface

### `src/engines/harness/harness-fleet.ts`

```typescript
import type { ChromeGovernor } from '../chrome-governor.js'
import { deriveSlaveId } from '../ids.js'

export class HarnessFleet {
  constructor(private governor: ChromeGovernor) {}

  /** Equivalent to cap-store fleet.ensure(providerId). Throws if slave
   *  cannot be guaranteed (circuit open / launch failed). */
  async ensure(providerId: string, accountId: string): Promise<{ slaveId: string; debugPort: number }> {
    const slaveId = deriveSlaveId(providerId, accountId)
    await this.governor.ensureRunning(slaveId)   // governor-owned fleet
    const slave = this.governor.getSlave(slaveId)
    if (!slave) throw new Error(`slave not available: ${slaveId}`)
    return { slaveId, debugPort: slave.debugPort }
  }

  /** Circuit state surfaced to the executor for fast-fail (cap-store §2.5). */
  circuitState(providerId: string, accountId: string) {
    return this.governor.getSlaveCircuit(deriveSlaveId(providerId, accountId))
  }
}
```

### Invariant guards

- `HarnessFleet` calls `governor.ensureRunning` / `governor.getSlave` — **never**
  `createCdpClient` or launcher directly (Governor Canon).
- Reuses governor's existing `consecutiveFailures` / `circuitState`.

## Acceptance Criteria

1. `HarnessFleet` exists with `ensure(providerId, accountId)` returning
   `{ slaveId, debugPort }`.
2. `ensure` delegates to `governor.ensureRunning` (no direct launch/client).
3. `circuitState(...)` exposes the governor `CircuitState`.
4. `typecheck` passes; existing fleet tests still green.
