# Unit 21.3 — Recipe types (port of cap-store `programToRecipe` domain)

**Design Doc:** `docs/atomic-v14/SYNTHESIS.md` §2.1
**Depends on:** 21.1
**Produces:** `src/engines/harness/recipe-types.ts` — the typed `ActionProgram` /
`ActionStep` / `Recipe` / `RecipeStep` model that makes vivim-final's capability
execution **multi-step** (proven cap-store injection), not just a single selector.

---

## Context

cap-store proves capabilities execute as ordered `ActionStep` ops
(`click|type|wait|navigate|arm`) compiled to CDP `RecipeStep` verbs. vivim-final's
`CapabilityProgramRow.configJson` is currently opaque. This unit defines the serialized
shape so 21.4 can compile and 23.1 can execute through the governor.

## Existing Baseline

- cap-store `src/executor/index.ts: programToRecipe` — op→verb mapping (reference).
- vivim-final `src/storage/contracts/capability-store.ts` — `CapabilityProgramRow`
  (`configJson` holds the program).
- `src/schema/` — Zod boundary convention.

## Interface

### `src/engines/harness/recipe-types.ts`

```typescript
import { z } from 'zod'

// ── cap-store ActionProgram (port) ────────────────────────────────────────
export const ActionStepSchema = z.discriminatedUnion('op', [
  z.object({ op: z.literal('click'), selector: z.string(), text: z.string().optional(), ref: z.string().optional() }),
  z.object({ op: z.literal('type'), selector: z.string(), text: z.string(), ref: z.string().optional() }),
  z.object({ op: z.literal('wait'), ms: z.number().int().positive() }),
  z.object({ op: z.literal('navigate'), url: z.string().url() }),
  z.object({ op: z.literal('arm'), ms: z.number().int().positive().optional() }),
])
export type ActionStep = z.infer<typeof ActionStepSchema>

export const ActionProgramSchema = z.object({
  id: z.string(),
  providerId: z.string(),
  steps: z.array(ActionStepSchema),
})
export type ActionProgram = z.infer<typeof ActionProgramSchema>

// ── cap-store Recipe (CDP-ready) ──────────────────────────────────────────
export type RecipeVerb = 'click' | 'type' | 'wait' | 'navigate' | 'arm'
export interface RecipeStep {
  id: string
  act: { verb: RecipeVerb; text?: string; selector?: string; url?: string; waitMs?: number }
}
export interface Recipe {
  name: string
  provider: string
  steps: RecipeStep[]
}
```

### Invariant guards

- Zod schemas at the boundary (no `any`); `ActionProgramSchema.parse` validates
  `configJson` before compile.

## Acceptance Criteria

1. `recipe-types.ts` exports `ActionStep`, `ActionProgram`, `Recipe`, `RecipeStep`
   with the 5 op verbs.
2. Zod schemas validate an arbitrary `configJson` into `ActionProgram`.
3. `typecheck` passes.
