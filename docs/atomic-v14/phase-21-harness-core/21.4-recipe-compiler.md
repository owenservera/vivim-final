# Unit 21.4 — Recipe compiler (port of cap-store `programToRecipe`)

**Design Doc:** `docs/atomic-v14/SYNTHESIS.md` §2.1
**Depends on:** 21.2, 21.3
**Produces:** `src/engines/harness/recipe-compiler.ts` — deserializes a
`CapabilityProgramRow.configJson` into an `ActionProgram`, then compiles to a `Recipe`
of CDP verbs. Pure function, no CDP. Reuses `HarnessFleet` for port resolution.

---

## Context

cap-store's `programToRecipe` is the proven translation from program rows to CDP steps.
Port it as a **pure compiler**; the actual CDP send happens later in 23.1 via the
governor. This keeps compilation testable and CDP-free.

## Existing Baseline

- cap-store `src/executor/index.ts: programToRecipe` (reference mapping).
- 21.3 `recipe-types.ts` (`ActionProgram`, `Recipe`).
- `src/ids.ts` — `newId` for step ids.

## Interface

### `src/engines/harness/recipe-compiler.ts`

```typescript
import { newId } from '../../ids.js'
import { ActionProgramSchema, type ActionProgram, type Recipe, type RecipeStep } from './recipe-types.js'
import type { HarnessFleet } from './harness-fleet.js'

export function compileProgram(configJson: string, providerId: string): Recipe {
  const program = ActionProgramSchema.parse(JSON.parse(configJson)) as ActionProgram
  const steps: RecipeStep[] = program.steps.map((s, i) => {
    const id = `step-${i}`
    switch (s.op) {
      case 'click': return { id, act: { verb: 'click', selector: s.selector, text: s.text } }
      case 'type':  return { id, act: { verb: 'type', selector: s.selector, text: s.text } }
      case 'wait':  return { id, act: { verb: 'wait', waitMs: s.ms } }
      case 'navigate': return { id, act: { verb: 'navigate', url: s.url } }
      case 'arm':   return { id, act: { verb: 'wait', waitMs: s.ms ?? 1000 } }
    }
  })
  return { name: program.id, provider: providerId, steps }
}

/** Resolve the debug port for a provider (cap-store resolveDebugPort). */
export function resolveDebugPort(fleet: HarnessFleet, providerId: string, accountId: string): number {
  return fleet.ensure(providerId, accountId).then((r) => r.debugPort)
}
```

### Invariant guards

- No `createCdpClient`, no `governor.cdp` here — pure compile + fleet port resolution.

## Acceptance Criteria

1. `compileProgram(configJson, providerId)` returns a `Recipe` with one `RecipeStep`
   per action step, verbs mapped click/type/wait/navigate/arm→wait.
2. Malformed `configJson` throws a Zod error (does not produce a partial recipe).
3. `typecheck` passes.

## Tests

`tests/unit/harness/recipe-compiler.test.ts` — compile a 3-step program; assert verb
