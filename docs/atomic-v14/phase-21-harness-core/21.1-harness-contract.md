# Unit 21.1 — Harness contract (the DI seam for the injection harness)

**Design Doc:** `docs/atomic-v14/SYNTHESIS.md` §2
**Depends on:** — (opens with phase 21)
**Produces:** `HarnessExecutor` contract + `HarnessExecutorDeps` type — the formal
dependency-injection seam for the proven cap-store harness, expressed as a vivim-final
**store contract** (Governor Canon + Store Contracts invariants).

---

## Context

cap-store proves an `executeBinding(db, opts)` entry point: load binding → program →
recipe → run against a fleet-managed Chrome. In vivim-final that entry point must be
**governor-gated** (no direct CDP) and **contract-injected** (engines never import
impls). This unit defines the contract that every later unit depends on.

## Existing Baseline

- `src/engines/chrome-governor.ts` — `ChromeGovernor` is the only CDP owner.
- `src/storage/contracts/capability-store.ts` — `CapabilityStore` (binding/program/selector/outcome).
- `src/engines/unified-registry.ts` — `UnifiedCapability` (`handler` closure).
- `src/executor/fleet-supervisor.ts` + `src/storage/contracts/fleet-supervisor.ts` — fleet lifecycle already exists.

## Interface

### `src/engines/harness/harness-contract.ts`

```typescript
import type { ChromeGovernor } from '../chrome-governor.js'
import type { CapabilityStore } from '../storage/contracts/capability-store.js'
import type { CapabilityEventBus } from './conversation-manager.js'

/** Injected dependencies for any harness executor (Store Contracts invariant). */
export interface HarnessExecutorDeps {
  governor: ChromeGovernor          // SINGLE CDP OWNER — never a raw CDP client
  store: CapabilityStore            // binding/program/selector/outcome
  eventBus?: CapabilityEventBus
}

/** Fine-grained execution sink — mirrors cap-store publishStreamBlock. */
export interface HarnessSink {
  onBlock(block: unknown, sequence: number): void
  onDone(reason: 'complete' | string): void
  onError(error: string): void
}

export interface HarnessExecuteOptions {
  capabilitySlug: string
  providerId: string
  accountId: string
  input?: Record<string, unknown>
  timeoutMs?: number
  sink?: HarnessSink
}

export interface HarnessExecuteResult {
  ok: boolean
  capabilityId: string
  bindingId: string | null
  programId: string | null
  output: Record<string, unknown>
  traceId: string
  latencyMs: number
  blocks: number
}

/** Contract only — impl in 23.1. */
export interface HarnessExecutor {
  execute(opts: HarnessExecuteOptions): Promise<HarnessExecuteResult>
}
```

### Invariant guards (compile-time)

- This file imports **types only**. No `BunCdpClient`, no `createCdpClient`.
- `governor: ChromeGovernor` is the only path to CDP (Governor Canon).

## Acceptance Criteria

1. `harness-contract.ts` exists with `HarnessExecutorDeps`, `HarnessExecutor`,
   `HarnessExecuteOptions`, `HarnessExecuteResult`, `HarnessSink`.
2. All CDP access flows through the `governor` field — no CDP transport imported.
3. The contract is pure types (no behavior) so it can be mocked in tests.
4. `typecheck` passes.

## Tests

`tests/unit/harness/harness-contract.test.ts` — type-level + mock-shape test asserting
an impl receiving `HarnessExecutorDeps` satisfies `HarnessExecutor` (structural).
