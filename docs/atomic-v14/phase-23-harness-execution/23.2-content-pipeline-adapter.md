# Unit 23.2 — Content pipeline adapter (cap-store content pipeline + vivim typing)

**Design Doc:** `docs/atomic-v14/SYNTHESIS.md` §2.2
**Depends on:** 23.1
**Produces:** `src/engines/harness/content-pipeline.ts` — composes the prompt/message
from `opts.input` and injects it into the recipe as human-like typing, reusing
vivim-final's `composer-typing.ts` (`submitMessage`/`typeMessage`) where cap-store uses
raw `Input.insertText`.

---

## Context

cap-store's `content-pipeline.ts` builds the message and inserts it. vivim-final already
has a superior primitive — `composer-typing.ts` types like a human. This adapter uses
the cap-store *composition* idea but the vivim *typing* engine, so injected text looks
human (stealth benefit vivim already owns).

## Existing Baseline

- `src/engines/composer-typing.ts` — `submitMessage`, `typeMessage`.
- cap-store `src/executor/content-pipeline.ts`, `content-blocks.ts` (reference).
- 23.1 `HarnessExecutorEngine` (calls this before/within `type` steps).

## Interface

### `src/engines/harness/content-pipeline.ts`

```typescript
import type { ChromeGovernor } from '../chrome-governor.js'
import { submitMessage, typeMessage } from '../composer-typing.js'

export interface ComposeInput {
  prompt: string
  model?: string
  actionTag?: string
  input?: Record<string, unknown>
}

/** Build the message block (cap-store content pipeline) + inject human-like. */
export async function injectComposedMessage(
  governor: ChromeGovernor,
  slaveId: string,
  compose: ComposeInput,
): Promise<{ text: string }> {
  const text = [compose.actionTag ? `[${compose.actionTag}] ` : '', compose.prompt].join('').trim()
  // vivim-final human typing (cap-store used raw Input.insertText)
  await typeMessage(governor, slaveId, text)
  await submitMessage(governor, slaveId)
  return { text }
}
```

### Wiring

`HarnessExecutorEngine` calls `injectComposedMessage` when a recipe step is `type` and
the step has no explicit selector text (i.e. it is the prompt). Keep `governor` as the
only CDP path.

## Acceptance Criteria

1. `injectComposedMessage` composes `actionTag`+`prompt` and uses `composer-typing`.
2. No direct CDP `insertText` — routes through `governor` + `composer-typing`.
3. `typecheck` passes; composer-typing tests unaffected.
