# Unit 23.1 — Harness executor engine (governor-gated cap-store injection)

**Design Doc:** `docs/atomic-v14/SYNTHESIS.md` §2, §3
**Depends on:** 22.4, 21.4
**Produces:** `src/engines/harness/harness-executor.ts` — the cap-store `executeBinding`
flow, vivim-styled: load binding → best program → compile recipe → `fleet.ensure` →
run steps via `governor.cdp.send` (SINGLE CDP OWNER) → record outcome → emit events.

---

## Context

This is the heart of the synthesis: cap-store's proven multi-step injection, executed
through vivim-final's governor (Governor Canon). It replaces the atomic-only
`CapabilityEngine.runSelector` path for *program* capabilities while keeping selector
capabilities working.

## Existing Baseline

- `src/engines/capability.ts` — `CapabilityEngine.execute` (selector path, recovery).
- `src/engines/chrome-governor.ts` — `governor.cdp.send(slaveId, method, params)`.
- 21.1 `HarnessExecutor` contract; 21.2 `HarnessFleet`; 21.4 `compileProgram`.
- 22.2/22.4 program + best-program access.

## Interface

### `src/engines/harness/harness-executor.ts`

```typescript
import { newId } from '../../ids.js'
import type { HarnessExecutor, HarnessExecutorDeps, HarnessExecuteOptions, HarnessExecuteResult, HarnessSink } from './harness-contract.js'
import { HarnessFleet } from './harness-fleet.js'
import { compileProgram } from './recipe-compiler.js'

export class HarnessExecutorEngine implements HarnessExecutor {
  private fleet: HarnessFleet
  constructor(private deps: HarnessExecutorDeps) { this.fleet = new HarnessFleet(deps.governor) }

  async execute(opts: HarnessExecuteOptions): Promise<HarnessExecuteResult> {
    const start = Date.now()
    const traceId = newId()
    const { store, governor, eventBus } = this.deps
    const cap = await store.getCapabilityBySlug(opts.capabilitySlug)
    if (!cap) return this.fail(opts, traceId, start, 'capability not found')
    const binding = await store.getBinding(cap.id, opts.providerId)
    if (!binding) return this.fail(opts, traceId, start, 'binding not found')
    const programId = await store.getBestProgramId(binding.id)
    if (!programId) return this.fail(opts, traceId, start, 'no best_program_id')
    const program = await store.getProgram(programId)
    if (!program) return this.fail(opts, traceId, start, 'program not found')

    const { slaveId } = await this.fleet.ensure(opts.providerId, opts.accountId)
    const recipe = compileProgram(program.configJson, opts.providerId)
    const sink = opts.sink
    let blocks = 0
    try {
      for (const step of recipe.steps) {
        await governor.cdp.send(slaveId, this.toCdpMethod(step.act), this.toCdpParams(step.act, opts.input))
        blocks++
        sink?.onBlock(step.act, blocks)
      }
      sink?.onDone('complete')
    } catch (e) {
      sink?.onError(String(e))
      return this.fail(opts, traceId, start, String(e))
    }
    const ok = true
    const latencyMs = Date.now() - start
    await store.createOutcome({ capabilityId: cap.id, bindingId: binding.id, providerId: opts.providerId, accountId: opts.accountId, ok, latencyMs, outputJson: JSON.stringify({ blocks }), traceId })
    await store.updateBindingHealth(binding.id, { status: 'healthy', healthScore: 1, lastSuccessAt: Date.now() })
    eventBus?.emit({ type: 'capability:executed', capabilityId: cap.id, bindingId: binding.id, providerId: opts.providerId, traceId, ok: true, latencyMs })
    return { ok, capabilityId: cap.id, bindingId: binding.id, programId, output: { blocks }, traceId, latencyMs, blocks }
  }

  private fail(o: HarnessExecuteOptions, traceId: string, start: number, error: string): HarnessExecuteResult {
    return { ok: false, capabilityId: '', bindingId: null, programId: null, output: {}, traceId, latencyMs: Date.now() - start, blocks: 0 }
  }
  private toCdpMethod(act: { verb: string }) { return act.verb === 'click' ? 'DOM.querySelector' : act.verb === 'navigate' ? 'Page.navigate' : act.verb === 'wait' ? 'Runtime.evaluate' : 'Input.insertText' }
  private toCdpParams(act: Record<string, unknown>, input?: Record<string, unknown>) { return act }
}
```

### Invariant guards

- Only `governor.cdp.send` touches CDP (Governor Canon). No `createCdpClient`.
- Deeper content/stream behaviour delegated to 23.2/23.3 (composition, not reimpl).

## Acceptance Criteria

1. `HarnessExecutorEngine implements HarnessExecutor` (21.1).
2. Loads binding → best program → compiles recipe → ensures slave via `HarnessFleet`.
3. Executes each recipe step through `governor.cdp.send` only.
4. Records outcome + updates binding health + emits `capability:executed`.
5. `typecheck` + lint pass.
