# Unit 23.4 — Circuit breaker adapter (cap-store `CircuitOpenError` → governor `CircuitState`)

**Design Doc:** `docs/atomic-v14/SYNTHESIS.md` §2.5
**Depends on:** 23.1
**Produces:** `src/engines/harness/circuit-breaker.ts` — surfaces cap-store's fast-fail
`CircuitOpenError` semantics on top of vivim-final's existing governor `CircuitState`
(`consecutiveFailures` / `circuitState`), so a provider whose slave keeps failing is
rejected with a retry-after error instead of hanging.

---

## Context

cap-store wraps `fleet.ensure` in a circuit breaker and throws `CircuitOpenError` with
`retryAfterMs`. vivim-final already tracks `CircuitState` in the governor. This unit
adapts cap-store's error contract onto the governor state so the harness executor
(23.1) can fast-fail consistently.

## Existing Baseline

- `src/engines/chrome-governor.ts` — `CircuitState`, `consecutiveFailures`.
- 21.2 `HarnessFleet.circuitState`.
- cap-store `src/executor/circuit-breaker.ts` (reference).

## Interface

### `src/engines/harness/circuit-breaker.ts`

```typescript
import type { HarnessFleet } from './harness-fleet.js'

export class CircuitOpenError extends Error {
  constructor(public providerId: string, public retryAfterMs: number) {
    super(`provider ${providerId} temporarily unavailable — retry in ${Math.ceil(retryAfterMs / 1000)}s`)
  }
}

/** Mirror cap-store fleet.ensure guard: throw if circuit open. */
export function guardCircuit(fleet: HarnessFleet, providerId: string, accountId: string): void {
  const state = fleet.circuitState(providerId, accountId)
  if (state === 'open') {
    throw new CircuitOpenError(providerId, 30_000) // governor reset window
  }
}
```

### Wiring

`HarnessExecutorEngine` (23.1) calls `guardCircuit` before `fleet.ensure`; on
`CircuitOpenError` it records a failed outcome and emits `capability:failed` with
`retryAfterMs`.

## Acceptance Criteria

1. `CircuitOpenError` carries `providerId` + `retryAfterMs`.
2. `guardCircuit` throws when governor `CircuitState === 'open'`.
3. No new circuit state stored — reuses governor's existing `CircuitState`.
4. `typecheck` passes.
