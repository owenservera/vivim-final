# Unit 25.2 — Recipe capability registration (extend `cdp-capability-registrar`)

**Design Doc:** `docs/atomic-v14/SYNTHESIS.md` §0, §3
**Depends on:** 25.1, 22.3
**Produces:** extension of `src/engines/cdp-capability-registrar.ts` so that, after
`capability-program-registrar` seeds a program (22.3), a `UnifiedCapability` is
auto-registered via `makeHarnessCapability` (25.1). This makes every seeded program a
first-class, multi-surface capability — the cap-store "binding becomes an executable
capability" idea, vivim-styled.

---

## Context

cap-store turns a `ProviderBinding`+`ActionProgram` into an executable endpoint.
vivim-final already turns CDP methods into capabilities (`cdp-capability-registrar`).
This unit extends that registrar to also turn **program-backed bindings** into
capabilities via the harness executor, completing the One Entry Point coverage.

## Existing Baseline

- `src/engines/cdp-capability-registrar.ts` — `cdpMethodToCapability`, `CdpExecutor`.
- 22.3 `CapabilityProgramRegistrar.register`.
- 25.1 `makeHarnessCapability`.

## Interface

### `src/engines/cdp-capability-registrar.ts` (extend)

```typescript
import { makeHarnessCapability } from './harness/make-harness-capability.js'
import type { HarnessExecutor } from './harness/harness-contract.js'

/** Register a seeded program as a UnifiedCapability backed by the harness executor. */
export function programToCapability(opts: {
  capabilitySlug: string; providerId: string; executor: HarnessExecutor
}): UnifiedCapability {
  return makeHarnessCapability({
    id: `cap:prog:${opts.capabilitySlug}:${opts.providerId}`,
    slug: `prog-${opts.capabilitySlug}-${opts.providerId}`,
    name: `${opts.capabilitySlug} @ ${opts.providerId}`,
    description: `Program-driven capability for ${opts.capabilitySlug}`,
    category: 'harness',
    executor: opts.executor,
    surfaces: ['cli', 'ui', 'api', 'mcp', 'workflow'],
  })
}
```

### Wiring

`CapabilityProgramRegistrar.register` (22.3) calls `programToCapability` and
`registry.register(...)` after upserting the program, so seeding a program also
publishes the capability.

## Acceptance Criteria

1. `programToCapability` returns a harness-backed `UnifiedCapability`.
2. `CapabilityProgramRegistrar` auto-registers the capability on seed.
3. Existing `cdpMethodToCapability` behaviour unchanged.
4. `typecheck` + lint pass.
