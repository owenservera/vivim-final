# Unit 25.4 — v14 verification (full invariant gate)

**Design Doc:** `docs/atomic-v14/SYNTHESIS.md` §1
**Depends on:** 25.1, 25.2, 25.3, 24.4
**Produces:** a consolidated verification pass proving atomic-v14 preserves every
vivim-final invariant while delivering the cap-store-proven harness. This is the final
gate before the devops loop marks all units `done`.

---

## Context

The devops skill gates each unit; this unit is the **phase-25 capstone** that runs the
full suite + the project invariant checker (`bun run devops invariants check`) and
documents that the Governor Canon, Store Contracts, and One Entry Point invariants hold
end-to-end.

## Existing Baseline

- `bun run devops gate` — typecheck + lint + bun test.
- `bun run devops invariants check` — enforces AGENTS.md critical boundaries.
- All units 21.1–25.3 implemented.

## Verification protocol

1. **Typecheck + lint + test**
   ```powershell
   bun run typecheck
   bun run lint
   bun test
   ```
2. **Invariant checks (must all pass)**
   - **Governor Canon** — grep confirms no new engine imports `BunCdpClient`; all CDP
     access routes through `ChromeGovernor` (21.1 contract + 23.1 executor).
   - **Store Contracts** — harness engines import from `storage/contracts/*`, not `impl`
     (22.2 program store split).
   - **One Entry Point** — every seeded program is reachable as a `UnifiedCapability`
     via `POST /api/capabilities/:id/execute` (25.1/25.2), and NLCL can resolve to it.
3. **Integration smoke** — seed one program (`CapabilityProgramRegistrar.seedAll`),
   execute via the registry handler, assert: recipe steps sent through governor, outcome
   recorded, binding advanced on ladder (24.1), stream blocks emitted (25.3).

## Acceptance Criteria

1. `bun run devops gate` is green.
2. `bun run devops invariants check` reports no violations.
3. Integration smoke passes: program → capability → governor-gated recipe → outcome →
   ladder advance → stream events.
4. `SYNTHESIS.md` updated with a "Verified" section; tracker `01-tracker.md` shows
   `done=21/21`.
