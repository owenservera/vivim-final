# Unit 23.1: ConfigUniversalSurface

**Phase:** 23 | **File:** `src/engines/config-universal-surface.ts`
**Depends:** ConfigManager, ConfigStore, TelemetryAggregator | **Source:** PRD §Implementation Decisions (module 7)

## Purpose
Aggregate EVERY configuration point of the system behind one testable interface
with `list()`, `get(scope, key)`, `set(scope, key, value)`, `snapshot()`, `rollback(id)`.
Zod-validated per scope. `set` emits `config:changed` on CapabilityEventBus.

## Scopes (initial)
- `engine:<id>` — engine config (from KernelRegistry descriptor.config)
- `capability:<id>` — capability config
- `store:<id>` — store config
- `route:<id>` — route config
- `autoheal` — OracleActuator AutoHealPolicy
- `nlcl` — NLCL resolver config (resolver, aiFallback, ...)
- `stealth` — stealth profile config
- `provider:<id>` — provider definition fields
- `workflow:<id>` — workflow DAG definition
- `canvas:layer:<slug>` — canvas layer definition bindings
- `kernel:topology` — live kernel topology
- `telemetry` — telemetry pipeline (via TelemetryAggregator.reprogram)

## Interface
```typescript
interface ConfigScope { id: string; description: string; schema?: ZodSchema; source: string }
interface ConfigValue { scope: string; key: string; value: unknown; updatedAt: number }
class ConfigUniversalSurface {
  constructor(deps: {
    registry: UnifiedCapabilityRegistry
    kernel?: Kernel
    configManager: ConfigManager
    configStore?: ConfigStore
    telemetry?: TelemetryAggregator
    eventBus: CapabilityEventBus
  })
  listScopes(): ConfigScope[]
  get(scope: string, key: string): ConfigValue
  set(scope: string, key: string, value: unknown): ConfigValue   // Zod-validated
  snapshot(): string                                             // returns snapshot id
  rollback(id: string): void
}
```

## Tests
- listScopes returns all 12 scopes
- get/set round-trips a value
- set rejects invalid value via Zod (boundary test)
- set emits `config:changed` on eventBus
- snapshot/rollback restores prior state
