# Unit 3.4 — Frontend: Message List with Live Streaming Updates

**Phase:** 3 | **ID:** 3.4 | **Dependencies:** 3.3

## Problem

The ConversationSurface from Unit 2.8 renders complete messages. For streaming, it needs to progressively update a message as blocks arrive over WebSocket.

## Spec

### Streaming-Aware Message State

```tsx
// web/sandbox/src/features/conversation-surface.tsx

interface StreamingMessage {
  id: string
  role: 'assistant'
  blocks: ContentBlock[]
  isStreaming: boolean
}

// In ConversationSurface component:

const [streamingMessage, setStreamingMessage] = useState<StreamingMessage | null>(null)

useEffect(() => {
  const ws = new WebSocket('ws://localhost:9420/ws')
  
  ws.onopen = () => {
    ws.send(JSON.stringify({
      type: 'subscribe',
      entityType: 'conversation',
      entityId: conversationId,
    }))
  }
  
  ws.onmessage = (ev) => {
    const msg = JSON.parse(ev.data)
    
    switch (msg.type) {
      case 'conversation:stream_start':
        // Start new streaming message
        setStreamingMessage({
          id: msg.messageId,
          role: 'assistant',
          blocks: [],
          isStreaming: true,
        })
        break
        
      case 'conversation:block':
        // Append block to streaming message
        setStreamingMessage(prev => prev ? {
          ...prev,
          blocks: [...prev.blocks, msg.block],
        } : null)
        break
        
      case 'conversation:stream_end':
      case 'conversation:complete':
        // Finalize: move streaming message to permanent list
        if (streamingMessage) {
          const text = streamingMessage.blocks
            .filter(b => b.kind === 'text')
            .map(b => b.content)
            .join('')
          setMessages(prev => [...prev, {
            id: streamingMessage.id,
            role: 'assistant',
            content: text,
            blocks: streamingMessage.blocks,
            createdAt: Date.now(),
          }])
          setStreamingMessage(null)
        }
        break
    }
  }
  
  return () => ws.close()
}, [conversationId])
```

### Text Accumulation for Partial Blocks

SSE deltas may arrive as partial text chunks. Accumulate them:

```tsx
// Instead of rendering each block separately, accumulate text blocks
const accumulatedText = streamingMessage.blocks
  .filter(b => b.kind === 'text')
  .reduce((acc, b) => acc + (b as any).content, '')

// For non-text blocks, render them as they arrive
const nonTextBlocks = streamingMessage.blocks.filter(b => b.kind !== 'text')
```

### Performance: RequestAnimationFrame Batching

Multiple blocks may arrive within a single frame. Batch updates:

```tsx
const pendingBlocks = useRef<ContentBlock[]>([])
const rafId = useRef<number | null>(null)

const flushBlocks = () => {
  if (pendingBlocks.current.length === 0) return
  setStreamingMessage(prev => prev ? {
    ...prev,
    blocks: [...prev.blocks, ...pendingBlocks.current],
  } : null)
  pendingBlocks.current = []
  rafId.current = null
}

// In ws.onmessage:
case 'conversation:block':
  pendingBlocks.current.push(msg.block)
  if (!rafId.current) {
    rafId.current = requestAnimationFrame(flushBlocks)
  }
  break
```
