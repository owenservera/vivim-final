# Unit 3.3 — Streaming: Progressive Block Delivery over WebSocket

**Phase:** 3 | **ID:** 3.3 | **Dependencies:** 2.5, 2.7

## Problem

Currently, the full response is captured and parsed only after completion. Users see nothing for 10-30 seconds. We need to stream content blocks to the frontend as they arrive.

## Spec

### Architecture: Chunked Capture → Incremental Parse → WS Forward

```
Network.dataReceived event
  → CdpTransportImpl captures chunk
  → StreamingProtocol.captureChunk(convId, msgId, chunk)
    → Parser.parse(chunk) → incremental ContentBlocks
    → EventBus.emit('conversation:block', { block })
      → WebSocket forwarder → Frontend
  → Frontend appends block to current message
```

### Implementation: Stream-Aware Send Pipeline

Replace the current "capture full body then parse" with progressive streaming:

```typescript
// ConversationManager.send() — streaming version

async sendStreaming(conversationId: string, message: string): Promise<void> {
  // ... steps 1-5 (resolve, ensure, type, submit) same as before ...
  
  // [6] STREAM CAPTURE
  const capturePattern = CAPTURE_PATTERNS[conv.providerId]
  const messageId = `msg_${Date.now()}`
  
  // Start streaming protocol
  await this.streamingProtocol.startConversation(conversationId)
  
  // Set up progressive capture
  const client = this.getClient(slaveId)
  await client.send('Network.enable')
  
  const matchingRequests = new Set<string>()
  let accumulatedBody = ''
  
  client.on('Network.responseReceived', (params) => {
    if (params.response?.url && capturePattern.test(params.response.url)) {
      matchingRequests.add(params.requestId)
    }
  })
  
  client.on('Network.dataReceived', async (params) => {
    if (!matchingRequests.has(params.requestId)) return
    
    // Try to get partial body
    try {
      const result = await client.send('Network.getResponseBody', {
        requestId: params.requestId,
      })
      if (result.body && result.body.length > accumulatedBody.length) {
        const newChunk = result.body.slice(accumulatedBody.length)
        accumulatedBody = result.body
        
        // Parse and emit incrementally
        await this.streamingProtocol.captureChunk(
          conversationId, messageId, newChunk
        )
      }
    } catch { /* body not ready yet */ }
  })
  
  client.on('Network.loadingFinished', async (params) => {
    if (!matchingRequests.has(params.requestId)) return
    
    // Final body
    const result = await client.send('Network.getResponseBody', {
      requestId: params.requestId,
    })
    
    await this.streamingProtocol.finishConversation(conversationId, messageId)
    
    // Store final message
    await this.store.createMessage({ ... })
    
    // Cleanup
    client.off('Network.responseReceived', ...)
    client.off('Network.dataReceived', ...)
    client.off('Network.loadingFinished', ...)
    await client.send('Network.disable')
  })
}
```

Some providers use `fetch()` for streaming. CDP can intercept fetch:

// Enable Fetch domain for the streaming URL pattern
await client.send('Fetch.enable', {
  patterns: [{ urlPattern: '*', requestStage: 'Response' }]
})

client.on('Fetch.requestPaused', async (params) => {
  if (!capturePattern.test(params.request.url)) {
    await client.send('Fetch.continueResponse', { requestId: params.requestId })
    return
  }
  
  // Get response body progressively
  const response = await client.send('Fetch.getResponseBody', { requestId: params.requestId })
  
  // ... parse and emit blocks ...
  
  // Continue the response
  await client.send('Fetch.continueResponse', { requestId: params.requestId })

### WebSocket Forwarding

```typescript
// In server bootstrap, wire conversation:block events to WebSocket
eventBus.on('conversation:block', (event) => {
  const msg = JSON.stringify({
    type: 'conversation:block',
    conversationId: event.conversationId,
    messageId: event.messageId,
    block: event.block,
    timestamp: event.timestamp,
  })
  // Forward to all subscribed clients
  for (const session of wsSessions.values()) {
    if (session.subscriptions.has(`conversation:${event.conversationId}`)) {
      session.ws.send(msg)
    }
  }
})
```
