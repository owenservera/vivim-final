# Unit 4.3 — Gemini Selector + Parser E2E Verification

**Phase:** 4 | **ID:** 4.3 | **Dependencies:** 3.6

## Problem

Gemini (Google Bard) uses a Quill-based contenteditable editor and returns a non-standard batch JSON format. The parser is the most complex of the three providers.

### Gemini Parser Verification

Gemini's response format is nested JSON arrays prefixed with XSSI protection:

```
)]}'

[["wrb.fr","qEhBsd","[[null,null,[\"\\\"2+2 equals 4.\\\"\"]]]"]]
```

The parser must:
1. Strip the `)]}'` prefix
2. Parse outer JSON array
3. Find inner JSON strings
4. Parse those as JSON arrays
5. Extract text from the deeply nested structure

### Verification Script

```typescript
async function verifyGeminiE2E(governor, cm) {
  const results = []
  
  const slave = await governor.spawn('gemini', 'test')
  results.push({ step: 'spawn', ok: !!slave })
  
  await governor.cdp.send(slave.slaveId, 'Page.navigate', { url: 'https://gemini.google.com/' })
  await delay(5000)
  
  // Check login (Google account)
  const loginCheck = await governor.cdp.send(slave.slaveId, 'Runtime.evaluate', {
    expression: `!!document.querySelector('a[aria-label*="Account"], img[alt*="Account"]')`,
    returnByValue: true,
  })
  results.push({ step: 'login', ok: loginCheck?.result?.value === true })
  
  // Check composer (Quill)
  const composerCheck = await governor.cdp.send(slave.slaveId, 'Runtime.evaluate', {
    expression: `!!document.querySelector('.ql-editor, [contenteditable]')`,
    returnByValue: true,
  })
  results.push({ step: 'composer', ok: composerCheck?.result?.value === true })
  
  // Send — Gemini requires clicking send button (Enter doesn't work in Quill)
  const conv = await cm.createConversation('gemini', 'E2E Test')
  const sendResult = await cm.send(conv.id, 'What is 2+2? Reply with just the number.')
  results.push({ step: 'send', ok: sendResult.ok, detail: sendResult.text })
  
  return results
}
```

### Parser Unit Test with Real Data

```typescript
test('Gemini parser handles batch JSON', () => {
  const sampleResponse = `)]}'

[["wrb.fr","qEhBsd","[[null,null,[\\"\\\\"The answer is 4.\\"\\"]]\\"],[null,null,[]]]"]],`
  
  const blocks = geminiParser.parse(sampleResponse)
  expect(blocks.length).toBeGreaterThan(0)
  expect(blocks[0].kind).toBe('text')
  expect(blocks[0].content).toContain('4')
})
```

test('Gemini E2E', async () => {
