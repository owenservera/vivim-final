# Unit 4.2 — Claude Selector + Parser E2E Verification

**Phase:** 4 | **ID:** 4.2 | **Dependencies:** 3.6

## Problem

Claude.ai uses a contenteditable div composer and Anthropic SSE format for streaming. The selectors and parser need E2E verification.

## Spec

### Claude-Specific Selectors

```typescript
const CLAUDE_SELECTORS = {
  composer: 'div[contenteditable="true"][role="textbox"]',
```

### Claude Parser Verification

Claude's SSE format:
```
event: message_start
data: {"type":"message_start","message":{"id":"msg_...","type":"message",...}}

event: content_block_start
data: {"type":"content_block_start","index":0,"content_block":{"type":"text","text":""}}

event: content_block_delta
data: {"type":"content_block_delta","index":0,"delta":{"type":"text_delta","text":"Hello"}}

event: content_block_stop
data: {"type":"content_block_stop","index":0}

event: message_delta
data: {"type":"message_delta","delta":{"stop_reason":"end_turn"},"usage":{...}}

event: message_stop
data: {"type":"message_stop"}
```

### Verification Script

```typescript
async function verifyClaudeE2E(governor, cm) {
  const results = []
  
  const slave = await governor.spawn('claude', 'test')
  results.push({ step: 'spawn', ok: !!slave })
  
  await governor.cdp.send(slave.slaveId, 'Page.navigate', { url: 'https://claude.ai/' })
  await delay(5000)
  
  // Check login
  const loginCheck = await governor.cdp.send(slave.slaveId, 'Runtime.evaluate', {
    expression: `!!document.querySelector('button[aria-label*="Profile"], a[href*="login"]')`,
    returnByValue: true,
  })
  const hasProfile = await governor.cdp.send(slave.slaveId, 'Runtime.evaluate', {
    expression: `!!document.querySelector('[data-testid="user-menu"], .account-menu')`,
    returnByValue: true,
  })
  results.push({ step: 'login', ok: hasProfile?.result?.value === true })
  
  // Check composer (contenteditable)
  const composerCheck = await governor.cdp.send(slave.slaveId, 'Runtime.evaluate', {
    expression: `!!document.querySelector('div[contenteditable="true"]')`,
    returnByValue: true,
  })
  results.push({ step: 'composer', ok: composerCheck?.result?.value === true })
  
  // Send
  const conv = await cm.createConversation('claude', 'E2E Test')
  const sendResult = await cm.send(conv.id, 'What is 2+2? Reply with just the number.')
  results.push({ step: 'send', ok: sendResult.ok, detail: sendResult.text })
  
  return results
}
```

## Test

```typescript
test('Claude E2E', async () => {
  const results = await verifyClaudeE2E(governor, cm)
  for (const r of results) {
    expect(r.ok, `${r.step}: ${r.detail}`).toBe(true)
  }
})
```
