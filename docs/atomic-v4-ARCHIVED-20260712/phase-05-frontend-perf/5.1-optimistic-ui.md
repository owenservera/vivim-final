# Unit 5.1 — Optimistic UI: Instant Message Echo on Send

**Phase:** 5 | **ID:** 5.1 | **Dependencies:** 3.4

## Problem

Users expect their message to appear instantly when they press Enter. Currently the frontend waits for the HTTP response before showing the user message. This adds perceived latency.

## Spec

### Instant Echo Pattern

```tsx
const handleSend = useCallback(async () => {
  if (!input.trim() || sending) return
  
  const messageText = input.trim()
  setSending(true)
  setInput('')
  
  // INSTANT: Show user message immediately (before HTTP)
  const tempId = `temp_${Date.now()}`
  const optimisticUserMsg: Message = {
    id: tempId,
    role: 'user',
    content: messageText,
    createdAt: Date.now(),
    pending: true,  // mark as pending
  }
  setMessages(prev => [...prev, optimisticUserMsg])
  
  // INSTANT: Show typing indicator for assistant
  const tempAssistantId = `temp_assistant_${Date.now()}`
  setStreamingMessage({
    id: tempAssistantId,
    role: 'assistant',
    blocks: [],
    isStreaming: true,
  })
  
  try {
    const resp = await fetch(`/api/conversations/${conversationId}/send`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ message: messageText }),
    })
    const result = await resp.json()
    
    if (result.ok) {
      // Confirm user message (remove pending flag)
      setMessages(prev => prev.map(m => 
        m.id === tempId ? { ...m, pending: false, id: 'confirmed' } : m
      ))
      // Assistant message arrives via WebSocket streaming
    } else {
      // FAILED: Remove optimistic messages, show error
      setMessages(prev => prev.filter(m => m.id !== tempId))
      setStreamingMessage(null)
      setError(result.error || 'Send failed')
    }
  } catch (err) {
    // Network error: Remove optimistic messages
    setMessages(prev => prev.filter(m => m.id !== tempId))
    setStreamingMessage(null)
    setError(String(err))
  } finally {
    setSending(false)
  }
}, [input, conversationId, sending])
```

### Pending Message Styling

```tsx
function MessageBubble({ message }: { message: Message }) {
  const isPending = message.pending
  return (
    <div className={`mb-3 ${message.role === 'user' ? 'text-right' : ''}`}>
      <div
        className={`inline-block px-4 py-2 rounded-lg max-w-[80%] ${
          message.role === 'user'
            ? isPending
              ? 'bg-blue-300 text-white opacity-70'  // pending style
              : 'bg-blue-600 text-white'              // confirmed style
            : 'bg-gray-100'
        }`}
      >
        {message.content}
      </div>
    </div>
  )
}
```

### Input Clear on Submit

The input should clear immediately on Enter/click, not after the HTTP response. This gives instant feedback.

### Enter Key Behavior

```tsx
onKeyDown={e => {
  if (e.key === 'Enter' && !e.shiftKey) {
    e.preventDefault()
    handleSend()
  }
}}
```

## Performance Target

- User message appears: < 16ms (1 frame) after Enter
- Input clears: < 16ms after Enter
- Typing indicator appears: < 16ms after Enter
- No layout shift during optimistic update

## Test

```typescript
test('optimistic echo appears within one frame', async () => {
  const input = screen.getByPlaceholderText('Type a message...')
  await user.type(input, 'Hello{Enter}')
  
  // User message should appear immediately
  await waitFor(() => {
    expect(screen.getByText('Hello')).toBeInTheDocument()
  }, { timeout: 50 })  // should be near-instant
})
```
