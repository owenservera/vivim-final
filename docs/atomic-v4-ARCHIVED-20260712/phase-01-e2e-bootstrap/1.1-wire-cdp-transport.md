# Unit 1.1 — Wire CDP Transport into ChromeGovernor Bootstrap

**Phase:** 1 | **ID:** 1.1 | **Dependencies:** none

## Problem

`createServerWithEngines()` in `src/server/index.ts:212` creates a `ChromeGovernor` but never calls `setCdpTransport()`. This makes `governor.cdp` throw `EngineError('CDP transport not configured')` at runtime, blocking all CDP operations.

## Spec

### File: `src/server/index.ts`

After governor construction (line ~220), add:

```typescript
import { CdpTransportImpl } from '../executor/cdp-transport.js'

// Inside createServerWithEngines, after governor construction:
const cdpTransport = new CdpTransportImpl()
governor.setCdpTransport(cdpTransport)
governor.setTraceLog(govStore)
governor.setHealthMonitor(govStore)
```

### Shutdown Hook

Register a shutdown hook to disconnect all CDP clients:

```typescript
onShutdown(async () => {
  await cdpTransport.disconnectAll()
  await governor.killAll()
})
```

### Verification

```typescript
// After boot, verify transport is wired:
const state = await governor.cdp.getPageState('test')
// Should not throw — returns { url: '', title: '', readyState: 'unavailable' } if no slave
```
