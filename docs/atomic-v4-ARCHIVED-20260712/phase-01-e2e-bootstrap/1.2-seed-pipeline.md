# Unit 1.2 — Provider Seed Pipeline at Boot

**Phase:** 1 | **ID:** 1.2 | **Dependencies:** none

## Problem

Provider seeds (`seeds/providers/*.json`) are not loaded at server boot. The DB has no provider definitions, endpoints, parsers, or capabilities unless manually seeded.

## Spec

### File: `src/server/index.ts`

In `createServerWithEngines()`, after DB init, before engine wiring:

```typescript
import { ProviderRegistrar } from '../engines/provider-registrar.js'
import { ProviderStoreImpl } from '../storage/impl/provider-store-impl.js'

// After db init:
const providerStore = new ProviderStoreImpl(db)
const registrar = new ProviderRegistrar(providerStore, undefined, eventBus)

// Seed all providers (idempotent — upserts)
const seedResult = await registrar.seedAll()
console.log(`[boot] Seeded ${seedResult.seeded.length} providers, ${seedResult.errors.length} errors`)

// Verify seeds are valid
const verifyResult = await registrar.verifySeeds()
if (!verifyResult.valid) {
  console.warn('[boot] Seed verification warnings:', verifyResult.providers.filter(p => p.status !== 'ok'))
}
```

### Idempotency

`ProviderRegistrar.register()` uses upsert semantics — calling `seedAll()` on every boot is safe. It will update existing providers if seed files change, and create new ones if they don't exist.

### Required Seeds

The following seed files must exist and be valid:
- `seeds/providers/chatgpt.json`
- `seeds/providers/claude.json`
- `seeds/providers/gemini.json`
- `seeds/providers/system.json` (generic system provider)

### Parser Seeds

Parser seeds must also be loaded. The parsers are referenced by the provider manifests via `parsers[].file` path. The `StreamParserEngine` loads them lazily from DB on first parse call, but preloading ensures they're available:

```typescript
import { ParserStoreImpl } from '../storage/impl/parser-store-impl.js'

const parserStore = new ParserStoreImpl(db)
await parserEngine.preloadAll()
```

Uses existing `ProviderStore` contract. No changes needed.

## Test

```typescript
test('providers seeded after boot', async () => {
  const ctx = await createServerWithEngines(0)
  const providers = await ctx.db.listProviders()
  expect(providers.length).toBeGreaterThanOrEqual(3)
  expect(providers.some(p => p.slug === 'chatgpt')).toBe(true)
  expect(providers.some(p => p.slug === 'claude')).toBe(true)
  expect(providers.some(p => p.slug === 'gemini')).toBe(true)
})
```
