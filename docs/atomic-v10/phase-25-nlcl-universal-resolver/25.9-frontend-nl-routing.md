# Unit 25.9: Frontend Chat Box NL Routing

**Phase:** 25 | **Files:** `web/sandbox/src/features/conversation-surface.tsx`
**Depends:** 25.7 | **Class:** CREATE

## Purpose
The frontend composer currently sends arbitrary text as a chat message. Make it NL-aware:
detect whether the user typed a **command** (routable by NLCL) or a **message** (a
normal chat turn), and route commands to `/api/interpret` while messages go to the
existing conversation send path. This is the exact mirror of the CLI REPL (25.8) — one
transport, two shells.

## Interface
```ts
// composer submit handler
async function onSubmit(text: string) {
  if (looksLikeCommand(text)) {
    const res = await fetch('/api/interpret', {
      method: 'POST',
      body: JSON.stringify({ text, ctx: { conversationId, providerId, canvasState } }),
    })
    // render clarification / confirmation / executed output
  } else {
    await sendMessage(conversationId, text)   // existing path
  }
}
```
`looksLikeCommand` heuristic: leading `/`, or text that NLCL confidently resolves
(server can pre-check via a lightweight `GET /api/interpret?dry=true`, or just always
attempt interpret and fall back to message on `classification: 'communication'` with
no capability match).

## Implementation
- In `conversation-surface.tsx`, the send handler branches on command vs message.
- Render `clarification` prompts inline (asks the user the missing value, then
  re-calls `/api/interpret` with `ctx.metadata.clarificationId`).
- Render `requiresConfirmation` as an inline confirm/cancel action (re-calls
  `/api/capabilities/:id/execute` with the token).
- Capability results that mutate the canvas (Phase 26) or channels (Phase 27) trigger
  their respective live-update subscriptions.
- Keep the existing streaming block delivery path for normal messages untouched.

## Tests
- Typing "/list providers" routes to `/api/interpret` and renders the provider list.
- Typing "what's the weather?" (no capability) falls back to a normal message send.
- A clarification response re-invokes interpret with the supplied value.
