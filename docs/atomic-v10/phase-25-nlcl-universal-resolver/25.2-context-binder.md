# Unit 25.2: Context Binder

**Phase:** 25 | **Files:** `src/engines/nlcl/context-binder.ts` (new)
**Depends:** 25.1 | **Class:** CREATE

## Purpose
Resolution is context-bound: the same sentence means different things depending on
which provider, conversation, canvas, or active session the user is in. The binder
turns the ambient request context (`conversationId`, `providerId`, `canvasState`,
`activeSessionId`) into a normalized `NLCContext` and resolves pronouns
("it", "the canvas", "my account", "switch to claude") against live state so the
resolver and parameter extractor downstream get grounded inputs.

## Interface
```ts
export interface RawRequestContext {
  conversationId?: string
  providerId?: string
  canvasState?: { activeLayerId?: string; background?: string }
  activeSessionId?: string
  userId?: string
  metadata?: Record<string, unknown>
}

export function bindContext(
  raw: RawRequestContext,
  deps: {
    conversationStore?: ConversationStore
    governor?: ChromeGovernor
  },
): Promise<NLCContext>

export function resolvePronouns(
  text: string,
  ctx: NLCContext,
): string   // rewrites "it"/"the canvas" → concrete ref the catalog can match
```

## Implementation
- New `context-binder.ts`. `bindContext`:
  - Maps raw fields to `NLCContext` (`surface` supplied by caller: `'cli' | 'ui' | ...`).
  - Augments `metadata` with `canvasState.activeLayerId` / `activeSessionId` so
    parameter extraction (25.5) and capabilities can read them.
  - If `providerId` missing but `conversationId` present, look up the conversation's
    provider via `conversationStore.get` to fill `providerId`/`accountId`.
- `resolvePronouns`:
  - `"the canvas"` → `canvas:${activeLayerId ?? 'root'}` token; `"it"` → previous
    resolved subject from `ctx.metadata.lastSubject`.
  - `"my account"` / `"switch to <provider>"` → resolved to a `providerId` via the
    governor's known instances (no-op if unknown; leaves ambiguity for 25.6).
- Wired into `NLCLEngine.interpret` (before `resolver.resolve`) and into
  `/api/interpret` (25.7) and the CLI REPL (25.8).

## Tests
- `bindContext({conversationId:'c1'})` resolves `providerId` from the conversation row.
- `resolvePronouns('change its background', {metadata:{lastSubject:'canvas:root'}})` → `'change canvas:root background'`.
- Missing context fields do not throw; binder returns a valid `NLCContext` with defaults.
