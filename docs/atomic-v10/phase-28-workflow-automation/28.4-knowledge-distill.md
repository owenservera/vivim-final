# Unit 28.4: Knowledge Distill Capability

**Phase:** 28 | **Files:** `src/engines/cross-conversation-synthesis.ts` (extend)
**Depends:** 24.1 | **Class:** PORT

## Purpose
Distillation is the "brain" of the newsletter (and any summary workflow). The
`CrossConversationSynthesizer` already exists; expose `knowledge_distill { window }`
as a capability so workflows (28.2) and NL (*"summarize the week's work"*) can call it
through the registry.

## Interface
```ts
// registered capability:
//  cap:knowledge:distill  { window: string }   // e.g. '7d', '24h', '30d'
//  → output: { summary: string, sources: string[], topics: string[] }
```

## Implementation
- Extend `CrossConversationSynthesizer` with a `distill(window)` method (parses the
  window into a time range, queries conversations/memory in range, synthesizes).
- Register `cap:knowledge:distill` in `capability-bootstrap.ts` (the synthesizer is
  already in `BootstrapServices`).
- Used as a node type in workflow templates (28.2) and directly via `/api/interpret`.

## Tests
- `cap:knowledge:distill {window:'7d'}` returns a `summary` + `sources` for seeded
  conversations in range.
- Invalid window string → validation error (400), not a crash.
