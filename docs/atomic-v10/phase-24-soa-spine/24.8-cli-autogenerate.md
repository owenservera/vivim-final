# Unit 24.8: CLI Auto-Generates from Registry

**Phase:** 24 | **Files:** `src/cli/index.ts`, `src/cli/commands/registry-bridge.ts`, delete `src/cli/bridges/*`
**Depends:** 24.4, 24.5, 24.6 | **Class:** FIX

## Purpose
The standalone CLI (`vivim <cmd>`) currently registers 7 hand-written commands
with broken HTTP paths and never calls `syncCliFromUnified`. Make the CLI a thin
shell: it connects to a running server (default `http://127.0.0.1:9420`) and
auto-generates every command from the registry via introspection.

## Interface
```bash
vivim [--remote <url>] [--auth <token>] <command> [args] [--flags]
vivim                                    # → REPL (25.8)
vivim help                               # → fetched from GET /api/capabilities?surface=cli
vivim providers list                     # → POST /api/capabilities/provider_list/execute
vivim kernel oracle query --op health    # → POST /api/capabilities/oracle_query/execute
vivim nl "load chatgpt"                  # → POST /api/interpret
```

## Implementation
- Rewrite `cli/index.ts`:
  - Parse `--remote` (default from `CAPSTORE_URL`/`localhost:9420`) and `--auth`.
  - On startup, `GET /api/capabilities?surface=cli` → build `CommandRegistry` entries where each handler is `async (args) => { const input = argvToInput(args, cap.inputSchema); return { data: await bridge.post('/api/capabilities/'+cap.id+'/execute', {input}) } }`.
  - `argvToInput`: map positional `args[]` + `--flag val` → object matching `inputSchema.properties` (positional → first N required props; flags → by name).
  - `--json` flag selects output mode (reuse `OutputFormatter`).
- Promote `registry-bridge.ts:36` `jsonSchemaToZod` to also drive `argvToInput` (inverse).
- `connectCapabilityRegistry()` becomes optional (only used when CLI runs in-process inside the server).
- Delete `cli/bridges/cap-store-bridge.ts`, `backend-bridge.ts`, `extension-bridge.ts` (the universal route replaces them).
- Keep `pipeline-engine.ts` (Phase 25.4 composites via NLCL).

## Tests
- `vivim providers list --remote http://localhost:9420` returns same as `GET /api/providers`.
- `vivim help` lists ≥24 commands fetched from server.
- Unknown command → exit 1 with "did you mean" fuzzy hint.
