# Unit 29.2: CLI REPL Interactive Session Loop

**Phase:** 29 | **Files:** `src/cli/repl.ts` (extend from 25.8)
**Depends:** 25.8, 29.1 | **Class:** CREATE

## Purpose
Make the REPL a full interactive session host (Scenario 2 end-to-end). After
`session_load`, the REPL streams the provider's responses and treats each subsequent
line as a message to the active session until the user switches/exits.

## Interface
```bash
$ vivim
> load my chatgpt.com and start an interactive session
[spawning chrome slave for chatgpt... session active: sess_1]
> what is quantum computing
[streaming response from chatgpt...]
> switch to claude
[session active: sess_2]
```

## Implementation
- Extend `src/cli/repl.ts` (25.8): maintain `activeSessionId` in REPL-local `ctx`.
- `session_load`/`session_switch` (29.1) update `activeSessionId`; subsequent lines are
  sent as messages via `conversation_send` (or the session's send path) with the
  active `conversationId`.
- Streaming responses from the active session print to stdout as they arrive (reuse the
  25.8 streaming path).
- `pronoun` resolution ("ask **it**…", "switch to claude") already handled by
  `resolvePronouns` (25.2) once `providerId`/`activeSessionId` are in `ctx`.

## Tests
- Spawned REPL: `load chatgpt` then `what is quantum computing` (mocked) prints a streamed
  response; `switch to claude` changes the active session id.
- REPL survives a session send error and keeps looping.
