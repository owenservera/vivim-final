# Unit 3.2 — DOM Recovery: Page Reload + SPA Navigation Handling

**Phase:** 3 | **ID:** 3.2 | **Dependencies:** 3.1

## Problem

Provider SPAs can reload or navigate between turns:
- ChatGPT: Redirects to `/c/{conversation-id}` after first message
- Claude: Navigates to `/chat/{conversation-id}`
- Gemini: URL stays the same but DOM structure changes

When the page changes, the composer selector may no longer match, and the capture pattern URL may be different.

## Spec

### Adaptive Selector Strategy

Instead of hardcoding one selector, try a list of fallback selectors:

```typescript
const COMPOSER_SELECTORS: Record<string, string[]> = {
  chatgpt: [
    '#prompt-textarea',
    'textarea[data-testid="prompt-textarea"]',
    'textarea',
    '[contenteditable][role="textbox"]',
  ],
  claude: [
    'div[contenteditable="true"]',
    '[role="textbox"]',
    'fieldset textarea',
    'textarea',
  ],
  gemini: [
    'div.ql-editor[contenteditable="true"]',
    '.ql-editor',
    'rich-textarea [contenteditable]',
    'textarea',
  ],
}

async function findComposer(governor, slaveId, providerId): Promise<string | null> {
  const selectors = COMPOSER_SELECTORS[providerId] ?? ['textarea']
  for (const selector of selectors) {
    const exists = await governor.cdp.send(slaveId, 'Runtime.evaluate', {
      expression: `!!document.querySelector(${JSON.stringify(selector)})`,
      returnByValue: true,
    })
    if (exists?.result?.value === true) return selector
  }
  return null
}
```

### Page Navigation Detection

After each send, detect if the URL changed (indicating SPA navigation):

```typescript
// After send, check if URL changed
const postSendState = await governor.cdp.getPageState(slaveId)
if (postSendState.url !== preSendState.url) {
  // SPA navigated — update stored URL
  await store.updateConversation(conversationId, {
    lastKnownUrl: postSendState.url,
  })
}
```

### Wait For Composer Ready

After page navigation, the composer may take time to render. Wait for it:

```typescript
async function waitForComposer(governor, slaveId, providerId, timeoutMs = 10_000) {
  const deadline = Date.now() + timeoutMs
  while (Date.now() < deadline) {
    const selector = await findComposer(governor, slaveId, providerId)
    if (selector) return selector
    await new Promise(r => setTimeout(r, 200))
  }
  throw new EngineError(`Composer not found for ${providerId} after ${timeoutMs}ms`)
}
```

### Provider-Specific URL Patterns

```typescript
const PROVIDER_URL_PATTERNS: Record<string, RegExp> = {
  chatgpt: /^https:\/\/chatgpt\.com\/(c\/.*)?$/,
  claude: /^https:\/\/claude\.ai\/(chat\/.*)?$/,
  gemini: /^https:\/\/gemini\.google\.com\/(app\/.*)?$/,
}
```
