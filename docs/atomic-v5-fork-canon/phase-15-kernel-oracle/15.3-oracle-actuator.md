# 15.3 — OracleActuator

**Phase:** 15 · **Domain:** Kernel Oracle · **Status:** DRAFT

## Purpose

Self-healing actions — detect problems, fix them automatically or with approval. The
oracle's "hands" — translates diagnostic issues into corrective actions.

## Interface

```typescript
export interface HealAction {
  id: string
  issueId: string
  kind: 'restart-engine' | 'reconfigure' | 'clear-cache' | 'reset-circuit' | 'reconnect' | 'notify'
  engineId: string
  description: string
  parameters: Record<string, unknown>
  status: 'pending' | 'executing' | 'completed' | 'failed'
  result?: string
  executedAt?: number
}

export interface AutoHealPolicy {
  stalledEngineRestart: { enabled: boolean; timeoutMs: number }
  circuitBreakerReset: { enabled: boolean; cooldownMs: number }
  configFallback: { enabled: boolean; defaults: Record<string, unknown> }
  notify: { enabled: boolean; channels: string[] }
}

export class OracleActuator {
  heal(issueId: string): Promise<HealAction>
  getActions(limit?: number): Promise<HealAction[]>
  getAction(id: string): Promise<HealAction | null>
  undo(actionId: string): Promise<void>

  getAutoHealPolicy(): Promise<AutoHealPolicy>
  setAutoHealPolicy(policy: AutoHealPolicy): Promise<void>
}
```

## Design

### Heal Actions by Issue Category

| Category | Action | Auto-fixable |
|----------|--------|-------------|
| `stalled` | `restart-engine` | ✅ Yes |
| `broken-wire` | `reconnect` | ⚠️ Sometimes |
| `missing-dep` | `notify` | ❌ No (manual) |
| `health-degraded` | `reset-circuit` | ✅ Yes |
| `config-missing` | `reconfigure` (use defaults) | ✅ Yes |
| `schema-mismatch` | `notify` | ❌ No (manual) |
| `stub` | `notify` | ❌ No (manual) |

### Auto-Heal Flow

```
DiagnosticIssue detected
  → Check AutoHealPolicy
  → If autoFixable && policy allows:
      → Execute HealAction
      → Record result
      → Emit event
  → If not autoFixable:
      → Emit notification event
      → Wait for manual intervention
```
