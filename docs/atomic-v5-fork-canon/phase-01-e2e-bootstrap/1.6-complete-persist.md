# Unit 1.6 — Complete Setup: Persist Account with Profile + Port

**Phase:** 1 | **ID:** 1.6 | **Dependencies:** 1.5

## Problem

The `complete` endpoint persists the account but doesn't store all the metadata needed for runtime: the provider's login URL, the workspace path, and the Chrome fleet config. The account row needs enough data for FleetSupervisor to recreate the exact same Chrome environment headlessly.

## Spec

### Enhanced Complete Endpoint

```typescript
// POST /api/setup/complete
interface CompleteRequest {
  providerId: string
  accountSlug: string
  workspace: string
  profileDir: string
  debugPort: number
  loginUrl?: string
}

// Persist:
await ctx.db.upsertAccount({
  id: `${providerId}_${accountSlug}`,
  providerId,
  email: accountSlug,  // or actual email if detected
  planTier: 'free',    // detect from DOM if possible
  loginState: 'authenticated',
  profileDir,
  debugPort,
})

// Also persist workspace-level config:
await ctx.db.setWorkspaceHint(workspace)

// Optionally kill the visible Chrome (user may want to keep it):
// Leave visible Chrome running — user can close it manually.
// The headless slave will be spawned on first conversation.
```

### Provider-Aware Account Slug

The account slug should default to something useful. Options:
- Email address (if detectable from DOM)
- User-provided nickname ("work", "personal")
- Default: "default"

```typescript
// Try to detect email from DOM
const emailResult = await cdp.send('Runtime.evaluate', {

const detectedEmail = emailResult?.result?.value
```

### Plan Tier Detection

```typescript
// Detect plan tier from provider UI
const PLAN_DETECTORS: Record<string, string> = {
  chatgpt: `(() => {
    const text = document.body.textContent || ''
    if (text.includes('ChatGPT Plus') || text.includes('ChatGPT Pro')) return 'pro'
    if (text.includes('ChatGPT Team')) return 'team'
    return 'free'
  })()`,
  claude: `(() => {
    const text = document.body.textContent || ''
    if (text.includes('Claude Pro')) return 'pro'
    if (text.includes('Claude Max')) return 'max'
    return 'free'
  })()`,
  gemini: `(() => {
    const text = document.body.textContent || ''
    if (text.includes('Advanced')) return 'pro'
    return 'free'
  })()`,
}
```

## Store Contract

Uses existing `db.upsertAccount()`. Requires these fields in the account row:
- `id`: `{providerId}_{accountSlug}`
- `providerId`: provider slug
- `email`: account slug or detected email
- `planTier`: detected or 'free'
- `loginState`: 'authenticated'
- `profileDir`: absolute path to Chrome profile
- `debugPort`: port used during login (informational)

## Test

```typescript
test('complete setup persists all account metadata', async () => {
  await fetch('/api/setup/complete', {
    method: 'POST',
    body: JSON.stringify({
      providerId: 'chatgpt',
      accountSlug: 'work',
      workspace: 'C:\\test-ws',
      profileDir: 'C:\\test-ws\\chatgpt\\work',
      debugPort: 9222,
    })
  })
  
  const accounts = await fetch('/api/setup/profiles').then(r => r.json())
  expect(accounts.profiles).toHaveLength(1)
  expect(accounts.profiles[0].providerId).toBe('chatgpt')
  expect(accounts.profiles[0].profileDir).toBe('C:\\test-ws\\chatgpt\\work')
  expect(accounts.profiles[0].loginState).toBe('authenticated')
})
```
