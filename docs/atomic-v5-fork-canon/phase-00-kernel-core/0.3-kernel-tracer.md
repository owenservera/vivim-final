# 0.3 — KernelTracer

**Phase:** 0 · **Domain:** Kernel Core · **Status:** DRAFT

## Purpose

Span-based tracing engine. Every significant operation creates a span with timing,
status, and attributes. Provides the raw data for diagnostics and provenance.

## Interface

```typescript
export interface TraceSpan {
  id: string
  traceId: string
  parentId: string | null
  name: string
  startTime: number
  endTime?: number
  duration?: number
  status: 'ok' | 'error' | 'timeout'
  error?: string
  attrs: Record<string, unknown>
  engineId?: string
}

export class KernelTracer {
  // Create span from async function
  span<T>(
    name: string,
    parent: string | null,
    fn: () => Promise<T>,
    attrs?: Record<string, unknown>
  ): Promise<T>

  // Manual span lifecycle
  start(name: string, parent: string | null, attrs?: Record<string, unknown>): string
  end(spanId: string, extra?: Record<string, unknown>): Promise<void>
  error(spanId: string, error: Error): Promise<void>

  // Queries
  getTrace(traceId: string): TraceSpan[]
  getRecentSpans(limit?: number): TraceSpan[]
  getSpansByEngine(engineId: string, limit?: number): TraceSpan[]
  getActiveSpans(): TraceSpan[]

  // Trace ID generation
  newTraceId(): string
}
```

## Design

### Ring Buffer

- In-memory ring buffer of 500 spans (configurable)
- On overflow, batch-persist to `kernel_spans` table
- On query, merge ring buffer + DB results

### Span Lifecycle

```
1. start() → creates span in ring buffer, returns spanId
2. end(spanId) → sets endTime, duration, status='ok'
3. error(spanId, error) → sets endTime, status='error', error message
```

### Auto-Trace Wrapper

```typescript
// Usage:
const result = await kernel.tracer.span(
  'conversation-manager:send',
  parentSpanId,
  async () => {
    // ... actual operation
    return result
  },
  { providerId: 'chatgpt', conversationId: '...' }
)
```

If the function throws, the span is automatically marked as `error`.

## Store Contract

- `src/storage/contracts/kernel-store.ts`: `KernelStore`
  - `batchInsertSpans(spans)`: batch persist on ring buffer overflow
  - `querySpans(traceId)`: load spans by trace ID
  - `queryRecentSpans(limit)`: load most recent spans
  - `querySpansByEngine(engineId, limit)`: filter by engine
