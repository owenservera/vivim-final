# Unit 5.2 — WebSocket Debouncing for Streaming Block Batching

**Phase:** 5 | **ID:** 5.2 | **Dependencies:** 3.4

## Problem

Streaming SSE responses can deliver 50+ blocks per second. Each block triggers a WebSocket message → Zustand update → React re-render. This causes frame drops and janky scrolling.

## Spec

### RequestAnimationFrame Batching

```tsx
const pendingBlocksRef = useRef<ContentBlock[]>([])
const rafRef = useRef<number | null>(null)

const flushBlocks = useCallback(() => {
  rafRef.current = null
  if (pendingBlocksRef.current.length === 0) return
  
  const newBlocks = pendingBlocksRef.current
  pendingBlocksRef.current = []
  
  setStreamingMessage(prev => {
    if (!prev) return prev
    return {
      ...prev,
      blocks: [...prev.blocks, ...newBlocks],
    }
  })
}, [])

// In ws.onmessage handler:
case 'conversation:block':
  pendingBlocksRef.current.push(msg.block)
  if (rafRef.current === null) {
    rafRef.current = requestAnimationFrame(flushBlocks)
  }
  break

// Cleanup on unmount:
useEffect(() => {
  return () => {
    if (rafRef.current !== null) {
      cancelAnimationFrame(rafRef.current)
    }
  }
}, [])
```

### Text Block Merging

For text blocks specifically, merge consecutive deltas instead of rendering each separately:

```tsx
const renderStreamingContent = (blocks: ContentBlock[]) => {
  // Merge consecutive text blocks
  const merged: ContentBlock[] = []
  for (const block of blocks) {
    const last = merged[merged.length - 1]
    if (block.kind === 'text' && last?.kind === 'text') {
      // Merge into previous text block
      last.content += block.content
    } else {
      merged.push({ ...block })
    }
  }
  return renderBlocks(merged)
}
```

### Adaptive Batching Interval

For very fast streams, batch over 2 frames (~32ms) to reduce render frequency:

```tsx
const BATCH_FRAMES = blocksPerSecond > 100 ? 2 : 1
```

### Performance Metrics

```tsx
const renderCountRef = useRef(0)
const lastMeasureRef = useRef(performance.now())

// In flushBlocks:
renderCountRef.current++
const now = performance.now()
if (now - lastMeasureRef.current > 1000) {
  const fps = renderCountRef.current * 1000 / (now - lastMeasureRef.current)
  console.log(`[streaming] ${fps.toFixed(0)} renders/sec, ${pendingBlocksRef.current.length} blocks pending`)
  renderCountRef.current = 0
  lastMeasureRef.current = now
}
```

## Test

```typescript
test('batching prevents render flooding', () => {
  const onBlock = vi.fn()
  
  // Simulate 100 blocks in 100ms
  for (let i = 0; i < 100; i++) {
    ws.simulateMessage({ type: 'conversation:block', block: { kind: 'text', content: 'x', index: i } })
  }
  
  // Should only render once per frame
  expect(onBlock).toHaveBeenCalledTimes(1) // or at most 2)
})
```
