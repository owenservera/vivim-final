# 0.7 — Test Infrastructure Consolidation

**Phase:** 00 · **Domain:** Testing · **Status:** DRAFT · **Effort:** M (8h)

## Purpose

Consolidate test fixtures, create shared mock contracts, establish coverage targets,
and build KernelContext mock for testing. This unit enables all subsequent engine tests.

## Problem Statement

Current test infrastructure has:
- Scattered test fixtures across `tests/` directories
- No shared mock store contracts
- No KernelContext mock for testing engines in isolation
- No coverage targets enforced

## Implementation
