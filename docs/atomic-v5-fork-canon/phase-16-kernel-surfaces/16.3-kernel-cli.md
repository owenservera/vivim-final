# 16.3 — Kernel CLI

**Phase:** 16 · **Domain:** Kernel Surfaces · **Status:** DRAFT

## Purpose

CLI commands for kernel operations. Provides operator-friendly access to system
status, diagnostics, traces, and healing.

## Interface

```bash
# System overview
bun run kernel status              → system topology + health summary
bun run kernel status --engine X   → single engine details

# Diagnostics
bun run kernel diagnose            → scan all engines for issues
bun run kernel diagnose --engine X → scan single engine

# Tracing
bun run kernel trace <traceId>     → show trace tree (spans with timing)
bun run kernel trace --recent N    → show N most recent traces

# Provenance
bun run kernel provenance <traceId> → show causal chain
bun run kernel provenance --engine X → show provenance for engine

# Config
bun run kernel config <engineId>       → show engine config
bun run kernel config <engineId> --set 'key=value' → update config

# Oracle
bun run kernel oracle 'why did chatgpt fail?' → query oracle
bun run kernel oracle --heal <issueId>        → trigger heal

# Events
bun run kernel events --last N     → show N most recent kernel events
```

## Design

### CLI Implementation

```typescript
// src/cli/kernel-cli.ts
import { Command } from 'commander'

const kernelCmd = new Command('kernel')
  .description('VIVIM Kernel operations')

kernelCmd
  .command('status')
  .description('System topology + health summary')
  .option('--engine <id>', 'Show specific engine')
  .action(async (opts) => {
    const kernel = await getKernel()
    if (opts.engine) {
      const engine = kernel.registry.getEngine(opts.engine)
      printEngine(engine)
    } else {
      const topology = kernel.registry.describe()
      const health = await kernel.oracle.health()
      printTopology(topology, health)
    }
  })

kernelCmd
  .command('diagnose')
  .description('Scan for problems')
  .option('--engine <id>', 'Scan specific engine')
  .action(async (opts) => {
    const kernel = await getKernel()
    const issues = opts.engine
      ? await kernel.oracle.diagnoseEngine(opts.engine)
      : await kernel.oracle.diagnose()
    printIssues(issues)
  })

kernelCmd
  .command('trace <traceId>')
  .description('Show trace tree')
  .action(async (traceId) => {
    const kernel = await getKernel()
    const spans = kernel.tracer.getTrace(traceId)
    printTraceTree(spans)
  })

kernelCmd
  .command('trace')
  .option('--recent <N>', 'Show N most recent traces', '10')
  .action(async (opts) => {
    const kernel = await getKernel()
    const spans = kernel.tracer.getRecentSpans(parseInt(opts.recent))
    printRecentTraces(spans)
  })

kernelCmd
  .command('provenance <traceId>')
  .description('Show causal chain')
  .action(async (traceId) => {
    const kernel = await getKernel()
    const chain = kernel.provenance.getChain(traceId)
    printCausalChain(chain)
  })

kernelCmd
  .command('config <engineId>')
  .description('Get or set engine config')
  .option('--set <key=value>', 'Set config value')
  .action(async (engineId, opts) => {
    const kernel = await getKernel()
    if (opts.set) {
      const [key, value] = opts.set.split('=')
      await kernel.config.updateScoped(engineId, { [key]: JSON.parse(value) })
      console.log(`Updated ${engineId}.${key}`)
    } else {
      const config = kernel.config.readScoped(engineId)
      printConfig(engineId, config)
    }
  })

kernelCmd
  .command('oracle <query>')
  .description('Query the oracle')
  .option('--heal <issueId>', 'Trigger heal for issue')
  .action(async (query, opts) => {
    const kernel = await getKernel()
    if (opts.heal) {
      const action = await kernel.oracle.heal(opts.heal)
      printHealAction(action)
    } else {
      const result = await kernel.oracle.query({ type: 'all', filter: { q: query } })
      printQueryResult(result)
    }
  })

kernelCmd
  .command('events')
  .description('Show recent kernel events')
  .option('--last <N>', 'Number of events', '20')
  .action(async (opts) => {
    const kernel = await getKernel()
    const events = kernel.oracle.events.getRecentEvents(parseInt(opts.last))
    printEvents(events)
  })
```
