# Unit 2.5 — Network Capture: Intercept Streaming API Response

**Phase:** 2 | **ID:** 2.5 | **Dependencies:** 2.2

## Problem

`CdpTransportImpl.capture()` listens for `Network.responseReceived` and then calls `Network.getResponseBody`. This works for non-streaming responses but fails for SSE streams because:
1. The response body isn't available until the stream completes
2. The `getResponseBody` call returns empty for active streams
3. The timeout (30s) may not be long enough for complex responses

## Spec

### Enhanced Capture: Stream-Aware

Replace single-shot capture with progressive stream capture:

```typescript
// CdpTransportImpl — new method for streaming capture

async captureStream(
  slaveId: string,
  pattern: RegExp,
  timeoutMs = 60_000,
): Promise<{ body: string; chunks: string[] }> {
  const client = this.getClient(slaveId)
  const chunks: string[] = []
  let body = ''
  let resolved = false

  await client.send('Network.enable')

  return new Promise((resolve, reject) => {
    const timer = setTimeout(() => {
      if (!resolved) {
        cleanup()
        if (body || chunks.length > 0) {
          resolve({ body, chunks })
        } else {
          reject(new Error(`Capture timeout after ${timeoutMs}ms`))
        }
      }
    }, timeoutMs)

    // Track request IDs that match our pattern
    const matchingRequests = new Set<string>()

    const responseHandler = (params: unknown) => {
      const event = params as { requestId?: string; response?: { url?: string } }
      if (event.response?.url && pattern.test(event.response.url)) {
        matchingRequests.add(event.requestId!)
      }
    }

    const dataHandler = (params: unknown) => {
      const event = params as { requestId?: string; dataLength?: number }
      if (event.requestId && matchingRequests.has(event.requestId)) {
        // Data is arriving — accumulate
      }
    }

    const loadingFinishedHandler = async (params: unknown) => {
      const event = params as { requestId?: string }
      if (event.requestId && matchingRequests.has(event.requestId)) {
        // Stream finished — get full body
        try {
          const result = await client.send<{ body: string }>('Network.getResponseBody', {
            requestId: event.requestId,
          })
          body = result.body
          resolved = true
          cleanup()
          resolve({ body, chunks })
        } catch {
          // Body not available — use accumulated chunks
          cleanup()
          resolve({ body: chunks.join(''), chunks })
        }
      }
    }

    const loadingFailedHandler = (params: unknown) => {
      const event = params as { requestId?: string }
      if (event.requestId && matchingRequests.has(event.requestId)) {
        cleanup()
        reject(new Error('Network request failed'))
      }
    }

    function cleanup() {
      clearTimeout(timer)
      client.off('Network.responseReceived', responseHandler)
      client.off('Network.dataReceived', dataHandler)
      client.off('Network.loadingFinished', loadingFinishedHandler)
      client.off('Network.loadingFailed', loadingFailedHandler)
    }

    client.on('Network.responseReceived', responseHandler)
    client.on('Network.dataReceived', dataHandler)
    client.on('Network.loadingFinished', loadingFinishedHandler)
    client.on('Network.loadingFailed', loadingFailedHandler)
  })
}
```

### Provider-Specific Capture Patterns

```typescript
const CAPTURE_PATTERNS: Record<string, RegExp> = {
  chatgpt: /\/backend-api\/conversation($|\?|\/)/,
  claude: /\/api\/organizations\/.*\/chat_conversations\/.*\/completion/,
  gemini: /\/_api\/BardFrontendService\/StreamGenerate/,
}

// In conversation-manager.ts send():
// [6] CAPTURE
const capturePattern = CAPTURE_PATTERNS[conv.providerId] ?? /\/api\/conversation\//
const captureResult = await this.governor.cdp.capture(slaveId, capturePattern, 60_000)
```

### Timing: Start Capture Before Submit

Critical: Network.enable and event listeners must be set up BEFORE the submit action, otherwise the initial request events are missed.

```typescript
// In send pipeline:
// [5.5] PRE-CAPTURE: Enable network monitoring before submit
await this.governor.cdp.send(slaveId, 'Network.enable')

// [5] SEND: Type + submit
await typeMessage(...)
await submitMessage(...)

// [6] CAPTURE: Wait for response
const captureResult = await this.governor.cdp.capture(slaveId, capturePattern, 60_000)

// [6.5] CLEANUP: Disable network monitoring
await this.governor.cdp.send(slaveId, 'Network.disable')
```
