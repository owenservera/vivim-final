# Unit 4.1 — ChatGPT Selector + Parser E2E Verification

**Phase:** 4 | **ID:** 4.1 | **Dependencies:** 3.6

## Problem

ChatGPT's seed manifest, selectors, and parser need end-to-end verification against the live site. ChatGPT frequently changes its DOM structure.

## Spec

### Verification Checklist

1. **Seed loaded**: `provider_definition` row exists for slug='chatgpt'
2. **Endpoints**: At least one `endpoint_type='chat'` with selectors
3. **Parser**: Active parser `chatgpt/001_openai_sse` in DB
4. **Login**: Headless Chrome with saved profile navigates to chatgpt.com and is logged in
5. **Composer**: `#prompt-textarea` exists and accepts text
6. **Submit**: Send button or Enter key submits the message
7. **Capture**: Network response from `/backend-api/conversation` is intercepted
8. **Parse**: Response body parses into ContentBlocks with text content
9. **Multi-turn**: 3 consecutive messages work without selector breakage

### Verification Script

```typescript
async function verifyChatGPTE2E(governor: ChromeGovernor, cm: ConversationManager) {
  const results: Array<{ step: string; ok: boolean; detail?: string }> = []
  
  // 1. Spawn
  const slave = await governor.spawn('chatgpt', 'test')
  results.push({ step: 'spawn', ok: !!slave })
  
  // 2. Navigate
  await governor.cdp.send(slave.slaveId, 'Page.navigate', { url: 'https://chatgpt.com/' })
  await delay(5000)
  const state = await governor.cdp.getPageState(slave.slaveId)
  results.push({ step: 'navigate', ok: state.url.includes('chatgpt.com') })
  
  // 3. Check login
  const loginCheck = await governor.cdp.send(slave.slaveId, 'Runtime.evaluate', {
    expression: `!!document.querySelector('nav button[aria-label*="Profile"], [data-testid="profile-button"]')`,
    returnByValue: true,
  })
  results.push({ step: 'login', ok: loginCheck?.result?.value === true })
  
  // 4. Check composer
  const composerCheck = await governor.cdp.send(slave.slaveId, 'Runtime.evaluate', {
    expression: `!!document.querySelector('#prompt-textarea')`,
    returnByValue: true,
  })
  results.push({ step: 'composer', ok: composerCheck?.result?.value === true })
  
  // 5. Send test message
  const conv = await cm.createConversation('chatgpt', 'E2E Test')
  const sendResult = await cm.send(conv.id, 'What is 2+2? Reply with just the number.')
  results.push({ step: 'send', ok: sendResult.ok, detail: sendResult.text })
  
  // 6. Verify response
  results.push({ 
    step: 'response', 
    ok: sendResult.ok && sendResult.text.length > 0,
    detail: sendResult.text.slice(0, 100),
  })
  
  return results
}
```

## Test

```typescript
test('ChatGPT E2E: send message and get response', async () => {
  const results = await verifyChatGPTE2E(governor, cm)
  for (const r of results) {

  }
})
```
