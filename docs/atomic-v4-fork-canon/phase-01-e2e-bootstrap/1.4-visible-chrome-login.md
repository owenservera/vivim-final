# Unit 1.4 — Launch Visible Chrome with Correct Profile for Login

**Phase:** 1 | **ID:** 1.4 | **Dependencies:** 1.3

## Problem

The `launch-visible` endpoint in `setup-router.ts:52` launches Chrome with `extraArgs: [loginUrl]`. Chrome treats extraArgs as URLs to open, which works, but the profile directory is created fresh if `ProfileAllocator.allocate()` hasn't been called yet. The login URL should be the initial navigation target, and the profile must be pre-allocated.

## Spec

### Fix: Pre-allocate Profile + Navigate

In `setup-router.ts`, `POST /api/setup/launch-visible`:

```typescript
const allocator = new ProfileAllocator(body.workspace)
// Pre-allocate (creates dir + meta)
const profileDir = await allocator.allocate(body.providerId, body.accountSlug)

const loginUrl = PROVIDER_LOGIN_URLS[body.providerId] ?? `https://${body.providerId}.com`
const port = body.port ?? 9222

const result = await launchChrome({
  visible: true,
  debugPort: port,
  profileDir,
  extraArgs: [loginUrl],  // Chrome opens this URL on launch
})
```

### Current Implementation Status

The current implementation is **mostly correct**. The `launchChrome()` function in `launcher.ts:114` already:
1. Finds the Chrome binary (cross-platform)
2. Builds args with `--user-data-dir=${profileDir}`
3. Spawns the process
4. Waits for the debug port to be ready

### Required Enhancement: Port Conflict Handling

If port 9222 is already in use (from a previous setup attempt), `launchChrome` should detect this and either:
- Kill the existing Chrome on that port, or
- Use an alternative port

```typescript
// In launcher.ts, before launching:
if (debugPort !== 0) {
  try {
    const resp = await fetch(`http://127.0.0.1:${debugPort}/json/version`)
    if (resp.ok) {
      // Port already has a Chrome — return existing
      return { process: null as any, debugPort, pid: 0, profileDir }
    }
  } catch { /* port free, continue */ }
}
```

### Required Enhancement: Visible Window Focus

On Windows, the hidden mode positions the window off-screen (`--window-position=-32000,-32000`). For visible mode, we should ensure the window is focused:

```typescript
if (opts.visible === true) {
  args.push('--window-position=100,100')
  args.push('--auto-open-devtools-for-tabs')  // optional, helps debugging
}
```

## Test

```typescript
test('launch visible Chrome with profile', async () => {
  const resp = await fetch('/api/setup/launch-visible', {
    method: 'POST',
    body: JSON.stringify({
      providerId: 'chatgpt',
      accountSlug: 'test',
      workspace: tempDir,
    })
  })
  const result = await resp.json()
  expect(result.ok).toBe(true)
  expect(result.profileDir).toContain('chatgpt')
  expect(result.profileDir).toContain('test')
  expect(result.loginUrl).toBe('https://chatgpt.com/')
  
  // Verify Chrome is running
  const versionResp = await fetch(`http://127.0.0.1:${result.debugPort}/json/version`)
  expect(versionResp.ok).toBe(true)
})
```
