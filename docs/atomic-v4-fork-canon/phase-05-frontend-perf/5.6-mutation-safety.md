# Unit 5.6 — Zero-Breakage: Webapp Mutation Safety Audit

**Phase:** 5 | **ID:** 5.6 | **Dependencies:** 5.4

## Problem

VIVIM interacts with provider web pages via CDP. These interactions (typing, clicking, navigating) are legitimate mutations. But VIVIM must never:
- Add persistent DOM nodes outside the provider's own update area
- Modify CSS that persists after the interaction
- Leave event listeners or scripts attached
- Change the page URL except through normal provider navigation
- Break the provider's own JavaScript (React state, event handlers)

## Spec

### Mutation Safety Audit Protocol

Before shipping, run an automated audit:

```typescript
async function auditMutationSafety(
  governor: ChromeGovernor,
  slaveId: string,
  providerId: string,
): Promise<AuditResult> {
  // 1. Take DOM snapshot BEFORE interaction
  const beforeSnapshot = await takeDomSnapshot(governor, slaveId)
  
  // 2. Execute VIVIM interaction (type + submit)
  await typeMessage(governor, slaveId, 'Test message', 'textarea')
  await submitMessage(governor, slaveId, { send_method: 'enter' }, 'textarea')
  
  // 3. Wait for provider to process
  await delay(5000)
  
  // 4. Take DOM snapshot AFTER interaction + provider update
  const afterSnapshot = await takeDomSnapshot(governor, slaveId)
  
  // 5. Diff: only the provider's own changes should appear
  const diff = diffSnapshots(beforeSnapshot, afterSnapshot)
  
  // 6. Verify no VIVIM-injected elements remain
  const violations = findVivimArtifacts(afterSnapshot)
  
  return { diff, violations, clean: violations.length === 0 }
}

async function takeDomSnapshot(governor, slaveId): Promise<DomSnapshot> {
  const result = await governor.cdp.send(slaveId, 'Runtime.evaluate', {
    expression: `JSON.stringify({
      bodyChildCount: document.body.children.length,
      htmlHash: document.documentElement.outerHTML.length,
      scriptCount: document.querySelectorAll('script').length,
      styleCount: document.querySelectorAll('style').length,
      divCount: document.querySelectorAll('div').length,
      // Check for VIVIM-injected elements
      vivimElements: document.querySelectorAll('[data-vivim], [class*="vivim"], [id*="vivim"]').length,
    })`,
    returnByValue: true,
  })
  return JSON.parse(result?.result?.value ?? '{}')
}
```

### Safe Typing Pattern

The typing implementations in Units 2.3-2.4 must follow safe patterns:

```typescript
// SAFE: Use native React-compatible value setter
const nativeSetter = Object.getOwnPropertyDescriptor(
  window.HTMLTextAreaElement.prototype, 'value'
)?.set
nativeSetter?.call(el, text)
el.dispatchEvent(new Event('input', { bubbles: true }))

// UNSAFE: Direct value assignment (may break React state)
el.value = text  // React won't detect this change

// SAFE: execCommand for contenteditable
document.execCommand('insertText', false, text)

// UNSAFE: innerHTML (can inject scripts, break sanitization)
el.innerHTML = text
```

### Post-Interaction Cleanup

After capture, clean up any CDP artifacts:

```typescript
// After Network capture:
await governor.cdp.send(slaveId, 'Network.disable')

// After Runtime.enable:
await governor.cdp.send(slaveId, 'Runtime.disable')

// Don't leave Network domain enabled — it adds overhead to the page
```

### Scroll Position Preservation

VIVIM must not change the provider page's scroll position:

```typescript
// Before interaction:
const scrollBefore = await governor.cdp.send(slaveId, 'Runtime.evaluate', {
  expression: 'JSON.stringify({ x: window.scrollX, y: window.scrollY })',
  returnByValue: true,
})

// ... interaction ...

// After interaction (if VIVIM caused scroll):
const scrollAfter = await governor.cdp.send(slaveId, 'Runtime.evaluate', {
  expression: 'JSON.stringify({ x: window.scrollX, y: window.scrollY })',
  returnByValue: true,
})

// Restore if changed by VIVIM (not by provider)
if (scrollBefore !== scrollAfter && !providerScrolled) {
  await governor.cdp.send(slaveId, 'Runtime.evaluate', {
    expression: `window.scrollTo(${scrollBefore.x}, ${scrollBefore.y})`,
  })
}
```
