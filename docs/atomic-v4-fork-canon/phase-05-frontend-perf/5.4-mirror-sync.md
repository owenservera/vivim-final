# Unit 5.4 — Mirror Engine: UI⇄Chrome Bidirectional State Sync

**Phase:** 5 | **ID:** 5.4 | **Dependencies:** 3.4

## Problem

The MirrorEngine exists (`src/engines/mirror-engine.ts`) but isn't wired into the conversation pipeline. It should maintain bidirectional state synchronization between the VIVIM UI and the Chrome page.

## Spec

### Mirror Engine Role

The MirrorEngine tracks two state stores per conversation:
1. **chromeState**: What the Chrome page looks like (URL, DOM hash, scroll position, presence of elements)
2. **uiState**: What the VIVIM UI shows (message list, streaming state, capability availability)

When either changes, the MirrorEngine projects the change to the other side.

### Sync Points

1. **After send**: Chrome state changes (new message in DOM, URL may change) → update uiState
2. **After capability execution**: Chrome DOM may change (e.g., model selector opened) → update uiState
3. **User scrolls in VIVIM**: uiState changes → optionally scroll Chrome to match (for observation mode)
4. **Provider page navigates**: Chrome state changes → update uiState with new URL/context

### Implementation: Wire into ConversationManager

```typescript
// ConversationManager constructor:
constructor(
  // ... existing ...
  private mirror?: MirrorEngine,
) {}

// In send(), after STORE+EMIT:
if (this.mirror) {
  // Capture Chrome state after response
  const pageState = await this.governor.cdp.getPageState(slaveId)
  await this.mirror.snapshot(conversationId, 'post-send')
  
  await this.mirror.store.upsertMirrorState({
    conversationId,
    chromeState: {
      url: pageState.url,
      title: pageState.title,
      messageCount: conv.messageCount + 2,
      lastAction: 'send',
    },
    uiState: {
      messageCount: conv.messageCount + 2,
      lastMessage: extractText(parseResult.blocks).slice(0, 100),
    },
  })
}
```

### Frontend State Sync

```tsx
// Periodically poll mirror state (or receive via WebSocket)
useEffect(() => {
  const interval = setInterval(async () => {
    const resp = await fetch(`/api/conversations/${conversationId}/mirror`)
    if (resp.ok) {
      const state = await resp.json()
      // Use mirror state to verify UI is in sync
      if (state.chromeState.messageCount !== messages.length) {
        console.warn('[mirror] State drift detected')
        // Reload messages from server
      }
    }
  }, 5000)
  return () => clearInterval(interval)
}, [conversationId])
```

### Observation Tap Integration

The ObservationTap can observe DOM mutations in Chrome and forward them to the MirrorEngine:

```typescript
// Wire ObservationTap into Chrome page after navigation
await observationTap.start(slaveId, {
  domMutations: true,
  networkEvents: false,
  consoleLogs: false,
})

observationTap.onEvent(slaveId, (event) => {
  if (event.type === 'dom_mutation') {
    // Update mirror state
    mirrorEngine.applyOptimisticUpdate(conversationId, 'dom_mutation', event.data)
  }
})
```

test('mirror state tracks Chrome state', async () => {
