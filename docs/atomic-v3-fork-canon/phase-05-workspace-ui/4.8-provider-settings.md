## Context

Per-provider card UI for managing accounts: login status, account switcher, consent toggle (for cloud providers in local-first mode), debug port, profile dir, health score, and the model list with capability flags. A "Log in" button spawns a **visible** Chrome via the Setup flow (Phase 5) to capture credentials.

Implement as React component at `builtinSurfaceId: 'provider-settings'`. **Depends on Phase 5's provider/account engine** for account + login data; this unit defines the surface contract and reads through REST to be added in Phase 5.

## Existing Baseline

- `src/engines/chrome-governor.ts` — `spawn(providerId, accountId, { visible: true })` is the visible-login primitive; health via `getHealth(slaveId)`.
- **Phase 5 (future)** defines `ProviderAccountStore` / account + consent models and `GET /api/providers` with `models[]` + capability flags. This surface consumes that contract.
- `WorkspaceManager` (4.1) — built-in surface id `provider-settings`.
- `ProviderRegistrar` (L0) — provider manifests source the model list (forward reference).

## Interface

### New file: `web/workspace/src/surfaces/ProviderSettingsSurface.tsx`

```typescript
import { useEffect, useState } from 'react'

interface ProviderVM {
  providerId: string
  displayName: string
  accounts: AccountVM[]
  models: ModelVM[]        // with capability flags (Phase 5)
  healthScore: number
}
interface AccountVM { accountId: string; status: 'logged-in' | 'logged-out'; consent: boolean }

export function ProviderSettingsSurface() {
  const [providers, setProviders] = useState<ProviderVM[]>([])
  useEffect(() => {
    fetch('/api/providers').then((r) => r.json()).then((d) => setProviders(d.providers))
  }, [])

  async function login(providerId: string, accountId: string) {
    await fetch(`/api/providers/${providerId}/accounts/${accountId}/login`, {
      method: 'POST', body: JSON.stringify({ visible: true }),
    })
  }
  async function setConsent(providerId: string, accountId: string, consent: boolean) {
    await fetch(`/api/providers/${providerId}/accounts/${accountId}/consent`, {
      method: 'POST', body: JSON.stringify({ consent }),
    })
  }

  return (/* per-provider card: status, account switcher, consent toggle, debug port, profile dir, health score, model list, Log in button */)
}
```

### Forward REST contract (Phase 5)

```
GET  /api/providers                      -> { providers: ProviderVM[] }
POST /api/providers/:p/accounts/:a/login   { visible: true }  // spawns visible Chrome
POST /api/providers/:p/accounts/:a/consent { consent: boolean }
```
