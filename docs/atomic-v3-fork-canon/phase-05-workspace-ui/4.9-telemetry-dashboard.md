## Context

A read-only dashboard of system health and provenance: charts for provider health over time, capability success rates, selector drift events, cost burn-down, latency percentiles, and agent-loop completion rates. Drilling down opens the ProvenanceInspectorSurface (Phase 8). All read-only.

Implement as React component at `builtinSurfaceId: 'telemetry-dashboard'`. **Depends on Phase 8's telemetry/provenance store**; this unit defines the surface + chart contract and reads through REST to be added in Phase 8.

## Interface

### New file: `web/workspace/src/surfaces/TelemetryDashboardSurface.tsx`

```typescript
import { useEffect, useState } from 'react'

interface TelemetryVM {
  providerHealth: TimeSeries[]
  capabilitySuccess: Record<string, number>  // slug -> rate
  selectorDrift: EventCount[]
  costBurnDown: TimeSeries[]
  latencyP95: Record<string, number>
  loopCompletion: number
}

export function TelemetryDashboardSurface() {
  const [data, setData] = useState<TelemetryVM | null>(null)
  useEffect(() => {
    const load = () => fetch('/api/telemetry/snapshot').then((r) => r.json()).then(setData)
    load()
    const t = setInterval(load, 5000) // poll; Phase 8 may upgrade to WS
    return () => clearInterval(t)
  }, [])

  return (/* chart grid: sparkline/latency/bar components, all read-only; row click -> provenance drill-down */)
}
```
