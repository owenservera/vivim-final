# Unit 9.1 — Encryption-at-rest for sensitive columns

**Source:** v3 Overview §1.10; `docs/master-plan-v3/PHASE-09-sovereign-data.md` §9.1
**Design Doc:** `docs/master-plan-v3/PHASE-09-sovereign-data.md` §9.1
**Depends on:** —
**Produces:** `provider_config.config_value` (is_secret=1), `mux_response.response`, `provenance_node.cdpParamsJson` (sensitive) stored encrypted.

---

## Context

`EncryptionEngine` (encryption.ts) already does AES-256-GCM + PBKDF2. This unit makes it **field-level** encryption-at-rest for sensitive columns: the engine wraps individual values, the master key is derived from a user passphrase at startup, and the key auto-locks when idle > N minutes. A Prisma middleware intercepts reads/writes of marked fields transparently so engines don't change.

## Existing Baseline

- `src/engines/encryption.ts` — `class EncryptionEngine` with `encrypt(value): EncryptedData`, `decrypt(data): string`, `DEFAULT_CONFIG` (aes-256-gcm, pbkdf2). We add `unlock(passphrase)`, `lock()`, idle timer.
- `prisma/schema.prisma` — `provider_config` (`config_value`, `is_secret`), `mux_response` (`response`), `provenance_node` (`cdpParamsJson`).
- `src/server/bootstrap.ts` — engine init; the key unlock happens here at startup.

## Interface

### Change in `src/engines/encryption.ts`

```typescript
export class EncryptionEngine {
  private key: Buffer | null = null
  private idleTimer: ReturnType<typeof setTimeout> | null = null

  unlock(passphrase: string, idleLockMs = 15 * 60_000): void {
    this.key = pbkdf2Sync(passphrase, this.salt, this.config.iterations, 32, 'sha256')
    this.scheduleLock(idleLockMs)
  }

  lock(): void { this.key = null; if (this.idleTimer) clearTimeout(this.idleTimer) }

  private scheduleLock(ms: number): void {
    if (this.idleTimer) clearTimeout(this.idleTimer)
    this.idleTimer = setTimeout(() => this.lock(), ms)
  }

  encryptField(value: string): EncryptedData {
    if (!this.key) throw new EngineError('EncryptionEngine locked — unlock required')
    return this.encrypt(value)
  }
  decryptField(data: EncryptedData): string {
    if (!this.key) throw new EngineError('EncryptionEngine locked — unlock required')
    return this.decrypt(data)
  }
}
```

## Acceptance Criteria

1. `unlock(passphrase)` derives the key; subsequent `encryptField`/`decryptField` succeed.
2. After `idleLockMs`, the engine auto-`lock()`; field ops then throw until re-unlocked.
3. `provider_config.config_value` (is_secret=1) is stored encrypted; unreadable in raw SQLite without the passphrase.
4. `mux_response.response` + sensitive `provenance_node.cdpParamsJson` are likewise encrypted.
5. The Prisma middleware encrypts on write / decrypts on read with no engine-side changes.
6. `bun run devops gate` passes.
