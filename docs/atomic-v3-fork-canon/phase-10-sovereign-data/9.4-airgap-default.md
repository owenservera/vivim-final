# Unit 9.4 — Airgap-by-default

**Source:** v3 Overview §1.10; `docs/master-plan-v3/PHASE-09-sovereign-data.md` §9.4
**Design Doc:** `docs/master-plan-v3/PHASE-09-sovereign-data.md` §9.4
**Depends on:** 5.1, 5.8
**Produces:** Fresh install defaults to `airgap_enabled: true`; cloud providers require explicit consent.

---

## Context

Sovereign/local-first must be the **default**, not opt-in. This unit sets `config.defaultAirgap = true` for new installs, requires `ProviderConsent` before any cloud provider is used, and has `AirGapEngine` probe for a local Ollama on first run — if found it becomes the default provider; if not, the user is prompted to install or opt into cloud.

## Existing Baseline

- `src/engines/airgap.ts` — `class AirGapEngine` with `AirGapConfig` (`enabled`), `AirGapStatus`, `LocalModelRouteResult`; `airGapMode = config.enabled`.
- `src/engines/local-model-adapter.ts` (5.1) — `LocalModelAdapter` probes Ollama via `/api/tags`.
- `src/engines/telemetry-audit.ts` (8.4/5.8) — `provider_consent` gate; cloud requires consent.
- `src/config.ts` — `ConfigManager` persists `defaultAirgap` for new installs.
- `docs/atomic-v3/phase-05-provider-expansion/5.1-local-model-adapter.md` — local-first provider wiring.

## Interface

### Change in `src/config.ts` (first-run default)

```typescript
async function ensureFirstRunDefaults(cfg: ConfigManager): Promise<void> {
  if (await cfg.has('defaultAirgap')) return
  await cfg.set('defaultAirgap', true)   // NEW installs airgap-by-default
}
```

### Change in `src/engines/airgap.ts`

```typescript
export class AirGapEngine {
  async probeLocalFirstRun(): Promise<LocalModelRouteResult> {
    const local = await this.localAdapter.listModels()
    if (local.length > 0) {
      this.airGapMode = true
      await this.configStore.setDefaultProvider('ollama')
      return { routed: true, provider: 'ollama' }
    }
    // no local model — prompt (do not auto-cloud)
    return { routed: false, promptUser: true }
  }
}
```

## Acceptance Criteria

1. A fresh install persists `defaultAirgap: true` (no cloud by default).
2. Any cloud provider use requires a preceding `ProviderConsent` row (enforced by 8.4/5.8).
3. On first run `AirGapEngine.probeLocalFirstRun` detects local Ollama and sets it as the default provider.
4. If no local model is found, the user is prompted (install local or opt into cloud) — no silent cloud fallback.
5. `AirGapStatus` reflects the resolved mode.
6. `bun run devops gate` passes.

## Tests

`tests/unit/engines/airgap-default.test.ts` (mock config + localAdapter + consent):
- fresh install → `defaultAirgap` set `true`.
- Ollama present → default provider = `ollama`, airgap on.
- no Ollama → `promptUser: true`, no default cloud provider set.
