# Unit 9.5 — Offline-capable autonomous execution

**Source:** v3 Overview §1.10; `docs/master-plan-v3/PHASE-09-sovereign-data.md` §9.5
**Design Doc:** `docs/master-plan-v3/PHASE-09-sovereign-data.md` §9.5
**Depends on:** 9.4
**Produces:** Autonomous tasks run on local models without network.

---

## Context

An autonomous task must be able to run **fully offline**. This unit makes `LocalModelAdapter` (5.1) a first-class participant in autonomous execution (Phase 7): LLM-backed planning (7.1) uses the local model by default, and cloud models are only used when explicitly chosen **per task**.

## Existing Baseline

- `src/engines/local-model-adapter.ts` — `class LocalModelAdapter` (`'ollama'|'llamacpp'|'none'`), `/api/generate`, `listModels`. Already usable behind `SynthesisLlmProvider`/planner.
- `src/engines/autonomous-execution.ts` (7.1) — `planGoal` delegates to `IntentDecomposer`; the decomposer's LLM must resolve to the local adapter by default.
- `src/engines/airgap.ts` (9.4) — `defaultAirgap=true` means no cloud unless consented.
- `src/engines/provider-registrar.ts` (5.1) — provider registry; local provider flagged `isLocal`.
- `docs/atomic-v3/phase-07-autonomous-orchestration/7.1-llm-planner.md` — planner is the integration point.

```typescript
export class IntentDecomposer {
  constructor(private llm: LlmProvider = new LocalModelAdapter()) {} // local by default

```

### Per-task provider selection (7.1 surface)

```typescript
// AutonomousGoal gains an optional `llmProvider` override:
export interface AutonomousGoal {
  // ...existing...
  llmProvider?: 'local' | string   // defaults to 'local' (airgap 9.4)
}
```

### Change in `src/engines/autonomous-execution.ts`

```typescript
private resolvePlanner(goal: AutonomousGoal): IntentDecomposer {
  const provider = goal.llmProvider ?? (this.airgap.enabled ? 'local' : 'cloud')
  return provider === 'local'
    ? new IntentDecomposer(new LocalModelAdapter())
    : new IntentDecomposer(this.cloudAdapter)
}
```

## Acceptance Criteria

1. With `defaultAirgap:true`, a task's planner resolves to `LocalModelAdapter` (no network).
2. `goal.llmProvider:'cloud'` is honored only when the cloud provider is consented (8.4/5.8).
3. A fresh autonomous task with no `llmProvider` runs end-to-end on local Ollama (acceptance: offline week works).
4. Cloud selection without consent throws `ConsentViolationError` (no silent cloud use).
5. `bun run devops gate` passes.

## Tests

`tests/unit/engines/autonomous-offline.test.ts` (mock `LocalModelAdapter` + `IntentDecomposer`):
- airgap on, no override → planner uses local adapter.
- override `'cloud'` + consented → cloud adapter used.
- override `'cloud'` + not consented → throws.
