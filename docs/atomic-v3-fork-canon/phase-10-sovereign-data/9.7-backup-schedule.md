# Unit 9.7 — Backup scheduling

**Source:** v3 Overview §1.10; `docs/master-plan-v3/PHASE-09-sovereign-data.md` §9.7
**Design Doc:** `docs/master-plan-v3/PHASE-09-sovereign-data.md` §9.7
**Depends on:** 9.6, 8.8
**Produces:** Registers a periodic encrypted-backup job on the shared `AutomationSchedule` (owned by 8.8), targeting a user-chosen directory.

---

## Context

The encrypted bundle (9.6) is only useful if it is made regularly. This unit adds an `AutomationSchedule` that runs an encrypted backup on a configurable interval to a user-chosen directory, with retention. Default: **daily 02:00** to `{dataDir}/backups/vivim-{date}.vivim`, 30-day retention.

## Existing Baseline

- `src/engines/export.ts` (9.6) — `exportBundle(passphrase)` produces the `.vivim` file; reused by the scheduler.
- `src/engines/health-digest.ts` (8.8) — `AutomationSchedule.everyDay(hour, fn)` pattern; reuse for backup cadence.
- `src/config.ts` — `ConfigManager` stores `backupDir`, `backupIntervalMs`, `backupRetentionDays` (defaults applied on first run).
- `src/schema/types.js` — `docs/audit/` / `{dataDir}/backups/` output location.

## Interface

### New file: `src/engines/backup-scheduler.ts`

```typescript
import type { ExportEngine } from './export.js'
import type { AutomationSchedule } from './automation-schedule.js'

export interface BackupConfig {
  dir: string
  intervalMs: number
  retentionDays: number
}

export class BackupScheduler {
  constructor(
    private exportEngine: ExportEngine,
    private scheduler: AutomationSchedule,
    private config: BackupConfig = { dir: 'backups', intervalMs: 24 * 3600_000, retentionDays: 30 },
  ) {}

  schedule(): void {
    this.scheduler.every(this.config.intervalMs, () => void this.run())
  }

  async run(): Promise<string> {
    const stamp = new Date().toISOString().slice(0, 10)
    const path = `${this.config.dir}/vivim-${stamp}.vivim`
    await this.exportEngine.exportBundle(process.env.BACKUP_PASSPHRASE ?? '')
    await this.prune()
    return path
  }

  private async prune(): Promise<void> {
    const cutoff = Date.now() - this.config.retentionDays * 24 * 3600_000
    for (const f of listBackups(this.config.dir)) {
      if (f.mtimeMs < cutoff) await removeBackup(f.path)
    }
  }
}
```

## Acceptance Criteria

1. `schedule()` registers a recurring job at `config.intervalMs` (default daily).
2. `run()` writes `vivim-{YYYY-MM-DD}.vivim` via `exportBundle` (9.6).
3. Files older than `retentionDays` (default 30) are pruned on each run.
4. Defaults applied on first run: daily 02:00-equivalent interval, `{dataDir}/backups/`, 30-day retention.
5. `dir` + `intervalMs` + `retentionDays` are user-configurable (via `ConfigManager`).
6. After 7 days of use, the bundle is <100MB (acceptance — sparse snapshot).
7. `bun run devops gate` passes.
