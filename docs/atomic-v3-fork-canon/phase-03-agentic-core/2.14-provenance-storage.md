## Context

`Outcome` (current schema) records `ok/fail/durationMs` but not *lineage*: which selector was tried, which parser produced the blocks, which program version was active, which provider state was assumed, which conversation turn triggered it. Without lineage, learning is impossible.

Every capability execution writes a `ProvenanceNode` linking `(outcomeId, selectorStrategyId, parserId, programVersionId, providerStateHash, conversationTurnId, parentProvenanceId)`. Edges connect sequential nodes within a turn. `ProvenanceRecorder` is the writer; the query API is 2.15.

## Existing Baseline

- `prisma/schema.prisma` — `Outcome` table (the existing narrow record). `ProvenanceGraph` extends it, not replaces it.
- `src/engines/selector-healer.ts` — consumer of provenance (feeds healing, Phase 7).
- `src/engines/version-manager.ts` — `programVersionId` source.
- `src/storage/contracts/` — new `ProvenanceStore` contract (tables `provenance_node`, `provenance_edge` per `00-OVERVIEW.md` §2).

## Interface

### New file: `src/engines/provenance-recorder.ts`

```typescript
export interface ProvenanceNodeRow {
  id: string
  outcomeId: string
  selectorStrategyId?: string
  parserId?: string
  programVersionId?: string
  providerStateHash?: string
  conversationTurnId?: string
  parentProvenanceId?: string
  createdAt: number
}

export interface ProvenanceEdgeRow {
  id: string
  fromNodeId: string
  toNodeId: string
  turnId: string
}

export interface ProvenanceStore {
  createNode(n: ProvenanceNodeRow): Promise<void>
  createEdge(e: ProvenanceEdgeRow): Promise<void>
  getNode(id: string): Promise<ProvenanceNodeRow | null>
}

export class ProvenanceRecorder {
  constructor(private store: ProvenanceStore) {}

  /** Record a node for one capability execution and chain it to its parent. */
  async record(params: Omit<ProvenanceNodeRow, 'id' | 'createdAt' | 'parentProvenanceId'> & { parentProvenanceId?: string }): Promise<string> {
    const id = newId()
    await this.store.createNode({ ...params, id, createdAt: Date.now() })
    if (params.parentProvenanceId) {
      await this.store.createEdge({ id: newId(), fromNodeId: params.parentProvenanceId, toNodeId: id, turnId: params.conversationTurnId ?? id })
    }
    return id
  }
}
```

## Acceptance Criteria

1. `record()` writes a `provenance_node` row with all lineage fields populated (where available).
2. When a `parentProvenanceId` is supplied, a `provenance_edge` is created linking parent→child.
3. The recorder does not mutate `Outcome` — it augments it.
4. Missing optional fields (`selectorStrategyId`, etc.) are stored as `null`, not dropped.
5. `bun run devops gate` passes; recorder ≥80% covered.
