## Context

`UnifiedCapabilityRegistry.register` (today `src/engines/unified-registry.ts:65`) is only callable from server bootstrap — an agent cannot define a new capability mid-conversation. The system is **closed at runtime**. `UnifiedCapabilityRegistry` extends it so capabilities can be registered at runtime from a JSON spec, persisted to a new `live_capability` table, and hot-reloaded via `CapabilityEventBus`.

## Interface

### New file: `src/engines/live-capability-registry.ts`

```typescript
import { UnifiedCapabilityRegistry, UnifiedCapability } from './unified-registry.js'
import type { CapabilityEventBus } from './capability-event-bus.js'

export type LiveHandlerKind = 'mcp' | 'http' | 'inline'

export interface LiveCapabilitySpec {
  slug: string
  name: string
  description: string
  handlerSpec: {
    kind: LiveHandlerKind
    serverId?: string          // mcp
    toolName?: string          // mcp
    url?: string               // http
    method?: string            // http
    headers?: Record<string, string> // http
    bodyTemplate?: string      // http (mustache)
    code?: string              // inline (runs in SandboxRunner, see 2.8/2.13)
  }
  inputSchema: Record<string, unknown>
  surfaces: Array<'cli' | 'ui' | 'workflow' | 'mcp' | 'api'>
  registeredBy: string
}

export interface LiveCapabilityStore {
  create(spec: LiveCapabilitySpec & { id: string; version: number; isActive: boolean; registeredAt: number }): Promise<void>
  listActive(): Promise<Array<LiveCapabilitySpec & { id: string }>>
  get(id: string): Promise<(LiveCapabilitySpec & { id: string }) | null>
  revoke(id: string): Promise<void>
}

export class UnifiedCapabilityRegistry extends UnifiedCapabilityRegistry {
  constructor(
    private liveStore: LiveCapabilityStore,
    private bus: CapabilityEventBus,
  ) { super() }

  /** Register a runtime capability: persist + hot-reload into the registry. */
  async registerLive(spec: LiveCapabilitySpec): Promise<string> {
    const id = newId()
    const cap = this.specToUnifiedCapability(spec, id)
    this.register(cap)
    await this.liveStore.create({ ...spec, id, version: 1, isActive: true, registeredAt: Date.now() })
    this.bus.emit({ type: 'live_capability:registered', id, slug: spec.slug, ts: Date.now() })
    return id
  }

  /** Load all persisted live capabilities at startup. */
  async loadFromDb(): Promise<void> {
    for (const spec of await this.liveStore.listActive()) {
      this.register(this.specToUnifiedCapability(spec, spec.id))
    }
  }

  async revokeLive(id: string): Promise<void> {
    const spec = await this.liveStore.get(id)
    if (spec) this.unregister(`live:${id}`)
    await this.liveStore.revoke(id)
    this.bus.emit({ type: 'live_capability:revoked', id, ts: Date.now() })
  }

  private specToUnifiedCapability(spec: LiveCapabilitySpec, id: string): UnifiedCapability { /* builds handler dispatch by kind (2.8/2.9/2.10) */ }
}
```

## Acceptance Criteria

1. `registerLive(spec)` persists a row and makes the capability callable via `registry.execute`.
2. `loadFromDb()` at startup re-registers all active live capabilities (no data loss across restarts).
3. `revokeLive(id)` removes from registry AND store AND emits `live_capability:revoked`.
4. `live_capability:registered` event fires on every `registerLive`.
5. `bun run devops gate` passes; registry ≥80% covered.
