# Unit 2.10 — UnifiedCapabilityRegistry — HTTP handler kind

**Source:** v3 Overview §1.3; `docs/master-plan-v3/PHASE-02-agentic-core.md` §2.10
**Design Doc:** `docs/master-plan-v3/PHASE-02-agentic-core.md` §2.10
**Depends on:** 2.7
**Produces:** Live capability whose handler is an HTTP POST.

---

## Context

A live capability may delegate to an HTTP endpoint: `handlerSpec = { kind: 'http', url, method, headers, bodyTemplate }`. `bodyTemplate` is a mustache-style template filled from the input; the response body becomes the capability output.

> Local-first enforcement (Phase 9 / invariant B8): HTTP live capabilities may only target hosts the user has consented to. Outbound calls to non-consented hosts are blocked at the network layer by `TelemetryAudit` (`src/engines/telemetry-audit.ts`). This unit must route through that enforced fetch, never a raw `fetch`.

## Existing Baseline

- `src/engines/live-capability-registry.ts` — `LiveCapabilitySpec.handlerSpec.kind: 'http'` (2.7).
- `src/engines/telemetry-audit.ts` — enforced outbound fetch (consent gating). Reuse it rather than `globalThis.fetch`.
- `src/engines/mcp-client-adapter.ts` — pattern reference for external-delegate handlers (2.9).

## Interface

### Extension in `src/engines/live-capability-registry.ts`

```typescript
import type { TelemetryAudit } from './telemetry-audit.js'

export class UnifiedCapabilityRegistry extends UnifiedCapabilityRegistry {
  constructor(
    private liveStore: LiveCapabilityStore,
    private bus: CapabilityEventBus,
    private sandbox: SandboxRunner,
    private mcp: McpClientAdapter,
    private audit: TelemetryAudit,      // consent-enforced fetch
  ) { super() }

  private specToUnifiedCapability(spec: LiveCapabilitySpec, id: string): UnifiedCapability {
    if (spec.handlerSpec.kind === 'http') {
      const { url, method = 'POST', headers = {}, bodyTemplate } = spec.handlerSpec
      return {
        ...base,
        handler: async (input) => {
          const body = this.renderTemplate(bodyTemplate ?? '{}', input)
          const res = await this.audit.fetch(url, { method, headers, body })  // consent-gated
          if (!res.ok) throw new EngineError(`HTTP handler ${url} failed: ${res.status}`)
          return res.json()
        },
      }
    }
  }

  private renderTemplate(tpl: string, input: Record<string, unknown>): string {
    return tpl.replace(/\{\{\s*(\w+)\s*\}\}/g, (_, k) => String(input[k] ?? ''))
  }
}
```

## Acceptance Criteria

1. An `http` live capability POSTs the rendered `bodyTemplate` to `url` and returns the JSON response.
2. The request goes through `TelemetryAudit.fetch` (consent-gated), never a raw `fetch`.
3. A non-consented host → request blocked, capability errors.
4. `{{var}}` tokens in `bodyTemplate` are interpolated from `input`.
5. `bun run devops gate` passes; HTTP path ≥80% covered with a mocked `TelemetryAudit`.

## Tests

`tests/unit/engines/live-capability-http.test.ts`:
- http spec → `audit.fetch` called with rendered body.
- unknown `{{var}}` → empty string substitution (no throw).
- non-consented host → `fetch` not called, error surfaced.
