## Context

With nodes/edges stored (2.14), the graph must be *queryable*. `ProvenanceQuery` enables "show me every outcome involving this selector in the last 7 days, grouped by parser" — the query that powers `SelectorHealer` (Phase 7), `VersionManager`, and the agent's own reflection step (2.11).

## Existing Baseline

- `src/engines/provenance-recorder.ts` — `ProvenanceRecorder` + `ProvenanceStore` (2.14). The query API builds on the same store (extend `ProvenanceStore` with read methods).
- `src/engines/selector-healer.ts` — consumer: needs `forSelector(selId).last(50)`.
- `src/engines/version-manager.ts` — consumer: `forProgramVersion(id)`.
- `src/engines/stream-parser.ts` — `parserId` source for `forParser`.

## Interface

### New file: `src/engines/provenance-query.ts`

```typescript
export interface ProvenanceQueryFilter {
  outcomeId?: string
  selectorStrategyId?: string
  parserId?: string
  programVersionId?: string
  conversationTurnId?: string
  from?: number
  to?: number
  limit?: number
}

export interface LineageNode {
  node: ProvenanceNodeRow
  children: LineageNode[]
}

export class ProvenanceQuery {
  constructor(private store: ProvenanceStore) {}

  forOutcome(outcomeId: string, limit = 50): Promise<ProvenanceNodeRow[]> {
    return this.store.query({ outcomeId, limit })
  }
  forSelector(selectorStrategyId: string, limit = 50): Promise<ProvenanceNodeRow[]> {
    return this.store.query({ selectorStrategyId, limit })
  }
  forParser(parserId: string, limit = 50): Promise<ProvenanceNodeRow[]> {
    return this.store.query({ parserId, limit })
  }
  /** Build the parent→child tree rooted at a node. */
  async lineage(rootId: string): Promise<LineageNode> {
    const root = await this.store.getNode(rootId)
    if (!root) throw new EngineError(`Provenance node not found: ${rootId}`)
    return this.buildTree(root, new Set())
  }
  private async buildTree(node: ProvenanceNodeRow, seen: Set<string>): Promise<LineageNode> {
    if (seen.has(node.id)) return { node, children: [] }   // guard against cycles
    seen.add(node.id)
    const children = await this.store.childrenOf(node.id)
    return { node, children: await Promise.all(children.map((c) => this.buildTree(c, seen))) }
  }
}
```

## Acceptance Criteria

1. `forSelector(selId).last(50)` returns ≤50 rows for that selector, newest first.
2. `forOutcome(outcomeId)` returns every node sharing the outcome.
3. `forParser(parserId)` returns nodes grouped by parser.
4. `lineage(rootId)` returns the full parent→child tree and is cycle-safe.
5. `bun run devops gate` passes; query API ≥80% covered.

## Tests

`tests/unit/engines/provenance-query.test.ts`:
- seed 3 nodes for one selector → `forSelector` returns 3, ordered.
- build a 3-deep chain → `lineage` reconstructs it.
- introduce a back-edge → `lineage` terminates (no infinite recursion).
