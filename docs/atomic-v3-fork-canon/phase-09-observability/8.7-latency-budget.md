# Unit 8.7 — Latency budget enforcement

**Source:** v3 Overview §1.4; `docs/master-plan-v3/PHASE-08-observability-audit.md` §8.7
**Design Doc:** `docs/master-plan-v3/PHASE-08-observability-audit.md` §8.7
**Depends on:** 8.1
**Produces:** Per-pipeline-stage latency budgets from `MirrorEngine`.

---

## Context

The mirror pipeline (Phase 3 / 4.9) has stage budgets: resolve 5ms, ensure 2s, send 500ms, capture 30s, parse 200ms. This unit enforces them: when a stage exceeds its budget we (a) record to `latency_budget_breach`, (b) emit `latency:breach`, (c) surface it in the dashboard (8.3). Persistent breaches on a provider degrade its `ProviderHealthKernel` score.

## Existing Baseline

- `src/engines/provider-health.ts` — `ProviderHealthKernel` + `HealthStatus` (`healthy`/`degraded`/`unhealthy`); the breach path degrades a provider's score.
- `docs/atomic-v3/phase-04-workspace-ui/4.9-mirror-engine-dashboard.md` — `MirrorEngine` exposes stage latencies; budgets come from there.
- `src/engines/trace-span.ts` (8.1) — `trace_span.durationMs` is the measured stage time.
- `src/engines/capability-event-bus.ts` — emits `latency:breach`.
- `src/schema/types.js` — `latency_budget_breach` table.

## Interface

### New file: `src/engines/latency-budget.ts`

```typescript
import type { ProviderHealthKernel } from './provider-health.js'

export const LATENCY_BUDGETS = {
  resolve: 5,        // ms
  ensure: 2000,
  send: 500,
  capture: 30_000,
  parse: 200,
} as const

export type LatencyStage = keyof typeof LATENCY_BUDGETS

export class LatencyBudgetEnforcer {
  private breaches = new Map<string, number>() // providerId -> consecutive breaches

  constructor(private health: ProviderHealthKernel, private bus: CapabilityEventBus) {}

  async check(providerId: string, stage: LatencyStage, durationMs: number): Promise<boolean> {
    const budget = LATENCY_BUDGETS[stage]
    if (durationMs <= budget) return true
    await this.store.recordLatencyBreach({ providerId, stage, durationMs, budget, ts: Date.now() })
    this.bus.emit('latency:breach', { providerId, stage, durationMs, budget })
    const count = (this.breaches.get(providerId) ?? 0) + 1
    this.breaches.set(providerId, count)
    if (count >= 3) this.health.degrade(providerId, `latency:${stage}`) // persistent breach
    return false
  }
}
```

### Wire into `MirrorEngine` stage execution (4.9)

```typescript
const span = tracer.start('mirror.${stage}', parent)
const t0 = Date.now()
await stageRun()
await enforcer.check(provider.id, stage, Date.now() - t0)
await tracer.end(span)
```

## Acceptance Criteria

1. A stage finishing within budget returns `true` and records nothing.
2. A stage over budget records to `latency_budget_breach`, emits `latency:breach`, returns `false`.
3. 3+ consecutive breaches on a provider call `ProviderHealthKernel.degrade`.
4. The breach is surfaced in `TelemetryDashboardSurface` (8.3) via the event bus.
5. Budgets come from `MirrorEngine` stage config (not hardcoded elsewhere).
6. `bun run devops gate` passes.

## Tests
