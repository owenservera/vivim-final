# Unit 8.5 — Audit report generator v2

**Source:** v3 Overview §1.10; `docs/master-plan-v3/PHASE-08-observability-audit.md` §8.5
**Design Doc:** `docs/master-plan-v3/PHASE-08-observability-audit.md` §8.5
**Depends on:** 8.4
**Produces:** `TelemetryAudit.generateSignedReport()` produces a tamper-evident report.

---

## Context

`TelemetryAudit.generateReport` (telemetry-audit.ts) already produces a basic `AuditReport`. This unit makes it **signed + tamper-evident**: a SHA-256 hash chain over every `NetworkCallRecord` in the period, the list of unique hosts contacted, a verdict (clean / suspicious / violating), and a per-initiator breakdown. Signed with a device-local key (the envelope from Phase 9). An external auditor must be able to verify it.

## Existing Baseline

- `src/engines/telemetry-audit.ts` — `class TelemetryAudit` with `generateReport(from,to): AuditReport`, `getCalls(from?,to?)`, `NetworkCallRecord`. We add `generateSignedReport`.
- `src/engines/telemetry-audit.ts` — `AuditReport` interface (extend with `hashChain`, `signature`, `verdict`, `perInitiator`).
- `docs/master-plan-v3/PHASE-09-*.md` — device-local signing key + envelope (Phase 9); this unit calls into it (`signEnvelope`).
- `src/engines/telemetry-audit-interceptor.ts` (8.4) — the source of `NetworkCallRecord`s.

## Interface

### Change in `src/engines/telemetry-audit.ts`

```typescript
import { signEnvelope } from './crypto-envelope.js' // Phase 9

export type AuditVerdict = 'clean' | 'suspicious' | 'violating'

export interface SignedAuditReport extends AuditReport {
  hashChain: string[]          // SHA-256 over ordered call records
  rootHash: string
  signature: string           // device-local key (Phase 9)
  verdict: AuditVerdict
  perInitiator: Record<string, { calls: number; hosts: string[] }>
}

export class TelemetryAudit {
  // ...existing generateReport...

  async generateSignedReport(from: number, to: number): Promise<SignedAuditReport> {
    const calls = this.getCalls(from, to).sort((a, b) => a.ts - b.ts)
    const chain: string[] = []
    let prev = '0'.repeat(64)
    for (const c of calls) {
      const leaf = sha256(JSON.stringify({ host: c.host, method: c.method, ts: c.ts }))
      prev = sha256(prev + leaf)
      chain.push(prev)
    }
    const hosts = [...new Set(calls.map((c) => c.host))]
    const verdict: AuditVerdict = calls.some((c) => !c.consented) ? 'violating'
      : hosts.length > 25 ? 'suspicious' : 'clean'
    const perInitiator = groupByInitiator(calls)
    const unsigned = { ...this.generateReport(from, to), hashChain: chain, rootHash: prev, verdict, perInitiator }
    const signature = await signEnvelope(unsigned) // Phase 9
    return { ...unsigned, signature }
  }
}
```

## Acceptance Criteria

1. `generateSignedReport` returns a `SignedAuditReport` with a non-empty `hashChain` + `rootHash`.
2. The chain is a proper SHA-256 hash chain (each entry = `sha256(prev + leaf)`).
3. `verdict` is `violating` if any call is unconsented, else `suspicious` if >25 hosts, else `clean`.
4. `perInitiator` breaks calls down by initiator + hosts.
5. The report carries a `signature` from the device-local key (Phase 9); an external auditor can verify it.
6. `bun run devops gate` passes.
