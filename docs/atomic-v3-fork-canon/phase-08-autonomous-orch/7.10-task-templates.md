## Context

Users repeatedly run similar tasks ("Refactor module", "Summarize PR"). This unit adds **task templates**: named plans with parameterized inputs (`{moduleName}`, `{targetPattern}`). Invoking a template spawns a task whose plan is pre-filled from `planGoal` (7.1) with the parameters bound. Templates are shareable + versioned.

## Existing Baseline

- `src/engines/autonomous-execution.ts:473` — `planGoal(goal)` (7.1) produces the `AutonomousStep[]`; templates pre-fill `goal.description` with bound params.

## Interface

### New methods on `AutonomousExecutionEngine`

```typescript
import { ulid } from '../ids.js'

export interface TaskTemplate {
  id: string
  name: string
  params: string[]          // e.g. ['moduleName', 'targetPattern']
  planJson: string          // serialized CapabilityDAG template
  version: number
  isShared: boolean
}

export class AutonomousExecutionEngine {
  // ...
  async spawnFromTemplate(templateId: string, bindings: Record<string, string>): Promise<string> {
    const tpl = await this.store.getTaskTemplate(templateId)
    const description = this.bindParams(tpl.planJson, tpl.params, bindings)
    const goal: AutonomousGoal = {
      id: ulid(), description, maxSteps: 20,
      maxDurationMs: 10 * 60_000, requireApprovalAbove: 'write',
      allowBrowser: true, costBudgetCents: 100, tokenBudget: 50_000, iterationBudget: 30,
    }
    return this.start(goal) // 7.1 planGoal runs on the bound description
  }

  private bindParams(plan: string, params: string[], bindings: Record<string, string>): string {
    return params.reduce((acc, p) => acc.replaceAll(`{${p}}`, bindings[p] ?? ''), plan)
  }

  async saveTemplate(name: string, planJson: string, params: string[], isShared = false): Promise<string> {
    return this.store.insertTaskTemplate({ id: ulid(), name, params, planJson, version: 1, isShared })
  }
}
```

## Acceptance Criteria

1. `saveTemplate` persists a named template with its params + plan JSON + version (starts at 1).
2. `spawnFromTemplate` substitutes `{param}` tokens in the plan with `bindings`.
3. A spawned task runs `planGoal` (7.1) on the bound description (no manual plan entry).
4. `isShared` templates are visible in the task library (7.11); private ones are not.
5. Template re-save increments `version` (no overwrite of prior versions).
6. `bun run devops gate` passes.
