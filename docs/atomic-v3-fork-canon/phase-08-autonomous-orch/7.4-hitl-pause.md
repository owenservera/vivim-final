# Unit 7.4 — HITL v2: pause / resume

**Source:** v3 Overview §1.8; `docs/master-plan-v3/PHASE-07-autonomous-orchestration.md` §7.4
**Design Doc:** `docs/master-plan-v3/PHASE-07-autonomous-orchestration.md` §7.4
**Depends on:** 7.3
**Produces:** Task state `paused`; snapshot plan + cursor; resume validates world state.

---

## Context

A user must be able to **pause** a running autonomous task and **resume** it later from any completed step. On pause we snapshot the plan + cursor into `agent_run.paused_state_json`. On resume we validate that the world still matches the snapshot (cursor + provenance chain); if not, we trigger a replan instead of blindly continuing.

## Existing Baseline

## Interface

### Change in `src/engines/autonomous-execution.ts`

```typescript
export type TaskStatus = 'pending' | 'running' | 'paused' | 'completed' | 'failed'

export class AutonomousExecutionEngine {
  async pause(taskId: string): Promise<void> {
    const task = this.activeTasks.get(taskId)
    if (!task) throw new CapStoreError(`No active task ${taskId}`)
    task.status = 'paused'
    const snapshot = { cursor: this.cursorOf(task), plan: task.steps, provenanceRoot: this.provRoot(task) }
    await this.store.updateAgentRun(taskId, { pausedStateJson: JSON.stringify(snapshot), status: 'paused' })
    this.bus.emit('task:paused', { taskId })
  }

  async resume(taskId: string): Promise<void> {
    const task = this.activeTasks.get(taskId)
    if (!task) throw new CapStoreError(`No active task ${taskId}`)
    const snapshot = this.store.getPausedState(taskId)
    const worldMatches = this.cursorMatches(task, snapshot.cursor) && this.provChainIntact(task, snapshot.provenanceRoot)
    task.status = 'running'
    this.bus.emit('task:resumed', { taskId, replanned: !worldMatches })
    if (!worldMatches) { void this.replanRemainingSteps(task); return }
    void this.continueFromCursor(task, snapshot.cursor)
  }
}
```

## Acceptance Criteria

1. `pause` sets `status:'paused'` and writes `paused_state_json` (cursor + plan + provenance root).
2. `resume` sets `status:'running'` and continues from the saved cursor.
3. If the world state (cursor + provenance chain) does NOT match the snapshot, `resume` triggers `replanRemainingSteps` instead of continuing.
4. `task:paused` / `task:resumed` events are emitted (with `replanned` flag).
5. A task paused for any duration resumes cleanly when the world is unchanged (acceptance scenario).
6. `bun run devops gate` passes.

## Tests

`tests/unit/engines/autonomous-pause.test.ts` (mock store):
- `pause` → `status:'paused'`, `paused_state_json` populated.

- `resume` with mismatched cursor → `replanRemainingSteps` called, event `replanned:true`.
