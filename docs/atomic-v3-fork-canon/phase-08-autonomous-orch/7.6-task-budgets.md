## Context

A task must not run away. `AutonomousGoal` already has `costBudgetCents` (autonomous-execution.ts:39); this unit adds `tokenBudget` and `iterationBudget`. Each task tracks consumption of all three. Exceeding **any** budget transitions the task to `paused` with reason `budget_exceeded`. The UI (4.x workspace) renders burn-down bars.

## Interface

### Change in `src/engines/autonomous-execution.ts`

```typescript
export interface AutonomousGoal {
  description: string
  maxSteps: number
  maxDurationMs: number
  requireApprovalAbove: ActionClassification
  allowBrowser: boolean
  costBudgetCents: number
  tokenBudget: number      // NEW
  iterationBudget: number   // NEW
}

export interface BudgetUsage {
  costCents: number
  tokens: number
  iterations: number
}

export class AutonomousExecutionEngine {
  private usage = new Map<string, BudgetUsage>()

  private assertBudget(task: AutonomousTask, stepCost: { cents: number; tokens: number }): void {
    const u = this.usage.get(task.id) ?? { costCents: 0, tokens: 0, iterations: 0 }
    u.costCents += stepCost.cents
    u.tokens += stepCost.tokens
    u.iterations += 1
    const g = task.goal
    const over = u.costCents > g.costBudgetCents || u.tokens > g.tokenBudget || u.iterations > g.iterationBudget
    if (over) {
      task.status = 'paused'
      this.store.updateAgentRun(task.id, { status: 'paused', pauseReason: 'budget_exceeded' })
      throw new BudgetExceededError(task.id, { ...u })
    }
    this.usage.set(task.id, u)
  }
}
```

## Acceptance Criteria

1. `AutonomousGoal` has `tokenBudget` + `iterationBudget` in addition to `costBudgetCents`.
2. Each executed step increments cost / tokens / iterations on the task's `BudgetUsage`.
3. Exceeding **any** of the three budgets pauses the task (reason `budget_exceeded`).
4. Under-budget execution completes normally (no false pause).
5. `BudgetUsage` is exposed for the UI burn-down (4.x).
6. `bun run devops gate` passes.
