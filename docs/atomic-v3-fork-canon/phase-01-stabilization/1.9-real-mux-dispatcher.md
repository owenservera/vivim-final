# Unit 1.9 — Replace MuxDispatcher stub with real provider dispatch

**Source:** v3 Overview observed issue; `src/server/index.ts` line ~378 defines `muxDispatcher` returning `{ ok: true, response: "routed to X" }` without calling any provider
**Design Doc:** `docs/master-plan-v3/PHASE-01-stabilization.md` §1.9
**Depends on:** 1.3
**Produces:** Provider mux routes actually invoke ConversationManager.send against target providers.

---

## Context

`createServerWithEngines` constructs:

```typescript
const muxDispatcher = {
  async dispatchToProvider(providerId, message, conversationId?) {
    return { ok: true, response: `routed to ${providerId}`, latencyMs: 0, costCents: 0 }
  },
}
```

This is a stub. Real dispatch needs to: (1) resolve or create a conversation for the target provider, (2) call `ConversationManager.send`, (3) record cost via `CostOptimizer`.

## Interface

```typescript
// src/server/index.ts (excerpt)

const muxDispatcher: MuxDispatcher = {
  async dispatchToProvider(
    providerId: string,
    message: string,
    conversationId?: string,
  ): Promise<{ ok: boolean; response: string; latencyMs: number; costCents: number; error?: string }> {
    const start = Date.now()
    try {
      let convId = conversationId
      
      if (!convId) {
        // Create a transient conversation for this mux response
        const conv = await db.createConversation({
          id: crypto.randomUUID(),
          providerSessionId: `mux_${providerId}_${Date.now()}`,
          providerId,
          title: `Mux: ${message.slice(0, 50)}`,
        })
        convId = conv.id
      }
      
      const result = await conversationManager.send(convId, message)
      
      const latencyMs = Date.now() - start
      const costCents = await estimateCost(providerId, result.latencyMs)
      
      if (costOptimizer) {
        await costOptimizer.recordCost(providerId, costCents, 0, 0)
      }
      
      return {
        ok: result.ok,
        response: result.text || '',
        latencyMs,
        costCents,
        error: result.error,
      }
    } catch (err) {
      return {
        ok: false,
        response: '',
        latencyMs: Date.now() - start,
        costCents: 0,
        error: err instanceof Error ? err.message : String(err),
      }
    }
  },
}

async function estimateCost(providerId: string, latencyMs: number): Promise<number> {
  if (costOptimizer) {
    return costOptimizer.estimateCost(providerId, 1000) // rough: 1000-char message
  }
  return 0
}
```

## Acceptance Criteria

1. `POST /api/route/auto` with `{"message":"hello"}` returns a real response from a provider (or a real error).
2. `POST /api/route/fanout` with multiple providers returns per-provider responses (not `"routed to X"`).
3. `mux_response` table has rows with real `response` text after a mux call.
4. `provider_cost_log` has rows after a mux call.
5. `bun run devops gate` passes.
