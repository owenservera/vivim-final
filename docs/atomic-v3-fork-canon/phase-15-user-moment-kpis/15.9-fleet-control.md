# 15.9 — Workspace Settings: Fleet Control

> **KPI:** Health-refresh accuracy + relogin success rate
> **Moment:** User opens workspace settings. Provider health cards auto-refresh.
> Fleet config shows active Chrome slaves. One-click relogin.

## User Moment

1. User opens workspace settings modal
2. Provider health cards display status
3. Cards auto-refresh every 15 seconds
4. Fleet panel shows Chrome slaves, debug ports, auth state
5. User clicks "Relogin" on a stale provider
6. Chrome spawns, user logs in, session restored

## KPI Metrics

| Metric | Threshold | Unit | Description |
|--------|-----------|------|-------------|
| `modal_open_to_render` | ≤ 300 | ms | Time from click to modal visible |
| `health_refresh_accuracy` | 100 | % | Health status matches actual provider state |
| `health_refresh_interval` | 15000 | ms | Auto-refresh interval (fixed) |
| `fleet_slave_detection` | 100 | % | All active slaves shown in fleet panel |
| `relogin_success_rate` | ≥ 95 | % | Relogin attempts that complete successfully |
| `relogin_time` | ≤ 30000 | ms | Time from relogin click to session restored |

## Measurement

- **Automatic:** `WorkspaceSettings` / `HealthDashboard` emit `user_moment:fleet_control` spans
- **Backend:** `FleetSupervisor` records slave detection, `ChromeGovernor` records relogin
- **Manual:** `bun run devops kpi record --moment=fleet_control --relogin-success=<bool>`
