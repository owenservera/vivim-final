# 15.8 — Multi-Surface Execution: Four Surfaces

> **KPI:** Cross-surface parity score
> **Moment:** Same capability executes across CLI, API, MCP, and UI.
> Result is identical regardless of surface.

## User Moment

1. User runs capability from CLI: `bun run cli capabilities execute <id>`
2. Same capability from API: `POST /api/capabilities/:id/execute`
3. Same from MCP server tool call
4. Same from UI capability catalog click
5. All four return identical results
6. `verify-cross-surface` confirms parity

## KPI Metrics

| Metric | Threshold | Unit | Description |
|--------|-----------|------|-------------|
| `parity_score` | 100 | % | CLI=API=MCP=UI result match rate |
| `cli_execute_time` | ≤ 2000 | ms | CLI execution latency |
| `api_execute_time` | ≤ 1000 | ms | API execution latency |
| `mcp_execute_time` | ≤ 1500 | ms | MCP execution latency |
| `ui_execute_time` | ≤ 2000 | ms | UI execution latency |
| `surface_coverage` | 100 | % | Capabilities registered on all 4 surfaces |
| `schema_consistency` | 100 | % | Input/output schemas match across surfaces |

## Measurement

- **Automatic:** `verifyCrossSurface()` (Spec 032) runs on every capability registration
- **Backend:** `UnifiedCapabilityRegistry` records surface registration
- **Manual:** `bun run devops verify-cross-surface` + `bun run devops kpi record --moment=multi_surface`
