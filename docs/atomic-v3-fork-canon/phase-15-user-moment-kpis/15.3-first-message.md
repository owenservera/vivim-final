# 15.3 — First Real Message: The Capability Reveal

> **KPI:** Time-to-first-token
> **Moment:** User types their first message. Full stack executes: dispatchBehavior →
> NLCL → IntentDecomposer → CapabilityResolutionEngine → provider CDP → streaming response.

## User Moment

1. User types message in composer
2. Message dispatched via `dispatchBehavior('help')` or direct interpret
3. NLCL classifies intent
4. Capability resolves and executes
5. First response token streams back
6. Blocks render in real-time

## KPI Metrics

| Metric | Threshold | Unit | Description |
|--------|-----------|------|-------------|
| `send_to_first_token` | ≤ 5000 | ms | Time from send to first response token |
| `nlcl_classify_time` | ≤ 200 | ms | NLCL intent classification time |
| `capability_resolve_time` | ≤ 300 | ms | Capability resolution time |
| `cdp_execute_time` | ≤ 3000 | ms | Provider CDP execution time |
| `stream_blocks_render` | ≤ 50 | ms | Time from block received to DOM render |
| `total_response_time` | ≤ 30000 | ms | Full response completion |

## Measurement

- **Automatic:** `StreamBlockStore` emits `user_moment:first_message` via block metadata
- **Backend:** `CapabilityResolutionEngine` records resolution span, `ChromeGovernor` records CDP span
- **Manual:** `bun run devops kpi record --moment=first_message --send-to-first-token=<ms>`
