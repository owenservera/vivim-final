# 15.7 — Help System: Context-Aware Guidance

> **KPI:** Time-to-answer + relevance
> **Moment:** User is confused. Opens help widget. Search bar queries capability
> catalog. AI chat classifies intent and responds with citations.

## User Moment

1. User clicks help widget (bottom-right)
2. `useScreenContext` captures current state
3. User types query in search bar
4. `useCapabilitySearch` fuzzy-matches against catalog
5. AI chat classifies intent via backend NLCL
6. Response with citations from design docs
7. Quick actions suggest executable capabilities

## KPI Metrics

| Metric | Threshold | Unit | Description |
|--------|-----------|------|-------------|
| `widget_open_to_ready` | ≤ 200 | ms | Time from click to help panel visible |
| `search_to_results` | ≤ 300 | ms | Time from keystroke to search results |
| `search_relevance` | ≥ 80 | % | Top-3 results contain correct answer |
| `ai_classify_time` | ≤ 500 | ms | Time to classify intent via NLCL |
| `ai_response_time` | ≤ 3000 | ms | Time to generate AI help response |
| `citation_accuracy` | ≥ 90 | % | Citations reference correct docs |
| `quick_action_relevance` | ≥ 70 | % | Suggested actions are contextually valid |

## Measurement

- **Automatic:** `HelpWidget` emits `user_moment:help_system` via analytics
- **Backend:** `/api/help/agent` records classification + generation spans
- **Manual:** `bun run devops kpi record --moment=help_system --search-to-results=<ms>`
