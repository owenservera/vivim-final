# 15.4 — Command Palette (Ctrl+K): The Power Surface

> **KPI:** Search-to-execute latency
> **Moment:** User presses Ctrl+K. Searchable grid overlays screen showing all
> capabilities. Typing filters instantly. Selecting executes immediately.

## User Moment

1. User presses Ctrl+K
2. Command palette overlay appears
3. User types query → instant fuzzy filter
4. Results show category, surfaces, description
5. User selects capability → executes via `dispatchBehavior`
6. Result toast appears

## KPI Metrics

| Metric | Threshold | Unit | Description |
|--------|-----------|------|-------------|
| `ctrl_k_to_overlay` | ≤ 100 | ms | Time from keypress to palette visible |
| `search_latency` | ≤ 50 | ms | Time from keystroke to filtered results |
| `search_result_count` | ≥ 5 | count | Minimum results for typical query |
| `select_to_execute` | ≤ 500 | ms | Time from selection to execution start |
| `execute_to_toast` | ≤ 2000 | ms | Time from execution to result toast |
| `total_discovery_time` | ≤ 5000 | ms | Keypress to capability executed |

## Measurement

- **Automatic:** `CommandPalette` component emits `user_moment:command_palette` via analytics
- **Frontend:** `useCapabilitySearch` records search latency
- **Manual:** `bun run devops kpi record --moment=command_palette --ctrl-k-to-overlay=<ms>`
