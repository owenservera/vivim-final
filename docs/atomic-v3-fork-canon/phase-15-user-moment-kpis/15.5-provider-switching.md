# 15.5 — Provider Switching: Seamless Context

> **KPI:** Context-transfer time
> **Moment:** User switches from one provider to another mid-conversation.
> Context transfers, next message routes through new provider's parser.

## User Moment

1. User types "switch to gemini" or clicks provider chip
2. `select_model` capability fires
3. Conversation context transfers to new provider
4. Next message routes through new parser (e.g. `gemini/001_batchexecute`)
5. Streaming format changes transparently
6. Same block-by-block rendering regardless of provider

## KPI Metrics

| Metric | Threshold | Unit | Description |
|--------|-----------|------|-------------|
| `switch_to_ready` | ≤ 2000 | ms | Time from switch request to new provider ready |
| `parser_swap_time` | ≤ 100 | ms | Time to swap parser chain |
| `context_transfer_size` | ≤ 50 | KB | Max context transferred between providers |
| `first_token_after_switch` | ≤ 5000 | ms | Time to first token on new provider |
| `format_consistency` | 100 | % | Same block types render identically |

## Measurement

- **Automatic:** `ConversationManager` emits `user_moment:provider_switch` span
- **Backend:** `StreamParserEngine` records parser swap time
- **Manual:** `bun run devops kpi record --moment=provider_switch --switch-to-ready=<ms>`
