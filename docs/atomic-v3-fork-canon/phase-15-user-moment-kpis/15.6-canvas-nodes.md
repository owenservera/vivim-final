# 15.6 — Canvas Nodes: Watching Intelligence Grow

> **KPI:** Time-to-first-token + streaming smoothness
> **Moment:** A canvas node executes. User watches thinking blocks appear,
> text accumulates word-by-word, code blocks syntax-highlight in real-time.

## User Moment

1. Canvas node begins executing
2. Thinking indicator appears
3. First text token streams in
4. Text accumulates smoothly (no jank)
5. Code blocks syntax-highlight
6. Cost/token metadata updates live
7. Node completes

## KPI Metrics

| Metric | Threshold | Unit | Description |
|--------|-----------|------|-------------|
| `node_start_to_thinking` | ≤ 1000 | ms | Time from execute to thinking indicator |
| `node_ttft` | ≤ 3000 | ms | Time to first text token |
| `stream_fps` | ≥ 30 | fps | Render frame rate during streaming |
| `stream_jank_count` | ≤ 2 | count | Frame drops > 100ms during stream |
| `code_highlight_latency` | ≤ 100 | ms | Time from code block received to highlighted |
| `cost_update_frequency` | ≤ 1000 | ms | Max delay between cost metric updates |
| `node_complete_accuracy` | 100 | % | Final state matches provider response |

## Measurement

- **Automatic:** `StreamBlockStore` emits `user_moment:canvas_node` via block metadata
- **Frontend:** `requestAnimationFrame` timing in `useStreamSlot`
- **Manual:** `bun run devops kpi record --moment=canvas_node --node_ttft=<ms>`
