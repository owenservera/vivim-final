# 15.1 — First Launch: The Black Canvas

> **KPI:** Time-to-first-agent-message
> **Moment:** User opens Vivim for the first time. Pure black screen with blinking cursor.
> Agent begins typing its first message character-by-character.

## User Moment

1. App launches → black screen with cursor
2. Agent detects first-run state (`checkNeedsSetup()` returns true)
3. Agent begins typing: first character appears within threshold
4. Full intro message visible within threshold

## KPI Metrics

| Metric | Threshold | Unit | Description |
|--------|-----------|------|-------------|
| `launch_to_cursor` | ≤ 500 | ms | Time from app mount to cursor visible |
| `cursor_to_first_char` | ≤ 2000 | ms | Time from cursor to first agent character |
| `full_intro_visible` | ≤ 15000 | ms | Time from cursor to full intro message |
| `agent_typing_cps` | ≥ 40 | chars/s | Typing speed (configurable, not < 30) |

## Measurement

- **Automatic:** `GuidedLanding` component emits `user_moment:first_launch` via `useHelpAnalytics`
- **Backend:** `TelemetryAggregator` records `moment.first_launch` span with duration
- **Manual:** `bun run devops kpi record --moment=first_launch --launch-to-cursor=<ms>`
