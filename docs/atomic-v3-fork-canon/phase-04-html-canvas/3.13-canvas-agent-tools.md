# Unit 3.13 — Canvas agent tools (MCP + UnifiedCapabilityRegistry)

**Source:** v3 Overview §1.6; `docs/master-plan-v3/PHASE-03-html-canvas.md` §3.13
**Design Doc:** `docs/master-plan-v3/PHASE-03-html-canvas.md` §3.13
**Depends on:** 3.3, 3.4, 3.5, 3.7
**Produces:** Canvas operations registered as capabilities + MCP tools.

---

## Context

To let external agents (Claude Code, etc.) and the internal workflow engine drive canvases, the canvas operations are registered as `UnifiedCapability` entries in the `UnifiedCapabilityRegistry` (1.3). Because the registry auto-exports to all five surfaces, each canvas operation becomes available as a CLI command, UI action, workflow node, **MCP tool**, and API endpoint — no duplicate wiring.

Capabilities:
- `canvas_spawn` — spawn an instance (3.3)
- `canvas_destroy` — destroy an instance (3.3)
- `canvas_mutate` — apply a structured mutation (3.5)
- `canvas_observe` — snapshot / list interactive (3.7)
- `canvas_fill_form` — drive a form (3.8)
- `canvas_define` — publish a definition (3.1)
- `canvas_list` — list definitions/instances (3.1/3.3)

## Existing Baseline

- `src/engines/unified-registry.ts` — `UnifiedCapability` shape, `register`, `exportForMcp`, `execute`.
- `src/engines/capability-bootstrap.ts` (1.3) — `registerDefaultCapabilities(registry, services)`; canvas caps are added here (or a `registerCanvasCapabilities` sibling taking the canvas engines).

- `src/server/index.ts` — `createServerWithEngines` constructs the registry; canvas engines are passed into the bootstrap.

## Interface

### New file: `src/engines/canvas-capabilities.ts`

```typescript
import type { UnifiedCapabilityRegistry } from './unified-registry.js'
import type { CanvasRegistry } from './canvas-registry.js'
import type { CanvasSpawner } from './canvas-spawner.js'
import type { CanvasMirror } from './canvas-mirror.js'
import type { CanvasDiscovery } from './canvas-discovery.js'

export interface CanvasCapabilityServices {
  registry: CanvasRegistry
  spawner: CanvasSpawner
  mirror: CanvasMirror
  discovery: CanvasDiscovery
}

function cap(partial: Omit<UnifiedCapability, 'surfaces' | 'isAsync' | 'requiresConfirmation' | 'tags'>): UnifiedCapability {
  return { ...partial, surfaces: ['cli', 'ui', 'workflow', 'mcp', 'api'], isAsync: true, requiresConfirmation: false, tags: ['canvas'] }
}

export function registerCanvasCapabilities(
  registry: UnifiedCapabilityRegistry,
  svc: CanvasCapabilityServices,
): void {
  registry.register(cap({
    id: 'cap:canvas:spawn', slug: 'canvas_spawn', name: 'Spawn Canvas',
    description: 'Spawn a canvas instance from a definition.',
    category: 'canvas',
    inputSchema: { type: 'object', properties: { definitionId: { type: 'string' } }, required: ['definitionId'] },
    outputSchema: { type: 'object' },
    mcpToolName: 'canvas_spawn',
    apiEndpoint: { method: 'POST', path: '/api/canvas/spawn' },
    handler: async (i) => svc.spawner.spawn({ definitionId: String(i.definitionId), spawnedBy: 'agent' }),
  }))

  registry.register(cap({
    id: 'cap:canvas:destroy', slug: 'canvas_destroy', name: 'Destroy Canvas',
    description: 'Destroy a canvas instance.',
    category: 'canvas',
    inputSchema: { type: 'object', properties: { canvasId: { type: 'string' } }, required: ['canvasId'] },
    outputSchema: { type: 'object' },
    mcpToolName: 'canvas_destroy',
    apiEndpoint: { method: 'DELETE', path: '/api/canvas/instance/{id}' },
    handler: async (i) => { await svc.spawner.destroy(String(i.canvasId)); return { ok: true } },
  }))

  registry.register(cap({
    id: 'cap:canvas:mutate', slug: 'canvas_mutate', name: 'Mutate Canvas',
    description: 'Apply a structured DOM mutation to a canvas.',
    category: 'canvas',
    inputSchema: { type: 'object', properties: { canvasId: { type: 'string' }, mutation: { type: 'object' } }, required: ['canvasId', 'mutation'] },
    outputSchema: { type: 'object' },
    mcpToolName: 'canvas_mutate',
    apiEndpoint: { method: 'POST', path: '/api/canvas/instance/{id}/mutate' },
    handler: async (i) => { await svc.mirror.applyMutation(String(i.canvasId), i.mutation as never); return { ok: true } },
  }))

  registry.register(cap({
    id: 'cap:canvas:observe', slug: 'canvas_observe', name: 'Observe Canvas',
    description: 'Snapshot a canvas DOM or list interactive elements.',
    category: 'canvas',
    inputSchema: { type: 'object', properties: { canvasId: { type: 'string' }, op: { type: 'string', enum: ['snapshot', 'listInteractive'] } }, required: ['canvasId'] },
    outputSchema: { type: 'object' },
    mcpToolName: 'canvas_observe',
    apiEndpoint: { method: 'GET', path: '/api/canvas/instance/{id}/snapshot' },
    handler: async (i) => {
      const op = (i.op as string) ?? 'snapshot'
      return op === 'listInteractive'
        ? { elements: await svc.discovery.listInteractive(String(i.canvasId)) }
        : { snapshot: await svc.discovery.snapshot(String(i.canvasId)) }
    },
  }))

  registry.register(cap({
    id: 'cap:canvas:fill_form', slug: 'canvas_fill_form', name: 'Fill Canvas Form',
    description: 'Fill a canvas form by field name.',
    category: 'canvas',
    inputSchema: { type: 'object', properties: { canvasId: { type: 'string' }, data: { type: 'object' } }, required: ['canvasId', 'data'] },
    outputSchema: { type: 'object' },
    mcpToolName: 'canvas_fill_form',
    apiEndpoint: { method: 'POST', path: '/api/canvas/instance/{id}/discover' },
    handler: async (i) => svc.discovery.fillForm(String(i.canvasId), i.data as Record<string, string>),
  }))

  registry.register(cap({
    id: 'cap:canvas:define', slug: 'canvas_define', name: 'Define Canvas',
    description: 'Publish a new canvas definition.',
    category: 'canvas',
    inputSchema: { type: 'object', properties: { name: { type: 'string' }, htmlTemplate: { type: 'string' }, cssTemplate: { type: 'string' }, bindingSpecJson: { type: 'string' } }, required: ['name', 'htmlTemplate'] },
    outputSchema: { type: 'object' },
    mcpToolName: 'canvas_define',
    apiEndpoint: { method: 'POST', path: '/api/canvas/definitions' },
    handler: async (i) => svc.registry.define({ ...(i as never), createdBy: 'agent' }),
  }))

  registry.register(cap({
    id: 'cap:canvas:list', slug: 'canvas_list', name: 'List Canvases',
    description: 'List canvas definitions and running instances.',
    category: 'canvas',
    inputSchema: { type: 'object', properties: {} },
    outputSchema: { type: 'object' },
    mcpToolName: 'canvas_list',
    apiEndpoint: { method: 'GET', path: '/api/canvas/definitions' },
    handler: async () => ({ definitions: await svc.registry.list(), instances: await svc.spawner.list() }),
  }))
}
```

Wired into `createServerWithEngines` after constructing the canvas engines and before/with `registerDefaultCapabilities`.

## Acceptance Criteria

1. After bootstrap, `registry.list({ category: 'canvas' }).length === 7`.
2. Each canvas capability is exported to MCP (`exportForMcp` includes `canvas_spawn`, etc.).
3. `registry.execute('cap:canvas:spawn', {definitionId}, ctx)` calls `spawner.spawn`.
4. `canvas_mutate` handler calls `mirror.applyMutation` with the passed mutation (structured, not string-built).
5. `canvas_observe` op switch returns snapshot or interactive list.
6. `bun run devops gate` passes; canvas MCP tools ≥80% covered.
