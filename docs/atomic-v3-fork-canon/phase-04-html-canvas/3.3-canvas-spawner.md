# Unit 3.3 — CanvasInstance model + CanvasSpawner engine

**Source:** v3 Overview §1.6; `docs/master-plan-v3/PHASE-03-html-canvas.md` §3.3
**Design Doc:** `docs/master-plan-v3/PHASE-03-html-canvas.md` §3.3
**Depends on:** 3.1
**Produces:** `canvas_instance` table; `CanvasSpawner.{spawn, destroy, list, get}`.

---

## Context

A `CanvasInstance` is a *live* canvas — a definition materialized into a rendering surface (a Chromium tab allocated via the Governor, per the CDP model in `chrome-governor.ts`, or a sandboxed iframe in the workspace frontend). Spawning: load the definition, allocate a unique `canvasId`, allocate the rendering surface, persist the row, emit `canvas:spawned`. Destruction reverses it and emits `canvas:destroyed`.

This unit owns the instance lifecycle and the `canvas_instance` persistence. Binding (3.4), mirror (3.5/3.6), and discovery (3.7/3.8) operate on instances produced here.

## Existing Baseline

- `src/engines/chrome-governor.ts` — `ChromeGovernor.spawn(providerId, accountId, opts)` allocates a `ChromeSlave` with a `debugPort`. For canvases we allocate a tab via a dedicated provider namespace (`providerId: 'canvas'`) so the fleet/health machinery still applies. `cdp` proxy exposes `Runtime.evaluate` / `Page.navigate` used later by 3.5.
- `src/engines/mirror-engine.ts` — `MirrorEngine` shows the existing bidirectional-sync pattern; `CanvasMirror` (3.5) will parallel it.
- `src/ids.ts` — `newId()` for `canvasId`.
- `CanvasRegistry` (3.1) — source of the `CanvasDefinition` to spawn from.

### New file: `src/engines/canvas-spawner.ts`

```typescript
import type { CanvasRegistry } from './canvas-registry.js'
import type { CanvasInstanceStore } from '../storage/contracts/canvas-instance-store.js'
import type { ChromeGovernor } from './chrome-governor.js'
import type { GovernorEventBus } from './chrome-governor.js'
import { EngineError } from '../errors.js'
import { newId } from '../ids.js'

export interface SpawnOptions {
  definitionId: string
  spawnedBy?: 'agent' | 'user' | 'system'
  backend?: 'tab' | 'iframe'
}

export class CanvasSpawner {
  constructor(
    private registry: CanvasRegistry,
    private instanceStore: CanvasInstanceStore,
    private governor: ChromeGovernor,
    private eventBus?: GovernorEventBus,
  ) {}

  async spawn(opts: SpawnOptions): Promise<CanvasInstanceRow> {
    const def = await this.registry.get(opts.definitionId)
    if (!def) throw new EngineError(`CanvasDefinition ${opts.definitionId} not found`)
    if (!def.isActive) throw new EngineError(`CanvasDefinition ${opts.definitionId} is not active`)

    const canvasId = newId()
    let slaveId: string | null = null
    if ((opts.backend ?? 'tab') === 'tab') {
      const slave = await this.governor.spawn('canvas', canvasId, { visible: false })
      slaveId = slave.slaveId
      // navigate the tab to the canvas host URL with canvasId in the query
      await this.governor.cdp.send(slave.slaveId, 'Page.navigate', {
        url: `vivim://canvas/${canvasId}`,
      })
    }

    const row = await this.instanceStore.createInstance({
      id: newId(),
      definitionId: def.id,
      canvasId,
      slaveId,
      capabilityToken: generateToken(def.requiredCapabilities),
      spawnedBy: opts.spawnedBy ?? 'agent',
    })
    this.eventBus?.emit('canvas:spawned', { canvasId, definitionId: def.id, slaveId })
    return row
  }

  async destroy(canvasId: string): Promise<void> {
    const row = await this.instanceStore.getInstanceByCanvasId(canvasId)
    if (!row) throw new EngineError(`CanvasInstance ${canvasId} not found`)
    if (row.slaveId) await this.governor.kill(row.slaveId)
    await this.instanceStore.deleteInstance(row.id)
    this.eventBus?.emit('canvas:destroyed', { canvasId })
  }

  get(canvasId: string): Promise<CanvasInstanceRow | null> {
    return this.instanceStore.getInstanceByCanvasId(canvasId)
  }

  list(opts?: { status?: string }): Promise<CanvasInstanceRow[]> {
    return this.instanceStore.listInstances(opts)
  }
}
```

`generateToken` (3.12) produces a signed token encoding `requiredCapabilities`.

## Acceptance Criteria

1. `spawn` on an active definition creates a row with `status: 'spawning'→'running'` and emits `canvas:spawned`.
2. `spawn` with backend `tab` allocates a Governor slave and navigates it to `vivim://canvas/<canvasId>`.
3. `spawn` on an inactive / missing definition throws `EngineError`.
4. `destroy` kills the slave (if any), deletes the row, emits `canvas:destroyed`.
5. `list`/`get` return persisted instances.
6. `bun run devops gate` passes.

## Tests

`tests/unit/engines/canvas-spawner.test.ts` (mock `CanvasRegistry`, `CanvasInstanceStore`, `ChromeGovernor`):
- spawn → instance persisted, `canvas:spawned` emitted.
- spawn tab backend → `governor.spawn` + `cdp.send Page.navigate` called.
- spawn missing definition → throws.
- destroy → `governor.kill` + row deleted + `canvas:destroyed` emitted.
