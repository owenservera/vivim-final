# Unit 3.11 — Canvas WebSocket protocol v2

**Source:** v3 Overview §3; `docs/master-plan-v3/PHASE-03-html-canvas.md` §3.11
**Design Doc:** `docs/master-plan-v3/PHASE-03-html-canvas.md` §3.11
**Depends on:** 3.6
**Produces:** Typed WS frames for canvas events.

---

## Context

The workspace frontend (and external agents over MCP) subscribe to canvas event streams over WebSocket. This unit defines the **typed frame schema** (v2) and the server-side fan-out hub that forwards the events emitted in 3.5/3.6 to `canvasId`-filtered subscribers. The protocol is the realtime counterpart to the HTTP router (3.10).

Frame types:
- `canvas:spawned` — instance created
- `canvas:destroyed` — instance destroyed
- `canvas:event` — user interaction (from 3.6)
- `canvas:mutated` — agent applied mutation (from 3.5)
- `canvas:action` — dispatched capability (3.4/3.9)
- `canvas:state` — periodic snapshot

Subscribers register interest by `canvasId`; the hub only delivers matching frames.

## Existing Baseline

- `CanvasEventIngest` (3.6) — emits `canvas:event` on `GovernorEventBus`/`CapabilityEventBus`; the hub subscribes here.
- `CanvasMirror` (3.5) — emits `canvas:mutated`.
- `CanvasSpawner` (3.3) — emits `canvas:spawned`/`canvas:destroyed`.
- `src/engines/capability-event-bus.ts` — `CapabilityEventBus` on/emit reused for the hub's internal wiring.
- Existing WS server (if present) — hub plugs into the same socket lifecycle.

## Interface

### New file: `src/server/canvas-ws.ts`

```typescript
import type { CapabilityEventBus } from '../engines/capability-event-bus.js'

export type CanvasFrame =
  | { type: 'canvas:spawned'; canvasId: string; definitionId: string; slaveId: string | null }
  | { type: 'canvas:destroyed'; canvasId: string }
  | { type: 'canvas:event'; canvasId: string; elementType: string; selector: string; eventType: string; value: unknown }
  | { type: 'canvas:mutated'; canvasId: string; mutation: unknown }
  | { type: 'canvas:action'; canvasId: string; capabilityInputKey: string; value: unknown }
  | { type: 'canvas:state'; canvasId: string; snapshot: unknown }

export interface CanvasWsClient {
  canvasId: string | null
  send(frame: CanvasFrame): void
}

export class CanvasWsHub {
  private clients = new Set<CanvasWsClient>()

  constructor(private bus: CapabilityEventBus) {
    // Fan out every canvas event the engines emit.
    bus.on('canvas:event', (e) => this.broadcast({ type: 'canvas:event', ...(e as object) } as CanvasFrame))
    bus.on('canvas:mutated', (e) => this.broadcast({ type: 'canvas:mutated', ...(e as object) } as CanvasFrame))
    bus.on('canvas:action', (e) => this.broadcast({ type: 'canvas:action', ...(e as object) } as CanvasFrame))
    bus.on('canvas:spawned', (e) => this.broadcast({ type: 'canvas:spawned', ...(e as object) } as CanvasFrame))
    bus.on('canvas:destroyed', (e) => this.broadcast({ type: 'canvas:destroyed', ...(e as object) } as CanvasFrame))
  }

  subscribe(client: CanvasWsClient, canvasId: string): void {
    client.canvasId = canvasId
    this.clients.add(client)
  }

  unsubscribe(client: CanvasWsClient): void {
    this.clients.delete(client)
  }

  private broadcast(frame: CanvasFrame): void {
    const target = 'canvasId' in frame ? (frame as { canvasId: string }).canvasId : null
    for (const c of this.clients) {
      if (c.canvasId === null || c.canvasId === target) c.send(frame)
    }
  }
}
```

## Acceptance Criteria

1. A client subscribed to `canvasId: X` receives only frames where `canvasId === X` (plus global frames if any).
2. `canvas:event`/`canvas:mutated`/`canvas:action`/`canvas:spawned`/`canvas:destroyed` are all forwarded from the `CapabilityEventBus`.
3. `unsubscribe` removes the client; no further deliveries.
4. Frame shapes match the `CanvasFrame` union (type-checked at send site).
5. `bun run devops gate` passes.
