## Context

The binding spec is the contract between an agent's capability I/O and the canvas DOM. It declares, declaratively, two directions:

- **outputs**: when a capability returns a value under `capabilityOutputKey`, push it onto the DOM element matched by `selector` at `attribute`.
- **inputs**: when the DOM element matched by `selector` fires `event`, emit a `canvas:action` carrying `capabilityInputKey` (the value is read from the element at event time).

`CanvasBinder` subscribes to capability output events (via `CapabilityEventBus`) and to canvas user events (3.6 `canvas:event`), and performs the appropriate DOM write/read through `CanvasMirror` (3.5). This keeps agent code free of selector plumbing.

## Interface

### New file: `src/engines/canvas-binder.ts`

```typescript
import type { CanvasInstanceStore } from '../storage/contracts/canvas-instance-store.js'
import type { CapabilityEventBus } from './capability-event-bus.js'
import type { CanvasMirror } from './canvas-mirror.js'
import { EngineError } from '../errors.js'

export interface BindingOutput {
  capabilityOutputKey: string
  selector: string
  attribute: string // e.g. 'innerHTML', 'value', 'textContent', 'data-state'
}

export interface BindingInput {
  selector: string
  event: string // 'click' | 'input' | 'change' | 'submit'
  capabilityInputKey: string
}

export interface BindingSpec {
  outputs: BindingOutput[]
  inputs: BindingInput[]
}

export class CanvasBinder {
  // canvasId -> unsubscribe fns
  private subscriptions = new Map<string, Array<() => void>>()

  constructor(
    private instanceStore: CanvasInstanceStore,
    private bus: CapabilityEventBus,
    private mirror: CanvasMirror,
  ) {}

  async bind(canvasId: string, spec: BindingSpec): Promise<void> {
    const instance = await this.instanceStore.getInstanceByCanvasId(canvasId)
    if (!instance) throw new EngineError(`CanvasInstance ${canvasId} not found`)

    this.unbind(canvasId)

    // Outputs: capability result -> DOM
    const offOut = this.bus.on('capability:output', (evt) => {
      const out = spec.outputs.find((o) => o.capabilityOutputKey === evt.outputKey)
      if (!out) return
      void this.mirror.applyMutation(canvasId, {
        op: 'setAttribute',
        selector: out.selector,
        attribute: out.attribute,
        value: evt.value,
      })
    })

    // Inputs: DOM event -> capability action
    const offIn = this.bus.on('canvas:event', (evt) => {
      const inp = spec.inputs.find(
        (i) => i.selector === evt.selector && i.event === evt.eventType,
      )
      if (!inp) return
      this.bus.emit('canvas:action', {
        canvasId,
        capabilityInputKey: inp.capabilityInputKey,
        value: evt.value,
      })
    })

    this.subscriptions.set(canvasId, [offOut, offIn])
  }

  unbind(canvasId: string): void {
    const subs = this.subscriptions.get(canvasId)
    if (subs) subs.forEach((off) => off())
    this.subscriptions.delete(canvasId)
  }
}
```

The binder stores `boundCapabilities` (derived from the spec) on the instance row so 3.12 can validate the token.

## Acceptance Criteria

1. `bind` registers listeners; `capability:output` for a bound key triggers a `CanvasMirror.applyMutation` with the right selector/attribute.
2. A matched `canvas:event` emits a `canvas:action` with the correct `capabilityInputKey`.
3. `bind` replaces any prior binding for the same `canvasId` (no duplicate listeners).
4. `unbind` removes all listeners.
5. `bind` on an unknown `canvasId` throws `EngineError`.
6. `bun run devops gate` passes.

## Tests

`tests/unit/engines/canvas-binder.test.ts` (mock `CanvasInstanceStore`, `CapabilityEventBus`, `CanvasMirror`):
- bus emits `capability:output` matching an output → `mirror.applyMutation` called with `{op:'setAttribute', ...}`.
- bus emits `canvas:event` matching an input → `canvas:action` emitted.
- re-`bind` → exactly one set of active listeners.
- `unbind` → further events produce no mutations.
