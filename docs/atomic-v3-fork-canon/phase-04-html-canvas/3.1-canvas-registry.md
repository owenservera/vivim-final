## Context

v3's central thesis is that frontends are *data* (declarative specs in the DB), not *code* (compiled React components). A `CanvasDefinition` is the immutable-ish template an agent (or user, or system) publishes: a bundle of HTML, CSS, optional sandboxed JS, and a binding spec that maps capability I/O to DOM elements.

Today there is no canvas concept in the schema or engines. This unit establishes the data model and the registry that stores/retrieves definitions. Later units (3.2) seed built-ins; 3.3 instances reference a definition by id.

## Existing Baseline

- `prisma/schema.prisma` — no canvas tables exist yet (grep `canvas` → 0 matches). This unit introduces the first canvas migration.
- `src/engines/unified-registry.ts` — `UnifiedCapability` shape used for capability references in `requiredCapabilities`.
- Storage contracts live in `src/storage/contracts/`. New tables follow the `XxxStore` contract pattern (see `MirrorStore` in `src/engines/mirror-engine.ts:68`).
- `src/ids.ts` — `newId()` ULID generator used for row ids.

## Interface

### New migration: `prisma/schema.prisma` (add model)

```prisma
model CanvasDefinition {
  id                 String   @id
  name               String
  description        String
  htmlTemplate       String   // text
  cssTemplate        String   // text
  jsTemplate         String?  // text | null (runs sandboxed in iframe)
  bindingSpecJson    String   // JSON-encoded BindingSpec (3.4)
  requiredCapabilities String[] // capability slugs this canvas needs
  version            Int      @default(1)
  isActive           Boolean  @default(true)
  createdBy          String   // 'agent' | 'user' | 'system'
  createdAt          DateTime @default(now())
  updatedAt          DateTime @updatedAt

  instances CanvasInstance[]

  @@index([createdBy])
  @@index([isActive])
}
```

### New file: `src/storage/contracts/canvas-store.ts`

```typescript
export interface CanvasDefinitionRow {
  id: string
  name: string
  description: string
  htmlTemplate: string
  cssTemplate: string
  jsTemplate: string | null
  bindingSpecJson: string
  requiredCapabilities: string[]
  version: number
  isActive: boolean
  createdBy: 'agent' | 'user' | 'system'
  createdAt: number
  updatedAt: number
}

export interface CanvasDefinitionInput {
  id: string
  name: string
  description: string
  htmlTemplate: string
  cssTemplate: string
  jsTemplate?: string | null
  bindingSpecJson: string
  requiredCapabilities?: string[]
  createdBy: 'agent' | 'user' | 'system'
}

export interface CanvasDefinitionStore {
  createDefinition(input: CanvasDefinitionInput): Promise<CanvasDefinitionRow>
  getDefinition(id: string): Promise<CanvasDefinitionRow | null>
  listDefinitions(opts?: { createdBy?: string; isActive?: boolean }): Promise<CanvasDefinitionRow[]>
  updateDefinition(id: string, patch: Partial<Omit<CanvasDefinitionInput, 'id'>>): Promise<CanvasDefinitionRow>
  deleteDefinition(id: string): Promise<void>
  setActive(id: string, isActive: boolean): Promise<void>
}
```

### New file: `src/engines/canvas-registry.ts`

```typescript
import type { CanvasDefinitionStore } from '../storage/contracts/canvas-store.js'
import { EngineError } from '../errors.js'

export interface CanvasBindingSpecStub {
  outputs: Array<{ capabilityOutputKey: string; selector: string; attribute: string }>
  inputs: Array<{ selector: string; event: string; capabilityInputKey: string }>
}

export class CanvasRegistry {
  constructor(private store: CanvasDefinitionStore) {}

  async define(input: Omit<CanvasDefinitionInput, 'id'> & { id?: string }): Promise<CanvasDefinitionRow> {
    const id = input.id ?? newId()
    // Validate the binding spec is parseable JSON
    try {
      JSON.parse(input.bindingSpecJson)
    } catch {
      throw new EngineError('bindingSpecJson must be valid JSON')
    }
    // Reject inline <script> injection in templates — CSP is enforced at render (3.12),
    // but we fail closed at definition time too.
    if (/<script\b/i.test(input.htmlTemplate) || /<script\b/i.test(input.jsTemplate ?? '')) {
      throw new EngineError('Canvas templates must not contain inline <script> tags')
    }
    return this.store.createDefinition({ ...input, id })
  }

  get(id: string): Promise<CanvasDefinitionRow | null> {
    return this.store.getDefinition(id)
  }

  list(opts?: { createdBy?: string; isActive?: boolean }): Promise<CanvasDefinitionRow[]> {
    return this.store.listDefinitions(opts)
  }

  async update(id: string, patch: Partial<Omit<CanvasDefinitionInput, 'id'>>): Promise<CanvasDefinitionRow> {
    if (patch.bindingSpecJson) JSON.parse(patch.bindingSpecJson) // validate
    if (patch.htmlTemplate && /<script\b/i.test(patch.htmlTemplate)) {
      throw new EngineError('Canvas templates must not contain inline <script> tags')
    }
    return this.store.updateDefinition(id, patch)
  }

  delete(id: string): Promise<void> {
    return this.store.deleteDefinition(id)
  }
}
```

## Acceptance Criteria

1. Migration adds `CanvasDefinition` and `bunx prisma generate` succeeds.
2. `CanvasRegistry.define` writes a row; `get`/`list` return it.
3. `define` rejects a definition whose `bindingSpecJson` is not valid JSON.
4. `define` rejects HTML/JS templates containing `<script>` tags.
5. `update` increments `version` and touches `updatedAt`.
6. `bun run devops gate` passes.

## Tests

`tests/unit/engines/canvas-registry.test.ts`:
- define → get round-trips a definition.
- list filters by `createdBy` and `isActive`.
- define with malformed `bindingSpecJson` → throws `EngineError`.
- define with `<script>` in `htmlTemplate` → throws.
- update patches fields; get reflects changes.
- delete removes the row.
