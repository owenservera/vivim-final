# Unit 3.7 — CanvasDiscovery read state

**Source:** v3 Overview §1.6; `docs/master-plan-v3/PHASE-03-html-canvas.md` §3.7
**Design Doc:** `docs/master-plan-v3/PHASE-03-html-canvas.md` §3.7
**Depends on:** 3.3
**Produces:** `CanvasDiscovery.{snapshot, extractForm, listInteractive, screenshot}`.

---

## Context

An agent often needs to *read* a canvas it did not author — e.g. inspect a third-party provider's rendered form to know what fields exist. `CanvasDiscovery` is the read-side toolkit, implemented over CDP on the canvas's backing tab (the same primitive `ChromeGovernor.cdp` exposes):

- `snapshot(canvasId)` → full DOM as a JSON tree.
- `extractForm(canvasId, selector)` → form field values keyed by `name`/`data-cap-bind`.
- `listInteractive(canvasId)` → all elements carrying `data-cap-bind` or a standard interactive role (button/input/select/a).
- `screenshot(canvasId)` → PNG (via `Page.captureScreenshot`).

## Existing Baseline

- `src/engines/chrome-governor.ts` — `cdp.send(slaveId, method, params)` (line 649); `captureScreenshot` (line 213). `Page.captureScreenshot` / `DOM.getDocument` + `DOM.getFlattenedDocument` are the CDP methods used.
- `CanvasSpawner` (3.3) — supplies `slaveId` per `canvasId`.
- `MirrorEngine` snapshot infra (`src/engines/mirror-engine.ts:54` `SnapshotRow`) shares the "capture state" concept.

## Interface

### New file: `src/engines/canvas-discovery.ts`

```typescript
import type { CanvasInstanceStore } from '../storage/contracts/canvas-instance-store.js'
import type { ChromeGovernor } from './chrome-governor.js'
import { EngineError } from '../errors.js'

export interface DomNode {
  tag: string
  selector: string
  attributes: Record<string, string>
  children: DomNode[]
  text?: string
}

export class CanvasDiscovery {
  constructor(
    private instanceStore: CanvasInstanceStore,
    private governor: ChromeGovernor,
  ) {}

  private async slaveFor(canvasId: string): Promise<string> {
    const inst = await this.instanceStore.getInstanceByCanvasId(canvasId)
    if (!inst?.slaveId) throw new EngineError(`Canvas ${canvasId} has no backing tab`)
    return inst.slaveId
  }

  async snapshot(canvasId: string): Promise<DomNode> {
    const slaveId = await this.slaveFor(canvasId)
    const res = await this.governor.cdp.send(slaveId, 'Runtime.evaluate', {
      expression: '(() => window.__canvasSnapshot ? window.__canvasSnapshot() : document.body.outerHTML)()',
      returnByValue: true,
    })
    return parseTree((res as { result?: { value?: unknown } }).result?.value)
  }

  async extractForm(canvasId: string, selector: string): Promise<Record<string, string>> {
    const slaveId = await this.slaveFor(canvasId)
    const res = await this.governor.cdp.send(slaveId, 'Runtime.evaluate', {
      expression: `(() => { const f = document.querySelector(${JSON.stringify(selector)}); if (!f) return {}; const out = {}; for (const el of f.elements) { const k = el.name || el.getAttribute('data-cap-bind'); if (k) out[k] = el.value; } return out; })()`,
      returnByValue: true,
    })
    return ((res as { result?: { value?: Record<string, string> } }).result?.value) ?? {}
  }

  async listInteractive(canvasId: string): Promise<Array<{ selector: string; role: string; capBind?: string }>> {
    const slaveId = await this.slaveFor(canvasId)
    const res = await this.governor.cdp.send(slaveId, 'Runtime.evaluate', {
      expression: `(() => { const els = [...document.querySelectorAll('[data-cap-bind],button,input,select,a')]; return els.map(el => ({ selector: cssPath(el), role: el.tagName.toLowerCase(), capBind: el.getAttribute('data-cap-bind') || undefined })); })()`,
      returnByValue: true,
    })
    return ((res as { result?: { value?: Array<{ selector: string; role: string; capBind?: string }> } }).result?.value) ?? []
  }

  async screenshot(canvasId: string): Promise<string> {
    const slaveId = await this.slaveFor(canvasId)
    return this.governor.cdp.captureScreenshot(slaveId, 'png')
  }
}

function parseTree(html: unknown): DomNode {
  // Delegate to runtime-side snapshot when available; fall back to minimal parse.
  if (typeof html === 'object' && html !== null) return html as DomNode
  return { tag: 'body', selector: 'body', attributes: {}, children: [], text: typeof html === 'string' ? html : undefined }
}
```

## Acceptance Criteria

1. `snapshot` returns a `DomNode` tree for a running canvas.
2. `extractForm` returns field values keyed by `name`/`data-cap-bind`.
3. `listInteractive` returns every `[data-cap-bind]` plus standard interactive elements with a CSS selector each.
4. `screenshot` returns a base64 PNG string.
5. All methods throw `EngineError` when the canvas has no backing tab.
6. `bun run devops gate` passes.

## Tests

`tests/unit/engines/canvas-discovery.test.ts` (mock `CanvasInstanceStore`, `ChromeGovernor`):
- `snapshot` → `cdp.send Runtime.evaluate` called, tree returned.
- `extractForm` → expression references the selector (assert `JSON.stringify(selector)` present, no interpolation of raw selector).
- `listInteractive` → returns array with `selector`/`role`.
- `screenshot` → `captureScreenshot` called with `'png'`.
- no `slaveId` → throws.
