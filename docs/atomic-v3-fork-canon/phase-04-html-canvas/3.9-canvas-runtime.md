**Design Doc:** `docs/master-plan-v3/PHASE-03-html-canvas.md` §3.9
**Depends on:** 3.6
**Produces:** `web/canvas-runtime/index.js` injected into every canvas iframe.

## Context

The canvas runtime is the ~200-line vanilla-JS glue injected into every canvas iframe. It is the *client* side of the sync protocol: it bridges the sandboxed iframe DOM to the parent workspace over `postMessage`, applies agent mutations, captures user events, and exposes an in-canvas capability dispatch. Crucially this script runs inside the strict CSP + sandbox established in 3.12, so it must be self-contained (no external imports) and must never `eval` untrusted strings.

Four responsibilities:
- (a) establish the `postMessage` channel with the parent workspace (handshake + heartbeat),
- (b) on `canvas:mutate` messages, apply DOM mutations to the live canvas,
- (c) on user events on `[data-cap-emit]` elements, send `canvas:event` messages,
- (d) expose `canvas.dispatch(actionId, params)` for in-canvas capability invocation.

## Existing Baseline

- `CanvasMirror.applyMutation` (3.5) — server side that produces `canvas:mutate` frames the runtime consumes.
- `CanvasEventIngest` (3.6) — server side that consumes the `canvas:event` frames this runtime emits.
- `SandboxRunner` (2.13) — the hardened `node:vm` context that runs a canvas's optional `jsTemplate`. The runtime is *separate* from `jsTemplate`: the runtime is trusted infra, `jsTemplate` is untrusted user/agent code executed only inside `SandboxRunner`.
- `src/engines/chrome-governor.ts` — canvases are served as `vivim://canvas/<canvasId>`; the host page injects this script.

## Interface

### New file: `web/canvas-runtime/index.js`

```javascript
// web/canvas-runtime/index.js — injected into every canvas iframe.
// Trusted infra. Runs under CSP `script-src 'self'` + iframe sandbox `allow-scripts`.
// NO eval / NO imports. Communicates with parent over postMessage.

(function () {
  const PARENT = window.parent
  let canvasId = null
  let token = null

  // (a) handshake
  function send(type, payload) {
    PARENT.postMessage({ __canvas: true, canvasId, token, type, payload }, '*')
  }
  window.addEventListener('message', (e) => {
    const msg = e.data
    if (!msg || msg.__canvas !== true) return
    if (msg.type === 'canvas:init') {
      canvasId = msg.payload.canvasId
      token = msg.payload.token
      send('canvas:ready', {})
    }
    if (msg.type === 'canvas:mutate') applyMutation(msg.payload.mutation)
  })

  // (b) apply agent mutations (structured — never string-built)
  function applyMutation(m) {
    const el = document.querySelector(m.selector)
    if (!el) return
    switch (m.op) {
      case 'setAttribute': el.setAttribute(m.attribute, m.value); break
      case 'insertHTML': el.insertAdjacentHTML(m.position, m.value); break
      case 'remove': el.remove(); break
      case 'setText': el.textContent = m.value; break
    }
  }

  // (c) capture user events on [data-cap-emit]
  document.addEventListener('click', onEmit, true)
  document.addEventListener('input', onEmit, true)
  document.addEventListener('change', onEmit, true)
  function onEmit(e) {
    const el = e.target.closest && e.target.closest('[data-cap-emit]')
    if (!el) return
    send('canvas:event', {
      elementType: el.tagName.toLowerCase(),
      selector: cssPath(el),
      eventType: e.type,
      value: el.value !== undefined ? el.value : null,
    })
  }

  // (d) in-canvas capability dispatch
  window.canvas = {
    dispatch(actionId, params) {
      send('canvas:action', { actionId, params })
    },
  }

  function cssPath(el) {
    if (!(el instanceof Element)) return ''
    const parts = []
    while (el && el.nodeType === 1) {
      let sel = el.tagName.toLowerCase()
      if (el.id) { sel += '#' + el.id; parts.unshift(sel); break }
      const sib = el.parentNode ? el.parentNode.children : []
      let idx = 1
      for (let i = 0; i < sib.length; i++) {
        if (sib[i] === el) break
        if (sib[i].tagName === el.tagName) idx++
      }
      parts.unshift(sel + ':nth-child(' + idx + ')')
      el = el.parentNode
    }
    return parts.join(' > ')
  }
})()
```

## Acceptance Criteria

1. The runtime establishes a `postMessage` handshake on `canvas:init` and replies `canvas:ready`.
2. On `canvas:mutate`, it applies `setAttribute`/`insertHTML`/`remove`/`setText` to the matched element.
3. Click/input/change on `[data-cap-emit]` elements emits a `canvas:event` with `selector`/`eventType`/`value`.
4. `window.canvas.dispatch(actionId, params)` emits a `canvas:action`.
5. The runtime never calls `eval`/`new Function` (CSP + 2.13 invariant). It is self-contained (no imports).
6. `bun run devops gate` passes; runtime lint clean.

## Tests

`tests/unit/web/canvas-runtime.test.ts` (jsdom or happy-dom):
- dispatch a `canvas:init` → runtime stores `canvasId` and posts `canvas:ready`.
- post `canvas:mutate {op:'setText'}` → element text updated.
- click a `[data-cap-emit]` button → `canvas:event` posted with correct selector.
- `window.canvas.dispatch('x', {a:1})` → `canvas:action` posted.
