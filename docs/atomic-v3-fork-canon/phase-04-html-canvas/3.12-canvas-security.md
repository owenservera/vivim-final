# Unit 3.12 — Canvas security model

**Source:** v3 Overview §1.9; `docs/master-plan-v3/PHASE-03-html-canvas.md` §3.12
**Design Doc:** `docs/master-plan-v3/PHASE-03-html-canvas.md` §3.12
**Depends on:** 3.9, 2.13
**Produces:** Per-canvas capability tokens; CSP rules; iframe sandbox.

---

## Context

Canvases execute third-party-shaped HTML/CSS/JS in the user's workspace. The security model has three layers:

1. **Per-canvas capability token** — every `CanvasInstance` (3.3) gets a `capabilityToken` listing the capability slugs it may invoke. The runtime (3.9) includes the token in every `canvas:action`; `CanvasEventIngest` (3.6) validates it before dispatching. Token generated from `definition.requiredCapabilities`.
2. **CSP** — `default-src 'none'; script-src 'self'`. Blocks any inline `<script>` injection in templates (also rejected at definition time in 3.1).
3. **Iframe sandbox** — `allow-scripts` only (no `allow-same-origin`), so canvas JS cannot reach parent DOM, cookies, or storage.

The canvas's optional `jsTemplate` (untrusted) runs inside `SandboxRunner` (2.13) — never via `new Function`/`eval`.

## Existing Baseline

- `src/engines/sandbox-runner.ts` (2.13) — hardened `node:vm` execution for `jsTemplate`. The canvas host page uses `SandboxRunner` to evaluate `jsTemplate`, NOT `loadInlineParser`'s `new Function` pattern (`src/engines/stream-parser.ts:195`).
- `src/engines/canvas-spawner.ts` (3.3) — calls `generateToken(def.requiredCapabilities)` to set `instance.capabilityToken`.
- `src/engines/canvas-event-ingest.ts` (3.6) — already validates `token === instance.capabilityToken`.
- `prisma/schema.prisma` — `CanvasInstance.capabilityToken` column added in 3.3.

## Interface

### New file: `src/engines/canvas-security.ts`

```typescript
import type { CanvasInstanceStore } from '../storage/contracts/canvas-instance-store.js'
import type { SandboxRunner } from './sandbox-runner.js'

export const CANVAS_CSP = "default-src 'none'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; connect-src 'self'"

export const CANVAS_SANDBOX = 'allow-scripts' // intentionally NO allow-same-origin

export function generateToken(allowedCapabilities: string[]): string {
  // Opaque, signed-ish token encoding the allow-list.
  const payload = Buffer.from(JSON.stringify({ caps: allowedCapabilities, ts: Date.now() })).toString('base64url')
  return `cvt_${payload}`
}

export function tokenAllows(token: string, capabilitySlug: string): boolean {
  if (!token.startsWith('cvt_')) return false
  try {
    const json = Buffer.from(token.slice(4), 'base64url').toString('utf8')
    const { caps } = JSON.parse(json) as { caps: string[] }
    return caps.includes(capabilitySlug)
  } catch {
    return false
  }
}

export class CanvasSecurity {
  constructor(
    private instanceStore: CanvasInstanceStore,
    private sandbox: SandboxRunner,
  ) {}

  // Run a canvas's optional untrusted jsTemplate inside the hardened sandbox.
  async runCanvasScript(canvasId: string, jsTemplate: string, input: Record<string, unknown>): Promise<unknown> {
    const instance = await this.instanceStore.getInstanceByCanvasId(canvasId)
    if (!instance) throw new EngineError(`CanvasInstance ${canvasId} not found`)
    // SandboxRunner enforces no process/require/fetch and a CPU/memory budget.
    const res = await this.sandbox.run(jsTemplate, input, {
      canFetch: [],
      canReadFile: [],
      canWriteFile: [],
      canUseClipboard: false,
    })
    if (!res.ok) throw new EngineError(`Canvas script failed: ${res.error}`)
    return res.output
  }
}
```

The CSP header is attached by the canvas host route (`vivim://canvas/<canvasId>`) using `CANVAS_CSP`; the iframe `sandbox` attribute uses `CANVAS_SANDBOX`.

## Acceptance Criteria

1. `generateToken(caps)` produces a token from which `tokenAllows` recovers the allow-list.
2. `tokenAllows` returns `true` only for slugs in the token; malformed/forged tokens return `false`.
3. `runCanvasScript` executes `jsTemplate` via `SandboxRunner` (no `new Function`/`eval` path).
4. CSP string is `default-src 'none'; script-src 'self'` (blocks inline script).
5. Sandbox attribute is `allow-scripts` only — no `allow-same-origin`.
6. `bun run devops invariants check --category F` (no eval outside SandboxRunner) passes; `bun run devops gate` passes.

## Tests

`tests/unit/engines/canvas-security.test.ts`:
- `generateToken` + `tokenAllows` round-trip; unknown slug → false.
- tampered token → `tokenAllows` false.
- `runCanvasScript` delegates to `SandboxRunner.run` with `canFetch:[]`.
- `CANVAS_CSP` contains `script-src 'self'` and no `'unsafe-inline'` script source; `CANVAS_SANDBOX === 'allow-scripts'`.
