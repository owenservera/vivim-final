# 0.6 — KernelBootstrap

**Phase:** 0 · **Domain:** Kernel Core · **Status:** DRAFT

## Purpose

Wire the kernel into `createServerWithEngines()`. Establishes the bootstrap sequence:
kernel first, then all engines receive KernelContext.

## Interface

```typescript
// src/server/index.ts — modified bootstrap:
export async function createServerWithEngines(opts: ServerOptions): Promise<ServerResult> {
  // 1. Create Kernel (before any engines)
  const kernel = createKernel({ prisma, eventBus, config })

  // 2. Create KernelContext
  const kctx = kernel.context()

  // 3. Pass KernelContext to every engine constructor
  //    (existing engines gain optional `kernel?: KernelContext` param)
  const chromeGovernor = new ChromeGovernor({ ... }, kctx)
  const conversationManager = new ConversationManager({ ... }, kctx)
  const capabilityEventBus = kctx.eventBus
  // ... etc

  // 4. Wire dependencies (after all engines created)
  //    kernel.registry marks each as 'wired'
  for (const engine of allEngines) {
    kctx.registry.markWired(engine.id)
  }

  // 5. Start kernel
  await kernel.start()

  // 6. Start topology snapshots (every 60s)
  setInterval(() => {
    const snapshot = kctx.registry.describe()
    kctx.store.saveTopology(snapshot)
  }, 60_000)

  // 7. Register shutdown hook
  process.on('SIGTERM', async () => {
    await kernel.stop()
  })

  return { server, kernel, ... }
}
```

## Bootstrap Sequence

```
1. Create Prisma client
2. Create CapabilityEventBus
3. Create ConfigManager
4. Create Kernel → KernelContext with all subsystems
5. Create ChromeGovernor(kctx) → registers as 'chrome-governor'
6. Create FleetSupervisor(kctx) → registers as 'fleet-supervisor'
7. Create UnifiedCapabilityRegistry(kctx) → registers as 'unified-registry'
8. Create ConversationManager(kctx) → registers as 'conversation-manager'
9. ... all other engines ...
10. Wire dependencies (markWired for each)
11. kernel.start() → marks all as 'running'
12. Start periodic topology snapshot
13. Start HTTP server
```

## Legacy Engine Handling

Engines that don't yet accept KernelContext are registered by the bootstrap with:
```typescript
kctx.registry.registerEngine({
  id: 'legacy-engine',
  kind: 'engine',
  dependencies: [],
  status: 'running',
  config: {},
  metadata: { legacy: true },
})
```
