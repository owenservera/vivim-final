# 0.6a — Server Bootstrap Refactor

**Phase:** 00 · **Domain:** Kernel Core · **Status:** DRAFT · **Effort:** S (4h)

## Purpose

Refactor `createServerWithEngines()` in `src/server/index.ts` to:
1. Create Kernel first (before all engines)
2. Pass `KernelContext` to every engine constructor
3. Register shutdown hooks for graceful teardown
4. Start periodic topology snapshots

## Problem Statement

Current `createServerWithEngines()` at `src/server/index.ts:212` creates engines
without a kernel context. The kernel must be created BEFORE engines because:
- Engines register with the kernel at construction time
- Kernel needs to be running for topology snapshots
- Shutdown hooks need kernel reference for cleanup

## Target Code

```typescript
// TARGET — kernel-first bootstrap
import { KernelRegistry } from '../engines/kernel/kernel-registry.js'
import { KernelTracer } from '../engines/kernel/kernel-tracer.js'
import { KernelProvenance } from '../engines/kernel/kernel-provenance.js'

export async function createServerWithKernel(config: ServerConfig): Promise<Server> {
  // 1. Create kernel components FIRST
  const kernelRegistry = new KernelRegistry()
  const kernelTracer = new KernelTracer(kernelStore)
  const kernelProvenance = new KernelProvenance(kernelStore)

  const kernelContext: KernelContext = {
    registry: kernelRegistry,
    tracer: kernelTracer,
    provenance: kernelProvenance,
    eventBus: CapabilityEventBusV2.getInstance(),
  }

  // 2. Pass kernel context to every engine
  const engines = await createEngines(kernelContext, config)

  // 3. Register shutdown hooks
  process.on('SIGTERM', async () => {
    await kernelTracer.flush()
    await kernelRegistry.stopAll()
    process.exit(0)
  })

  // 4. Start periodic topology snapshots (every 30s)
  setInterval(async () => {
    const topology = kernelRegistry.describe()
    await kernelStore.saveTopology(topology)
  }, 30_000)

  // 5. Create server with kernel context
  return createServer({ engines, kernelContext, ...config })
}
```
