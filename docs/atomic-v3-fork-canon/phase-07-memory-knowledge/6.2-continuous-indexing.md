# Unit 6.2 — Continuous indexing pipeline

**Source:** v3 Overview §1.5; `docs/master-plan-v3/PHASE-06-memory-knowledge.md` §6.2
**Design Doc:** `docs/master-plan-v3/PHASE-06-memory-knowledge.md` §6.2

**Produces:** Every conversation message + every asserted fact gets indexed automatically.

---

## Context

Indexing must be automatic, not on-demand. `MemoryEngine.recordEpisode` and `assertFact` trigger `SemanticSearchEngine.index` asynchronously — queued and debounced so a burst of messages doesn't flood the embedder. Vectors live in `memory_embedding`. Reindex fires only when a content hash changes (skip churn).

## Existing Baseline

- `src/engines/semantic-search.ts` — `SemanticSearchEngine.index(text, entityType, entityId)` + `indexBatch(...)`. `upsertEmbedding` writes `{ embedding, model, dimensions }`.
- `src/engines/memory-engine.ts` — `MemoryEngine` with `recordEpisode` / `assertFact`; we hook these.
- `src/engines/stream-parser.ts` — message finalization is the trigger point.
- `src/engines/conversation-manager.ts` — emits completion events the extractor (6.3) also listens to.

## Interface

### New file: `src/engines/indexing-pipeline.ts`

```typescript
import type { SemanticSearchEngine } from './semantic-search.js'
import type { MemoryEngine } from './memory-engine.js'

export class IndexingPipeline {
  private queue: Array<{ text: string; type: string; id: string; hash: string }> = []
  private timer: ReturnType<typeof setTimeout> | null = null
  private seenHashes = new Map<string, string>()

  constructor(
    private semantic: SemanticSearchEngine,
    private memory: MemoryEngine,
    private debounceMs = 500,
  ) {}

  // Call from recordEpisode / assertFact.
  enqueue(text: string, type: string, id: string): void {
    const hash = hashContent(text)
    if (this.seenHashes.get(id) === hash) return // no content change -> skip reindex
    this.seenHashes.set(id, hash)
    this.queue.push({ text, type, id, hash })
    this.schedule()
  }

  private schedule(): void {
    if (this.timer) return
    this.timer = setTimeout(() => void this.flush(), this.debounceMs)
  }

  private async flush(): Promise<void> {
    this.timer = null
    const batch = this.queue.splice(0)
    if (batch.length === 0) return
    await this.semantic.indexBatch(
      batch.map((b) => b.text),
      batch.map((b) => b.type),
      batch.map((b) => b.id),
    )
  }
}
```

### Wiring

```typescript
// inside MemoryEngine.recordEpisode / assertFact, after persisting:
this.pipeline?.enqueue(text, 'episode' | 'fact', row.id)
```

## Acceptance Criteria

1. `recordEpisode` enqueues the message text for embedding; the queue flushes within `debounceMs`.
2. `assertFact` enqueues the fact; indexed into `memory_embedding`.
3. Identical content re-enqueued with an unchanged hash is skipped (no reindex churn).
4. A burst of N messages results in a single batched `indexBatch` call (debounced).
5. `bun run devops gate` passes.
