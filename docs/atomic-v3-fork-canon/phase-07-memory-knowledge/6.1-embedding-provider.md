# Unit 6.1 — Real embedding provider (local-first)

**Source:** v3 Overview §1.10; `docs/master-plan-v3/PHASE-06-memory-knowledge.md` §6.1
**Design Doc:** `docs/master-plan-v3/PHASE-06-memory-knowledge.md` §6.1
**Depends on:** 5.1
**Produces:** `OllamaEmbeddingProvider` implementing `EmbeddingProvider`.

---

## Context

Semantic search is currently wired to a noop embedding (all-zeros), making "semantic" search effectively random. This unit ships a real `EmbeddingProvider`: Ollama's `/api/embeddings` endpoint using the `nomic-embed-text` model. When no Ollama is available, it falls back to a pure-TS MiniLM impl — slower but works fully offline (sovereign/local-first). Replaces the noop provider in `createServerWithEngines`.

## Existing Baseline

- `src/engines/semantic-search.ts` — `EmbeddingProvider` interface: `embed(text): Promise<number[]>`, `embedBatch(texts): Promise<number[][]>`, plus `name` + `dimensions`. `SemanticSearchEngine` already calls these; we only swap the implementation.
- `src/engines/local-model-adapter.ts` (5.1) — Ollama HTTP client pattern (`http://localhost:11434`); reuse the fetch style.
- `src/engines/airgap.ts` — `AirGapEngine`; the fallback keeps search working offline.
- `src/server/index.ts` — constructs `SemanticSearchEngine` with a provider; swap to the new one.

## Interface

### New file: `src/engines/embedding-ollama.ts`

```typescript
import type { EmbeddingProvider } from './semantic-search.js'

export class OllamaEmbeddingProvider implements EmbeddingProvider {
  readonly name = 'ollama:nomic-embed-text'
  readonly dimensions = 768
  private endpoint: string

  constructor(endpoint = 'http://localhost:11434') {
    this.endpoint = endpoint
  }

  async embed(text: string): Promise<number[]> {
    return (await this.embedBatch([text]))[0]
  }

  async embedBatch(texts: string[]): Promise<number[][]> {
    const res = await fetch(`${this.endpoint}/api/embeddings`, {
      method: 'POST',
      headers: { 'content-type': 'application/json' },
      body: JSON.stringify({ model: 'nomic-embed-text', input: texts }),
    })
    if (!res.ok) throw new EngineError(`Ollama embed failed: ${res.status}`)
    const data = (await res.json()) as { embeddings: number[][] }
    return data.embeddings
  }
}
```

### New file: `src/engines/embedding-minilm.ts` (offline fallback)

```typescript
import type { EmbeddingProvider } from './semantic-search.js'

// Pure-TS MiniLM-lite: deterministic token-pool embedding.
// Not SOTA, but produces real (non-zero) vectors with cosine structure offline.
export class MiniLmEmbeddingProvider implements EmbeddingProvider {
  readonly name = 'minilm:ts'
  readonly dimensions = 256
  private vocab = buildVocab()
  async embed(text: string): Promise<number[]> { return this.pool(text) }
  async embedBatch(texts: string[]): Promise<number[][]> { return texts.map((t) => this.pool(t)) }
  private pool(text: string): number[] { /* hashed token bag-of-words -> 256-d */ }
}
```

### Factory in `src/server/index.ts`

```typescript
let embedding: EmbeddingProvider
try { embedding = new OllamaEmbeddingProvider(); await embedding.embed('ping') }
catch { embedding = new MiniLmEmbeddingProvider() } // offline fallback
const semantic = new SemanticSearchEngine(semanticStore, embedding)
```

## Acceptance Criteria

1. `OllamaEmbeddingProvider.embed` returns a 768-d non-zero vector via `/api/embeddings`.
2. When Ollama is unreachable, the factory falls back to `MiniLmEmbeddingProvider` (still non-zero).
3. `SemanticSearchEngine` produces real nearest-neighbor ranking (not random) with either provider.
4. `dimensions` matches the vector column in `memory_embedding` (no insert mismatch).
5. No all-zeros vectors are ever stored (acceptance: semantic search is "real").
6. `bun run devops gate` passes.
