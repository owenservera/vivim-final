## Context

Users must be able to **port** their memory graph out (backup, move, share) and back in. `ExportEngine` exists; this unit makes export real and adds a symmetric import. Formats: `json` (full fidelity, includes embeddings-free facts + episodes + rules) and `markdown` (human-readable digest). **Encryption is NOT applied here** — the wire format carries an `encrypted` flag defaulting to `false`; Phase 9 (MemoryBrowserSurface "real marks") applies envelope encryption. Conflicting IDs on import are remapped to preserve local facts (merge-by-content, prefer higher confidence).

## Interface

### Extension in `src/engines/export.ts`

```typescript
export type ExportFormat = 'json' | 'markdown'

export interface MemoryExport {
  version: 1
  encrypted: false // Phase 9 flips + wraps payload
  exportedAt: number
  facts: SemanticMemoryRow[]
  episodes: EpisodicMemoryRow[]
  rules: ProceduralRuleRow[]
}

export class ExportEngine {
  constructor(private memory: MemoryEngine) {}

  async export(format: ExportFormat): Promise<string> {
    const data: MemoryExport = {
      version: 1, encrypted: false, exportedAt: Date.now(),
      facts: await this.memory.getAllFacts(),
      episodes: await this.memory.getAllEpisodes(),
      rules: await this.memory.getAllRules(),
    }
    return format === 'json' ? JSON.stringify(data, null, 2) : toMarkdown(data)
  }

  async import(json: string): Promise<{ merged: number; skipped: number }> {
    const data = JSON.parse(json) as MemoryExport
    let merged = 0, skipped = 0
    for (const f of data.facts) {
      const existing = await this.memory.findByContent(f.subject, f.predicate, f.object)
      if (existing && existing.confidence >= f.confidence) { skipped++; continue }
      await this.memory.assertFact({ ...f, source: 'import', confidence: f.confidence })
      merged++
    }
    // episodes + rules appended similarly (dedupe by content hash)
    return { merged, skipped }
  }
}

function toMarkdown(d: MemoryExport): string { /* grouped by entity */ }
```

## Acceptance Criteria

1. `export('json')` returns a parseable `MemoryExport` with `encrypted:false` and all facts/episodes/rules.
2. `export('markdown')` returns human-readable grouped text.
3. `import(json)` merges by content; equal/higher-confidence existing facts are `skipped` (no clobber).
4. Imported facts carry `source:'import'`.
5. Round-trip: export → import yields `merged` equal to exported count (empty target).
6. `bun run devops gate` passes.
