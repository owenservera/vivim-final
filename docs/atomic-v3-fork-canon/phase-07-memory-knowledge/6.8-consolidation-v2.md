# Unit 6.8 — Consolidation v2 (real)

**Source:** v3 Overview §1.5; `docs/master-plan-v3/PHASE-06-memory-knowledge.md` §6.8
**Design Doc:** `docs/master-plan-v3/PHASE-06-memory-knowledge.md` §6.8
**Depends on:** 6.1, 6.7
**Produces:** `MemoryEngine.consolidate` runs a real pass: dedupe, decay, promote.

---

## Context

`MemoryEngine.consolidate` today is a no-op or trivial. This unit makes it a real maintenance pass that runs on a schedule (and on-demand):
1. **Dedupe** — facts with identical `subject`+`predicate`+`object` are merged; the surviving row keeps the max confidence and is re-`index`ed (6.2).
2. **Decay** — unverified facts older than `decayDays` lose confidence by a factor; confidence ≤ `minConfidence` get deprecated.
3. **Promote** — a `subject`+`predicate` pair that recurs with high confidence across ≥ `promoteThreshold` facts becomes a `ProceduralRule` (stable operational knowledge).

## Existing Baseline

- `src/engines/memory-engine.ts` — `MemoryEngine.consolidate()`; `EpisodicMemory` / `SemanticMemory` / `ProceduralRule` interfaces. We replace the body.
- `src/engines/semantic-search.ts` — `indexBatch` re-indexes surviving deduped facts.
- `src/engines/memory-engine.ts` `assertFact` — the procedural-rule sink.
- `src/engines/capability-event-bus.ts` — emit `memory:consolidated` with a summary.

## Interface

### Extension in `src/engines/memory-engine.ts`

```typescript
export interface ConsolidationConfig {
  decayDays: number
  decayFactor: number
  minConfidence: number
  promoteThreshold: number
}

export interface ConsolidationReport {
  merged: number
  decayed: number
  deprecated: number
  promoted: number
}

export class MemoryEngine {
  // ...
  async consolidate(cfg: Partial<ConsolidationConfig> = {}): Promise<ConsolidationReport> {
    const c = { decayDays: 30, decayFactor: 0.9, minConfidence: 0.2, promoteThreshold: 3, ...cfg }
    const report: ConsolidationReport = { merged: 0, decayed: 0, deprecated: 0, promoted: 0 }

    // 1. Dedupe
    const dupes = await this.store.findDuplicateFacts()
    for (const group of dupes) {
      const survivor = group.reduce((a, b) => (b.confidence > a.confidence ? b : a))
      await this.store.mergeFacts(group.map((g) => g.id), survivor.id)
      await this.semantic.index(survivor.object, 'fact', survivor.id)
      report.merged += group.length - 1
    }

    // 2. Decay
    const stale = await this.store.getStaleUnverifiedFacts(c.decayDays)
    for (const f of stale) {
      const next = Math.max(0, f.confidence * c.decayFactor)
      if (next <= c.minConfidence) { await this.store.updateSemanticFact(f.id, { deprecated: true }); report.deprecated++ }
      else { await this.store.updateSemanticFact(f.id, { confidence: next }); report.decayed++ }
    }

    // 3. Promote recurring high-confidence pairs to ProceduralRule
    const pairs = await this.store.getFrequentPairs(c.promoteThreshold)
    for (const p of pairs) {
      await this.assertProcedureRule({ trigger: p.subject, action: p.predicate, outcome: p.object, confidence: p.confidence })
      report.promoted++
    }

    this.bus.emit('memory:consolidated', report)
    return report
  }
}
```

## Acceptance Criteria

1. Duplicate `subject`+`predicate`+`object` groups are merged to one survivor (max confidence).
2. Merged survivor is re-indexed via `SemanticSearchEngine.index`.
3. Stale unverified facts decay by `decayFactor`; those dropping ≤ `minConfidence` are deprecated.
4. Frequent high-confidence pairs become `ProceduralRule` rows (promotion).
5. `consolidate` emits `memory:consolidated` with a numeric report.
6. `bun run devops gate` passes.
