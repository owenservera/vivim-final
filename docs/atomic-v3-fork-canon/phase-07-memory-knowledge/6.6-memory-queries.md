# Unit 6.6 — In-flight memory queries (agent action)

**Source:** v3 Overview §1.4; `docs/master-plan-v3/PHASE-06-memory-knowledge.md` §6.6
**Design Doc:** `docs/master-plan-v3/PHASE-06-memory-knowledge.md` §6.6
**Depends on:** 6.1
**Produces:** Capabilities `memory_query`, `memory_assert`, `memory_remember`, `memory_forget` registered in `UnifiedCapabilityRegistry`.

---

## Context

The agent must query and mutate memory **mid-loop** — e.g. "what did I learn about this user's codebase last week?" via `memory_query`. Assertions during a loop (`memory_assert`) feed the graph immediately so the *next* iteration recalls them (acceptance). This is what makes the agent adaptive rather than stateless.

Implemented as four capabilities registered in `UnifiedCapabilityRegistry` (1.3) so they auto-export to MCP/CLI/UI/API. `memory_query` is also a dependency of `AgenticConversationLoop.adapt` (2.11).

## Existing Baseline

- `src/engines/memory-engine.ts` — `MemoryEngine` with `recallFacts(query)`, `assertFact(input)`, `forgetFact(id)`, `recallEpisodes(...)`. These are the handlers.
- `src/engines/semantic-search.ts` — `SemanticSearchEngine.search(query, k)` powers `memory_query` relevance (real embeddings from 6.1).
- `src/engines/unified-registry.ts` (1.3) — `register` / `exportForMcp`.
- `src/engines/capability-bootstrap.ts` (1.3) — `registerDefaultCapabilities` is extended here.

## Interface

### Extension in `src/engines/capability-bootstrap.ts`

```typescript
import type { MemoryEngine } from './memory-engine.js'
import type { SemanticSearchEngine } from './semantic-search.js'

function registerMemoryCapabilities(registry: UnifiedCapabilityRegistry, svc: { memory: MemoryEngine; semantic: SemanticSearchEngine }): void {
  registry.register(makeCapability({
    id: 'cap:memory:query', slug: 'memory_query', name: 'Query Memory',
    description: 'Semantic query over episodic/semantic/procedural memory.',
    category: 'memory',
    inputSchema: { type: 'object', properties: { query: { type: 'string' }, k: { type: 'number' } }, required: ['query'] },
    outputSchema: { type: 'array' },
    mcpToolName: 'memory_query',
    apiEndpoint: { method: 'GET', path: '/api/memory/query' },
  }, async (input) => {
    const hits = await svc.semantic.search(String(input.query), Number(input.k ?? 8))
    return hits
  }))

  registry.register(makeCapability({
    id: 'cap:memory:assert', slug: 'memory_assert', name: 'Assert Fact',
    description: 'Assert a subject-predicate-object fact immediately.',
    category: 'memory',
    inputSchema: { type: 'object', properties: { subject: { type: 'string' }, predicate: { type: 'string' }, object: { type: 'string' }, confidence: { type: 'number' } }, required: ['subject', 'predicate', 'object'] },
    outputSchema: { type: 'object' },
    mcpToolName: 'memory_assert',
    apiEndpoint: { method: 'POST', path: '/api/memory/facts' },
  }, async (input) => svc.memory.assertFact({
    subject: String(input.subject), predicate: String(input.predicate), object: String(input.object),
    confidence: Number(input.confidence ?? 0.6), source: 'agent',
  })))

  registry.register(makeCapability({
    id: 'cap:memory:remember', slug: 'memory_remember', name: 'Remember Episode',
    description: 'Record an episodic memory.',
    category: 'memory',
    inputSchema: { type: 'object', properties: { content: { type: 'string' }, topic: { type: 'string' } }, required: ['content'] },
    outputSchema: { type: 'object' },
    mcpToolName: 'memory_remember',
    apiEndpoint: { method: 'POST', path: '/api/memory/episodes' },
  }, async (input) => svc.memory.recordEpisode({ content: String(input.content), topic: input.topic as string | undefined })))

  registry.register(makeCapability({
    id: 'cap:memory:forget', slug: 'memory_forget', name: 'Forget Fact',
    description: 'Deprecate a fact by id (not hard delete).',
    category: 'memory',
    inputSchema: { type: 'object', properties: { id: { type: 'string' } }, required: ['id'] },
    outputSchema: { type: 'object' },
    mcpToolName: 'memory_forget',
    apiEndpoint: { method: 'DELETE', path: '/api/memory/facts/{id}' },
  }, async (input) => { await svc.memory.forgetFact(String(input.id)); return { ok: true } }))
}
```

Called from `registerDefaultCapabilities` after the conversation capabilities.

## Acceptance Criteria

1. After bootstrap, `registry.list({ category: 'memory' }).length >= 4`.
2. `memory_query` handler calls `semantic.search` with the query + `k`.
3. `memory_assert` calls `memory.assertFact` and the fact is immediately `recallFacts`-able (no async lag).
4. `memory_remember` records an episode; `memory_forget` deprecates (does not hard-delete).
5. All four export to MCP (`exportForMcp` includes `memory_query` etc.).
6. `bun run devops gate` passes.

## Tests

`tests/unit/engines/memory-capabilities.test.ts` (mock `MemoryEngine`, `SemanticSearchEngine`):

- `memory_forget` → `forgetFact` (deprecate) called.
