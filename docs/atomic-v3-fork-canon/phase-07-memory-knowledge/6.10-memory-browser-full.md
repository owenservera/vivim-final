## Context

The `conversation-browser` (4.7) is a partial memory surface; this unit is the **full** MemoryBrowserSurface — the dedicated knowledge-graph view. It renders the graph from `6.5`, lists episodes on a `timeline`, exposes **curation controls** (verify/reject/edit from 6.7), runs **synthesis** (6.4), and supports **import/export** (6.9). Built in React (new dep, see 4.x) with a force-directed graph (cytoscape or d3-force). It is a primary UX surface in the sovereign/local-first vision.

## Interface

### New file: `web/src/surfaces/MemoryBrowser.tsx` (sketch)

```tsx
import { useEffect, useState } from 'react'
import cytoscape from 'cytoscape'
import { useMemoryStore } from '../stores/memoryStore' // zustand (4.x)

export function MemoryBrowser() {
  const { graph, loadSubgraph, verify, reject, edit } = useMemoryStore()
  const ref = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!ref.current || !graph) return
    cytoscape({ container: ref.current, elements: toCytoscape(graph), layout: { name: 'cose' }, style: graphStyle })
  }, [graph])

  return (
    <div className="memory-browser">
      <GraphPanel ref={ref} />
      <TimelinePanel onSelect={(id) => loadSubgraph(id)} />
      <CurationPanel onVerify={verify} onReject={reject} onEdit={edit} />
      <SynthesisPanel onSubmit={(q) => synthesize(q)} />
      <ImportExportPanel />
    </div>
  )
}
```

### Store contract (`web/src/stores/memoryStore.ts`)

```typescript
interface MemoryStore {
  graph: GraphView | null
  loadSubgraph(focal: string, depth?: number): Promise<void>
  verify(id: string): Promise<void>   // PATCH /api/memory/facts/{id}
  reject(id: string): Promise<void>   // DELETE /api/memory/facts/{id}
  edit(id: string, patch: { object?: string }): Promise<void>
  synthesize(query: string): Promise<SynthesisResult>
  exportMemory(format: 'json' | 'markdown'): Promise<string>
  importMemory(json: string): Promise<void>
}
```

### Registration (4.6 surface router)

```typescript
registerSurface({ id: 'memory-browser', label: 'Memory', component: MemoryBrowser, icon: 'graph' })
```

## Acceptance Criteria

1. Surface mounts inside the workspace shell (4.x) as a tab/route `memory-browser`.
2. Graph renders nodes/edges from `6.5` `subgraph` with confidence-weighted edges.
3. Clicking a node loads its `subgraph` (depth 2) and the timeline.
4. Verify/Reject/Edit controls call `6.7` endpoints and update the local graph.
5. Synthesis panel calls `6.4` and renders `text` + `sources` + `gaps`.
6. Import/Export panel calls `6.9` endpoints.
7. `bun run devops gate` passes and `web/` typechecks under the new React deps.
