# Unit 6.3 — Knowledge extractor continuous mode

**Source:** v3 Overview §1.5; `docs/master-plan-v3/PHASE-06-memory-knowledge.md` §6.3
**Design Doc:** `docs/master-plan-v3/PHASE-06-memory-knowledge.md` §6.3
**Depends on:** 1.8
**Produces:** `KnowledgeExtractor` runs on every assistant message in the background.

---

## Context

Entity / decision / pattern extraction should happen continuously, not as a batch job. The extractor subscribes to `conversation:complete` events; for each completed assistant message it runs `extractFromMessage`. Crucially, it uses the agent's reflection signal (from 2.11 `AgenticConversationLoop`) to weight confidence — facts extracted from **successful** turns get a +0.2 confidence boost (the agent "meant it" when the loop succeeded).

## Existing Baseline

- `src/engines/knowledge-extractor.ts` — `KnowledgeExtractor` with `extractFromMessage(message, ctx)` + `KnowledgeExtractorConfig`. We add background subscription, not rewrite extraction.
- `src/engines/agentic-loop.ts` (2.11) — emits a reflection/confidence signal per completed turn; the extractor reads it via event payload.
- `src/engines/capability-event-bus.ts` — `conversation:complete` event source.
- `src/engines/memory-engine.ts` — `assertFact` (the sink for extracted facts); 6.2 indexes them.

## Interface

### New file: `src/engines/knowledge-extractor-continuous.ts`

```typescript
import type { KnowledgeExtractor } from './knowledge-extractor.js'
import type { CapabilityEventBus } from './capability-event-bus.js'
import type { MemoryEngine } from './memory-engine.js'

export class KnowledgeExtractorContinuous {
  constructor(
    private extractor: KnowledgeExtractor,
    private bus: CapabilityEventBus,
    private memory: MemoryEngine,
  ) {}

  start(): void {
    this.bus.on('conversation:complete', (evt) => {
      void this.onComplete(evt as ConversationCompleteEvent)
    })
  }

  private async onComplete(evt: ConversationCompleteEvent): Promise<void> {
    for (const msg of evt.assistantMessages) {
      const result = await this.extractor.extractFromMessage(msg, {
        conversationId: evt.conversationId,
      })
      const boost = evt.turnSuccess ? 0.2 : 0
      for (const fact of result.facts) {
        await this.memory.assertFact({
          subject: fact.subject, predicate: fact.predicate, object: fact.object,
          confidence: Math.min(1, fact.confidence + boost),
          source: 'extraction',
        })
      }
    }
  }
}

interface ConversationCompleteEvent {
  conversationId: string
  assistantMessages: Array<{ id: string; content: string }>
  turnSuccess: boolean // from 2.11 reflection signal
}
```

## Acceptance Criteria

1. `start()` subscribes to `conversation:complete`; each assistant message is extracted.
2. Extracted facts are written via `memory.assertFact`.
3. `turnSuccess: true` adds +0.2 confidence (capped at 1.0).
4. `turnSuccess: false` applies no boost.
5. Extractor failures are caught per-message (one bad message does not stop the loop).
6. `bun run devops gate` passes.

## Tests
