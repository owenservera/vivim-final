# Unit 1.5 — Replace `as never` and `as any` in engines

**Source:** invariant D2 (`checkD2_TypeSafety`)
**Design Doc:** `docs/master-plan-v3/PHASE-01-stabilization.md` §1.5
**Depends on:** —
**Produces:** Zero `any` in `src/engines/`; zero `as never` escape hatches.

---

## Context

`devops invariants check --category D` reports D2 violations for every `: any` and `as any` in `src/engines/`. Known offenders (from initial scan):

- `src/engines/capability.ts:92` — `input?.recoveryStrategies as RecoveryStrategy[] | undefined`
- `src/engines/conversation-manager.ts:209` — `(resolved.composer[0] as unknown as { selector?: string })?.selector`
- `src/engines/autonomous-execution.ts:642` — `this.governor.cdp as unknown as InstanceType<...>`
- `src/engines/provider-mux.ts:122` — `ctx.providerMux as unknown as { store: { ... } }`
- `src/engines/harness-runtime.ts:240` — `this.createRealContext(slaveId, telemetry).query(selector)` (recursive `as any` workaround)
- Multiple `biome-ignore lint/suspicious/noExplicitAny` pragmas in `src/storage/impl/*-store-impl.ts` (these are storage layer, but check if any engine imports them and re-exposes `any`).

## Strategy

Three patterns cover 90% of cases:

### Pattern 1: Replace `as any` with `unknown` + type narrowing

**Before:**
```typescript
const data = result as any
const value = data?.field?.subField
```

**After:**
```typescript
const data = result as Record<string, unknown>
const field = data?.field as Record<string, unknown> | undefined
const value = field?.subField
```

### Pattern 2: Replace `as any` with proper generic constraint

**Before (autonomous-execution.ts):**
```typescript
const transport = this.governor.cdp as unknown as InstanceType<
  typeof SemanticGroundingEngine
> extends { transport: infer T }
  ? T
  : never
```

**After:** Add a public getter on `ChromeGovernor`:
```typescript
// src/engines/chrome-governor.ts
export class ChromeGovernor {
  /** Returns the raw CDP transport (for advanced consumers like SelectorHealer). */
  getTransport(): CDPTransport | null {
    return this.cdpTransport
  }
}
```
Then `SelectorHealer` consumers call `governor.getTransport()` and pass it to `SemanticGroundingEngine` constructor — no cast.

### Pattern 3: Replace Prisma escape hatches with typed client

**Before (`capability-store-impl.ts`):**
```typescript
private get p(): any {
  return this.db.prisma
}
```

**After:** Use the actual generated Prisma type:
```typescript
import type { PrismaClient } from '@prisma/client'

export class CapabilityStoreImpl implements CapabilityStore {
  private prisma: PrismaClient
  
  constructor(db: CapStoreDb) {
    this.prisma = db.prisma as PrismaClient
  }
  
  // No getter needed; methods reference `this.prisma` directly with full types.
}
```

The single `as PrismaClient` cast happens once at construction; everything downstream is typed.

## Acceptance Criteria

1. `rg ": any\b|as any\b" src/engines/` returns zero hits (excluding comments).
2. `rg "as never" src/engines/ src/server/` returns zero hits.
3. All `biome-ignore lint/suspicious/noExplicitAny` pragmas in `src/engines/` are removed.
4. `bun run typecheck` passes (no new type errors).
5. `bun run devops invariants check --category D` reports zero D2 warnings.
6. `bun run devops gate` passes.

## Risk

- **Medium.** Type narrowing can be tedious and may surface latent bugs (good!) or require refactoring (acceptable).
- The `provider-mux.ts:122` cast is breaking an encapsulation (accessing `engine.store` directly). Better fix: add `getRoutingPreferences()` method on `ProviderMuxEngine`. Do this as part of this unit.
