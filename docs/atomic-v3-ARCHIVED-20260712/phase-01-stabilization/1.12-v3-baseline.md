# Unit 1.12 — Establish v3 baseline: green devops gate

**Source:** v3 Overview §4 Scenario E
**Design Doc:** `docs/master-plan-v3/PHASE-01-stabilization.md` §1.12
**Depends on:** 1.1, 1.2, 1.3, 1.4, 1.5, 1.6, 1.7, 1.8, 1.9, 1.10, 1.11
**Produces:** A v3 baseline commit on which all subsequent phase work builds.

---

## Context

After 1.1-1.11 are complete, the codebase is in a known-good state. This unit verifies that state and locks it in as the v3 baseline.

## Acceptance Criteria

1. `bun run devops gate --strict` passes:
   - typecheck: PASS
   - lint: PASS
   - tests: PASS
   - invariants: PASS (zero violations across all categories A-E)
   - audit: PASS
   - coverage: PASS (engines ≥80%, server ≥85%, storage ≥70%, cli ≥60%)
   - strict: PASS (zero new lint issues in changed files)
2. `bun run devops truth scan` reports truth score ≥80% (target: ≥95% by Phase 10, but ≥80% is the baseline).
3. `bun run devops report` shows Phase 1 fully done.
4. Git commit tagged `v3-baseline` exists.
5. `CHANGELOG-v3.md` exists with Phase 1 summary.

## Steps

1. Run final gate:
   ```powershell
   bun run devops gate --strict
   ```
2. If any step fails, fix and re-run (do not bypass).
3. Run truth scan:
   ```powershell
   bun run devops truth scan
   ```
4. Tag the commit:
   ```powershell
   git add -A
   git commit -m "chore(v3): phase 1 baseline — stabilization complete"
   git tag v3-baseline
   ```
5. Create `CHANGELOG-v3.md`:
   ```markdown
   # v3 Changelog
   
   ## Phase 1: Stabilization & Cleanup (v3-baseline)
   
   - Removed legacy provider-logic/ directory (B3 compliance)
   - Wired AutonomousExecutionEngine into server bootstrap
   - Registered 18+ default capabilities in UnifiedCapabilityRegistry
   - Eliminated all stub markers in src/engines/
   - Replaced all `as any` and `as never` in engines with proper types
   - Replaced all raw `new Error()` in engines with CapStoreError subclasses
   - Fixed TelemetryAggregator SQL dialect for SQLite
   - Wired KnowledgeIngestion to extract entities from imported conversations
   - Replaced MuxDispatcher stub with real provider dispatch
   - Consolidated test fixtures and mock helpers
   - Achieved 80%+ coverage on engines, 85%+ on server
   ```

## DevOps Verification

```powershell
bun run devops gate --strict
bun run devops truth scan
bun run devops report
git tag --list v3-baseline
```
