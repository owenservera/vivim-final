# Unit 1.10 — Consolidate test fixtures and mock helpers

**Source:** v3 Overview §1.7 (test maintainability)
**Design Doc:** `docs/master-plan-v3/PHASE-01-stabilization.md` §1.10
**Depends on:** —
**Produces:** Single canonical mock store per contract; `createMockEngineContext()` helper; tests run faster.

---

## Context

The test suite has overlapping mock infrastructure:

- `tests/helpers/prisma-mock.ts` — full Prisma mock.
- `tests/integration/helpers/mock-chrome-launcher.ts`, `fake-chrome.ts`, `chrome-mock.ts` — three separate Chrome mocks.
- Per-test inline mocks for `ConversationStore`, `GovernorStore`, etc. — duplicated across many test files.
- No canonical way to construct a fully-wired engine context for integration tests.

## Strategy

### Single source of truth per store contract

For each `src/storage/contracts/*.ts` interface, create `tests/helpers/mocks/<contract-name>.mock.ts`:

```typescript
// tests/helpers/mocks/conversation-store.mock.ts
import { mock } from 'bun:test'
import type { ConversationStore, ConversationRow, ConversationMessageRow } from '@/storage/contracts/conversation-store'

export function createMockConversationStore(overrides: Partial<ConversationStore> = {}): ConversationStore {
  const conversations = new Map<string, ConversationRow>()
  const messages = new Map<string, ConversationMessageRow[]>()
  
  return {
    getConversation: mock(async (id: string) => conversations.get(id) ?? null),
    createConversation: mock(async (input) => {
      const row: ConversationRow = {
        id: crypto.randomUUID(),
        providerSessionId: input.providerSessionId,
        providerId: input.providerId,
        title: input.title ?? null,
        state: input.state ?? 'active',
        messageCount: 0,
        lastMessageAt: null,
        contextJson: input.contextJson ?? '{}',
        createdAt: Date.now(),
        updatedAt: Date.now(),
      }
      conversations.set(row.id, row)
      return row
    }),
    updateConversation: mock(async () => {}),
    deleteConversation: mock(async () => {}),
    listConversations: mock(async () => [...conversations.values()]),
    createMessage: mock(async (input) => {
      const msg: ConversationMessageRow = {
        id: crypto.randomUUID(),
        conversationId: input.conversationId,
        role: input.role,
        content: input.content ?? null,
        blocksJson: input.blocksJson ?? '[]',
        blockCount: input.blockCount ?? 0,
        parentMessageId: input.parentMessageId ?? null,
        sequenceIndex: input.sequenceIndex ?? 0,
        latencyMs: input.latencyMs ?? null,
        tokenCount: input.tokenCount ?? null,
        model: input.model ?? null,
        metadataJson: input.metadataJson ?? '{}',
        createdAt: Date.now(),
      }
      const list = messages.get(input.conversationId) ?? []
      list.push(msg)
      messages.set(input.conversationId, list)
      return msg
    }),
    getMessage: mock(async () => null),
    getMessages: mock(async (id: string) => messages.get(id) ?? []),
    getLastMessage: mock(async () => null),
    getAccount: mock(async () => null),
    ...overrides,
  }
}
```

### `createMockEngineContext` helper

```typescript
// tests/helpers/mock-engine-context.ts
import { CapabilityEventBus } from '@/engines/capability-event-bus'
import { createMockConversationStore } from './mocks/conversation-store.mock'
import { createMockCapabilityStore } from './mocks/capability-store.mock'
import { createMockGovernorStore } from './mocks/governor-store.mock'
// ... etc for every contract ...

export interface MockEngineContext {
  eventBus: CapabilityEventBus
  stores: {
    conversation: ReturnType<typeof createMockConversationStore>
    capability: ReturnType<typeof createMockCapabilityStore>
    governor: ReturnType<typeof createMockGovernorStore>
    // ... etc
  }
}

export function createMockEngineContext(): MockEngineContext {
  CapabilityEventBus.resetInstance()
  const eventBus = CapabilityEventBus.getInstance()
  
  return {
    eventBus,
    stores: {
      conversation: createMockConversationStore(),
      capability: createMockCapabilityStore(),
      governor: createMockGovernorStore(),
      // ... etc
    },
  }
}
```

## Migration

For each existing test file:

1. Identify which mocks it uses.
2. Replace inline mock definitions with imports from `tests/helpers/mocks/*`.
3. Replace manual engine-context wiring with `createMockEngineContext()`.
4. Run the test to verify it still passes.

## Acceptance Criteria

1. `tests/helpers/mocks/` exists with one mock per store contract.
2. `tests/helpers/mock-engine-context.ts` exports `createMockEngineContext`.
3. No test file in `tests/unit/` defines inline mocks longer than 20 lines.
4. The three old Chrome mock files are deleted.
5. `bun test` runs ≥20% faster than before (measured against a baseline).
6. `bun run devops gate` passes.
