# Unit 6.5 — Memory graph visualization data API

**Source:** v3 Overview §3 (MemoryBrowserSurface depends on this); `docs/master-plan-v3/PHASE-06-memory-knowledge.md` §6.5
**Design Doc:** `docs/master-plan-v3/PHASE-06-memory-knowledge.md` §6.5

**Produces:** `MemoryGraphApi.{subgraph, neighbors, timeline, clusters}` endpoints.

---

## Context

The MemoryBrowserSurface (4.7/6.10) needs graph data: entities as nodes, predicates as edges, confidence as edge weight. This unit exposes `MemoryGraphApi` returning JSON shaped for force-directed rendering (D3 / cytoscape). Four queries: `subgraph` (a focal entity + its neighborhood), `neighbors` (1-hop), `timeline` (episodes over time), `clusters` (community detection over the entity graph).

## Existing Baseline

- `src/engines/memory-engine.ts` — `MemoryEngine` holds `SemanticMemory` (subject/predicate/object) + `EpisodicMemory` + `ProceduralRule`. The graph is derived from semantic facts.
- `src/engines/semantic-search.ts` — `SemanticSearchEngine` can rank neighbors by embedding proximity.
- `src/schema/types.js` — `SemanticMemoryRow` shape (`subject`, `predicate`, `object`, `confidence`, `verified`).
- `4.7` already defined the forward REST contract (`/api/memory/facts`, `/episodes`, `/rules`); this unit adds the graph-specific endpoints.

## Interface

### New file: `src/engines/memory-graph-api.ts`

```typescript
import type { MemoryEngine } from './memory-engine.js'
import type { SemanticSearchEngine } from './semantic-search.js'

export interface GraphNode { id: string; label: string; type: 'entity' | 'fact'; confidence: number; verified: boolean }
export interface GraphEdge { source: string; target: string; label: string; weight: number }

export interface GraphView { nodes: GraphNode[]; edges: GraphEdge[] }

export class MemoryGraphApi {
  constructor(private memory: MemoryEngine, private semantic: SemanticSearchEngine) {}

  async subgraph(focalEntity: string, depth = 2): Promise<GraphView> {
    const facts = await this.memory.getFactsByEntity(focalEntity, depth)
    return toGraph(facts)
  }

  async neighbors(entityId: string, k = 10): Promise<GraphView> {
    const near = await this.semantic.search(entityId, k)
    return toGraph(near.map((n) => n.fact))
  }

  async timeline(opts?: { from?: number; to?: number }): Promise<EpisodeVM[]> {
    return this.memory.getEpisodes(opts)
  }

  async clusters(): Promise<Array<{ id: string; members: string[] }>> {
    // Community detection (label propagation) over the entity graph.
    return detectClusters(await this.memory.getAllFacts())
  }
}

function toGraph(facts: SemanticMemoryRow[]): GraphView {
  const nodes = new Map<string, GraphNode>()
  const edges: GraphEdge[] = []
  for (const f of facts) {
    nodes.set(f.subject, { id: f.subject, label: f.subject, type: 'entity', confidence: f.confidence, verified: f.verified })
    nodes.set(f.object, { id: f.object, label: f.object, type: 'entity', confidence: f.confidence, verified: f.verified })
    edges.push({ source: f.subject, target: f.object, label: f.predicate, weight: f.confidence })
  }
  return { nodes: [...nodes.values()], edges }
}
```

## Acceptance Criteria

1. `subgraph(focal, depth)` returns nodes + edges within `depth` hops of `focal`.
2. `neighbors` returns the `k` nearest entities by embedding proximity.
3. `timeline` returns episodes optionally filtered by time window.
4. `clusters` returns non-overlapping member groups over the entity graph.
5. Output is plain JSON (D3/cytoscape-friendly: `nodes[]`, `edges[]` with `weight`).
6. `bun run devops gate` passes.

## Tests

`tests/unit/engines/memory-graph-api.test.ts` (mock `MemoryEngine`, `SemanticSearchEngine`):

- `neighbors` → `semantic.search` called with `k`.
- `clusters` → members are disjoint.
