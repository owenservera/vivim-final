# Unit 6.7 — Curation wiring (verification feedback loop)

**Source:** v3 Overview §3 (MemoryBrowserSurface depends on this); `docs/master-plan-v3/PHASE-06-memory-knowledge.md` §6.7
**Design Doc:** `docs/master-plan-v3/PHASE-06-memory-knowledge.md` §6.7
**Depends on:** 6.5, 6.6
**Produces:** `MemoryEngine.verifyFact` / `editFact` / `rejectFact`; curation events on the bus.

---

## Context

Memory quality depends on the user correcting it. The browser surface (4.7 / 6.10) shows facts with accept/reject/edit controls; this unit wires those controls into `MemoryEngine` so curated facts change the graph. **Verified** facts get a confidence stamp + `verified: true` and are weighted higher in synthesis (6.4) and search (6.1). **Rejected** facts are deprecaated (not deleted). **Edited** facts replace the object without losing the provenance link.

## Existing Baseline

- `src/engines/memory-engine.ts` — `MemoryEngine` with `assertFact`; we add curation methods. `SemanticMemoryRow` has `confidence`, `verified`, `deprecated`.
- `src/engines/capability-event-bus.ts` — emits domain events; we add `memory:curated`.
- `4.7` browser surface emits `verify/reject/edit` intents to `/api/memory/facts/{id}` (PATCH/DELETE) — those endpoints are implemented here.
- `src/schema/types.js` — `SemanticMemoryRow` shape.

## Interface

### Extension in `src/engines/memory-engine.ts`

```typescript
export class MemoryEngine {
  // ... existing assertFact/recallFacts ...

  async verifyFact(id: string, by: string): Promise<void> {
    await this.store.updateSemanticFact(id, { verified: true, confidence: Math.min(1, (await this.getFact(id)).confidence + 0.15) })
    this.bus.emit('memory:curated', { id, action: 'verify', by })
  }

  async editFact(id: string, patch: { object?: string; predicate?: string }, by: string): Promise<void> {
    await this.store.updateSemanticFact(id, patch)
    this.bus.emit('memory:curated', { id, action: 'edit', by })
  }

  async rejectFact(id: string, by: string): Promise<void> {
    await this.store.updateSemanticFact(id, { deprecated: true })
    this.bus.emit('memory:curated', { id, action: 'reject', by })
  }
}
```

### New routes: `src/server/routes/memory-curation.ts`

```
PATCH  /api/memory/facts/{id}   body: { verified?, object?, predicate? }
DELETE /api/memory/facts/{id}   (reject -> deprecate)
```

## Acceptance Criteria

1. `verifyFact` sets `verified: true` and bumps confidence (capped at 1.0).
2. `rejectFact` sets `deprecated: true` (no hard delete).
3. `editFact` updates `object`/`predicate` and emits `memory:curated`.
4. Each curation action emits `memory:curated` on the bus with `action` + `by`.
5. Verified facts rank higher in `SemanticSearchEngine.search` (weight applied by 6.1).
6. `bun run devops gate` passes.
