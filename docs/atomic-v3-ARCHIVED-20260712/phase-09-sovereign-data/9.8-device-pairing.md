# Unit 9.8 — Device pairing UX

**Source:** v3 Overview §1.10; `docs/master-plan-v3/PHASE-09-sovereign-data.md` §9.8

**Produces:** In-app device pairing flow (canvas-based).

## Context

`SyncEngine.pairWithCode` (9.3) is the back end; this unit adds the **UX**: show a 6-digit pairing code on device A, enter it on device B, keys are exchanged, sync starts. A status surface shows paired devices + last sync time + pending entries. Builds as a canvas-based flow (Phase 3) or workspace panel (4.x).

## Existing Baseline

- `src/engines/sync.ts` (9.3) — `pairWithCode(code): Promise<SyncPeer>`; `SyncPeer` carries `deviceId`, `lastSyncAt`, `pending`.

## Interface

### New file: `web/src/surfaces/DevicePairing.tsx` (sketch)

```tsx
export function DevicePairing() {
  const [code, setCode] = useState<string | null>(null)
  const [peers, setPeers] = useState<SyncPeer[]>([])

  async function startPairing() {
    const c = await fetch('/api/sync/code', { method: 'POST' }).then(r => r.json())
    setCode(c.code) // show on device A
  }
  async function enterCode(c: string) {
    await fetch('/api/sync/pair', { method: 'POST', body: JSON.stringify({ code: c }) }).then(r => r.json())
    setPeers(await fetch('/api/sync/peers').then(r => r.json()))
  }

  return (
    <div className="device-pairing">
      <PairingCodeDisplay code={code} />
      <CodeEntry onSubmit={enterCode} />
      <PeerStatusList peers={peers} />
    </div>
  )
}
```

### Routes: `src/server/routes/sync-pairing.ts`

```
POST /api/sync/code      -> { code: '123456' }   (device A)
POST /api/sync/pair      body { code }     (device B -> pairWithCode)
GET  /api/sync/peers     -> SyncPeer[]
```

## Acceptance Criteria

1. Device A `POST /api/sync/code` returns a 6-digit code displayed in-UI.
2. Device B entering the code calls `pairWithCode` (9.3) and registers the peer.
3. After pairing, sync auto-starts (9.3 `syncOnce` scheduled).
4. Status surface lists paired devices with `lastSyncAt` + `pending` count.
5. Pairing two devices completes within 30s; subsequent sync < 10s (acceptance).
6. `bun run devops gate` passes (root + `web/`).
