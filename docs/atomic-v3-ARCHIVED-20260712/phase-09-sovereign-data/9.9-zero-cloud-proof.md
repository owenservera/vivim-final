# Unit 9.9 — Telemetry audit zero-cloud proof

**Source:** v3 Overview §1.10; `docs/master-plan-v3/PHASE-09-sovereign-data.md` §9.9
**Design Doc:** `docs/master-plan-v3/PHASE-09-sovereign-data.md` §9.9
**Depends on:** 8.4, 8.5
**Produces:** User can generate a "zero-cloud proof" report certifying no outbound calls were made.

---

## Context

Distinct from the daily audit report (8.5), this is an **on-demand, signed, one-page** compliance artifact: a time range, the list of hosts contacted (which, for an airgap user, should be **empty**), the network call count, and a device signature. It proves to an independent party that the system stayed offline.

## Existing Baseline

- `src/engines/telemetry-audit.ts` (8.4/8.5) — `TelemetryAudit` with `getCalls(from?,to?)`, `NetworkCallRecord`, `generateSignedReport()` (8.5, with `hashChain`/`signature`/`verdict`).
- `src/engines/telemetry-audit-interceptor.ts` (8.4) — the only legal outbound path; records every call to `NetworkCallRecord`.
- `src/engines/encryption.ts` (9.1) — device-local signing key (`signEnvelope`).
- `docs/atomic-v3/phase-08-observability-audit/8.5-audit-report.md` — `generateSignedReport` is the building block; this unit adds a zero-cloud-specific view/summary.

## Interface

### New method on `TelemetryAudit`

```typescript
export interface ZeroCloudProof {
  timeRange: { from: number; to: number }
  hostsContacted: string[]      // expected: [] for airgap
  networkCallCount: number
  verdict: 'zero-cloud' | 'cloud-detected'
  signature: string          // device-local key (9.1)
  verifiable: true
}

export class TelemetryAudit {
  // ...generateSignedReport (8.5)...

  async generateZeroCloudProof(from: number, to: number): Promise<ZeroCloudProof> {
    const calls = this.getCalls(from, to)
    const hosts = [...new Set(calls.map((c) => c.host))]
    const verdict: ZeroCloudProof['verdict'] = hosts.length === 0 ? 'zero-cloud' : 'cloud-detected'
    const signature = await signEnvelope({ from, to, hosts, count: calls.length, verdict })
    return { timeRange: { from, to }, hostsContacted: hosts, networkCallCount: calls.length, verdict, signature, verifiable: true }
  }
}
```

### New route: `src/server/routes/zero-cloud-proof.ts`

```
GET /api/audit/zero-cloud?from=<ts>&to=<ts>  -> ZeroCloudProof
```

## Acceptance Criteria

1. `generateZeroCloudProof` returns `hostsContacted`, `networkCallCount`, `verdict`, `signature`.
2. For an offline period, `hostsContacted` is `[]` and `verdict` is `zero-cloud`.
3. For a period with any call, `verdict` is `cloud-detected` and hosts are listed.
4. The proof carries a device-local `signature` (9.1) an independent party can verify.
5. The report is one-page / on-demand (not the scheduled daily digest 8.8).
6. `bun run devops gate` passes.

## Tests

`tests/unit/engines/telemetry-zero-cloud.test.ts` (mock `signEnvelope`):
- offline period → `verdict:'zero-cloud'`, `hostsContacted:[]`, count 0.
- period with 1 call → `verdict:'cloud-detected'`, host listed.
