# Unit 9.6 — Encrypted export v2

**Source:** v3 Overview §1.10; `docs/master-plan-v3/PHASE-09-sovereign-data.md` §9.6
**Design Doc:** `docs/master-plan-v3/PHASE-09-sovereign-data.md` §9.6

**Produces:** `ExportEngine.export` produces an encrypted bundle (`.vivim`) incl. canvases, memory, conversations, agents.

---

## Context

`ExportEngine.export` (export.ts) already exports JSON/csv scopes. This unit adds an **encrypted bundle**: a single `.vivim` file (zip + AES-256-GCM via `EncryptionEngine` 9.1) containing the SQLite snapshot, canvas templates, memory graph, and agent runs. Restorable on a fresh install.

## Existing Baseline

- `src/engines/export.ts` — `class ExportEngine` with `export(opts: ExportOptions): ExportManifest`, `importJson(jsonPath)`, `ExportScope` (`full|conversations|memory|providers|config`). We add `exportBundle` / `restoreBundle`.
- `src/engines/encryption.ts` (9.1) — `encrypt`/`decrypt` + `unlock(passphrase)`. Bundle is encrypted after zip.
- `src/engines/airgap.ts` (9.4) — `AirGapEngine`; the bundle never leaves the device (sovereign).
- `src/server/routes/...` — existing export endpoints; add bundle endpoints.

## Interface

### Change in `src/engines/export.ts`

```typescript
import { zipSync } from 'fflate' // or node:zlib

export interface BundleManifest {
  version: 1
  encrypted: true
  createdAt: number
  includes: Array<'sqlite' | 'canvasTemplates' | 'memory' | 'agentRuns'>
}

export class ExportEngine {
  // ...existing export/importJson...

  async exportBundle(passphrase: string): Promise<string> {
    const snap = await this.takeSnapshot() // sqlite + canvas + memory + runs
    const json = JSON.stringify(snap)
    const zipped = zipSync({ 'snapshot.json': new TextEncoder().encode(json) })
    const enc = new EncryptionEngine().encrypt(Buffer.from(zipped).toString('base64'))
    const path = `vivim-export-${Date.now()}.vivim`
    await writeFile(path, JSON.stringify({ manifest: { version: 1, encrypted: true, includes: snap.includes }, payload: enc }))
    return path
  }

  async restoreBundle(path: string, passphrase: string): Promise<{ restored: Record<string, number> }> {
    const raw = JSON.parse(await readFile(path, 'utf8'))
    const dec = new EncryptionEngine().decrypt(raw.payload, passphrase)
    const unzipped = unzipSync(Buffer.from(dec, 'base64'))
    return this.applySnapshot(JSON.parse(new TextDecoder().decode(unzipped['snapshot.json'])))
  }
}
```

### New routes: `src/server/routes/export-bundle.ts`

```
GET  /api/export/bundle?pass=<phrase>   -> .vivim download
POST /api/export/restore            body: { path, pass }
```

## Acceptance Criteria

1. `exportBundle` produces a single `.vivim` file containing the SQLite snapshot, canvas templates, memory graph, and agent runs.
2. The bundle payload is AES-256-GCM encrypted (unreadable without `passphrase`).
3. `restoreBundle` on a fresh install rehydrates all four inclusions.
4. The bundle is produced/consumed entirely locally (no network — sovereign, 9.4).
5. Restore fails closed on a wrong passphrase (no partial apply).
6. `bun run devops gate` passes.

## Tests

`tests/unit/engines/export-bundle.test.ts` (mock store + EncryptionEngine):
- `exportBundle` → `.vivim` written; payload is `EncryptedData`, not plaintext.
- `restoreBundle(path, pass)` → all inclusions restored.
- wrong passphrase → decrypt throws, no apply.
