# Unit 4.2 — Workspace default layouts + presets

**Source:** v3 Overview §1.7; `docs/master-plan-v3/PHASE-04-workspace-ui.md` §4.2
**Design Doc:** `docs/master-plan-v3/PHASE-04-workspace-ui.md` §4.2
**Depends on:** 4.1
**Produces:** 5 layout presets; first-run default.

---

## Context

A new user should see a sensible workspace immediately (acceptance: sensible default within 2s of first run). This unit seeds five built-in presets and applies the first-run default. Users can also save their own custom presets (stored as named `WorkspaceLayout` rows owned by the user).

Presets:
- `chat` — single conversation surface.
- `dual` — two canvases side-by-side.
- `dashboard` — grid of 4 canvases.
- `agent-monitor` — agent frontend surface + a canvas.
- `memory-workbench` — memory browser + conversation + canvas.

Presets are *templates*: applying one expands built-in surface ids / (for canvas-based presets) spawns the referenced canvases via `CanvasSpawner` (3.3) and references their `canvasInstanceId`.

## Existing Baseline

- `WorkspaceManager` (4.1) — `setLayout(userId, panels, name)` is the apply path.
- `CanvasSpawner` (3.3) — `spawn({ definitionId })` produces `canvasInstanceId` for canvas-based presets.
- Built-in surface ids referenced: `conversation-list`, `agent-frontend`, `memory-browser`, `capability-palette`, `provider-settings`, `telemetry-dashboard`, `devops-console` (4.4–4.10).
- `seeds/` — convention for seed files (3.2 uses `seeds/canvases/`).

## Interface

### New file: `src/engines/workspace-presets.ts`

```typescript
import type { WorkspaceManager, PanelSpec } from './workspace-manager.js'
import type { CanvasSpawner } from './canvas-spawner.js'

export type PresetId = 'chat' | 'dual' | 'dashboard' | 'agent-monitor' | 'memory-workbench'

interface PresetDef {
  id: PresetId
  name: string
  // Resolved against a live WorkspaceManager + spawner at apply time.
  build: (spawn: (def: string) => Promise<string>) => Promise<PanelSpec[]>
}

const PRESETS: Record<PresetId, PresetDef> = {
  chat: {
    id: 'chat', name: 'Chat',
    build: async () => [{ kind: 'builtin', builtinSurfaceId: 'conversation-list' }],
  },
  dual: {
    id: 'dual', name: 'Dual Canvas',
    build: async (spawn) => [
      { kind: 'canvas', canvasInstanceId: await spawn('cv:system:chat-pane') },
      { kind: 'canvas', canvasInstanceId: await spawn('cv:system:markdown-viewer') },
    ],
  },
  dashboard: {
    id: 'dashboard', name: 'Dashboard',
    build: async (spawn) => (['cv:system:dashboard-grid', 'cv:system:data-table', 'cv:system:image-gallery', 'cv:system:code-block'] as const)
      .map(async (d) => ({ kind: 'canvas' as const, canvasInstanceId: await spawn(d) })),
  },
  agent-monitor: {
    id: 'agent-monitor', name: 'Agent Monitor',
    build: async (spawn) => [
      { kind: 'builtin', builtinSurfaceId: 'agent-frontend' },
      { kind: 'canvas', canvasInstanceId: await spawn('cv:system:chat-pane') },
    ],
  },
  memory-workbench: {
    id: 'memory-workbench', name: 'Memory Workbench',
    build: async (spawn) => [
      { kind: 'builtin', builtinSurfaceId: 'memory-browser' },
      { kind: 'builtin', builtinSurfaceId: 'conversation-list' },
      { kind: 'canvas', canvasInstanceId: await spawn('cv:system:markdown-viewer') },
    ],
  },
}

export class WorkspacePresets {
  constructor(private manager: WorkspaceManager, private spawner: CanvasSpawner) {}

  list(): PresetId[] { return Object.keys(PRESETS) as PresetId[] }

  async apply(userId: string, preset: PresetId): Promise<WorkspaceLayoutRow> {
    const def = PRESETS[preset]
    const spawn = async (definitionId: string) => {
      const inst = await this.spawner.spawn({ definitionId, spawnedBy: 'system' })
      return inst.canvasId
    }
    const panels = await def.build(spawn)
    return this.manager.setLayout(userId, panels, def.name)
  }

  // First-run: ensure a default layout exists; otherwise apply `chat`.
  async ensureDefault(userId: string, existing?: WorkspaceLayoutRow | null): Promise<WorkspaceLayoutRow> {
    const current = existing ?? await this.manager.getLayout(userId, 'default')
    if (current && current.panels.length > 0) return current
    return this.apply(userId, 'chat')
  }
}
```

User-saved custom presets are just `setLayout(userId, panels, customName)` calls — no extra code needed.

## Acceptance Criteria

1. `list()` returns the 5 preset ids.
2. `apply(userId, 'chat')` → layout with one `conversation-list` builtin panel.
3. `apply(userId, 'dual')` → spawns 2 canvases and references their `canvasInstanceId`.
4. `ensureDefault` on a fresh user applies `chat`; on an existing non-empty layout returns it (idempotent-ish, no duplicate spawn).
5. `bun run devops gate` passes.

## Tests

`tests/unit/engines/workspace-presets.test.ts` (mock `WorkspaceManager`, `CanvasSpawner`):
- apply chat → manager.setLayout called with 1 builtin panel.
- apply dual → spawner.spawn called twice; panels reference canvasInstanceId.
- ensureDefault with no layout → applies chat.
- ensureDefault with existing panels → no spawn, returns as-is.
