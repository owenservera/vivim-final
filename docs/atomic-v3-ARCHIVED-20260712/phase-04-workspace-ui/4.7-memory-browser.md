# Unit 4.7 — Built-in surface: MemoryBrowserSurface

**Source:** v3 Overview §3; `docs/master-plan-v3/PHASE-04-workspace-ui.md` §4.7
**Design Doc:** `docs/master-plan-v3/PHASE-04-workspace-ui.md` §4.7
**Depends on:** 4.3, Phase 6
**Produces:** Browse episodic/semantic/procedural memory; curate facts; trigger consolidation.

---

## Context

The memory workbench: three tabs — Episodes (timeline), Facts (subject-predicate-object with confidence), Rules (condition→action with success/fail counts). Users can pin/verify/hide facts and manually trigger `minePatterns` and `consolidate` (the Phase 6 memory-engine operations).

Implement as React component at `builtinSurfaceId: 'memory-browser'`. **Depends on Phase 6's `MemoryEngine`** for the underlying data; this unit defines the *surface contract* and reads through the Phase 6 store, so it is forward-compatible.

## Existing Baseline

- **Phase 6 (future)** defines `MemoryEngine` with `listEpisodes`, `listFacts`, `listRules`, `verifyFact`, `hideFact`, `minePatterns`, `consolidate`. This surface calls those via REST (`/api/memory/*`) to be added in Phase 6; we stub the contract here.
- `WorkspaceManager` (4.1) — built-in surface id `memory-browser`.
- `src/engines/mirror-engine.ts` — no overlap, but the same React host renders this.
- Forward reference: facts have shape `{ id, subject, predicate, object, confidence, verified, hidden }`; rules `{ id, condition, action, successCount, failCount }`.

## Interface

### New file: `web/workspace/src/surfaces/MemoryBrowserSurface.tsx`

```typescript
import { useEffect, useState } from 'react'

type Tab = 'episodes' | 'facts' | 'rules'

export function MemoryBrowserSurface() {
  const [tab, setTab] = useState<Tab>('facts')
  const [facts, setFacts] = useState<FactVM[]>([])

  useEffect(() => {
    if (tab === 'facts') {
      fetch('/api/memory/facts').then((r) => r.json()).then((d) => setFacts(d.facts))
    }
    // episodes / rules follow the same shape in Phase 6
  }, [tab])

  async function verify(id: string) { await fetch(`/api/memory/facts/${id}/verify`, { method: 'POST' }) }
  async function hide(id: string) { await fetch(`/api/memory/facts/${id}/hide`, { method: 'POST' }) }
  async function trigger(kind: 'minePatterns' | 'consolidate') {
    await fetch(`/api/memory/${kind}`, { method: 'POST' })
  }

  return (/* tab switcher + timeline/fact-table/rule-table + verify/hide buttons + trigger buttons */)
}
```

### Forward REST contract (implemented in Phase 6)

```
GET  /api/memory/facts         -> { facts: FactVM[] }
POST /api/memory/facts/:id/verify
POST /api/memory/facts/:id/hide
GET  /api/memory/episodes      -> { episodes: EpisodeVM[] }
GET  /api/memory/rules         -> { rules: RuleVM[] }
POST /api/memory/minePatterns
POST /api/memory/consolidate
```
