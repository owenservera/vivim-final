# Unit 4.5 — Built-in surface: AgentFrontendSurface

**Source:** v3 Overview §1.8; `docs/master-plan-v3/PHASE-04-workspace-ui.md` §4.5
**Design Doc:** `docs/master-plan-v3/PHASE-04-workspace-ui.md` §4.5
**Depends on:** 4.3, 2.11
**Produces:** The agent's visible UI.

---

## Context

The agent needs a visible face: a surface showing what it is doing *right now*. Renders: current task/goal header, the plan DAG as a collapsible tree (per-node status, started/completed timestamps, error), a scrolling live action log, HITL gate prompts with inline buttons (approve/deny/skip), a cost/token budget bar, and cancel/pause/replay controls. Subscribes to `agent:state_changed`.

This is the primary dogfooding surface for the autonomous loop (2.11).

## Existing Baseline

- `src/engines/agentic-loop.ts` (2.11) — `AgenticConversationLoop` exposes the plan DAG, action log, budget, and HITL gates; emits `agent:state_changed`.
- `WorkspaceManager` (4.1) — built-in surface id `agent-frontend`.
- `CanvasWsHub` (3.11) — though agent state uses the app WS channel `agent:*` (distinct from `canvas:*`).
- `src/engines/errors.ts` — typed errors surfaced in the action log.

## Interface

### New file: `web/workspace/src/surfaces/AgentFrontendSurface.tsx`

```typescript
import { useEffect, useState } from 'react'

interface AgentState {
  taskId: string
  goal: string
  plan: PlanNode[]          // DAG
  actionLog: ActionEntry[]  // scrolling
  budget: { spent: number; limit: number; unit: string }
  gates: HitlGate[]         // pending approvals
  status: 'idle' | 'running' | 'paused' | 'blocked' | 'done'
}

export function AgentFrontendSurface() {
  const [state, setState] = useState<AgentState | null>(null)

  useEffect(() => {
    const ws = new WebSocket(`${WS_BASE}/agent`)
    ws.onmessage = (e) => {
      const f = JSON.parse(e.data)
      if (f.type === 'agent:state_changed') setState(f.state as AgentState)
    }
    return () => ws.close()
  }, [])

  async function respondGate(gateId: string, decision: 'approve' | 'deny' | 'skip') {
    await fetch('/api/agent/gate', {
      method: 'POST', body: JSON.stringify({ gateId, decision }),
    })
  }
  async function control(op: 'cancel' | 'pause' | 'replay') {
    await fetch(`/api/agent/${op}`, { method: 'POST' })
  }

  return (/* header + plan DAG tree + scrolling log + gate prompts + budget bar + controls */)
}
```

The plan DAG renders `PlanNode` with collapse state; status colors derived from node state.

## Acceptance Criteria

1. Surface subscribes to `agent:state_changed` and renders goal, plan DAG, action log.
2. Pending HITL gates render inline approve/deny/skip buttons that POST `/api/agent/gate`.
3. Budget bar reflects `budget.spent / limit`.
4. cancel/pause/replay controls POST to the matching endpoint and reflect new status.
5. Updates appear with sub-second latency (acceptance: live progress <1s).
6. `bun run devops gate` passes.
