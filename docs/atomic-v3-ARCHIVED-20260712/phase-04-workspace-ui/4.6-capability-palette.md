# Unit 4.6 — Built-in surface: CapabilityPaletteSurface

**Source:** v3 Overview §3; `docs/master-plan-v3/PHASE-04-workspace-ui.md` §4.6
**Design Doc:** `docs/master-plan-v3/PHASE-04-workspace-ui.md` §4.6
**Depends on:** 4.3, 1.3
**Produces:** Visual capability browser grouped by category and surface.

---

## Context

A searchable, grouped browser over every registered capability — compiled defaults (1.3), live caps (Phase 2), and composite caps. Each entry shows metadata; clicking invokes it (an input-schema form is rendered); dragging a capability onto a canvas panel creates a binding (feeds 3.4's `CanvasBinder`). Search by name, alias, or category.

Implement as React component mounted at `builtinSurfaceId: 'capability-palette'`.

## Existing Baseline

- `src/engines/unified-registry.ts` (1.3) — `UnifiedCapabilityRegistry.list({ category })` and `exportForCli()` provide the full set. `inputSchema` drives the invoke form.
- `WorkspaceManager` (4.1) — built-in surface registry maps `capability-palette` → this component.
- `CanvasBinder` (3.4) — the binding created by drag-to-canvas; POST `/api/canvas/instance/:id/bind` (route added here).
- `src/server/index.ts` — `execute(capId, input, ctx)` is the invoke path.

## Interface

### New file: `web/workspace/src/surfaces/CapabilityPaletteSurface.tsx`

```typescript
import { useEffect, useState } from 'react'

interface CapabilityVM {
  id: string
  slug: string
  name: string
  description: string
  category: string
  surfaces: string[]
  aliases: string[]
  inputSchema: Record<string, unknown>
}

export function CapabilityPaletteSurface() {
  const [caps, setCaps] = useState<CapabilityVM[]>([])
  const [query, setQuery] = useState('')

  useEffect(() => {
    fetch('/api/capabilities').then((r) => r.json()).then((d) => setCaps(d.capabilities))
  }, [])

  const filtered = caps.filter((c) =>
    (c.name + ' ' + c.aliases.join(' ') + ' ' + c.category).toLowerCase().includes(query.toLowerCase()),
  )
  const grouped = groupBy(filtered, (c) => c.category)

  async function invoke(cap: CapabilityVM, input: Record<string, unknown>) {
    await fetch(`/api/capabilities/${cap.id}/invoke`, {
      method: 'POST', body: JSON.stringify({ input }),
    })
  }

  return (/* search box + category groups + invoke form + drag handle (dataTransfer capId) */)
}
```

### New route: `src/server/routes/capability-palette.ts`

```typescript
import type { UnifiedCapabilityRegistry } from '../../engines/unified-registry.js'

export function capabilityPaletteRouter(registry: UnifiedCapabilityRegistry) {
  return {
    routes: [
      { method: 'GET', path: '/api/capabilities',
        handler: async () => ({ capabilities: registry.list() }) },
      { method: 'POST', path: '/api/capabilities/:id/invoke',
        handler: async (req) => ({ result: await registry.execute(req.params.id, req.body.input, { metadata: {} }) }) },
      { method: 'POST', path: '/api/canvas/instance/:id/bind',
        handler: async (req) => ({ ok: await binder.bind(req.params.id, req.body.spec) }) },
    ],
  }
}
```

## Acceptance Criteria

1. Surface lists **all** registered capabilities (acceptance: 20+ defaults + any live caps from Phase 2).
2. Search filters by name, alias, or category in real time.
3. Clicking a capability renders an input form from `inputSchema` and invokes via `registry.execute`.
4. Dragging a capability onto a canvas panel issues a bind (3.4).
5. Capabilities are grouped by `category` with surface badges.
6. `bun run devops gate` passes.
