# Unit 4.11 — Workspace agent actions

**Source:** v3 Overview §1.7; `docs/master-plan-v3/PHASE-04-workspace-ui.md` §4.11
**Design Doc:** `docs/master-plan-v3/PHASE-04-workspace-ui.md` §4.11
**Depends on:** 4.1, 3.13
**Produces:** Agent can open/close/rearrange workspace panels via capability calls.

---

## Context

This closes Scenario A from the overview: the agent says "build me a dashboard" and, through capability calls, opens two canvases and arranges them. The workspace mutation capabilities are registered in `UnifiedCapabilityRegistry` (1.3) so they auto-export to MCP/CLI/UI/API — same pattern as 3.13.

Capabilities:
- `workspace_open_canvas` — spawn a canvas (3.3) and open it as a panel (4.1).
- `workspace_close_panel` — close a panel by id (4.1).
- `workspace_set_layout` — replace the user's layout with a preset or explicit panels (4.2/4.1).
- `workspace_focus_panel` — bring a panel into focus (UI hint; emits event).

## Existing Baseline

- `WorkspaceManager` (4.1) — `openPanel`/`closePanel`/`setLayout`/`rearrange` are the engine methods called.
- `CanvasSpawner` (3.3) — `workspace_open_canvas` spawns then opens.
- `WorkspacePresets` (4.2) — `workspace_set_layout` can take a preset id.
- `src/engines/canvas-capabilities.ts` (3.13) — same `registerXCapabilities(registry, svc)` pattern reused here.
- `src/engines/unified-registry.ts` (1.3) — `UnifiedCapability` + `register`.

## Interface

### New file: `src/engines/workspace-capabilities.ts`

```typescript
import type { UnifiedCapabilityRegistry } from './unified-registry.js'
import type { WorkspaceManager } from './workspace-manager.js'
import type { CanvasSpawner } from './canvas-spawner.js'
import type { WorkspacePresets } from './workspace-presets.js'

export interface WorkspaceCapabilityServices {
  manager: WorkspaceManager
  spawner: CanvasSpawner
  presets: WorkspacePresets
}

function cap(p: Omit<UnifiedCapability, 'surfaces' | 'isAsync' | 'requiresConfirmation' | 'tags'>): UnifiedCapability {
  return { ...p, surfaces: ['cli', 'ui', 'workflow', 'mcp', 'api'], isAsync: true, requiresConfirmation: false, tags: ['workspace'] }
}

export function registerWorkspaceCapabilities(
  registry: UnifiedCapabilityRegistry,
  svc: WorkspaceCapabilityServices,
): void {
  registry.register(cap({
    id: 'cap:workspace:open_canvas', slug: 'workspace_open_canvas', name: 'Open Canvas Panel',
    description: 'Spawn a canvas and open it as a workspace panel.',
    category: 'workspace',
    inputSchema: { type: 'object', properties: { userId: { type: 'string' }, definitionId: { type: 'string' }, title: { type: 'string' } }, required: ['userId', 'definitionId'] },
    outputSchema: { type: 'object' },
    mcpToolName: 'workspace_open_canvas',
    apiEndpoint: { method: 'POST', path: '/api/workspace/open-canvas' },
    handler: async (i) => {
      const inst = await svc.spawner.spawn({ definitionId: String(i.definitionId), spawnedBy: 'agent' })
      return svc.manager.openPanel(String(i.userId), { kind: 'canvas', canvasInstanceId: inst.canvasId, title: i.title as string | undefined })
    },
  }))

  registry.register(cap({
    id: 'cap:workspace:close_panel', slug: 'workspace_close_panel', name: 'Close Panel',
    description: 'Close a workspace panel by id.',
    category: 'workspace',
    inputSchema: { type: 'object', properties: { panelId: { type: 'string' } }, required: ['panelId'] },
    outputSchema: { type: 'object' },
    mcpToolName: 'workspace_close_panel',
    apiEndpoint: { method: 'POST', path: '/api/workspace/close-panel' },
    handler: async (i) => { await svc.manager.closePanel(String(i.panelId)); return { ok: true } },
  }))

  registry.register(cap({
    id: 'cap:workspace:set_layout', slug: 'workspace_set_layout', name: 'Set Workspace Layout',
    description: 'Apply a preset or explicit panel list to the user layout.',
    category: 'workspace',
    inputSchema: { type: 'object', properties: { userId: { type: 'string' }, preset: { type: 'string' }, panels: { type: 'array' } }, required: ['userId'] },
    outputSchema: { type: 'object' },
    mcpToolName: 'workspace_set_layout',
    apiEndpoint: { method: 'POST', path: '/api/workspace/set-layout' },
    handler: async (i) => {
      if (i.preset) return svc.presets.apply(String(i.userId), i.preset as PresetId)
      return svc.manager.setLayout(String(i.userId), i.panels as PanelSpec[])
    },
  }))

  registry.register(cap({
    id: 'cap:workspace:focus_panel', slug: 'workspace_focus_panel', name: 'Focus Panel',
    description: 'Bring a workspace panel into focus.',
    category: 'workspace',
    inputSchema: { type: 'object', properties: { panelId: { type: 'string' } }, required: ['panelId'] },
    outputSchema: { type: 'object' },
    mcpToolName: 'workspace_focus_panel',
    apiEndpoint: { method: 'POST', path: '/api/workspace/focus-panel' },
    handler: async (i) => { /* emit focus event; UI scrolls/activates the panel */ return { ok: true } },
  }))
}
```

## Acceptance Criteria

1. After bootstrap, `registry.list({ category: 'workspace' }).length === 4`.
2. `workspace_open_canvas` handler spawns a canvas then opens a panel referencing its `canvasInstanceId`.
3. `workspace_set_layout` with `preset` delegates to `presets.apply`; with `panels` delegates to `manager.setLayout`.
4. `workspace_close_panel` calls `manager.closePanel`.
5. All four export to MCP (`exportForMcp` includes the `workspace_*` names).
6. `bun run devops gate` passes.
