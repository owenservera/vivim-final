# Unit 3.5 — CanvasMirror agent→canvas sync

**Source:** v3 Overview §1.6; `docs/master-plan-v3/PHASE-03-html-canvas.md` §3.5
**Design Doc:** `docs/master-plan-v3/PHASE-03-html-canvas.md` §3.5
**Depends on:** 3.3
**Produces:** `CanvasMirror.applyMutation(canvasId, mutation)`.

---

## Context

When the agent wants to change a canvas (set an attribute, insert HTML, remove a node, set text), it issues a **structured mutation** — never a string of JS. `CanvasMirror` applies it through the Governor's CDP `Runtime.evaluate` using **structured values** (no string interpolation), which is inherently injection-safe: a malicious `value` cannot break out of the evaluated expression. After applying, the mirror re-queries the DOM to confirm the mutation took; if it didn't, it throws (no silent failure — acceptance criterion for the phase).

This is the canvas analogue of `MirrorEngine` (`src/engines/mirror-engine.ts:142`) but operates on canvas tabs/iframes via the Governor rather than conversation chrome.

## Existing Baseline

- `src/engines/chrome-governor.ts` — `ChromeGovernor.cdp.send(slaveId, method, params)` (line 649) is the CDP entry point. `Runtime.evaluate` with `returnByValue` is the primitive used here.
- `src/engines/mirror-engine.ts` — `MirrorEngine` bidirectional sync pattern; `CanvasMirror` mirrors its structure (optimistic apply + confirm via re-query).
- `CanvasSpawner` (3.3) — owns the `slaveId` per `canvasId` we resolve here.
- `src/engines/capability-event-bus.ts` — bus used to emit `canvas:mutated` confirmations.

## Interface

### New file: `src/engines/canvas-mirror.ts`

```typescript
import type { CanvasInstanceStore } from '../storage/contracts/canvas-instance-store.js'
import type { ChromeGovernor } from './chrome-governor.js'
import type { GovernorEventBus } from './chrome-governor.js'
import { EngineError } from '../errors.js'

export type CanvasMutation =
  | { op: 'setAttribute'; selector: string; attribute: string; value: unknown }
  | { op: 'insertHTML'; selector: string; position: 'before' | 'after' | 'append' | 'prepend'; value: string }
  | { op: 'remove'; selector: string }
  | { op: 'setText'; selector: string; value: string }

export class CanvasMirror {
  constructor(
    private instanceStore: CanvasInstanceStore,
    private governor: ChromeGovernor,
    private eventBus?: GovernorEventBus,
  ) {}

  async applyMutation(canvasId: string, mutation: CanvasMutation): Promise<void> {
    const instance = await this.instanceStore.getInstanceByCanvasId(canvasId)
    if (!instance) throw new EngineError(`CanvasInstance ${canvasId} not found`)
    if (!instance.slaveId) throw new EngineError(`Canvas ${canvasId} has no backing tab`)
    if (instance.status !== 'running') throw new EngineError(`Canvas ${canvasId} is not running`)

    // Structured apply: pass values as arguments, never via string concat.
    const expression = buildApplyExpression(mutation)
    const args = buildApplyArgs(mutation)

    const result = await this.governor.cdp.send(instance.slaveId, 'Runtime.evaluate', {
      expression,
      arguments: args, // structured values -> Runtime.callFunctionOn style
      returnByValue: true,
    })

    // Confirm via re-query (no silent failure).
    const confirmed = await this.confirm(canvasId, mutation, result)
    if (!confirmed) {
      throw new EngineError(`Canvas mutation failed to apply on ${canvasId}: ${mutation.op}`)
    }
    this.eventBus?.emit('canvas:mutated', { canvasId, mutation })
  }

  private async confirm(canvasId: string, m: CanvasMutation, _applied: unknown): Promise<boolean> {
    const instance = await this.instanceStore.getInstanceByCanvasId(canvasId)
    if (!instance?.slaveId) return false
    const res = await this.governor.cdp.send(instance.slaveId, 'Runtime.evaluate', {
      expression: `(() => { const el = document.querySelector(${JSON.stringify(m.selector)}); return !!el; })()`,
      returnByValue: true,
    })
    return Boolean((res as { result?: { value?: boolean } })?.result?.value)
  }
}

// Build a function-body string that uses structured args (no interpolation of user values).
function buildApplyExpression(m: CanvasMutation): string {
  switch (m.op) {
    case 'setAttribute':
      return `(el, value) => el.setAttribute(value.attr, value.val)`
    case 'insertHTML':
      return `(el, value) => el.insertAdjacentHTML(value.pos, value.html)`
    case 'remove':
      return `(el) => el.remove()`
    case 'setText':
      return `(el, value) => { el.textContent = value }`
  }
}

function buildApplyArgs(m: CanvasMutation): unknown[] {
  switch (m.op) {
    case 'setAttribute':
      return [{ attr: m.attribute, val: m.value }]
    case 'insertHTML':
      return [{ pos: m.position, html: m.value }]
    case 'remove':
      return []
    case 'setText':
      return [m.value]
  }
}
```

## Acceptance Criteria

1. `applyMutation` resolves the `slaveId` from the instance and calls `Runtime.evaluate` with structured args (no string-concatenated `value`).
2. A `value` containing `</script>` or quote characters cannot break out of the evaluated expression (injection-safe by construction).
3. After applying, the mirror re-queries and throws `EngineError` if the mutation is not reflected.
4. Applying to a non-running or tab-less instance throws `EngineError`.
5. A successful apply emits `canvas:mutated`.
6. `bun run devops gate` passes.

## Tests

`tests/unit/engines/canvas-mirror.test.ts` (mock `CanvasInstanceStore`, `ChromeGovernor`):
- `setText` → `Runtime.evaluate` called; re-query returns true → success, `canvas:mutated` emitted.
- mutation not reflected on re-query → throws.
- `value` with malicious markup → still a single structured arg, expression unchanged (assert no `.includes(value)` string building).
- instance `status: 'spawning'` → throws.
