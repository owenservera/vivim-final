# Unit 3.10 — Canvas HTTP router (`/api/canvas/*`)

**Source:** v3 Overview §3; `docs/master-plan-v3/PHASE-03-html-canvas.md` §3.10
**Design Doc:** `docs/master-plan-v3/PHASE-03-html-canvas.md` §3.10
**Depends on:** 3.1, 3.3, 3.4, 3.5, 3.7
**Produces:** REST endpoints for canvas CRUD + spawn/destroy + query.

---

## Context

External callers (CLI, MCP gateways, the workspace frontend) need an HTTP surface to manage canvases. This unit mounts the `/api/canvas/*` router wiring the engines from 3.1/3.3/3.4/3.5/3.7 to HTTP. Each endpoint maps to a capability (3.13) so the same handler serves both REST and capability invocation.

Endpoints:
- `GET  /api/canvas/definitions` — list definitions
- `POST /api/canvas/definitions` — define a new canvas
- `POST /api/canvas/spawn` — spawn an instance (3.3)
- `DELETE /api/canvas/instance/:id` — destroy an instance (3.3)
- `GET  /api/canvas/instance/:id/snapshot` — read DOM (3.7)
- `POST /api/canvas/instance/:id/mutate` — agent mutation (3.5)
- `POST /api/canvas/instance/:id/discover` — discovery ops (3.7/3.8)

## Existing Baseline

- `src/server/index.ts` — `createServerWithEngines` where routers mount and engines are constructed (see 1.3 wiring).
- `src/engines/unified-registry.ts` — `apiEndpoint` surface; capabilities in 3.13 reuse these handlers.
- Engines: `CanvasRegistry` (3.1), `CanvasSpawner` (3.3), `CanvasBinder` (3.4), `CanvasMirror` (3.5), `CanvasDiscovery` (3.7).
- Auth/guard pattern: reuse the existing API auth middleware (if any) for `createdBy` resolution.

## Interface

### New file: `src/server/routes/canvas.ts`

```typescript
import type { Router } from './types.js'
import type { CanvasRegistry } from '../../engines/canvas-registry.js'
import type { CanvasSpawner } from '../../engines/canvas-spawner.js'
import type { CanvasBinder } from '../../engines/canvas-binder.js'
import type { CanvasMirror } from '../../engines/canvas-mirror.js'
import type { CanvasDiscovery } from '../../engines/canvas-discovery.js'

export interface CanvasRouterDeps {
  registry: CanvasRegistry
  spawner: CanvasSpawner
  binder: CanvasBinder
  mirror: CanvasMirror
  discovery: CanvasDiscovery
  auth: (req: unknown) => { userId: string }
}

export function canvasRouter(deps: CanvasRouterDeps): Router {
  const r: Router = { routes: [] }

  r.routes.push({
    method: 'GET', path: '/api/canvas/definitions',
    handler: async () => ({ definitions: await deps.registry.list() }),
  })

  r.routes.push({
    method: 'POST', path: '/api/canvas/definitions',
    handler: async (req) => {
      const body = req.body as Record<string, unknown>
      return { definition: await deps.registry.define({
        ...(body as never),
        createdBy: 'user',
      }) }
    },
  })

  r.routes.push({
    method: 'POST', path: '/api/canvas/spawn',
    handler: async (req) => {
      const { definitionId } = req.body as { definitionId: string }
      return { instance: await deps.spawner.spawn({ definitionId, spawnedBy: 'user' }) }
    },
  })

  r.routes.push({
    method: 'DELETE', path: '/api/canvas/instance/:id',
    handler: async (req) => {
      await deps.spawner.destroy(req.params.id)
      return { ok: true }
    },
  })

  r.routes.push({
    method: 'GET', path: '/api/canvas/instance/:id/snapshot',
    handler: async (req) => ({ snapshot: await deps.discovery.snapshot(req.params.id) }),
  })

  r.routes.push({
    method: 'POST', path: '/api/canvas/instance/:id/mutate',
    handler: async (req) => {
      const { mutation } = req.body as { mutation: never }
      await deps.mirror.applyMutation(req.params.id, mutation as never)
      return { ok: true }
    },
  })

  r.routes.push({
    method: 'POST', path: '/api/canvas/instance/:id/discover',
    handler: async (req) => {
      const { op, ...rest } = req.body as { op: string } & Record<string, unknown>
      const result = await (deps.discovery as Record<string, (...a: unknown[]) => Promise<unknown>>)[op](req.params.id, rest)
      return { result }
    },
  })

  return r
}
```

## Acceptance Criteria

1. `GET /api/canvas/definitions` returns the list from `CanvasRegistry.list`.
2. `POST /api/canvas/definitions` creates with `createdBy:'user'`.
3. `POST /api/canvas/spawn` returns a spawned instance.
4. `DELETE /api/canvas/instance/:id` destroys it.
5. `GET .../snapshot` returns a DOM tree; `POST .../mutate` applies a mutation; `POST .../discover` dispatches a discovery op.
6. `bun run devops gate` passes; endpoints mirror the 3.13 capability set.
