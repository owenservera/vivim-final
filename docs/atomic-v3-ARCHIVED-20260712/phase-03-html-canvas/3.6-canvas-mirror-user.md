# Unit 3.6 — CanvasMirror canvas→agent sync

**Source:** v3 Overview §1.6; `docs/master-plan-v3/PHASE-03-html-canvas.md` §3.6
**Design Doc:** `docs/master-plan-v3/PHASE-03-html-canvas.md` §3.6
**Depends on:** 3.5
**Produces:** Event listener in canvas runtime that emits `canvas:event` over WebSocket.

---

## Context

The reverse direction of 3.5: when a *user* interacts with a `[data-cap-emit]` element in the canvas, the in-iframe runtime (3.9) sends a `canvas:event` message up the `postMessage` channel. The server receives it, validates the `capabilityToken` (3.12), fans it out to subscribed agents over the WebSocket protocol (3.11), and records it in a `canvas_event` table that is **truncated to 7 days** (retention window).

This unit defines the server-side ingestion of `canvas:event`: the table, the store contract, the ingest function, and how it forwards to the WS layer and `CapabilityEventBus` (so 3.4's binder can react).

### New file: `src/engines/canvas-event-ingest.ts`

```typescript
import type { CanvasInstanceStore } from '../storage/contracts/canvas-instance-store.js'
import type { CanvasEventStore } from '../storage/contracts/canvas-event-store.js'
import type { CapabilityEventBus } from './capability-event-bus.js'
import type { GovernorEventBus } from './chrome-governor.js'
import { EngineError } from '../errors.js'

export interface RawCanvasEvent {
  canvasId: string
  elementType: string
  selector: string
  eventType: string
  value: unknown
  token: string // capabilityToken echoed from runtime
}

export class CanvasEventIngest {
  constructor(
    private instanceStore: CanvasInstanceStore,
    private eventStore: CanvasEventStore,
    private bus: CapabilityEventBus,
    private govBus?: GovernorEventBus,
  ) {}

  async ingest(raw: RawCanvasEvent): Promise<CanvasEventRow> {
    const instance = await this.instanceStore.getInstanceByCanvasId(raw.canvasId)
    if (!instance) throw new EngineError(`CanvasInstance ${raw.canvasId} not found`)
    // 3.12: token must match the instance's capabilityToken
    if (raw.token !== instance.capabilityToken) {
      throw new EngineError(`Invalid canvas capability token for ${raw.canvasId}`)
    }

    const row = await this.eventStore.createEvent({
      id: newId(),
      canvasId: raw.canvasId,
      elementType: raw.elementType,
      selector: raw.selector,
      eventType: raw.eventType,
      value: raw.value == null ? null : JSON.stringify(raw.value),
    })

    // Fan out to agents (3.11 WS) and to binder (3.4 CapabilityEventBus).
    this.govBus?.emit('canvas:event', row)
    this.bus.emit('canvas:event', {
      canvasId: raw.canvasId,
      selector: raw.selector,
      eventType: raw.eventType,
      value: raw.value,
    })
    return row
  }
}
```

Retention sweep: a periodic job calls `eventStore.purgeOlderThan(Date.now() - 7 * 86_400_000)`.

## Acceptance Criteria

1. `ingest` validates `token === instance.capabilityToken`; mismatch throws `EngineError`.
2. A valid event is persisted and fanned out on both `GovernorEventBus` (`canvas:event`) and `CapabilityEventBus` (`canvas:event`).
3. The persisted `value` is JSON-encoded when present, null otherwise.
4. `purgeOlderThan` removes events beyond the 7-day window.
5. `bun run devops gate` passes.

## Tests

`tests/unit/engines/canvas-event-ingest.test.ts` (mock stores + buses):
- valid token → event persisted, both buses receive `canvas:event`.
- wrong token → throws, nothing persisted.
- `value` object → stored as JSON string.
- `purgeOlderThan` deletes only stale rows.
