# Unit 3.8 — CanvasDiscovery write state

**Source:** v3 Overview §1.6; `docs/master-plan-v3/PHASE-03-html-canvas.md` §3.8
**Design Doc:** `docs/master-plan-v3/PHASE-03-html-canvas.md` §3.8

## Context

The write-side companion to 3.7. These are high-level operations — analogous to `SlaveWrite` in the fleet model but targeted at canvases — that let an agent *drive* a canvas it didn't author. `fillForm` walks a form and sets each field by name; `click`/`type`/`scroll` perform the corresponding primitive interaction. All go through CDP `Runtime.evaluate` / `Input.dispatchMouseEvent` on the canvas's backing tab, using structured args (never string-built DOM from untrusted values).

## Existing Baseline

- `src/engines/canvas-discovery.ts` (3.7) — `CanvasDiscovery` class extended here with write methods; shares `slaveFor`.
- `src/engines/chrome-governor.ts` — `cdp.send` (line 649) for `Input.dispatchMouseEvent` / `Runtime.evaluate`.
- `CanvasMirror.applyMutation` (3.5) — lower-level structured mutation; 3.8 is the semantic layer on top (form-aware).

## Interface

### Extension in `src/engines/canvas-discovery.ts`

```typescript
export interface FillFormResult {
  canvasId: string
  setFields: string[]
  skippedFields: string[]
}

export interface ClickOptions { selector: string }
export interface TypeOptions { selector: string; text: string }
export interface ScrollOptions { selector?: string; x?: number; y?: number }

// inside class CanvasDiscovery:

async fillForm(canvasId: string, data: Record<string, string>): Promise<FillFormResult> {
  const slaveId = await this.slaveFor(canvasId)
  const res = await this.governor.cdp.send(slaveId, 'Runtime.evaluate', {
    expression: `((data) => {
      const out = { set: [], skipped: [] };
      for (const [k, v] of Object.entries(data)) {
        const el = document.querySelector('[name="'+k+'"], [data-cap-bind="'+k+'"]');
        if (!el) { out.skipped.push(k); continue; }
        el.value = v; el.dispatchEvent(new Event('input', { bubbles: true }));
        out.set.push(k);
      }
      return out;
    })`,
    arguments: [{ value: data }], // structured, not interpolated
    returnByValue: true,
  })
  const r = (res as { result?: { value?: FillFormResult } }).result?.value
  return r ?? { canvasId, setFields: [], skippedFields: [] }
}

async click(canvasId: string, opts: ClickOptions): Promise<void> {
  const slaveId = await this.slaveFor(canvasId)
  await this.governor.cdp.send(slaveId, 'Runtime.evaluate', {
    expression: `document.querySelector(${JSON.stringify(opts.selector)})?.click()`,
  })
}

async type(canvasId: string, opts: TypeOptions): Promise<void> {
  const slaveId = await this.slaveFor(canvasId)
  await this.governor.cdp.send(slaveId, 'Runtime.evaluate', {
    expression: `((sel, text) => { const el = document.querySelector(sel); if (!el) return; el.focus(); el.value = text; el.dispatchEvent(new Event('input', { bubbles: true })); })(${JSON.stringify(opts.selector)}, ${JSON.stringify(opts.text)})`,
  })
}

async scroll(canvasId: string, opts: ScrollOptions): Promise<void> {
  const slaveId = await this.slaveFor(canvasId)
  const target = opts.selector ? `document.querySelector(${JSON.stringify(opts.selector)})` : 'document.scrollingElement'
  await this.governor.cdp.send(slaveId, 'Runtime.evaluate', {
    expression: `(${target}).scrollTo(${opts.x ?? 0}, ${opts.y ?? 0})`,
  })
}
```

## Acceptance Criteria

1. `fillForm` sets each provided field by `name`/`data-cap-bind` and returns the set/skipped split.
2. `fillForm` passes `data` as a **structured argument**, not via string concatenation of values.
3. `click` clicks the matched element; `type` focuses + sets value + fires `input`; `scroll` scrolls the target.
4. Selector values are passed via `JSON.stringify` (structured), so quote injection cannot break the expression.
5. All methods throw `EngineError` when the canvas has no backing tab.
6. `bun run devops gate` passes.
