# Unit 2.4 — CapabilityComposer — DAG definition + execution

**Source:** v3 Overview §1.2; `docs/master-plan-v3/PHASE-02-agentic-core.md` §2.4
**Design Doc:** `docs/master-plan-v3/PHASE-02-agentic-core.md` §2.4
**Depends on:** 1.3
**Produces:** Composite capabilities stored as typed DAGs in `composite_capability` + `composite_node` tables.

---

## Context

`CapabilityEngine.execute` (today via `CapabilityMacroEngine`, `src/engines/capability-macro.ts`) runs one selector-based capability at a time, and `CapabilityMacroEngine.define()` stores an **opaque `dagJson` string** (`capability-macro.ts:14`). There is no way to declare "search + click + extract + summarize" as a reusable, typed composite whose nodes reference capability slugs.

`CapabilityComposer` defines composite capabilities as typed DAGs whose nodes are `(capabilitySlug, inputMapping, outputKey)` triples. Composites become first-class `UnifiedCapabilityRegistry` entries and inherit the full surface export (2.6). Execution iterates nodes in topological order, binding inputs from prior outputs and shared context, and **detects cycles at register-time**.

## Existing Baseline

- `src/engines/capability-macro.ts` — `CapabilityMacroEngine` (line 44), `CapabilityMacroRow.dagJson` (line 14, opaque), `HarnessRuntime.executeDag` (line 28). Composer supersedes the opaque-DAG path.
- `src/engines/unified-registry.ts` — `UnifiedCapabilityRegistry.register` (line 65), `execute(id, input, ctx)` (line 110). Composites register here and delegate node execution to `registry.execute`.
- `src/storage/contracts/` — new `CompositeCapabilityStore` contract (tables `composite_capability`, `composite_node` per `00-OVERVIEW.md` §2).

## Interface

### New file: `src/engines/capability-composer.ts`

```typescript
import type { UnifiedCapabilityRegistry } from './unified-registry.js'

export interface CompositeNode {
  id: string
  capabilitySlug: string
  inputMapping: Record<string, unknown>   // may reference `${upstream.outputKey}`
  outputKey?: string
}

export interface CompositeCapability {
  id: string
  slug: string
  name: string
  description: string
  nodes: CompositeNode[]
  edges: Array<{ from: string; to: string }>
  version: number
  isActive: boolean
}

export interface CompositeCapabilityStore {
  create(c: CompositeCapability): Promise<CompositeCapability>
  get(id: string): Promise<CompositeCapability | null>
  list(opts?: { activeOnly?: boolean }): Promise<CompositeCapability[]>
  update(id: string, patch: Partial<CompositeCapability>): Promise<void>
}

export class CapabilityComposer {
  constructor(
    private store: CompositeCapabilityStore,
    private registry: UnifiedCapabilityRegistry,
  ) {}

  /** Register-time cycle detection. Throws EngineError on cycle. */
  async registerComposite(spec: Omit<CompositeCapability, 'id' | 'version'>): Promise<CompositeCapability> {
    this.assertAcyclic(spec.nodes, spec.edges)
    const composite = await this.store.create({ ...spec, id: newId(), version: 1 })
    this.registry.register(this.toUnifiedCapability(composite))
    return composite
  }

  /** Execute in topological order, binding upstream outputs to downstream inputs. */
  async execute(compositeId: string, input: Record<string, unknown>, ctx: CapabilityContext): Promise<unknown> {
    const c = await this.store.get(compositeId)
    if (!c) throw new EngineError(`Composite not found: ${compositeId}`)
    const order = this.topoSort(c.nodes, c.edges)
    const outputs = new Map<string, unknown>()
    for (const node of order) {
      const resolved = this.bindInputs(node.inputMapping, outputs, input)
      const result = await this.registry.execute(
        this.slugToId(node.capabilitySlug), resolved, ctx,
      )
      if (node.outputKey) outputs.set(node.outputKey, result)
    }
    return outputs.get('__result__') ?? result
  }

  private assertAcyclic(nodes: CompositeNode[], edges: { from: string; to: string }[]): void { /* DFS color mark */ }
  private topoSort(nodes: CompositeNode[], edges: { from: string; to: string }[]): CompositeNode[] { /* Kahn */ }
  private bindInputs(mapping: Record<string, unknown>, outputs: Map<string, unknown>, root: Record<string, unknown>): Record<string, unknown> { /* interpolate ${key} */ }
}
```

## Acceptance Criteria

1. Registering a composite with a cycle throws `EngineError` (cycle detected at register-time).
2. `execute()` runs nodes in topological order and binds `upstream.outputKey` into a downstream node's `inputMapping`.
3. Every node's `capabilitySlug` resolves via `registry.getBySlug()`; an unknown slug fails fast.
4. After `registerComposite`, the composite is present in `registry.list()`.
5. `bun run devops gate` passes; composer ≥80% covered (cycle + topo + bind cases).
