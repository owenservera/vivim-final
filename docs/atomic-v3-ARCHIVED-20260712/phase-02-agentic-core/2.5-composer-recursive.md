# Unit 2.5 — CapabilityComposer — recursive composition + versioning

**Source:** v3 Overview §1.2; `docs/master-plan-v3/PHASE-02-agentic-core.md` §2.5
**Design Doc:** `docs/master-plan-v3/PHASE-02-agentic-core.md` §2.5
**Depends on:** 2.4
**Produces:** Composites can reference other composites; full version chain via `VersionManager`.

---

## Context

Phase 2.4 stores flat composites. This unit adds **recursive composition** (a composite node may reference another composite's slug) and **versioning** so composites get a full version chain. `CapabilityComposer.execute(compositeId)` resolves nested composites recursively; `VersionManager.snapshotCapability` is extended to snapshot composite DAGs.

## Existing Baseline

- `src/engines/capability-composer.ts` — `execute()` (2.4) currently resolves only leaf `capabilitySlug`s. This unit teaches it to detect a composite slug and recurse.
- `src/engines/version-manager.ts` — `VersionManager` owns snapshot/version logic for engines; extend `snapshotCapability` to accept a composite DAG.
- `src/engines/unified-registry.ts` — composite slugs live alongside leaf slugs in `UnifiedCapabilityRegistry` (line 62 `capabilities` map).

## Interface

### Extension in `src/engines/capability-composer.ts`

```typescript
import type { VersionManager } from './version-manager.js'

export class CapabilityComposer {
  constructor(
    private store: CompositeCapabilityStore,
    private registry: UnifiedCapabilityRegistry,
    private versions: VersionManager,
  ) {}

  /** Recursively resolve: a node whose slug is a composite delegates to execute(). */
  async execute(compositeId: string, input: Record<string, unknown>, ctx: CapabilityContext): Promise<unknown> {
    const c = await this.store.get(compositeId)
    if (!c) throw new EngineError(`Composite not found: ${compositeId}`)
    const order = this.topoSort(c.nodes, c.edges)
    const outputs = new Map<string, unknown>()
    for (const node of order) {
      const resolved = this.bindInputs(node.inputMapping, outputs, input)
      const target = this.registry.getBySlug(node.capabilitySlug)
      if (!target) throw new EngineError(`Unknown capability slug: ${node.capabilitySlug}`)
      // Recursive: if the resolved capability is itself a composite, delegate.
      const result = target.isComposite
        ? await this.execute(target.compositeId!, resolved, ctx)
        : await this.registry.execute(target.id, resolved, ctx)
      if (node.outputKey) outputs.set(node.outputKey, result)
    }
    return outputs.get('__result__') ?? result
  }

  /** Bump version + snapshot the DAG via VersionManager. */
  async revise(compositeId: string, next: Omit<CompositeCapability, 'id' | 'version'>): Promise<CompositeCapability> {
    const current = await this.store.get(compositeId)
    if (!current) throw new EngineError(`Composite not found: ${compositeId}`)
    await this.versions.snapshotCapability(compositeId, current) // new overload for composite DAGs
    return this.store.update(compositeId, { ...next, version: current.version + 1 })
  }
}
```

`UnifiedCapability` gains `isComposite?: boolean` and `compositeId?: string` (extend `unified-registry.ts:19`).

## Acceptance Criteria

1. A composite whose node references another composite's slug executes recursively (depth ≥2).
2. Infinite recursion is prevented: a composite referencing itself (directly or transitively) throws before execution.
3. `revise()` increments `version` and calls `VersionManager.snapshotCapability` with the prior DAG.
4. `VersionManager` can reconstruct a prior composite DAG version.
5. `bun run devops gate` passes; recursion + versioning ≥80% covered.
