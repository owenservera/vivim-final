# Unit 2.12 — AgenticConversationLoop — integration with ConversationManager

**Source:** v3 Overview §1.4; `docs/master-plan-v3/PHASE-02-agentic-core.md` §2.12
**Design Doc:** `docs/master-plan-v3/PHASE-02-agentic-core.md` §2.12
**Depends on:** 2.11
**Produces:** `ConversationManager.send` delegates to `AgenticConversationLoop` when provider is agentic-capable.

---

## Context

`AgenticConversationLoop` (2.11) must be reachable from the normal send path. `ConversationManager.send` (`src/engines/conversation-manager.ts:147`) becomes a thin wrapper: for providers flagged `isAgentic`, it delegates to the loop; for others it keeps the legacy 8-step pipeline.

The provider definition gains an `isAgentic` flag. Agentic providers (claude, chatgpt with tool-use, gemini with function-calling) go through the loop; the rest use the linear pipeline.

## Existing Baseline

- `src/engines/conversation-manager.ts` — `ConversationManager.send` (line 147) and its constructor (line 132). Add `AgenticConversationLoop` to the constructor and a branch in `send`.
- `src/engines/agentic-conversation-loop.ts` — `run(conversationId, userMessage)` (2.11).
- `src/storage/contracts/provider-store.js` (or `provider-registrar.ts`) — `ProviderDefinition` gains `isAgentic: boolean`. Check the schema/contract before editing; the field is new (declared in `00-OVERVIEW.md` §2 as `provider_definition.consent_state` sibling — add `isAgentic` alongside).

## Interface

### Change in `src/engines/conversation-manager.ts`

```typescript
export class ConversationManager {
  constructor(
    private governor: ChromeGovernor,
    private resolution: CapabilityResolutionEngine,
    private parser: StreamParserEngine,
    private blocks: StreamBlockStore,
    private store: ConversationStore,
    private eventBus: CapabilityEventBus,
    private memoizer: ExecutionMemoizer,
    private memory?: MemoryEngine,
    private contextAssembly?: ContextAssemblyEngine,
    private agenticLoop?: AgenticConversationLoop,   // NEW
  ) {}

  async send(conversationId: string, message: string): Promise<SendResult> {
    const conv = await this.store.getConversation(conversationId)
    const provider = await this.store.getProvider(conv.providerId)
    // Route agentic-capable providers through the reflective loop.
    if (this.agenticLoop && provider?.isAgentic) {
      const loopResult = await this.agenticLoop.run(conversationId, message)
      if (!loopResult.success) return { ok: false, messageId: '', blocks: [], text: '', latencyMs: loopResult.durationMs, error: loopResult.error }
      // Convert last episode result into a SendResult-shaped payload.
      return this.loopResultToSendResult(loopResult)
    }
    // ... existing 8-step pipeline unchanged ...
  }
}
```

## Acceptance Criteria

1. `send()` on an `isAgentic` provider delegates to `agenticLoop.run` and returns a `SendResult`.
2. `send()` on a non-agentic provider still runs the unmodified 8-step pipeline.
3. When `agenticLoop` is absent (undef) even agentic providers fall back to the linear pipeline.
4. `ProviderDefinition.isAgentic` is respected (false → linear; true → loop).
5. `bun run devops gate` passes; routing branch ≥80% covered.
