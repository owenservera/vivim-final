# Unit 8.6 — Cost + token tracking

**Source:** v3 Overview §1.4; `docs/master-plan-v3/PHASE-08-observability-audit.md` §8.6
**Design Doc:** `docs/master-plan-v3/PHASE-08-observability-audit.md` §8.6
**Depends on:** 7.6
**Produces:** `cost_log` joined to `agent_run` + `provenance_node`.

---

## Context

Cost today is provider-level (`ProviderCostLog` / `CostOptimizer`). This unit extends it per-**task** and per-**capability**: `cost_log` gains `agentRunId` + `provenanceNodeId`. This enables "this autonomous task cost $0.42, of which $0.30 was the summarize step." Surfaces in `AgentFrontendSurface` (4.5) and `TelemetryDashboardSurface` (8.3).

## Existing Baseline

- `src/engines/cost-optimizer.ts` — `CostOptimizer` with `createCostLog(...)`, `getCostLogs(providerId, from, to)`, `CostReport`, `ProviderCostSummary`. We extend the log row.
- `src/schema/types.js` — `cost_log` table (add `agentRunId`, `provenanceNodeId`).
- `src/engines/autonomous-execution.ts` (7.6) — `BudgetUsage` per task; the task id is the `agentRunId` join key.
- `docs/atomic-v3/phase-02-agentic-core/2.14-provenance-graph.md` — `provenance_node` is the `provenanceNodeId` join key.

## Interface

### Change in `src/engines/cost-optimizer.ts`

```typescript
export interface CostLogRow {
  id: string
  providerId: string
  capabilityId: string
  cents: number
  tokens: number
  ts: number
  agentRunId: string | null   // NEW: links to autonomous task
  provenanceNodeId: string | null // NEW: links to provenance node
}

export class CostOptimizer {
  // ...
  async createCostLog(input: Omit<CostLogRow, 'id'>): Promise<void> {
    await this.store.createCostLog(input) // store persists agentRunId + provenanceNodeId
  }

  async costForTask(agentRunId: string): Promise<{ totalCents: number; byCapability: Record<string, number> }> {
    const rows = await this.store.getCostLogsForRun(agentRunId)
    const byCapability: Record<string, number> = {}
    for (const r of rows) byCapability[r.capabilityId] = (byCapability[r.capabilityId] ?? 0) + r.cents
    return { totalCents: rows.reduce((s, r) => s + r.cents, 0), byCapability }
  }
}
```

### Surface bindings (4.5 / 8.3)

```
GET /api/cost/task/:agentRunId   -> { totalCents, byCapability }
```

## Acceptance Criteria

1. `cost_log` rows carry `agentRunId` + `provenanceNodeId` (nullable for non-task calls).
2. `createCostLog` persists both new fields.
3. `costForTask(runId)` returns total cents + a per-capability breakdown for that run.
4. A task's cost is derivable in real time (joins to `BudgetUsage` from 7.6) and accurate to within 5% of the provider invoice.
5. Surfaced in `AgentFrontendSurface` + `TelemetryDashboardSurface`.
6. `bun run devops gate` passes.

## Tests

`tests/unit/engines/cost-optimizer-task.test.ts` (mock store):

- costForTask → total = sum; byCapability groups correctly.
- run with no logs → `{ totalCents: 0, byCapability: {} }`.
