# Unit 8.8 — System health report (daily digest)

**Source:** v3 Overview §3; `docs/master-plan-v3/PHASE-08-observability-audit.md` §8.8
**Design Doc:** `docs/master-plan-v3/PHASE-08-observability-audit.md` §8.8
**Depends on:** 8.3, 8.6
**Produces:** `AutomationSchedule` that runs daily and writes a markdown digest.

---

## Context

Operators want a hands-off daily summary. This unit adds an `AutomationSchedule` that fires at 09:00 daily, gathers the day's providers/costs/capabilities/drift/tasks/memory-growth, and writes `docs/audit/daily-{date}.md`. Optional email/file notification. It composes `TelemetryAggregator` trends (8.3), `CostOptimizer` figures (8.6), and `RegistrationAuditor` drift results.

## Existing Baseline

- `src/engines/telemetry-aggregator.ts` — `TelemetryAggregator` with `CycleResult`, `TrendPoint`, `RetentionPolicy`; `runCycle()` is the data source.
- `src/engines/cost-optimizer.ts` — `CostOptimizer.CostReport` / `ProviderCostSummary`.
- `src/engines/registration-auditor.ts` — `RegistrationAuditor.DriftDetectionResult` (drift events resolved).
- `src/engines/autonomous-execution.ts` (7.x) — autonomous tasks completed (count from `activeTasks`/store).
- `src/engines/memory-engine.ts` (6.x) — memory growth (fact/ episode counts).
- `docs/audit/` — output directory (per schemas / docs layout).

## Interface

### New file: `src/engines/health-digest.ts`

```typescript
import type { TelemetryAggregator } from './telemetry-aggregator.js'
import type { CostOptimizer } from './cost-optimizer.js'
import type { RegistrationAuditor } from './registration-auditor.js'

export interface DigestInput {
  date: string
  providersUsed: string[]
  costCents: number
  capabilitiesExecuted: Array<{ slug: string; count: number; successRate: number }>
  driftResolved: number
  tasksCompleted: number
  memoryGrowth: { facts: number; episodes: number }
}

export class DailyHealthDigest {
  constructor(
    private agg: TelemetryAggregator,
    private cost: CostOptimizer,
    private auditor: RegistrationAuditor,
    private scheduler: AutomationSchedule,
  ) {}

  scheduleDaily(atHour = 9): void {
    this.scheduler.everyDay(atHour, () => void this.run(new Date()))
  }

  async run(day: Date): Promise<string> {
    const input = await this.collect(day)
    const md = renderDigest(input)
    const path = `docs/audit/daily-${isoDate(day)}.md`
    await this.fs.writeFile(path, md)
    await this.notify(path) // optional email/file
    return path
  }

  private async collect(day: Date): Promise<DigestInput> {
    const trends = await this.agg.runCycle({ from: startOfDay(day), to: endOfDay(day) })
    const cost = await this.cost.report(startOfDay(day), endOfDay(day))
    const drift = await this.auditor.detectDrift()
    return {
      date: isoDate(day),
      providersUsed: cost.providers,
      costCents: cost.totalCents,
      capabilitiesExecuted: trends.byCapability,
      driftResolved: drift.resolved,
      tasksCompleted: await this.store.countTasks(day),
      memoryGrowth: await this.memory.growthSince(startOfDay(day)),
    }
  }
}

function renderDigest(i: DigestInput): string {
  return `# Health Digest — ${i.date}\n\n` +
    `- Providers used: ${i.providersUsed.join(', ') || 'none'}\n` +
    `- Cost: $${(i.costCents / 100).toFixed(2)}\n` +
    `- Capabilities: ${i.capabilitiesExecuted.length} (success rates inline)\n` +
    `- Drift resolved: ${i.driftResolved}\n` +
    `- Tasks completed: ${i.tasksCompleted}\n` +
    `- Memory growth: +${i.memoryGrowth.facts} facts, +${i.memoryGrowth.episodes} episodes\n`
}
```

## Acceptance Criteria

1. `scheduleDaily(9)` registers a daily 09:00 job via `AutomationSchedule`.
2. `run(day)` collects providers/costs/capabilities/drift/tasks/memory-growth.
3. Output is written to `docs/audit/daily-{YYYY-MM-DD}.md`.
4. Digest content includes all six sections (providers, cost, capabilities+success, drift, tasks, memory growth).
5. Manual trigger endpoint (`POST /api/admin/run-digest`) exists for testing.
6. `bun run devops gate` passes.

## Tests
