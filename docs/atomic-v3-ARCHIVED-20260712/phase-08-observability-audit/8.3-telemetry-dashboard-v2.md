# Unit 8.3 — Real-time telemetry dashboard v2

**Source:** v3 Overview §3; `docs/master-plan-v3/PHASE-08-observability-audit.md` §8.3
**Design Doc:** `docs/master-plan-v3/PHASE-08-observability-audit.md` §8.3
**Depends on:** 4.9
**Produces:** `TelemetryDashboardSurface` wired to live data via WebSocket.

---

## Context

The dashboard today is static. This unit makes `TelemetryDashboardSurface` live: streaming sparklines for the last 60s, animated health-score transitions, and drift events surfaced as toast notifications. A WebSocket subscription (filterable by provider) feeds `TelemetryAggregator` output in real time. Builds on `MirrorEngine` health scores (4.9).

## Existing Baseline

- `src/engines/telemetry-aggregator.ts` — `TelemetryAggregator` with `CycleResult`, `TrendPoint`, `AggregationFn` (`p50`/`p95`/`p99`…). The live feed reads its aggregates.
- `src/engines/provider-health.ts` — `ProviderHealthKernel` + `HealthStatus`; health score is the animated value.
- `src/engines/registration-auditor.ts` — `DriftDetectionResult` drives drift toasts.
- `docs/atomic-v3/phase-04-workspace-ui/4.9-mirror-engine-dashboard.md` — `MirrorEngine` dashboard; this reuses its WebSocket transport.
- `src/engines/capability-event-bus.ts` — event bus the dashboard subscribes to for drift toasts.

## Interface

### New file: `web/src/surfaces/TelemetryDashboard.tsx` (sketch)

```tsx
export function TelemetryDashboard() {
  const [spark, setSpark] = useState<TrendPoint[]>([])
  const [health, setHealth] = useState<Record<string, number>>({})
  const { toast } = useToaster()

  useEffect(() => {
    const ws = new WebSocket(`/api/telemetry/stream?provider=${filter}`)
    ws.onmessage = (e) => {
      const msg = JSON.parse(e.data) as TelemetryFrame
      if (msg.kind === 'spark') setSpark(msg.points)
      if (msg.kind === 'health') animateHealth(setHealth, msg.scores)
      if (msg.kind === 'drift') toast(`Drift: ${msg.detail}`)
    }
    return () => ws.close()
  }, [filter])

  return (
    <div className="telemetry-dashboard">
      <Sparkline data={spark} windowSec={60} />
      <HealthScores scores={health} />
      <DriftToasts />
    </div>
  )
}
```

### Server: `src/server/routes/telemetry-stream.ts`

```
GET /api/telemetry/stream   (WebSocket; frames: spark|health|drift)
```

## Acceptance Criteria

1. Dashboard opens a WebSocket and consumes `spark`/`health`/`drift` frames.
2. Sparklines show a rolling 60s window from `TelemetryAggregator` trends.
3. Health scores animate on `health` frames (no hard jump).
4. Drift events arrive as toast notifications via the event bus.
5. Subscription is filterable by `provider` query param.
6. `bun run devops gate` passes (root + `web/`).
