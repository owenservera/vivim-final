# Unit 8.4 — Telemetry audit enforcement (network layer)

**Source:** v3 Overview §1.10; `docs/master-plan-v3/PHASE-08-observability-audit.md` §8.4
**Design Doc:** `docs/master-plan-v3/PHASE-08-observability-audit.md` §8.4
**Depends on:** 5.8
**Produces:** `TelemetryAuditInterceptor` (single owner) monkey-patches `globalThis.fetch` and `Bun.fetch`, consulting the `provider_consent` policy from 5.8.

---

## Context

The system must only ever talk to user-consented hosts. This unit installs `TelemetryAuditInterceptor` that wraps `globalThis.fetch` and `Bun.fetch`: every outbound call (a) checks `provider_consent` for the host, (b) records to `NetworkCallRecord`, (c) throws `ConsentViolationError` if unconsented. The patch is installed in `src/server/bootstrap.ts` **before** any engine code runs, so it cannot be bypassed.

## Existing Baseline

- `src/engines/telemetry-audit.ts` — `TelemetryAudit` with `NetworkCallRecord` interface, `recordCall(record)`, `generateReport(from,to)`, `getCalls(from?,to?)`. The interceptor feeds `recordCall`.
- `src/schema/types.js` — `provider_consent` table (host → consent state) and `NetworkCallRecord` persistence target.
- `docs/master-plan-v3/PHASE-05-*.md` §5.8 — provider consent/audit layer; we depend on its consent store.
- `src/server/bootstrap.ts` — bootstrap entry; the patch is applied here first.

## Interface

### New file: `src/engines/telemetry-audit-interceptor.ts`

```typescript
import { TelemetryAudit } from './telemetry-audit.js'
import { ProviderConsentStore } from './provider-consent.js'

export class TelemetryAuditInterceptor {
  constructor(private audit: TelemetryAudit, private consent: ProviderConsentStore) {}

  install(): void {
    const orig = globalThis.fetch.bind(globalThis)
    const self = this
    globalThis.fetch = async (input: RequestInfo | URL, init?: RequestInit) => {
      const url = new URL(typeof input === 'string' ? input : (input as Request).url)
      self.assertConsent(url.host)
      const started = Date.now()
      const res = await orig(input, init)
      self.audit.recordCall({
        host: url.host, method: (init?.method ?? 'GET'),
        status: res.status, ts: started, durationMs: Date.now() - started,
        consented: true,
      })
      return res
    }
    // Bun.fetch mirror for non-globalThis callers
    if ('Bun' in globalThis && typeof (globalThis as any).Bun.fetch === 'function') {
      const bOrig = (globalThis as any).Bun.fetch.bind((globalThis as any).Bun)
      ;(globalThis as any).Bun.fetch = async (input: any, init?: any) => {
        const url = new URL(typeof input === 'string' ? input : input?.url)
        self.assertConsent(url.host)
        return bOrig(input, init)
      }
    }
  }

  private assertConsent(host: string): void {
    if (!this.consent.isConsented(host)) {
      throw new ConsentViolationError(host)
    }
  }
}
```

### Install in `src/server/bootstrap.ts` (first line, before engine init)

```typescript
const interceptor = new TelemetryAuditInterceptor(audit, consentStore)
interceptor.install() // MUST run before any engine constructs
```

## Acceptance Criteria

1. After `install()`, `globalThis.fetch` checks `provider_consent` for the target host before sending.
2. A consented call is recorded to `NetworkCallRecord` (via `audit.recordCall`).
3. An unconsented call throws `ConsentViolationError` and is **not** sent.
4. `Bun.fetch` is patched identically (no bypass path).
5. The interceptor is installed in `bootstrap.ts` before engine construction.
6. `bun run devops gate` passes.

## Tests

`tests/unit/engines/telemetry-audit-interceptor.test.ts`:
- consented host → fetch proceeds, `recordCall` called with `consented:true`.
- unconsented host → `ConsentViolationError` thrown, underlying fetch NOT called.
- `Bun.fetch` path also intercepted (spy on both).
