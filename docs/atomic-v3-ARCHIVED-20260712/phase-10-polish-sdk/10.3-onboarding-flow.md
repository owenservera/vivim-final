# Unit 10.3 — Onboarding flow

**Source:** v3 Overview §4; `docs/master-plan-v3/PHASE-10-polish-sdk.md` §10.3
**Design Doc:** `docs/master-plan-v3/PHASE-10-polish-sdk.md` §10.3
**Depends on:** Phase 4, Phase 5
**Produces:** 5-step first-run experience.

---

## Context

A new user must reach a useful task fast. This unit ships a 5-step onboarding wizard (each step a canvas-driven screen): (1) Welcome + privacy explanation, (2) Choose workspace dir, (3) Detect/install Ollama (or opt into cloud), (4) Pair a cloud provider (optional, with consent), (5) Try a sample task. Builds on `AirGapEngine` (9.4) defaults + `LocalModelAdapter` (5.1).

## Interface

### New file: `web/src/surfaces/Onboarding.tsx` (sketch)

```tsx
const STEPS = ['welcome', 'workspace', 'model', 'provider', 'sample'] as const

export function Onboarding() {
  const [step, setStep] = useState<typeof STEPS[number]>('welcome')
  return (
    <Wizard steps={STEPS} current={step} onNext={setStep}>
      <WelcomeStep />
      <WorkspaceDirStep onPick={(dir) => config.set('workspaceDir', dir)} />
      <ModelStep probe={airgap.probeLocalFirstRun} />
      <ProviderStep optional consentRequired />   {/* step 4, consent-gated */}
      <SampleTaskStep template="hello-world" /> {/* step 5 */}
    </Wizard>
  )
}
```

### Route: `src/server/routes/setup-router.ts` (extend)

```
GET  /api/setup/status      -> { onboarded: boolean, step: string }
POST /api/setup/workspace    body { dir }
POST /api/setup/model        body { mode: 'local'|'cloud' }
```

## Acceptance Criteria

1. First run shows a 5-step wizard; completion persists `onboarded:true`.
2. Step 2 persists `workspaceDir` via `ConfigManager`.
3. Step 3 detects Ollama (via `AirGapEngine`) or offers cloud opt-in.
4. Step 4 (cloud provider) is **optional** and consent-gated (`ProviderConsent`).
5. Step 5 runs a sample task (template) to validate the install end-to-end.
6. A new user completes onboarding + a useful task within 10 minutes (acceptance).
7. `bun run devops gate` passes (root + `web/`).
