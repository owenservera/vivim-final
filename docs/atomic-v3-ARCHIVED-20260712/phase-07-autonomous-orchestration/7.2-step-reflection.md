# Unit 7.2 — Step reflection + adaptation

**Source:** v3 Overview §1.4; `docs/master-plan-v3/PHASE-07-autonomous-orchestration.md` §7.2
**Design Doc:** `docs/master-plan-v3/PHASE-07-autonomous-orchestration.md` §7.2
**Depends on:** 2.11, 2.14
**Produces:** `reflect()` records `(expectedState, actualState)` deltas; `reflect()` updates plan confidence + triggers replan.

---

## Context

`AgenticLoopEngine.reflect` (agentic-loop.ts:166) today returns a boolean ("did state change?"). This unit makes reflection structured: after each step, compare the **expected** state (from the plan) to the **actual** observed state. If the delta exceeds a threshold, replan the remaining steps. Every reflection records `ProvenanceGraph` edges linking the step to its predecessor + the replan decision.

## Interface

### Change in `src/engines/agentic-loop.ts`

```typescript
export interface ReflectionResult {
  delta: number                       // magnitude of expected-vs-actual divergence
  expectedState: unknown
  actualState: unknown
  confidenceDelta: number             // applied to plan confidence
  needsReplan: boolean
}

export class AgenticLoopEngine {
  // ...
  private reflect(expected: unknown, actual: unknown, _action: string): ReflectionResult {
    const delta = stateDelta(expected, actual)            // structured diff, not boolean
    const needsReplan = delta > this.replanThreshold
    const confidenceDelta = needsReplan ? -0.15 : +0.05
    this.provenance.recordEdge(this.currentStepId, this.predecessorStepId, 'step-successor', { delta })
    if (needsReplan) {
      this.provenance.recordEdge(this.currentStepId, 'replan', 'replan-decision', { delta })
    }
    return { delta, expectedState: expected, actualState: actual, confidenceDelta, needsReplan }
  }

  private adapt(result: ReflectionResult): void {
    this.planConfidence = clamp(this.planConfidence + result.confidenceDelta, 0, 1)
    if (result.needsReplan) void this.replanRemainingSteps()
  }
}
```

## Acceptance Criteria

1. `reflect` returns a `ReflectionResult` (not boolean) with `delta`, `expectedState`, `actualState`, `confidenceDelta`, `needsReplan`.
2. `delta > replanThreshold` sets `needsReplan: true` and records a `replan-decision` edge.
3. Every step records a `step-successor` `ProvenanceGraph` edge to its predecessor.
4. `adapt` lowers `planConfidence` on replan, raises it on success.
5. `bun run devops gate` passes.
