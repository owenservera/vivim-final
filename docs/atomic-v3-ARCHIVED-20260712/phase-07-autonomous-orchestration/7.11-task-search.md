# Unit 7.11 — Task search + history

**Source:** v3 Overview §1.8; `docs/master-plan-v3/PHASE-07-autonomous-orchestration.md` §7.11
**Design Doc:** `docs/master-plan-v3/PHASE-07-autonomous-orchestration.md` §7.11
**Depends on:** 7.5
**Produces:** Task list view with full-text search + per-task provenance timeline.

---

## Context

As tasks accumulate, the user needs to find them and inspect their history. This unit adds a task list with **full-text search** over goal text + step descriptions, and a per-task drill-down showing the DAG + provenance edges + gate resolutions + replays (7.5). Filterable by status / date / cost.

## Interface

### New file: `src/engines/task-history.ts`

```typescript
export interface TaskSummary {
  id: string
  goal: string
  status: TaskStatus
  stepCount: number
  costCents: number
  startedAt: number
}

export interface TaskTimeline {
  dag: AutonomousStep[]
  provenance: ProvenanceEdge[]
  gates: HitlGate[]
  replays: ReplayRecord[]
}

export class TaskHistoryService {
  constructor(private engine: AutonomousExecutionEngine, private store: TaskStore) {}

  async search(query: string, filter?: { status?: TaskStatus; from?: number; to?: number }): Promise<TaskSummary[]> {
    const all = await this.store.listTasks(filter)
    if (!query) return all
    const q = query.toLowerCase()
    return all.filter((t) =>
      t.goal.toLowerCase().includes(q) ||
      t.stepCount > 0 && this.store.stepText(t.id).toLowerCase().includes(q),
    )
  }

  async timeline(taskId: string): Promise<TaskTimeline> {
    return {
      dag: await this.store.steps(taskId),
      provenance: await this.provenance.edgesFor(taskId),
      gates: await this.store.gates(taskId),
      replays: await this.store.replays(taskId),
    }
  }
}
```

### New route: `src/server/routes/tasks.ts`

```
GET /api/tasks?q=<text>&status=<s>&from=<ts>&to=<ts>
GET /api/tasks/:id/timeline
```

## Acceptance Criteria

1. `search` returns tasks whose goal **or** step text matches the query (case-insensitive).
2. `filter.status` / `from` / `to` narrow results independently.
3. `timeline(taskId)` returns `dag` + `provenance` + `gates` + `replays` for one task.
4. Empty query returns the full filtered list (no error).
5. Result powers the workspace task list (4.x) with status/date/cost filters.
6. `bun run devops gate` passes.
