# Unit 7.5 — Replay with branching

**Source:** v3 Overview §1.5; `docs/master-plan-v3/PHASE-07-autonomous-orchestration.md` §7.5
**Design Doc:** `docs/master-plan-v3/PHASE-07-autonomous-orchestration.md` §7.5
**Depends on:** 2.14
**Produces:** `AutonomousExecutionEngine.replay(taskId, { fromStep, branch })`.

---

## Context

Replay re-executes a completed (or partial) plan so the user can inspect or redo it. With `branch: true` the original task is **never** mutated — a new task is created that shares the prefix up to `fromStep`. This powers "what if I had answered that gate differently?" exploration. The branch is linked to its origin via `ProvenanceGraph`.

## Interface

### New method on `AutonomousExecutionEngine`

```typescript
export interface ReplayOptions {
  fromStep: number
  branch: boolean
}

export class AutonomousExecutionEngine {
  // ...
  async replay(taskId: string, opts: ReplayOptions): Promise<string> {
    const original = this.activeTasks.get(taskId)
    if (!original) throw new CapStoreError(`No task ${taskId}`)

    if (!opts.branch) {
      // In-place re-execution from fromStep.
      await this.continueFrom(original, opts.fromStep)
      return original.id
    }

    // Branch: clone prefix, new task id, untouched original.
    const branchTask: AutonomousTask = {
      id: ulid(),
      goal: { ...original.goal },
      status: 'running',
      steps: original.steps.slice(0, opts.fromStep + 1).map((s) => ({ ...s, taskId: 'PENDING' })),
      startedAt: Date.now(),
      completedAt: null,
      result: null,
      error: null,
    }
    branchTask.steps.forEach((s) => (s.taskId = branchTask.id))
    this.activeTasks.set(branchTask.id, branchTask)
    this.provenance.recordEdge(branchTask.id, original.id, 'replay-branch', { fromStep: opts.fromStep })
    await this.continueFrom(branchTask, opts.fromStep + 1)
    return branchTask.id
  }
}
```

## Acceptance Criteria

1. `replay(id, { fromStep, branch:false })` re-executes the original task from `fromStep` (mutates it).
2. `replay(id, { fromStep, branch:true })` creates a **new** task with the prefix `0..fromStep` and leaves the original unchanged.
3. The branch task records a `replay-branch` `ProvenanceGraph` edge to its origin.
4. Continuing past `fromStep` reuses `planGoal` to resolve the remaining tail.
5. Replaying an unknown `taskId` throws (no silent no-op).
6. `bun run devops gate` passes.

## Tests

`tests/unit/engines/autonomous-replay.test.ts` (mock store + provenance):
- `branch:false` → original task continues; same id returned.
- `branch:true` → new id; original steps after `fromStep` untouched.
