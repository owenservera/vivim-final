# ADR-010: 196-models-in-one-schema-migration-ownership-cost-and-drift-

**Status:** PROPOSED
**Date:** 2026-08-06
**Author:** review-system (run run-2026-08-06)
**Finding:** FIX-B2-1 ([P1] prisma/schema.prisma)

## Problem Statement

196 models in one schema — migration/ownership cost and drift risk is high; single-file schema is a long-term bottleneck

## Evidence

196 models, `migrate list` spans years/files

## Proposed Approach

split by bounded context (node, provider, user, memory, workflow) with per-context migrations; consider a schema report/audit
