# Unit 17.2: ContextAssemblyEngine

**Phase:** 17 | **File:** src/engines/context-assembly.ts
**Depends:** 17.1 SituationDetector, 15.6 SemanticSearch | **Source:** upgrade-02-architecture.md §7, upgrade-05-memory-intelligence.md

## Purpose
5-stage pipeline: DETECT -> RECALL -> RANK -> BUDGET -> INJECT. Assembles context from memory, search, and history before sending to provider.

export interface ContextLayer {

  content: string
  tokenCount: number

export interface AssembledContext {
  conversationId: string
