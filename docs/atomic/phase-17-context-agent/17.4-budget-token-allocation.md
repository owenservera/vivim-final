# Unit 17.4: Budget-Aware Token Allocation

**Phase:** 17 | **File:** src/engines/context-assembly.ts (extends 17.2)
**Depends:** 17.2 ContextAssembly | **Source:** upgrade-05-memory-intelligence.md

## Purpose
Allocate token budget across context layers based on task type.

## Default Budget (adaptive):
- conversation_history: 30%
- recent_episodes: 15%
- topic (semantic): 20%
- entity: 10%
- project_state: 10%
- preferences: 10%
- identity: 5%

Adjusted per task type (coding weights recent_episodes higher, research weights topic higher).

## Tests
- Total tokens <= budget
- High-priority layers preserved when truncating
- Budget allocation adjusts per situation
