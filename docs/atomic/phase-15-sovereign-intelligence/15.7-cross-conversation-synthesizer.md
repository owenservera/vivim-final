# Unit 15.7: CrossConversationSynthesizer

**Phase:** 15 | **File:** `src/engines/cross-conversation-synthesis.ts`
**Depends:** 15.6 SemanticSearch | **Produces:** Synthesize answers across all conversations
**Source:** upgrade-02-architecture.md §4

## Purpose

Answer user questions by synthesizing insights from multiple conversations. "What did I learn about X?" returns a synthesized answer citing specific conversations.

## Interface

```typescript
export interface SynthesisQuery {
  question: string
  scope: { providerIds?: string[]; topicIds?: string[]; dateFrom?: number; dateTo?: number }
  maxSources: number
  synthesisStyle: 'summary' | 'detailed' | 'bullets'
}

export interface SynthesisResult {
  answer: string
  sources: Array<{ conversationId: string; messageId: string; snippet: string; relevance: number }>
  confidence: number
  gaps: string[]
}

export class CrossConversationSynthesizer {
  constructor(store: CrossConversationSynthesizerStore, searchEngine: SemanticSearchEngine, llmProvider: SynthesisLlmProvider)
  async synthesize(query: SynthesisQuery): Promise<SynthesisResult>
  async quickAnswer(question: string): Promise<SynthesisResult>
}
```

## Execution Flow

1. Semantic search for relevant messages
2. Gather related facts and decisions
3. Build synthesis prompt with sources
4. Call LLM provider to synthesize
5. Return answer with source citations

## Tests

- Synthesize answer from 3 relevant conversations
- Quick answer returns single best source
- No relevant results → returns gaps
