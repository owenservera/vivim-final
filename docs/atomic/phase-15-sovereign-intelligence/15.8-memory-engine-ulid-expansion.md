# Unit 15.8: MemoryEngine ULID Fix + 10-Type Expansion

**Phase:** 15 | **File:** `src/engines/memory-engine.ts`
**Depends:** 15.5 KnowledgeExtractor | **Produces:** Fix IDs to ULID, expand memory types
**Source:** upgrade-02-architecture.md §Modified Engines

## Purpose

Fix MemoryEngine's non-ULID ID generation (uses `mem_${Date.now()}_${counter}`, line 128) and expand from 3 memory types to 10 by adding entity, decision, pattern, topic, project, summary, preference support.

## Changes

### Remove:
```typescript
// DELETE lines 126-129:
let idCounter = 0
function newId(): string {
  return `mem_${Date.now()}_${++idCounter}`
}
```

### Add:
```typescript
import { newId } from '../ids.js'  // ULID
```

### Add methods for new memory types:
```typescript
async recordEntity(input: { name: string; type: string; description?: string; conversationId?: string; messageId?: string }): Promise<void>
async recordDecision(input: { conversationId: string; messageId: string; decisionText: string; rationale?: string; alternatives?: string[] }): Promise<void>
async recordPattern(input: { name: string; description: string; patternType: string }): Promise<void>
async getTopics(): Promise<Topic[]>
async getProjects(): Promise<Project[]>
async assignTopic(conversationId: string, topicId: string): Promise<void>
```

## Tests

- `recordEpisode()` generates ULID (26 chars, uppercase)
- `recordEntity()` creates entity row
- `recordDecision()` creates decision row
- IDs are sortable (ULID property)

## Gate

- `bun run typecheck` passes
- All IDs start with ULID format (01J... prefix)
