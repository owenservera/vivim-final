# Unit 15.1: KnowledgeIngestionEngine

**Phase:** 15 | **File:** `src/engines/knowledge-ingestion.ts`
**Depends:** 14.5 ConvMgr EventBus Fix | **Produces:** Import external conversation exports into local knowledge base
**Source:** upgrade-02-architecture.md §1, upgrade-05-memory-intelligence.md

## Purpose

Ingest conversation history from external AI providers (ChatGPT, Claude, Gemini) into the local database. Creates Conversation + ConversationMessage + StreamBlock rows from parsed export files.

## Interface


## Execution Flow

1. Create ImportJob (status=pending)
2. Read file → detect format → call source-specific parser (15.2-15.4)
3. For each parsed conversation:
   a. Check duplicate via `store.findExistingConversation(source, externalId)`
   b. If dup and `deduplicate` → skip
   c. Create Conversation with `source='imported'`, `externalId`
   d. For each message → create ConversationMessage + StreamBlock
4. If `extractEntities` → call `extractor.batchExtract()`
5. If `generateEmbeddings` → call `searchEngine.indexBatch()`
6. Update ImportJob → status=complete
7. Emit `knowledge:imported` event

## Error Mapping

| Error | When | Recovery |
|-------|------|----------|
| FileNotFoundError | File doesn't exist | Mark job failed |
| ParseError | Unknown format | Try generic JSON parser |
| DuplicateError | Already imported | Skip, increment counter |

## Tests

- Duplicate detection skips existing
- Import job status transitions: pending → parsing → complete
