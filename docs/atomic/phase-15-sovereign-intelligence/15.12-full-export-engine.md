# Unit 15.12: Full Export Engine

**Phase:** 15 | **File:** `src/engines/export.ts`
**Depends:** — | **Produces:** JSON/CSV export of all data
**Source:** upgrade-02-architecture.md §12, upgrade-09-sovereign-data.md

## Purpose

Export all VIVIM data (conversations, memory, providers, config) as JSON or CSV for portability and no-lock-in.

## Interface

```typescript
export type ExportFormat = 'json' | 'csv'
export type ExportScope = 'full' | 'conversations' | 'memory' | 'providers' | 'config'

export interface ExportOptions {
  format: ExportFormat
  scope: ExportScope
  outputPath: string
  includeEmbeddings: boolean
  encryptWithPassphrase?: string
  dateFrom?: number
  dateTo?: number
}

export interface ExportResult {
  filePath: string
  format: ExportFormat
  scope: ExportScope
  tablesExported: string[]
  totalRows: number
  fileSizeBytes: number
  durationMs: number
  encrypted: boolean
}

export class ExportEngine {
  constructor(private db: CapStoreDb)
  async export(options: ExportOptions): Promise<ExportResult>
  async importFromJson(filePath: string): Promise<{ tablesImported: string[]; rowsImported: number }>
}
```

## Execution Flow

1. Determine tables from scope
2. Query each table → collect rows
3. Format as JSON (single file) or CSV (directory of files)
4. Optionally encrypt with passphrase
5. Write to disk → return stats
