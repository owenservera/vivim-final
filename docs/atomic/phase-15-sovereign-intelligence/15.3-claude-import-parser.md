# Unit 15.3: Claude Export Parser

**Depends:** 15.1 KnowledgeIngestionEngine | **Produces:** Parse Claude export format

## Purpose

Parse Claude conversation exports into normalized ParsedConversation[].

## Interface

```typescript
export class ClaudeExportParserImpl {
  parse(rawJson: string): ParsedConversation[]
}
```

## Implementation

Parse Claude export format with `chat_messages` array, mapping `sender: "human"` → `"user"`, `sender: "assistant"` → `"assistant"`. External ID = `uuid`.
