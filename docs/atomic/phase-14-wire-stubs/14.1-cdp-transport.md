# Unit 14.1: CDPTransport Implementation

**Phase:** 14 | **File:** `src/executor/cdp-transport.ts`
**Depends:** 11.1 BunCdpClient | **Produces:** Real CDP transport wiring Governor to Chrome
**Source:** upgrade-02-architecture.md §Modified Engines

## Purpose

Wire `BunCdpClient` (src/executor/cdp.ts, 273 lines) into the `CDPTransport` interface defined in `ChromeGovernor` (src/engines/chrome-governor.ts:137-142). Currently the Governor uses `stubCdp` which throws "implement in Phase 9". This unit creates the concrete adapter that makes Governor CDP operations functional.

## Interface

```typescript
// src/executor/cdp-transport.ts

import type { CDPTransport, CaptureResult, PageState } from '../engines/chrome-governor.js'
import { BunCdpClient } from './cdp.js'

export class CdpTransportImpl implements CDPTransport {
  private clients = new Map<string, BunCdpClient>()

  async send(slaveId: string, method: string, params?: Record<string, unknown>): Promise<unknown>
  async capture(slaveId: string, pattern: RegExp, timeoutMs?: number): Promise<CaptureResult>
  async getPageState(slaveId: string): Promise<PageState>
  async captureScreenshot(slaveId: string, format?: 'png' | 'jpeg'): Promise<string>
  async connect(slaveId: string, debugPort: number): Promise<void>
  async disconnect(slaveId: string): Promise<void>
  async disconnectAll(): Promise<void>
  isConnected(slaveId: string): boolean
}
```

## Store Contract

No store contract — this is a pure adapter wrapping `BunCdpClient`.

## Execution Flow

1. `connect(slaveId, debugPort)` → create `BunCdpClient` with `ws://127.0.0.1:{port}/devtools/browser` → store in clients map
2. `send(slaveId, method, params)` → get client from map → call `client.send(method, params)` → return result
3. `capture(slaveId, pattern, timeoutMs)` → enable Network domain → listen for matching response → return body
4. `getPageState(slaveId)` → call `send('Runtime.evaluate', { expression: 'JSON.stringify({url: location.href, title: document.title, readyState: document.readyState})' })` → parse result
5. `captureScreenshot(slaveId, format)` → call `send('Page.captureScreenshot', { format })` → return base64 data
6. `disconnect(slaveId)` → call `client.disconnect()` → remove from map

## Error Mapping

| Error | When | Recovery |
|-------|------|----------|
| `CdpConnectionError` | Client not connected | Attempt reconnect, fail after 3 retries |
| `CdpTimeoutError` | Command exceeds 30s | Abort, return error |
| `SlaveNotConnectedError` | slaveId not in clients map | Return error |

## Tests

- `connect()` creates BunCdpClient and stores it
- `send()` routes to correct BunCdpClient
- `send()` throws if slaveId not connected
- `getPageState()` returns url, title, readyState
- `captureScreenshot()` returns base64 string
- `disconnect()` removes client from map
- `disconnectAll()` clears all clients
- `isConnected()` returns correct status

## Implementation Notes

- Each slave gets its own `BunCdpClient` instance (one WebSocket per Chrome instance)
- The `capture()` method needs Network.enable + response body fetching via `Network.getResponseBody`
- Use `AbortSignal.timeout()` for capture timeout
- BunCdpClient already has auto-reconnect (cdp.ts:231-249)
