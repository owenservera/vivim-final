# Unit 14.6: Server → ConversationManager Wiring

**Phase:** 14 | **File:** `src/server/conversation-router.ts`
**Depends:** 14.5 ConvMgr EventBus Fix | **Produces:** Server routes call engine, not DB directly
**Source:** upgrade-02-architecture.md

## Purpose

The server's conversation-router.ts (79 lines) currently creates conversations directly via `ctx.db.createConversation()` (line 40) and never calls `ConversationManager.send()`. This unit wires the server to use the real ConversationManager engine, adds missing routes (send message, get capabilities), and creates the engine bootstrap.

## Changes

### Add to ServerContext:
```typescript
export interface ServerContext {
  port: number
  db: CapStoreDb
  eventBus: CapabilityEventBus

```

### Add routes:
```typescript
// POST /api/conversations/:id/send
const sendMatch = pathname.match(/^\/api\/conversations\/([^/]+)\/send$/)
if (sendMatch && method === 'POST') {
  const conversationId = sendMatch[1]
  const body = await req.json() as { message: string }
  if (!ctx.conversationManager) return errorResponse('Engine not wired', 'InternalError', 500)
  const result = await ctx.conversationManager.send(conversationId, body.message)
  return json(result)
}

// GET /api/providers/:id/capabilities
const capMatch = pathname.match(/^\/api\/providers\/([^/]+)\/capabilities$/)
if (capMatch && method === 'GET') {
  const providerId = capMatch[1]
  const planTier = url.searchParams.get('planTier') ?? 'free'
  if (!ctx.resolutionEngine) return errorResponse('Engine not wired', 'InternalError', 500)
  const resolved = await ctx.resolutionEngine.resolve(providerId, planTier as PlanTier)
  return json(resolved)
}

// POST /api/fleet/start
if (pathname === '/api/fleet/start' && method === 'POST') {
  const body = await req.json() as { providerId: string; accountId: string }
  if (!ctx.governor) return errorResponse('Engine not wired', 'InternalError', 500)
  const slave = await ctx.governor.spawn(body.providerId, body.accountId)
  return json(slave, 201)
}
```
