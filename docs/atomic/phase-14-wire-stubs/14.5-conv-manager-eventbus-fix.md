## Purpose

ConversationManager (conversation-manager.ts) defines its own local `interface CapabilityEventBus { emit(event: unknown): void }` (line 83) and local stub interfaces for `CapabilityResolutionEngine`, `StreamBlockStore`, and `CapabilityEventBus`. These shadow the real implementations and cause type mismatches. This unit removes all local stubs and imports the real classes.
