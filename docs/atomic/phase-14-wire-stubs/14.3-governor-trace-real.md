## Purpose

Replace the trace stubs in ChromeGovernor (lines 662-672) that throw "Trace logging not configured - implement Phase 12" with real implementations using the existing `TraceLog` class.

## Changes

### Remove stub methods (lines 662-672):
```typescript
// DELETE these:
async recordTrace(_entry: TraceEntryInput): Promise<TraceEntryRow> { throw ... }
async getTrace(_slaveId: string, _limit?: number): Promise<TraceEntryRow[]> { throw ... }
async getConversationTrace(_conversationId: string): Promise<TraceEntryRow[]> { throw ... }
```

### Replace with:
```typescript
private traceLog: TraceLog | null = null

setTraceLog(store: GovernorStore): void {
  this.traceLog = new TraceLog(store)
}

async recordTrace(entry: TraceEntryInput): Promise<TraceEntryRow> {
  if (!this.traceLog) throw new EngineError('TraceLog not configured. Call setTraceLog() first.')
  return this.traceLog.record(entry)
}

async getTrace(slaveId: string, limit?: number): Promise<TraceEntryRow[]> {
  if (!this.traceLog) throw new EngineError('TraceLog not configured.')
  return this.traceLog.getTrace(slaveId, limit)
}

async getConversationTrace(conversationId: string): Promise<TraceEntryRow[]> {
  if (!this.traceLog) throw new EngineError('TraceLog not configured.')
  return this.traceLog.getConversationTrace(conversationId)
}
```

## Tests

- `recordTrace()` stores entry via GovernorStore
- `getTrace()` returns entries for slaveId
- `getConversationTrace()` returns entries for conversationId
- Throws if TraceLog not configured
