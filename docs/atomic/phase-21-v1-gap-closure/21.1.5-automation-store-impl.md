## Purpose

Implement `AutomationStoreImpl` backed by Prisma. The `Scheduler` engine (`src/engines/scheduler.ts`) exists but has no corresponding store contract or implementation.

## Required: Define Contract First

Create `src/storage/contracts/automation-store.ts` with:

```typescript
export interface Automation {
  id: string
  name: string
  type: string
  schedule?: string
  enabled: boolean
  config: Record<string, unknown>
  lastRunAt?: number
  nextRunAt?: number
  createdAt: number
}

export interface AutomationStore {
  save(automation: Automation): Promise<void>
  findById(id: string): Promise<Automation | null>
  listEnabled(): Promise<Automation[]>
  updateLastRun(id: string, timestamp: number): Promise<void>
  delete(id: string): Promise<void>
}
```

## Acceptance Criteria

1. Create `src/storage/contracts/automation-store.ts` (contract)
2. Create `src/storage/impl/automation-store-impl.ts` implementing `AutomationStore`
3. Uses Prisma client for all operations
4. Handles `Automation.config` as JSON (Prisma `Json` field)
5. No `any` types — proper typing throughout
6. Unit test: `tests/unit/storage/impl/automation-store-impl.test.ts`

Verify `automations` table exists in `prisma/schema.prisma`. If not, add it.
