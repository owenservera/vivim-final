## 21.4.1 — StreamingProtocol → StreamBlockStore Integration

**Gap:** StreamingProtocol events don't persist to StreamBlockStore
**File:** `src/engines/streaming-protocol.ts:30-47`
**Current code:**
```typescript
export class StreamingProtocol {
  private handlers: StreamingEventHandler[] = []
  private blockBuffer: ContentBlock[] = []
  constructor(private readonly parser: ParserModule) {}
  onEvent(handler: StreamingEventHandler): () => void { ... }
  private emit(event: StreamingEvent): void { ... }
}
```
**Problem:** Events are emitted to in-memory handlers only; blocks are never persisted to `StreamBlockStore`
**Required:** Inject `StreamBlockStore` dependency; in `captureChunk()`, call `this.store.createBlock()` after emitting
**Design Doc:** `04-merged-engines.md` §13 StreamBlockStore
**Target:** `src/engines/streaming-protocol.ts` (edit existing)

## 21.4.3 — TelemetryAggregator Cron Scheduling

**Gap:** TelemetryAggregator has no cron/timer scheduling
**File:** `src/engines/telemetry-aggregator.ts:268-299`
**Current code:**
```typescript
export class TelemetryAggregator {
  private timerHandle: ReturnType<typeof setInterval> | null = null
  // ...
  constructor(...) {
    this.registerSchema()
    this.config = this.loadConfig()
  }
}
```
**Problem:** `timerHandle` is declared but never set; no `start()` method to begin scheduled aggregation cycles
**Required:** Add `start()` method that:
1. Reads `triggerMode` from config ('timer', 'event', 'manual', 'hybrid')
2. For 'timer' mode: sets `setInterval` at `schedules[].intervalMs`
3. For 'event' mode: subscribes to `eventBus` events listed in `EVENT_TRIGGER_TO_BUS`
4. For 'hybrid': both
**Design Doc:** `05-merged-lifecycles.md` §TelemetryAggregator
**Target:** `src/engines/telemetry-aggregator.ts` (add `start()` and `stop()` methods)
**Test:** `tests/unit/engines/telemetry-aggregator.test.ts`
**Gate:** `bun test tests/unit/engines/telemetry-aggregator.test.ts` passes
