# 21.3 — Schema Type Mismatches (3 units)

**Status:** PLANNED
**Priority:** P2 — HIGH (type safety violations)
**Depends on:** Phases 4-10 (v1 engines exist)

---

## Purpose

Three row types in `schema/types.ts` don't match their counterparts in store contracts or `schema/core.ts`. This causes type errors when engines import from the wrong layer.

---

## 21.3.1 — ConfigEntryRow Alignment

**Gap:** `ConfigEntryRow` in `schema/types.ts` differs from `config-store.ts`
**Schema/types.ts (L468-477):**
```typescript
export interface ConfigEntryRow {
  id: string
  engine_id: string
  config_key: string
  config_value: string
  config_type: string
  is_runtime: number
  created_at: number
  updated_at: number
}
```
**config-store.ts (L18-27):**
```typescript
export interface ConfigEntryRow {
  id: string
  engineId: string
  scopeType: string
  scopeId: string | null
  configJson: string
  schemaVersion: number
  createdAt: number
  updatedAt: number
}
```
**Problem:** Different fields entirely — `config_key`/`config_value`/`config_type`/`is_runtime` vs `scopeType`/`scopeId`/`configJson`/`schemaVersion`
**Design Doc:** `03-merged-schema.md` §config_entry table
**Resolution:** Align `schema/types.ts` to match `config-store.ts` (which matches Prisma schema)
**Target:** `src/schema/types.ts` (edit L468-477)
**Test:** `bun run typecheck` passes with no ConfigEntryRow errors
**Gate:** `bun run typecheck` zero errors

## 21.3.3 — SelectorStrategyRow Alignment

**Gap:** `SelectorStrategyRow` in `capability-store.ts` differs from `schema/core.ts`
**capability-store.ts (L37-48):**
```typescript
export interface SelectorStrategyRow {
  id: string
  capabilityId: string
  providerId: string
  selector: string
  priority: number
  strategyType: string
  hitCount: number
  missCount: number
  createdAt: number
  updatedAt: number
}
```
**schema/core.ts (L90-102):**
```typescript
export interface SelectorStrategy {
  id: string
  name: string
  capabilityId: string
  providerId: string
  strategyType: 'css' | 'xpath' | 'text' | 'aria' | 'data' | 'regex' | 'composite'
  selectorValue: string
  priority: number
  isActive: boolean
  hitCount: number
  missCount: number
  lastUsedAt: number | null
}
```
**Problem:** Missing `name`, `isActive`, `lastUsedAt` in store; `selector` vs `selectorValue`; `strategyType` is `string` vs union type
**Design Doc:** `03-merged-schema.md` §selector_strategy table
**Resolution:** Align `capability-store.ts` SelectorStrategyRow to match `schema/core.ts` SelectorStrategy (add missing fields, rename `selector` → `selectorValue`, narrow `strategyType`)
**Target:** `src/storage/contracts/capability-store.ts` (edit L37-48)
**Test:** `bun run typecheck` passes with no SelectorStrategyRow errors
**Gate:** `bun run typecheck` zero errors
