## Purpose

25 engines have zero test files. This unit creates one test file per engine, using mocked store contracts per `AGENTS.md` testing protocol.

---

## Testing Protocol

- Use `bun test` runner (NOT Jest/Vitest)
- Mock store contracts from `src/storage/contracts/*.ts`
- Test individual functions (unit tests)
- Aim for 80%+ coverage per engine
- Use `describe`/`it` blocks with descriptive names
