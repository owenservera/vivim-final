## Purpose

Implement `AlertStoreImpl` backed by Prisma. The `Alerter` engine (`src/engines/alerter.ts`) exists but has no corresponding store contract or implementation.

## Required: Define Contract First

Create `src/storage/contracts/alert-store.ts` with:

```typescript
export interface Alert {
  id: string
  type: string
  severity: 'info' | 'warning' | 'error' | 'critical'
  source: string
  message: string
  metadata?: Record<string, unknown>
  acknowledged: boolean
  createdAt: number
}

export interface AlertStore {
  save(alert: Alert): Promise<void>
  findById(id: string): Promise<Alert | null>
  findUnacknowledged(limit?: number): Promise<Alert[]>
  acknowledge(id: string): Promise<void>
  delete(id: string): Promise<void>
}
```

## Acceptance Criteria

1. Create `src/storage/contracts/alert-store.ts` (contract)
2. Create `src/storage/impl/alert-store-impl.ts` implementing `AlertStore`
3. Uses Prisma client for all operations
4. No `any` types — proper typing throughout
5. Unit test: `tests/unit/storage/impl/alert-store-impl.test.ts`
