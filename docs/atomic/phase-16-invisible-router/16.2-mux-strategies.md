# Unit 16.2: Mux Strategies (fan_out, round_robin, cost_optimized)

**Phase:** 16 | **File:** src/engines/provider-mux.ts (extends 16.1)
**Depends:** 16.1 ProviderMuxEngine | **Source:** upgrade-06-muxing-routing.md

## Purpose
Implement the 4 dispatch strategies within ProviderMuxEngine.

## Strategies
1. **fan_out**: Promise.allSettled to all providers simultaneously
2. **round_robin**: Sequential dispatch, stop on first success
3. **cost_optimized**: Sort by estimated cost, try cheapest first
4. **priority**: Use existing Router priority ordering

Each strategy creates MuxResponse rows for every attempt.

## Tests
- fan_out returns all responses (success + failure)
- round_robin stops on first success
- cost_optimized tries cheapest first
- All strategies record timing
