# Unit 16.4: Automatic Failover

**Phase:** 16 | **File:** src/engines/provider-mux.ts (extends 16.1)
**Depends:** 16.1 ProviderMuxEngine | **Source:** upgrade-06-muxing-routing.md

## Purpose
If a provider fails or times out, automatically try the next provider.

## Implementation
- Each dispatch wrapped in try/catch with timeout
- Failed dispatch recorded with error
- Next provider tried automatically
- All attempts logged to MuxResponse table

## Tests
- First provider timeout → second provider tried
- All providers fail → returns error with all failure details
- Timeout kills slow provider
