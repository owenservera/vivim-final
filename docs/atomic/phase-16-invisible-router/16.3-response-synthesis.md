# Unit 16.3: Response Synthesis

**Phase:** 16 | **File:** src/engines/provider-mux.ts (extends 16.1)
**Depends:** 16.1 ProviderMuxEngine | **Source:** upgrade-06-muxing-routing.md

## Purpose
Merge multiple provider responses into a single coherent answer.

## Implementation
1. Collect successful responses
2. Build synthesis prompt with all responses
3. Route to cheapest available provider for synthesis
4. Return synthesized text

## Tests
- 2 responses → synthesized into single answer
- 1 response → returned as-is (no synthesis needed)
- Synthesis failure → returns best individual response
