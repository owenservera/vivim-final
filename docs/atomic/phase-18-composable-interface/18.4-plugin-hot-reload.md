# Unit 18.4: Plugin Hot-Reload

**Phase:** 18 | **File:** src/engines/plugin-hot-reload.ts
**Depends:** 18.1 UnifiedRegistry | **Source:** upgrade-07-composable-interface.md

## Purpose
Watch plugins/ directory for .ts/.js changes and hot-reload without restart.

## Interface
`	ypescript
export class PluginHotReload {
  start(directory: string): void
  stop(): void
  onPluginLoaded(handler: (plugin: ProviderPlugin) => void): void
  onPluginUnloaded(handler: (pluginId: string) => void): void
  onPluginError(handler: (error: Error, filePath: string) => void): void
  listLoaded(): string[]
}
`

## Tests
- Plugin file added -> loaded automatically
- Plugin file changed -> old unloaded, new loaded
- Plugin file deleted -> unloaded
