# Unit 18.8: Memory Visualization API

**Phase:** 18 | **File:** src/server/memory-viz-router.ts
**Depends:** 15.5 KnowledgeExtractor | **Source:** upgrade-07-composable-interface.md

## Purpose
REST API for memory visualization: entity graph, timeline, statistics.

## Routes
- GET /api/memory/graph?entityId=X — entity + connections
- GET /api/memory/timeline?from=&to= — chronological events
- GET /api/memory/stats — aggregate statistics
- GET /api/memory/curated — curated entries
- PUT /api/memory/:type/:id — edit entry
- DELETE /api/memory/:type/:id — delete entry
