# Unit 18.2: CLI Complete

**Phase:** 18 | **File:** src/cli/commands/
**Depends:** 18.1 UnifiedRegistry | **Source:** upgrade-07-composable-interface.md

## Purpose
All capabilities registered in UnifiedCapabilityRegistry are automatically available as CLI commands.

## Implementation
Bridge between UnifiedCapabilityRegistry and existing CommandRegistry:
`	ypescript
export function syncCliFromUnified(registry: UnifiedCapabilityRegistry, cliRegistry: CommandRegistry): void {
  const capabilities = registry.exportForCli()
  for (const cap of capabilities) {
    cliRegistry.register({
      name: cap.name,
      description: cap.description,
      subsystem: 'backend',
      schema: z.object(cap.schema),
      handler: async (args) => ({ data: await registry.execute(cap.name, args, { metadata: {} }) }),
      examples: [],
    })
  }
}
`
