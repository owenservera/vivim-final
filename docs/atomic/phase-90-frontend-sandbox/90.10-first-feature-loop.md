# Unit 90.10 — First Feature End-to-End via Sandbox

**Phase:** 90 (Frontend Sandbox)
**Depends:** 90.8, 90.9
**Source:** `.kilo/plans/1783690988012-sandbox-frontend-system.md` (Phase 5)

## Interface

Drive ONE real feature end-to-end via sandbox:
1. Select capability from catalog
2. Execute via sandbox harness
3. Iterate UI → find best practice
4. Codify into `web/ui` registry
5. Verify agent can perform every step via `agent:command`

Candidate features:
- Chrome-slave account management
- Single capability execution
- Conversation creation + message send

## Store Contract

- Uses all previous units (90.1-90.9)
- Tests the full loop: UI → backend → execution → result → promotion

## Gate Criteria

- [ ] Feature works end-to-end in sandbox
- [ ] Agent can perform same steps via `agent:command`
- [ ] Best practice note written in `PROMOTED.md`
- [ ] No action exists that human can do but agent cannot

## Notes

- This is the proof that the system works
- Validates B8 invariant (agent parity)
- If this fails, the sandbox system needs revision
