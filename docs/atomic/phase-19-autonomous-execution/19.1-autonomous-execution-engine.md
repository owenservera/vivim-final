# Unit 19.1: AutonomousExecutionEngine

**Phase:** 19 | **File:** src/engines/autonomous-execution.ts
**Depends:** 14.2 Governor CDP, 18.1 UnifiedRegistry | **Source:** upgrade-02-architecture.md §9, upgrade-08-autonomous-execution.md

## Purpose
Multi-step autonomous task executor. Decomposes goals into steps, executes via capabilities/CDP, manages HITL gates.

## Interface
`	ypescript
export type TaskStatus = 'pending' | 'planning' | 'executing' | 'waiting_approval' | 'complete' | 'failed' | 'cancelled'
export type ActionClassification = 'read' | 'write' | 'navigate' | 'destructive' | 'financial' | 'communication'

export interface AutonomousGoal {
  description: string
  maxSteps: number
  maxDurationMs: number
  requireApprovalAbove: ActionClassification
  allowBrowser: boolean
  costBudgetCents: number
}

export interface AutonomousStep {
  id: string
  taskId: string
  stepIndex: number
  description: string
  action: string
  actionInput: Record<string, unknown>
  classification: ActionClassification
  status: 'pending' | 'running' | 'complete' | 'failed' | 'skipped' | 'waiting_human'
  result: unknown
  error: string | null
  startedAt: number | null
  completedAt: number | null
  requiresHumanApproval: boolean
}

export interface HitlGate {
  id: string
  taskId: string
  stepId: string
  gateType: 'approval' | 'confirmation' | 'selection' | 'input'
  prompt: string
  options: string[]
  defaultValue: string | null
  status: 'pending' | 'approved' | 'denied' | 'skipped' | 'expired'
  resolvedBy: string | null
  resolvedAt: number | null
  response: string | null
  createdAt: number
  expiresAt: number | null
}

export class AutonomousExecutionEngine {
  constructor(store: AutonomousExecutionStore, registry: UnifiedCapabilityRegistry, policyEngine: ExecutionPolicyEngine, governor: ChromeGovernor, eventBus: CapabilityEventBus)
  async execute(goal: AutonomousGoal): Promise<AutonomousTask>
  async cancel(taskId: string): Promise<void>
  async getStatus(taskId: string): Promise<AutonomousTask | null>
  async resolveGate(gateId: string, response: string, resolvedBy: string): Promise<void>
  async getPendingGates(): Promise<HitlGate[]>
  async replay(taskId: string, fromStep?: string): Promise<AutonomousTask>
}
`

## Execution Flow
1. PLAN: decompose goal into steps (pattern-based + LLM)
2. For each step: classify, check policy, execute via registry or CDP
3. If requires approval: create HITL gate, pause
4. Record all results
5. FINALIZE: mark complete/failed

## Tests
- Navigate + screenshot completes without approval
- Destructive action triggers HITL gate
- resolveGate(approve) resumes execution
- resolveGate(deny) skips step
- Max steps limit prevents infinite loops
- Cancel stops execution
