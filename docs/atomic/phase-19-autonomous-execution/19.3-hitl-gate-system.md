# Unit 19.3: HITL Gate System

**Phase:** 19 | **File:** src/engines/autonomous-execution.ts (extends 19.1)
**Depends:** 19.1 AutonomousExecution | **Source:** upgrade-08-autonomous-execution.md

## Purpose
Human-in-the-loop approval gates for autonomous actions.

## Implementation
Part of AutonomousExecutionEngine. Creates HitlGate rows, waits for resolution via resolveGate().

## Gate Types
- approval: approve/deny/skip
- confirmation: yes/no
- selection: choose from options
- input: free text response

## Tests
- Gate created for write action
- resolveGate(approve) continues execution
- resolveGate(deny) skips step
- Gate expires after timeout
