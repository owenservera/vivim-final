# Unit 20.3: Export Engine

**Phase:** 20 | **File:** `src/engines/export.ts`
**Depends:** 20.1 EncryptionEngine | **Source:** upgrade-09-sovereign-data.md §ExportEngine

## Purpose
Full JSON/CSV export of all data, with optional encryption. Import from JSON backup.

## Interface
```typescript
export type ExportFormat = 'json' | 'csv'
export type ExportScope = 'full' | 'conversations' | 'memory' | 'providers' | 'config'

export interface ExportOptions {
  format: ExportFormat
  scope: ExportScope
  outputPath: string
  encryptWithPassphrase?: string
}

export interface ExportResult {
  filePath: string
  format: ExportFormat
  scope: ExportScope
  tablesExported: string[]
  totalRows: number
  fileSizeBytes: number
  durationMs: number
  encrypted: boolean
}

export class ExportEngine {
  constructor(db: CapStoreDb, encryption?: EncryptionEngine)
  async export(options: ExportOptions): Promise<ExportResult>
  async importFromJson(filePath: string): Promise<{ tablesImported: string[]; rowsImported: number }>
}
```

## Scope → Tables Mapping
- `conversations`: conversation, conversation_message, stream_block
- `memory`: episodic_memory, semantic_memory, procedural_rule, entity, entity_mention, decision_record, pattern_extract, memory_embedding
- `providers`: provider_definition, provider_endpoint, provider_parser, provider_capability, provider_config, provider_model, provider_account
- `config`: config_entry, config_audit
- `full`: all tables

## Tests
- JSON export produces valid JSON file
- CSV export produces one file per table
- Encrypted export → decrypt roundtrip
- Import restores data correctly
- Scope filtering exports correct tables
