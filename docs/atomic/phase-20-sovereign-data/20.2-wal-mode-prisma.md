# Unit 20.2: WAL Mode + Prisma Config

**Phase:** 20 | **File:** `src/storage/prisma.ts`
**Depends:** — | **Source:** upgrade-09-sovereign-data.md §WAL Mode

## Purpose
Configure SQLite WAL mode, busy_timeout, cache_size, and foreign_keys for better concurrent read performance and crash recovery.

## Changes
Add PRAGMA statements to Prisma client initialization in `src/storage/prisma.ts`:
```typescript
client.$executeRawUnsafe('PRAGMA journal_mode = WAL')
client.$executeRawUnsafe('PRAGMA synchronous = NORMAL')
client.$executeRawUnsafe('PRAGMA busy_timeout = 5000')
client.$executeRawUnsafe('PRAGMA cache_size = -64000') // 64MB
client.$executeRawUnsafe('PRAGMA foreign_keys = ON')
```

## Tests
- WAL mode enabled after client init
- busy_timeout set to 5000ms
- foreign_keys enforced
- Concurrent reads don't block
