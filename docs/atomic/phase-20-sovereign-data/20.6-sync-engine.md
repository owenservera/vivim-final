# Unit 20.6: SyncEngine

**Phase:** 20 | **File:** `src/engines/sync.ts`
**Depends:** 20.1 EncryptionEngine | **Source:** upgrade-09-sovereign-data.md §SyncEngine

## Purpose
E2E-encrypted multi-device sync. Pair devices via code, exchange keys, sync unsynced entries through a relay. All data encrypted with peer's public key before transmission.

## Interface
```typescript
export interface SyncConfig {
  enabled: boolean
  relayUrl: string
  deviceId: string
  syncIntervalMs: number
  conflictResolution: 'last_write_wins' | 'manual'
}

export interface SyncPeer {
  id: string
  deviceId: string
  name: string
  publicKey: string
  lastSyncAt: number | null
  status: 'paired' | 'pending' | 'revoked'
}

export interface SyncLogEntry {
  id: string
  deviceId: string
  table: string
  recordId: string
  operation: 'create' | 'update' | 'delete'
  dataJson: string
  ts: number
  syncedAt: number | null
}

export interface SyncStore {
  createLogEntry(entry: SyncLogEntry): Promise<void>
  getUnsyncedEntries(deviceId: string, limit?: number): Promise<SyncLogEntry[]>
  markSynced(ids: string[]): Promise<void>
  createPeer(peer: SyncPeer): Promise<void>
  updatePeer(id: string, patch: Partial<SyncPeer>): Promise<void>
  getPeers(): Promise<SyncPeer[]>
  getPeer(deviceId: string): Promise<SyncPeer | null>
}

export class SyncEngine {
  constructor(
    private store: SyncStore,
    private config: SyncConfig,
    private encryption: EncryptionEngine,
  )

  async pair(newDeviceId: string, name: string): Promise<{ pairingCode: string }>
  async confirmPair(deviceId: string, pairingCode: string): Promise<void>
  async sync(): Promise<{ entriesSynced: number; conflicts: number }>
  async getPendingSync(): Promise<number>
  async getPeers(): Promise<SyncPeer[]>
  async revokePeer(deviceId: string): Promise<void>
  start(): void
  stop(): void
}
```

## Execution Flow
### pair(deviceId, name)
1. Generate 6-digit pairing code
2. Create SyncPeer row with `status='pending'`
3. Return pairing code

### confirmPair(deviceId, code)
1. Verify pairing code matches
2. Update peer `status='paired'`, `pairedAt=now`

### sync()
1. Get all paired peers
2. For each peer: get unsynced entries (up to 100)
3. Encrypt each entry's `dataJson` with `encryption.encryptField()`
4. POST encrypted entries to `{relayUrl}/sync/{peerDeviceId}`
5. On success: mark entries as synced
6. Return `{ entriesSynced, conflicts }`

### Background sync
- `start()` runs `sync()` on interval (`config.syncIntervalMs`)
- `stop()` clears interval

## Tests
- pair creates pending peer with valid pairing code
- confirmPair activates peer
- sync encrypts entries before transmission
- sync sends unsynced entries to relay
- sync marks entries as synced after relay confirms
- revokePeer sets status='revoked', excludes from sync
- getPendingSync returns count of unsynced entries
- start/stop manages background interval
- Relay unreachable: sync returns 0, entries remain unsynced for retry
