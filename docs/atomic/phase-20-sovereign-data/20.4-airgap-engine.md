# Unit 20.4: AirGapEngine

**Phase:** 20 | **File:** `src/engines/airgap.ts`
**Depends:** — | **Source:** upgrade-09-sovereign-data.md §AirGapEngine

## Purpose
Offline mode with local model fallback. Detects network status, routes to local Ollama/llama.cpp when air-gap enabled.

## Interface
```typescript
export interface AirGapConfig {
  enabled: boolean
  localModelEndpoint: string
  localModelProvider: string
}

export interface AirGapStatus {
  isAirGapMode: boolean
  networkReachable: boolean
  localModelAvailable: boolean
  localModelName: string
  cachedResponses: number
}

export class AirGapEngine {
  constructor(config: AirGapConfig, eventBus?: CapabilityEventBus)
  async enable(): Promise<void>
  async disable(): Promise<void>
  async getStatus(): Promise<AirGapStatus>
  async checkNetwork(): Promise<boolean>
  async checkLocalModel(): Promise<boolean>
  async routeToLocalModel(message: string): Promise<{ ok: boolean; response: string; error?: string }>
}
```

## Tests
- enable/disable toggles mode
- checkNetwork returns boolean (DNS probe)
- checkLocalModel pings Ollama /api/tags
- routeToLocalModel sends to Ollama /api/generate
- disabled state returns error on routeToLocalModel
