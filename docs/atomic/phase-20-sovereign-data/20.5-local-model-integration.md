# Unit 20.5: Local Model Integration

**Phase:** 20 | **File:** `src/engines/local-model-adapter.ts`
**Depends:** 20.4 AirGapEngine | **Source:** upgrade-09-sovereign-data.md §AirGapEngine

## Purpose
Adapter for local LLM backends (Ollama, llama.cpp) that routes inference requests when air-gap mode is enabled or when local inference is preferred.

## Interface
```typescript
export type LocalModelProvider = 'ollama' | 'llamacpp' | 'none'

export interface LocalModelConfig {
  provider: LocalModelProvider
  endpoint: string       // e.g., http://localhost:11434
  model: string          // e.g., llama3, codellama
  timeoutMs: number
  maxTokens: number
  temperature: number
}

export interface LocalModelResponse {
  ok: boolean
  response: string
  model: string
  promptEvalCount: number
  evalCount: number
  durationMs: number
  error?: string
}

export class LocalModelAdapter {
  constructor(private config: LocalModelConfig)

  async isAvailable(): Promise<boolean>
  async generate(prompt: string): Promise<LocalModelResponse>
  async generateStream(prompt: string): AsyncGenerator<string>
  async listModels(): Promise<string[]>
  async ping(): Promise<{ ok: boolean; latencyMs: number }>
}
```

## Execution Flow
1. `isAvailable()` → GET `{endpoint}/api/tags` → check if model exists in response
2. `generate(prompt)` → POST `{endpoint}/api/generate` with `{ model, prompt, stream: false }`
3. `generateStream(prompt)` → POST with `stream: true`, yield lines from NDJSON response
4. `listModels()` → GET `{endpoint}/api/tags` → map to model name list
5. `ping()` → measure round-trip to `/api/tags`

## Store Contract
None — stateless adapter, config-only.

## Tests
- isAvailable returns true when Ollama is running
- isAvailable returns false when endpoint unreachable
- generate returns valid response with model attribution
- generateStream yields chunks incrementally
- listModels returns array of available model names
- Timeout produces error response, not exception
- Wrong endpoint produces graceful error
