# Unit 20.7: Telemetry Audit

**Phase:** 20 | **File:** `src/engines/telemetry-audit.ts`
**Depends:** — | **Source:** upgrade-09-sovereign-data.md §Telemetry Audit

## Purpose
Zero-cloud proof: record every outbound network call and generate audit reports. Proves that only user-configured AI provider endpoints are contacted — no telemetry, no analytics, no third-party tracking.

## Interface
```typescript
export interface NetworkCallRecord {
  id: string
  timestamp: number
  method: string
  url: string
  initiator: string     // engine or module that made the call
  responseStatus: number | null
  durationMs: number
  isToAiProvider: boolean
}

export interface AuditReport {
  generatedAt: number
  periodFrom: number
  periodTo: number
  totalOutboundCalls: number
  callsToAiProviders: number
  callsToOther: number
  nonProviderCalls: Array<{ url: string; count: number; initiator: string }>
  verdict: 'clean' | 'suspicious' | 'violating'
  details: string[]
}

export class TelemetryAudit {
  constructor(providerUrls: string[])

  recordCall(record: Omit<NetworkCallRecord, 'id'>): void
  generateReport(from: number, to: number): AuditReport
  getCalls(from?: number, to?: number): NetworkCallRecord[]
  clear(): void
}
```

## Execution Flow
### recordCall()
1. Generate ULID for call record
2. Auto-classify `isToAiProvider` by checking if URL contains any known provider URL
3. Store in memory array (persisted to DB in production)

### generateReport(from, to)
1. Filter calls within time range
2. Split into AI-provider calls vs other calls
3. Group non-provider calls by normalized URL + initiator
4. Determine verdict:
   - `clean`: zero non-provider calls
   - `suspicious`: 1-10 non-provider calls
   - `violating`: >10 non-provider calls
5. Build details list with URLs, counts, initiators

### Verdict Logic
```
if (callsToOther === 0) → 'clean'
if (callsToOther <= 10) → 'suspicious'
if (callsToOther > 10) → 'violating'
```

## Store Contract
None — in-memory ring buffer with optional persistence. For MVP, keep last 10,000 records in memory.

## Tests
- recordCall stores call with auto-classified provider flag
- generateReport returns clean verdict with zero non-provider calls
- generateReport returns suspicious with non-provider URLs listed
- generateReport returns violating with >10 non-provider calls
- URL normalization strips paths and query strings
- Time range filtering works correctly
- Empty period returns clean report with zero counts
- AI provider URL detection matches configured provider domains
