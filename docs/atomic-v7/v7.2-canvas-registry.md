# Unit v7.2 — CanvasRegistry: describe / register / get / list / update / delete

**Source:** vision §1.1, §3.1, §3.3 (P1)
**Design Doc:** v7 tracker §v7.2
**Depends on:** v7.1
**Produces:** `CanvasRegistry.{define,get,getBySlug,list,update,deprecate,delete}`.

---

## Context

The shell is re-programmable by design (P1): a layer is published, not
compiled. `CanvasRegistry` is the describe/register surface. There is no
build step between imagining a layer and running it — write the definition,
spawn the instance.

## Existing Baseline

- `src/engines/canvas-registry.ts` (v3 3.1) — single flat store; v7
  elevates it with the full `CanvasDefinition` shape, version-bump on update,
  inline-script rejection at definition time, and the closed primitive check.
- `src/canvas/schema.ts` — `validateDefinition` (Zod, strict, `.refine`
  for binding integrity + `assertNoInlineScript`).

## Interface — `src/canvas/canvas-registry.ts`

```typescript
export class CanvasRegistry {
  constructor(private store: CanvasStore) {}
  async define(input: Omit<CanvasDefinitionInput,'id'> & { id?: string }): Promise<CanvasDefinition>
  async get(id: string): Promise<CanvasDefinition | null>
  async getBySlug(slug: string): Promise<CanvasDefinition | null>
  async list(opts?: { category?; author?; status? }): Promise<CanvasDefinition[]>
  async update(id: string, patch: Partial<...>): Promise<CanvasDefinition>  // re-validates, bumps version
  async deprecate(id: string): Promise<CanvasDefinition>
  async delete(id: string): Promise<void>
  static sandbox(overrides?): SandboxPolicy   // least-privilege default
  static fromRow(row): CanvasDefinition
}
```

## Acceptance Criteria

1. `define` writes a row; `get`/`getBySlug`/`list` return it.
2. `define` rejects inline `<script>` in html/css (closed, P8).
3. `define` rejects a binding referencing BOTH a primitive and a capability.
4. `update` re-validates the whole merged definition and bumps `version`.
5. `deprecate` flips `status` without deleting; `delete` hard-removes.
6. `bun test tests/unit/canvas` passes.
