# Unit v7.10 — CanvasEngine orchestrator + core-layer seed

**Source:** vision §2 (P1–P9 summary), §3.2 (seed table)
**Design Doc:** v7 tracker §v7.10
**Depends on:** v7.1–v7.9
**Produces:** `CanvasEngine` (compiles all engines), `seedCoreLayers()`, barrel `src/canvas/index.ts`.

---

## Context

The orchestrator compiles the dumb shell (`LayerHost`), the registry,
the on-demand mounter, the sandboxed capability bridge, the live
mirror, the oracle reader, the closed primitive set, and the designer
into one engine. Future-proof and plugin-ready: every surface is a
contract, every layer is data, every op is a capability.

## Interface — `src/canvas/canvas-engine.ts`

```typescript
export interface CanvasEngineDeps {
  store: CanvasStore
  host: LayerHost
  executor: CapabilityExecutor
  oracle: OracleReadProvider
  primities?: PrimitiveProvider[]
  mirrorStore?: CanvasMirrorStore
}

export class CanvasEngine {
  readonly registry: CanvasRegistry
  readonly mounter: LayerMounter
  readonly mirror: CanvasMirror
  readonly bridge: SandboxBridge
  readonly oracle: OracleReader
  readonly primities: CorePrimitiveRegistry
  readonly designer: CanvasDesigner
  constructor(deps: CanvasEngineDeps) {}
  registerCapabilities(registry: UnifiedCapabilityRegistry): void  // → v7.9
  async seedCoreLayers(): Promise<CanvasDefinition[]>   // system/chat/designer seed
}
```

The barrel `src/canvas/index.ts` re-exports every public type + engine
and the `CanvasStore` contract + mappers.

## Seed (vision §3.2, closed core menu)

`seedCoreLayers()` defines `system` (oracle map), `chat`
(conversations primitive + `conversation_create` cap), and `designer`
(`canvas_define` cap) if absent. Each is data, sandboxed, composable.

## Acceptance Criteria

1. `new CanvasEngine(deps)` wires all sub-engines (no raw CDP import).
2. `seedCoreLayers()` seeds ≥3 core layers idempotently.
3. `registerCapabilities(fakeRegistry)` registers exactly 6 caps.
4. Barrel `src/canvas/index.ts` exports every engine + `CanvasStore`.
5. `bun test tests/unit/canvas` passes.
