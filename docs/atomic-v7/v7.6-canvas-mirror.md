# Unit v7.6 — CanvasMirror: bidirectional optimistic live mirror (P2 / SOTA-01)

**Source:** vision §5.2 (bidirectional live mirror)
**Design Doc:** v7 tracker §v7.6
**Depends on:** v7.1
**Produces:** `CanvasMirror`, `CanvasMirrorStore`, `InMemoryCanvasMirrorStore`, `OptimisticUpdate`.

---

## Context

Adopt the MirrorEngine pattern for layer ⇄ state sync: optimistic
updates, per-stage latency budgets, and a non-blocking observation
tap. A layer should feel instant (optimistic) while the real
state catches up. The user never waits to know their action registered.

## Interface — `src/canvas/canvas-mirror.ts`

```typescript
export interface CanvasMirrorStore {
  upsertRegionState(s: MirrorRegionState): Promise<void>
  getRegionState(instanceId: string, regionId: string): Promise<MirrorRegionState | null>
  listRegionStates(instanceId: string): Promise<MirrorRegionState[]>
}

export class CanvasMirror {
  constructor(store: CanvasMirrorStore) {}
  async pushOptimistic(instanceId, regionId, expectedState): Promise<OptimisticUpdate>
  async confirm(instanceId, regionId, actualState): Promise<void>
  async revert(instanceId, regionId, reason): Promise<void>
  getRegionState(instanceId, regionId): Promise<MirrorRegionState | null>
  listRegionStates(instanceId): Promise<MirrorRegionState[]>
  enforceBudget(stage: string, actualMs: number): MirrorBudget
}
```

Latency budgets (ms): `bind:5, capture:30000, store:10, emit:5, reconcile:200`.

## Acceptance Criteria

1. `pushOptimistic` records expected state with `confirmed:false`.
2. `confirm` sets `confirmedAt` (real state synced).
3. `revert` marks the region reverted (pending dropped).
4. `enforceBudget` reports `withinBudget` vs the per-stage budget.
5. `bun test tests/unit/canvas` passes.
