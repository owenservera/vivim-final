# Unit v7.5 — Sandboxed CapabilityBridge (postMessage, P8)

**Source:** vision §1.2, §3.3 (P8 sandboxed by default)
**Design Doc:** v7 tracker §v7.5
**Depends on:** v7.1
**Produces:** `SandboxBridge`, `SandboxPort`, `BridgeMessage` protocol.

---

## Context

Layer JS runs sandboxed in an iframe. It can ONLY talk to the host
through this bridge — never reaches into the host DOM, never opens its
own outbound channel. Every capability call is checked against the
layer's whitelist; every primitive read flows through `PrimitiveReader`.
This is how untrusted (agent-authored) layers stay safe. The canvas
never touches Chrome/CDP directly (P7) — mutation flows through the
`CapabilityExecutor` contract, which routes to the Governed authority.

## Interface — `src/canvas/capability-bridge.ts`

```typescript
export interface SandboxPort {
  postMessage(msg: BridgeMessage): void
  onMessage(cb: (msg: BridgeMessage) => void): void
  close(): void
}

export class SandboxBridge {
  constructor(store: CanvasStore, executor: CapabilityExecutor, reader: PrimitiveReader) {}
  attach(instanceId: string, port: SandboxPort): void
  detach(instanceId: string): void
  pushState(instanceId: string, regionId: string, state: unknown): void
  onLayerState?: (instanceId: string, regionId: string, state: unknown) => void
}
```

Protocol (`BridgeMessage`): `bridge:ready`, `bridge:capability:request/response`,
`bridge:observe:request/response`, `bridge:state:push`, `bridge:state:apply`,
`bridge:error`.

## Sandbox enforcement (P8)

- `canUseCapability(def, slug)` gates every `capability:request` — denied
  → `SandboxPermissionError` response, never executed.
- `assertNoInlineScript` rejects inline `<script>` at definition time AND the
  host rejects it at render time.
- `allowNetwork:false` by default → no raw fetch; all I/O goes through
  the bridge → `executor`/`reader` contracts.

## Acceptance Criteria

1. `attach` + `capability:request` for a whitelisted slug → `executor.execute` called, `ok:true` response.
2. `capability:request` for a non-whitelisted slug → `ok:false`, no execute.
3. `observe:request` → `reader.read(primitive, query)`.
4. `state:push` from a layer → `onLayerState` sink fired.
5. `bun test tests/unit/canvas` passes.
