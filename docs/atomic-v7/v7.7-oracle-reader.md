## Context

The `vivim-home` canvas is privileged. It sees and reaches everything —
every provider, every store, every engine's health, every open layer,
every project, the whole knowledge graph. It is the one surface that
renders the *whole system to itself*. Visibility is total; mutation still
flows through capability contracts and the Governor Canon (P7). Home
*sees* all and *routes* all, but it does not bypass the rules.

The canvas also carries a machine-readable **living manifest** of its
own regions so agents can navigate and mutate safely (P9).

## Interface — `src/canvas/oracle-reader.ts`

```typescript
export interface OracleReadProvider {
  visibility(): Promise<OracleVisibility>
}

export class OracleReader {
  constructor(sources: {
    visibility: OracleReadProvider
    listDefinitions(): Promise<CanvasDefinition[]>
    listInstances(opts?: { status? }): Promise<LayerInstance[]>
  }) {}
  async visibility(): Promise<OracleVisibility>
  async buildManifest(): Promise<CanvasManifest>   // P9 living manifest
  static regionIsWellFormed(region: RegionSpec): boolean
}
```

## Acceptance Criteria

1. `visibility()` fans out to the `OracleReadProvider` aggregate.
2. `buildManifest()` lists every definition's regions (from bindings),
   live instances, and current oracle visibility.
3. A `system`-category region is scoped `oracle`; others `scoped`.
4. `regionIsWellFormed` returns false for a region bound to an
   unknown primitive (closed-set integrity, P6).
5. `bun test tests/unit/canvas` passes.
