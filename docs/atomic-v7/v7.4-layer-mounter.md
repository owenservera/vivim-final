# Unit v7.4 — LayerMounter: spawn → mount → bind → live → dismiss (P3)

**Source:** vision §3.3 (P3, on-demand never all-at-once)
**Design Doc:** v7 tracker §v7.4
**Depends on:** v7.1, v7.2
**Produces:** `LayerMounter.{spawn,list,getInstance,markBindingActive,dismiss}`, `LayerHost` (dumb shell surface).

---

## Context

Layers are lazy by contract. A layer is fetched, mounted, and bound
only when requested; when dismissed it releases its DOM and its capability
bindings. The canvas can *describe* a thousand layers while
*instantiating* three. The shell is dumb (P2); the mounter only
coordinates instance records and asks `LayerHost` to mount/unmount.

## Interface — `src/canvas/layer-mounter.ts`

```typescript
export interface LayerHost {
  mount(instanceId: string, def: CanvasDefinition): Promise<{ hostNodeId: string }>
  unmount(instanceId: string): Promise<void>
  isMounted(instanceId: string): boolean
}

export class LayerMounter {
  constructor(store: CanvasStore, host: LayerHost, registry: { get(id): Promise<CanvasDefinition|null> })
  async spawn(definitionId: string, opts?: { spawnedBy?; hostNodeId? }): Promise<LayerInstance>
  async list(opts?: { status? }): Promise<LayerInstance[]>
  async getInstance(instanceId: string): Promise<LayerInstance | null>
  async markBindingActive(instanceId: string, regionId: string): Promise<void>
  async dismiss(instanceId: string): Promise<void>
  isMounted(instanceId: string): boolean
}
```

## Acceptance Criteria

1. `spawn` fetches the def, writes an `mounting` instance, asks the
   host to mount, flips to `live`.
2. `spawn` refuses a `deprecated` definition (`CanvasSpawnError`).
3. `dismiss` releases DOM (host.unmount) and sets `status='dismissed'`
   + `dismissedAt`; definition persists.
4. `markBindingActive` records the region id in `bindingsActiveJson`.
5. `bun test tests/unit/canvas` passes.
