## 1. Problem Statement

Research currently lives in two places with no coordination:
- `docs/research/` — 2 ad-hoc SOTA reports (event-bus, tooling)

Missing: index, lifecycle tracking, traceability to ADRs/goals, synthesis, retrieval.

## 4. New Invariants (Category A — Hard Blocks)

### A5: Deep Research for CREATE Units

**Rule:** Any unit classified as CREATE must have a corresponding research brief
in `docs/research/briefs/` before implementation begins.

**Enforcement:** `devops/invariants.ts` checks:
1. Unit classification = CREATE
2. `docs/research/briefs/<topic>-brief.md` exists
3. Brief has `confidence: High|Medium` (not Low)

**Check:**
```
If classification = CREATE:
  docs/research/briefs/<topic>-brief.md must exist
  Brief confidence must be High or Medium
```

### A6: ADR Research Evidence

**Rule:** No ADR may reach DECIDED status without a research brief attached.

**Enforcement:** `devops/invariants.ts` checks ADR markdown for `## Research`
section containing at least one brief link.

**Check:**
```
docs/decisions/ADR-NNN-title.md must contain:
  ## Research section with link to docs/research/briefs/
```

### A7: Research Freshness Gate

**Rule:** Research reports older than 6 months must be re-verified before
supporting new implementations.

**Enforcement:** `devops/invariants.ts` checks FRESHNESS.md for report age.

**Check:**
```
If report date > 6 months ago:
  Must have "Last Verified" date within 3 months
  OR must be in stale/ with replacement
```

## 6. Updated Workflow 1 Protocol

```
LOOP:
  1. sel = bun run devops select
  2. bun run devops mark <id> in_progress
     └─ INVARIANT A1/A5 CHECK: research exists? → FAIL if not

  3. Read unit's atomic file
     3a. Check docs/research/CROSS-REF.md for existing research
     3b. If research exists → read brief, use in implementation
     3c. If no research → check docs/research/gaps/
     3d. If gap exists → bun run devops research topic <gap-topic>
     3e. If no gap → create gap, run research, then proceed

  4. Fidelity cross-check (now includes research evidence)
     4a. Read research brief for this domain
     4b. Verify implementation aligns with research findings
     4c. Log any drift between research and implementation

  5. Implement
  6. bun run devops gate
     └─ NEW CHECK: research freshness in gate output
  7. bun run devops mark <id> done
  8. bun run devops goals progress
  9. Report progress
  10. bun run devops roadmap --discover
      └─ NEW: discovers research gaps too
```

## 7. Updated Workflow 2 Protocol

```
1. bun run devops decision create
2. NEW: bun run devops research for-adr <adr-id>
```

```markdown
**Source:** [full report](../reports/nl-command-translation-2026.md)
**Confidence:** High | **Sources:** 35+ | **Date:** 2026-07-12

## TL;DR
4-layer hybrid pipeline (rules → DistilBERT → local SLM → LLM) achieves ~95%
command coverage without cloud LLM. One new dependency: @xenova/transformers.

## Key Decisions
1. Rules first (70-80% coverage, <1ms, zero deps)
2. DistilBERT classifier for paraphrases (90-95%, <50ms, 250MB)
3. Local SLM fallback only when L0+L1 fail (opt-in)
4. All types use Zod validation

## Evidence Summary
- NL2Shell: 800M model, 12K training pairs, <200ms (High confidence)
- ScaleDown: SLM beats GPT-5.4 Nano at 200x lower cost (High confidence)
- Falconsai DistilBERT: 99.87% accuracy on intent classification (High confidence)

## Open Questions
- Classifier accuracy on vivim-specific commands (needs benchmarking)
- ONNX Runtime performance in Bun (needs profiling)

## Used In
- ADR-014 (Event Bus) — NL commands flow through typed event bus
- v5 2.1-2.3 IntentDecomposer — direct implementation target
```
