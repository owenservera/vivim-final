# 15.1 — OracleQueryEngine

**Phase:** 15 · **Domain:** Kernel Oracle · **Status:** DRAFT

## Purpose

Structured queries about system state. The oracle's "brain" — takes a question about the
system and returns an answer with confidence score and suggestions.

## Interface

```typescript
export interface SystemQuery {
  type: 'topology' | 'health' | 'trace' | 'provenance' | 'config' | 'capability' | 'all'
  filter?: Record<string, unknown>
  limit?: number
}

export interface QueryResult {
  query: SystemQuery
  answer: unknown
  confidence: number
  suggestions: string[]
  timestamp: number
}

export interface TopologyDescription {
  totalEngines: number
  totalStores: number
  totalCapabilities: number
  layers: Record<string, { engines: string[]; status: string }>
  dependencyGraph: Record<string, string[]>
  healthSummary: { healthy: number; degraded: number; unhealthy: number; unknown: number }
}

export interface HealthSnapshot {
  aggregateScore: number
  engines: Array<{ id: string; status: string; score?: number; lastCheck: number }>
  issues: DiagnosticIssue[]
  timestamp: number
}

export interface Explanation {
  target: string
  description: string
  causalChain: CausalNode[]
  relatedTraces: string[]
  suggestions: string[]
}

export class OracleQueryEngine {
  query(q: SystemQuery): Promise<QueryResult>
  describe(): Promise<TopologyDescription>
  health(): Promise<HealthSnapshot>
  explain(target: string): Promise<Explanation>
  capabilitySummary(): Promise<CapabilitySummary>
}
```

## Design

### Query Resolution

```typescript
async query(q: SystemQuery): Promise<QueryResult> {
  switch (q.type) {
    case 'topology':
      return { answer: await this.describe(), confidence: 1.0, ... }
    case 'health':
      return { answer: await this.health(), confidence: 0.95, ... }
    case 'trace':
      return { answer: await this.tracer.getTrace(q.filter.traceId), confidence: 1.0, ... }
    case 'provenance':
      return { answer: await this.provenance.getChain(q.filter.traceId), confidence: 1.0, ... }
    case 'config':
      return { answer: await this.config.readScoped(q.filter.engineId), confidence: 1.0, ... }
    case 'capability':
      return { answer: await this.capabilitySummary(), confidence: 0.9, ... }
  }
}
```

### Explain Logic

```typescript
async explain(target: string): Promise<Explanation> {
  // target can be: traceId, engineId, error message, etc.
  const chain = await this.provenance.getChain(target)
  const relatedTraces = chain.nodes.map(n => n.traceId).filter(unique)
  const suggestions = this.generateSuggestions(chain)
  return { target, description: this.describeChain(chain), causalChain: chain, relatedTraces, suggestions }
}
```

### Confidence Scoring

- `1.0`: Direct data query (topology, config, trace)
- `0.9-0.95`: Derived data (health aggregation, capability summary)
- `0.7-0.89`: Pattern-based (explain, suggestions)
- `<0.7`: Low confidence (requires manual verification)
