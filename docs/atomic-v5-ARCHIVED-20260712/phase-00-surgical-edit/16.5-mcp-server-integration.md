# 16.5 — MCP Server Kernel Integration

**Phase:** 16 · **Domain:** Kernel Surfaces · **Status:** DRAFT · **Effort:** S (4h)

## Purpose

Register kernel tools in the existing `DiscoveryMcpServer` at `src/mcp/server.ts`.
Adds `system.describe`, `system.health`, `system.diagnose`, `system.explain`,
`system.heal`, `system.config`, `system.trace` MCP tools.

## Problem Statement

The MCP server exists and registers tools, but has no kernel tools. Users interacting
via MCP clients (Claude Desktop, etc.) cannot query the system's self-model.

## Tools to Register

```typescript
// In src/mcp/server.ts — add kernel tools

server.tool('system.describe', 'Describe the system topology', {}, async () => {
  const topology = kernelContext.registry.describe()
  return { content: [{ type: 'text', text: JSON.stringify(topology, null, 2) }] }
})

server.tool('system.health', 'Get health status of all engines', {}, async () => {
  const engines = kernelContext.registry.listEngines()
  const health = engines.map(e => ({
    id: e.id,
    status: e.health?.status ?? 'unknown',
    score: e.health?.score,
  }))
  return { content: [{ type: 'text', text: JSON.stringify(health, null, 2) }] }
})

server.tool('system.diagnose', 'Diagnose system issues', {}, async () => {
  const diagnostics = await kernelContext.oracle.diagnose()
  return { content: [{ type: 'text', text: JSON.stringify(diagnostics, null, 2) }] }
})

server.tool('system.explain', 'Explain what an engine does', { engineId: 'string' }, async (params) => {
  const engine = kernelContext.registry.getEngine(params.engineId)
  if (!engine) return { content: [{ type: 'text', text: `Engine ${params.engineId} not found` }] }
  return { content: [{ type: 'text', text: JSON.stringify(engine, null, 2) }] }
})

server.tool('system.heal', 'Attempt to heal a degraded engine', { engineId: 'string' }, async (params) => {
  const result = await kernelContext.actuator.heal(params.engineId)
  return { content: [{ type: 'text', text: JSON.stringify(result, null, 2) }] }
})

server.tool('system.config', 'Get configuration for an engine', { engineId: 'string' }, async (params) => {
  const config = kernelContext.registry.getEngine(params.engineId)?.config ?? {}
  return { content: [{ type: 'text', text: JSON.stringify(config, null, 2) }] }
})

server.tool('system.trace', 'Get recent traces', { limit: 'number?' }, async (params) => {
  const traces = await kernelContext.tracer.queryRecent(params.limit ?? 10)
  return { content: [{ type: 'text', text: JSON.stringify(traces, null, 2) }] }
})
```
