# 16.6 — CLI Kernel Commands

**Phase:** 16 · **Domain:** Kernel Surfaces · **Status:** DRAFT · **Effort:** S (4h)

## Purpose

Add kernel subcommands to the existing CLI at `src/cli/`. Provides terminal-based
access to system self-understanding: `bun run kernel status/diagnose/trace/config/oracle`.

## Commands

```typescript
// src/cli/kernel.ts

import { Command } from 'commander'
import { createKernelContext } from '../engines/kernel/bootstrap.js'

const kernel = new Command('kernel')
  .description('Kernel self-understanding commands')

kernel
  .command('status')
  .description('Show system topology and health')
  .action(async () => {
    const ctx = await createKernelContext()
    const topology = ctx.registry.describe()
    console.log(JSON.stringify(topology, null, 2))
  })

kernel
  .command('diagnose')
  .description('Run system diagnostics')
  .action(async () => {
    const ctx = await createKernelContext()
    const diagnostics = await ctx.oracle.diagnose()
    console.log(JSON.stringify(diagnostics, null, 2))
  })

kernel
  .command('trace')
  .description('Show recent traces')
  .option('-l, --limit <n>', 'Number of traces', '10')
  .action(async (opts) => {
    const ctx = await createKernelContext()
    const traces = await ctx.tracer.queryRecent(parseInt(opts.limit))
    console.log(JSON.stringify(traces, null, 2))
  })

kernel
  .command('config')
  .description('Show engine configuration')
  .argument('<engineId>', 'Engine ID')
  .action(async (engineId) => {
    const ctx = await createKernelContext()
    const engine = ctx.registry.getEngine(engineId)
    if (!engine) {
      console.error(`Engine ${engineId} not found`)
      process.exit(1)
    }
    console.log(JSON.stringify(engine.config, null, 2))
  })

kernel
  .command('oracle')
  .description('Query the kernel oracle')
  .argument('<question>', 'Question to ask')
  .action(async (question) => {
    const ctx = await createKernelContext()
    const answer = await ctx.oracle.query(question)
    console.log(JSON.stringify(answer, null, 2))
  })

export default kernel
```
