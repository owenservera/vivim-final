# 0.4 — KernelProvenance

**Phase:** 0 · **Domain:** Kernel Core · **Status:** DRAFT

## Purpose

Causal chain recording — what caused what. Records the flow of data through the system:
selector reads DOM → parser extracts content → result stored. Enables "why did this happen?"
queries.

## Interface

```typescript
export interface CausalNode {
  id: string
  traceId: string
  parentId: string | null
  kind: 'selector' | 'parser' | 'result' | 'action' | 'error' | 'decision'
  engineId: string
  description: string
  input: unknown
  output: unknown
  duration?: number
  timestamp: number
}

export interface CausalChain {
  traceId: string
  nodes: CausalNode[]
  rootCause?: CausalNode       // first error in chain
  totalDuration: number
}

export class KernelProvenance {
  record(node: Omit<CausalNode, 'id' | 'timestamp'>): string
  getChain(traceId: string): CausalChain
  queryFailure(traceId: string): CausalChain
  queryByEngine(engineId: string, limit?: number): CausalNode[]
  queryByKind(kind: string, limit?: number): CausalNode[]
  queryRecent(limit?: number): CausalNode[]
}
```

## Design

### Recording Pattern

```typescript
// In a selector engine:
const nodeId = kernel.provenance.record({
  traceId,
  parentId: null,
  kind: 'selector',
  engineId: 'capability-resolution',
  description: 'resolved capability cap.chat.send for chatgpt',
  input: { capabilityId: 'cap.chat.send', providerId: 'chatgpt' },
  output: { selectorId: 'sel.chatgpt.send', confidence: 0.95 },
  duration: 12
})

// In a parser engine:
kernel.provenance.record({
  traceId,
  parentId: nodeId,
  kind: 'parser',
  engineId: 'stream-parser',
  description: 'parsed SSE stream into 3 ContentBlocks',
  input: { rawLength: 1024 },
  output: { blockCount: 3, types: ['text', 'text', 'source'] },
  duration: 45
})
```

### Failure Chain

```typescript
const chain = kernel.provenance.queryFailure(traceId)
// Returns ordered chain of nodes leading to the failure
// rootCause points to the first error node
```

## Store Contract

- `src/storage/contracts/kernel-store.ts`: `KernelStore`
  - `insertProvenanceNode(node)`: persist provenance node
  - `queryProvenanceByTrace(traceId)`: get all nodes for a trace
  - `queryProvenanceByEngine(engineId, limit)`: filter by engine
  - `queryProvenanceByKind(kind, limit)`: filter by kind
