# 0.2 — KernelContext

**Phase:** 0 · **Domain:** Kernel Core · **Status:** DRAFT

## Purpose

Unified context object passed to every engine constructor. Provides access to the kernel's
subsystems (registry, tracer, provenance, config, store, logger) through a single object.

## Interface

```typescript
export interface KernelContext {
  kernel: Kernel
  registry: KernelRegistry
  tracer: KernelTracer
  provenance: KernelProvenance
  eventBus: CapabilityEventBus
  config: ConfigManager
  store: KernelStore
  logger: KernelLogger
}

export interface Kernel {
  context(): KernelContext
  start(): Promise<void>
  stop(): Promise<void>
  snapshot(): TopologySnapshot
}

export class KernelLogger {
  info(msg: string, data?: Record<string, unknown>): void
  warn(msg: string, data?: Record<string, unknown>): void
  error(msg: string, data?: Record<string, unknown>): void
  debug(msg: string, data?: Record<string, unknown>): void

  child(prefix: string): KernelLogger

  // Structured fields
  withFields(fields: Record<string, unknown>): KernelLogger
}
```

## Design

### Constructor Pattern

```typescript
// Every engine constructor gains optional KernelContext:
class SomeEngine {
  constructor(deps: { /* existing deps */ }, kernel?: KernelContext) {
    if (kernel) {
      kernel.registry.registerEngine({
        id: 'some-engine',
        kind: 'engine',
        layer: 'some-layer',
        dependencies: [],
        status: 'registered',
        config: {},
      })
      this.tracer = kernel.tracer
      this.logger = kernel.logger.child('some-engine')
    }
  }
}
```

### Fallback for Legacy Engines

Engines that don't receive KernelContext are registered by the bootstrap with status
`registered` and a `legacy: true` metadata flag. They still appear in the topology
but without tracing or provenance.
