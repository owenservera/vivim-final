# Unit 3.1 — Engage Live Browser (engage.ts)

**Depends on:** 2.1, 1.2
**Produces:** `devops/runtime-test/engage.ts`
**Source:** `docs/atomic-runtime/RUNTIME-OS-DESIGN.md` §3.4

## Problem
The loop must open a real browser tab via the ChromeGovernor (Governor Canon — only Governor touches
CDP) so it can read the live UI and drive flows. Raw `Runtime.enable`/`evaluate` are eliminated by 1.2;
engage must use the mediated surface exclusively.

## Approach
- `engage.ts`: connect to Governor, `enableDomains(['Runtime','DOM','Page'])`, open target, return a
  `Session` handle with `evaluate(expr)`, `navigate(url)`, `screenshot()`, `findSelector()`.
- All CDP goes through `governor.evaluate` / `governor.enableDomains` (no raw send outside Governor).
- Expose `engage.open(url)` + `engage.close()`; integrate with supervisor lifecycle (2.1).

## Acceptance
- `engage.open('http://127.0.0.1:9420')` returns a session; `evaluate('1+1')` → 2.
- grep confirms no `Runtime.enable` outside `chrome-governor.ts` (guard from 1.2).
- `bunx tsc --noEmit` clean.

## Tests
- `tests/integration/runtime-test/engage.test.ts`: mocked Governor session.
