# Unit 6.2 — vivim-runtime SKILL.md (capstone) ✨

**Depends on:** 6.1
**Produces:** `.opencode/skill/vivim-runtime/SKILL.md`
**Source:** `docs/atomic-runtime/RUNTIME-OS-DESIGN.md` (whole)

## Problem
The runtime-OS must be a first-class agent skill so opencode/claude-code invoke it as `vivim-runtime`.
Without the SKILL.md, the loop is just a script, not an agent-capable dev runtime. This is the capstone
deliverable of atomic-v12.

## Approach
- Write `.opencode/skill/vivim-runtime/SKILL.md` documenting:
  - Purpose: agent becomes the runtime of its own dev loop (launch→engage→discover→test→debug→build→repeat).
  - Two modes: autonomous (`bun run devops runtime-test`) + human-in-the-middle.
  - Preconditions (Phase 1 done), commands (`bootstrap`, `preflight`, `engage`, `discover-*`, `test`,
    `ui-gate`, `debug`, `build`, `runtime` loop).
  - Invariants: Governor Canon, Store Contracts, FRONTEND=BACKEND (5.1), One Entry Point.
  - Failure playbook: read `DebugReport`, apply fix, re-run loop.
  - Acceptance gate: 6.5 end-to-end loop smoke.

## Acceptance
- Skill loads via the skill system; `vivim-runtime` is invocable.
- Skill content matches implemented commands (no phantom APIs).
- References the atomic-v12 tracker as the build ledger.

## Tests
- Manual: skill invoked, prints the loop plan; `bunx tsc --noEmit` unaffected.
