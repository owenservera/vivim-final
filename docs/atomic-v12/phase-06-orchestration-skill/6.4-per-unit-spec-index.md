# Unit 6.4 — Per-Unit Spec Index (R5.4)

**Depends on:** 6.2
**Produces:** `docs/atomic-runtime/SPEC-INDEX.md` (expanded), `docs/atomic-v12/PHASE-DEPENDENCIES.md`
**Source:** `docs/atomic-runtime/RUNTIME-OS-DESIGN.md` §3 (R5.4)

## Problem
`loadDeps` (deps.ts) needs every unit to have a spec file with `# Unit N.N` + `**Depends on:**`. The
SPEC-INDEX must list all runtime-OS units so the tracker and deps stay wired and human-navigable.

## Approach
- Ensure all 23 atomic-v12 spec files exist with correct `# Unit N.N` + `**Depends on:**` (done in
  phases 1-6 of this build).
- Expand `docs/atomic-runtime/SPEC-INDEX.md` to map R1-R5 (+ DISC) → spec file paths + dependency edges.
- Add `docs/atomic-v12/PHASE-DEPENDENCIES.md` summarizing phase gate order.

## Acceptance
- `bun run devops deps --tracker docs/atomic-v12/01-tracker.md` resolves all 23 units' deps without
  missing-file errors.
- SPEC-INDEX lists every runtime-OS unit with a valid path.

## Tests
- `node`-level: deps loader returns 23 entries; no `undefined` deps.
