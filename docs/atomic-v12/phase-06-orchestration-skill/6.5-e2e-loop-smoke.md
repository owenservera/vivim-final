# Unit 6.5 — End-to-End Loop Smoke (R5.5 acceptance) 🏁

**Depends on:** 6.1, 6.2, 6.3
**Produces:** `tests/e2e/runtime-os-loop.test.ts`
**Source:** `docs/atomic-runtime/RUNTIME-OS-DESIGN.md` §3 (R5.5)

## Problem
The whole skill needs one acceptance gate: a real end-to-end run of the loop against the live stack that
(1) discovers a known gap, (2) builds the fix, (3) re-tests green, with zero manual steps. If this passes,
atomic-v12 is complete.

## Approach
- `tests/e2e/runtime-os-loop.test.ts`: start supervisor (2.1), preflight (2.3), engage (3.1),
  discover (3.2/3.3), inject a controlled orphan ui cap (or missing handler), run `runtime` loop
  (6.1) in autonomous mode with `maxCycles`, assert the loop builds the fix and `test`+`ui-gate` go green.
- Use a short budget so the test is fast; tear down via `bootstrap.down`.
- This doubles as the demo for `vivim-runtime` SKILL.md.

## Acceptance
- E2E loop: discovers gap → builds fix → re-test green, fully automated.
- `bun test tests/e2e/runtime-os-loop.test.ts` passes.
- `bunx tsc --noEmit` clean.

## Tests
- The test itself is the acceptance gate.
