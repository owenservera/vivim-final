# Unit 2.2 — Dev PS1 Wrappers (scripts/dev-*.ps1)

**Depends on:** 2.1
**Produces:** `scripts/dev-backend.ps1`, `scripts/dev-frontend.ps1`, `scripts/dev-slave.ps1`
**Source:** `docs/atomic-runtime/RUNTIME-OS-DESIGN.md` §3.2

## Problem
Windows/pwsh dev needs consistent detached launchers (background jobs) so the agent can bring the
stack up/down without blocking. Today there is no canonical launcher and `bun` is a `.ps1` (not a
direct exe), so naive `Start-Process bun` fails.

## Approach
- `dev-backend.ps1`: `Start-Process` `bun.ps1 run serve` as a background job, writes pid file,
  polls `/api/health`.
- `dev-frontend.ps1`: launch the frontend dev server (if present) the same way.
- `dev-slave.ps1`: launch `bun run slave --cdp` detached.
- All accept `-Stop` to kill by pid file; return non-zero on launch failure.

## Acceptance
- `pwsh scripts/dev-backend.ps1` brings backend up; `-Stop` tears it down; no orphan processes.
- Combined with 2.1 supervisor, the stack comes up hands-free.

## Tests
- Manual smoke: `dev-backend.ps1` then curl health → 200.
