# 0.1 — StreamBlockStore type fix

**Phase:** 0 (Baseline Typecheck Green) · **Status:** done · **Depends on:** —
**Source:** Int→BigInt DB migration regression (DISC-baseline)

## Objective
Make `StreamBlockStore` compile under the post-migration schema where `BlockRow.createdAt`
is `bigint`.

## Context
`prisma/schema.prisma` casts `createdAt`/`updatedAt` timestamps to `BigInt`. The in-repo
`BlockRow` contract still typed `createdAt: number`, so `toRow` rejected the `bigint` source
and the public `StreamBlock` returned a `bigint` where callers expected `number`.

## Deliverable
`src/engines/stream-block-store.ts`:
- `toRow` param: `createdAt: number` → `createdAt: bigint`.
- return object: `createdAt: raw.createdAt` → `createdAt: Number(raw.createdAt)`.

## Acceptance
`bunx tsc --noEmit` no longer reports an error for `stream-block-store.ts`.
