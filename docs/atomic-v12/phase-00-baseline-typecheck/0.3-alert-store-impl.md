# 0.3 — alert-store-impl type fix

**Phase:** 0 (Baseline Typecheck Green) · **Status:** done · **Depends on:** —
**Source:** Int→BigInt DB migration regression (DISC-baseline)

## Objective
Align `AlertStore.toAlert` with the `bigint` `AlertRow.firedAt`.

## Context
`AlertRow.firedAt` is `bigint` post-migration. `toAlert` declared `firedAt: number` and
returned `createdAt: row.firedAt` (still bigint), both rejected by the compiler.

## Deliverable
`src/storage/impl/alert-store-impl.ts`:
- `toAlert` param: `firedAt: number` → `firedAt: bigint`.
- return object: `createdAt: row.firedAt` → `createdAt: Number(row.firedAt)`.

## Acceptance
`bunx tsc --noEmit` no longer reports an error for `alert-store-impl.ts`.
