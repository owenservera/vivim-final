# 0.2 — server/index.ts ts coercion

**Phase:** 0 (Baseline Typecheck Green) · **Status:** done · **Depends on:** —
**Source:** Int→BigInt DB migration regression (DISC-baseline)

## Objective
Coerce the `createdAt` bigint returned by `CapabilityEngine.list` before serializing the
SSE `ts` field.

## Context
`GET /api/capabilities` streams `ts: r.createdAt`. After the migration `r.createdAt` is
`bigint`; the SSE payload expected `number`, producing a TS2322 error at `src/server/index.ts`.

## Deliverable
`src/server/index.ts` (capabilities SSE map, ~line 405):
- `ts: r.createdAt` → `ts: Number(r.createdAt)`.

## Acceptance
`bunx tsc --noEmit` no longer reports an error at `src/server/index.ts` for this coercion.
