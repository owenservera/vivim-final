# Unit 1.1 — SQLite WAL / Hot-Restart Hardening (DISC-2)

**Depends on:** none
**Produces:** `src/storage/prisma.ts`, `src/storage/db.ts`, `src/server/index.ts`
**PRD:** `docs/roadmap/prds/PRD-DISC-2-sqlite-wal.md`

## Problem
`initPrismaWal` uses `$executeRawUnsafe` (returns rows → SQLite error) and competes with
`configurePrisma` for pragma authority. `gracefulShutdown` never closes the pool, leaking WAL files
and deadlocking supervisor hot-restart. The runtime-OS supervisor (2.1) cannot restart the backend
reliably until this is fixed.

## Approach
- Make `configurePrisma` the SOLE pragma authority (journal_mode=wal, busy_timeout=5000,
  foreign_keys=on, synchronous=NORMAL, cache_size=-64000).
- `initPrismaWal` delegates to `configurePrisma` (no raw execute).
- `configurePrisma` logs+warn on non-fatal pragma failure; throws only on journal_mode fail.
- `gracefulShutdown` awaits idempotent `closeDb()`.

## Acceptance
- `bun run serve` → `[db] pragmas configured — journal_mode=wal`, zero `prisma:error`.
- 2 consecutive shutdown+boot cycles succeed (supervisor hot-restart).
- `bunx tsc --noEmit` clean.

## Tests
- `tests/unit/storage/db.test.ts`: configurePrisma + closeDb idempotent.
- Manual supervisor restart loop (2.1) ×5 clean.
